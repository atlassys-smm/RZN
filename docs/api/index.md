## Группы эндпоинтов

| Группа | Описание |
|--------|----------|
| `auth` | Авторизация и аутентификация |
| `users` | Пользователи и профили |
| `professions` | Справочник профессий |
| `quiz` | Викторина |
| `profstart` | ПрофСтарт — тестирование |
| `analytics` | Аналитика и события |
| `cms` | CMS — управление контентом |
| `feedback` | Обратная связь и анкеты |
| `files` | Загрузка и управление файлами |
