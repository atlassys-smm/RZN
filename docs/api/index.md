|-------|-----|

## Группы эндпоинтов

| Модуль | Группы запросов и назначение |
|--------|--------------------------|
| Авторизация | Вход и сессии пользователя/сотрудника, QR-подключение устройства |
| Устройства | Регистрация, роли и токены |
| Пользователь | Профиль и рекомендации |
| Аватары | Аватары профессий и пользователей |
| Викторина | LED, CMS, оператор, игрок и состояние сессии |
| ПрофСтарт | [CMS и прохождение тестов](profstart.md) |
| Профессии в действии | LED, CMS, оператор, зритель и состояние показа |
| Обратная связь | LED, CMS и пользователь |
| Профессии | Каталог профессий, отраслей и направлений |
| Компетенции | Справочник компетенций |
| Организации | Учебные заведения и работодатели |
| Согласия | Тексты, версии и принятия |
| Файлы | Скачивание файлов |
| Аналитика | События |
| Справочники | Общие данные CMS |

## Файл спецификации

Полная спецификация — [openapi.yaml](openapi.yaml)


## Загрузка файлов

Файлы передаются непосредственно в multipart-запросе, ответы содержат универсальный
объект `file`. Поля формы и файлы вариантов по индексам
описаны в [контракте файлов](../entities/files.md#загрузка-и-ответ-api).
