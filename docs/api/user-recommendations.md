# API рекомендаций пользователя

GET `/api/users/me/recommendations` требует Bearer-токен и возвращает только профиль текущего пользователя. До первого завершённого теста ответ 200 содержит JSON null. Параметры user_id, исходные баллы и веса клиент не передаёт.

| Поле | Назначение |
|---|---|
| `id`, `user_id` | Профиль и его владелец |
| `created_at`, `updated_at` | Создание и последнее обновление профиля |
| `is_complete` | Получены все ожидаемые источники с положительным весом |
| `available_weight` | Сумма весов имеющихся источников с положительным весом |
| `weights` | Настройки source_code и weight, включая нулевые веса |
| `missing_sources` | Недостающие коды источников с положительным весом |
| `sources` | Использованные источники: id, source_code, source_reference, текущий weight и effective_weight_percent |
| `professions` | До трёх профессий: profession_id/name, score, position, contributions |

contributions содержит source_id, source_code, weight, effective_weight_percent, test_score, contribution и reasons каждого источника. reasons — снимок объяснений поставщика источника; ПрофСтарт сохраняет группы, нормированные показатели и коэффициенты. Десятичные поля этих вложенных объяснений могут быть строками. Нулевая оценка профессии в пройденном источнике не исключает его вес из знаменателя.

Профиль обновляется атомарно после последнего ответа нового типа и при изменении весов CMS. GET читает сохранённый рейтинг. Изменение связей профессий, подписей групп или названий не пересчитывает старые источники. ПрофСтарт сохраняет исходные веса 40/40/20 либо текущую настройку CMS; каждый тип можно завершить один раз, независимо от версии. Источник с весом 0 сохраняется, но не входит в sources текущей выдачи; его можно включить последующим изменением весов.

Порядок профессий: score DESC, profession_id ASC. Полный набор из трёх не гарантируется; возможен пустой массив professions при существующем профиле. Наличие всех источников может давать is_complete=true даже при пустом рейтинге. Ошибка авторизации — 401.

GET `/api/profstart/me/recommendations` сохраняет совместимый формат ПрофСтарта, читая тот же профиль. Исторический результат отдельного теста по-прежнему доступен через `/api/profstart/sessions/{id}/result` с массивом scores.
