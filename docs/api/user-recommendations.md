# API рекомендаций пользователя

GET `/api/users/me/recommendations` требует Bearer-токен и возвращает только профиль текущего пользователя. До первого сохранённого источника ответ 200 содержит JSON null. Параметры user_id, исходные баллы и веса клиент не передаёт. Итоговый рейтинг рассчитывается при каждом запросе из снимков источников и не сохраняется.

| Поле | Назначение |
|---|---|
| `id`, `user_id` | Профиль и его владелец |
| `created_at`, `updated_at` | Создание профиля и последнее добавление источника |
| `is_complete` | Получены все ожидаемые источники с положительным весом |
| `available_weight` | Сумма весов имеющихся источников с положительным весом |
| `weights` | Модуль source_module, код source_code и вес weight из кода |
| `missing_sources` | Недостающие источники с положительным весом: объекты source_module и source_code |
| `sources` | Использованные источники: id, source_module, source_code, source_reference, weight и effective_weight_percent |
| `professions` | До трёх профессий: profession_id/name, score, position, contributions |

contributions содержит source_id, source_module, source_code, weight, effective_weight_percent, test_score, contribution и reasons каждого источника. reasons — снимок объяснений поставщика источника; ПрофСтарт сохраняет группы и нормированные показатели. Десятичные поля этих вложенных объяснений могут быть строками. Нулевая оценка профессии в пройденном источнике не исключает его вес из знаменателя.

Источник определяется парой source_module и source_code: например, profstart и solomin. Одинаковые коды разных модулей независимы. Последний ответ любого типа атомарно добавляет источник с показателями групп и профессий. Источники дополнительных типов сохраняются наравне со встроенными, но без настройки в SOURCE_WEIGHTS не участвуют в итоговом рейтинге. Веса заданы в `app/models/user_recommendations/weights.py`: 40/40/20 для Соломина, Голланда и Деллингера; через CMS не меняются. Изменение весов в коде влияет на следующий GET. Изменение связей профессий, подписей групп или названий не пересчитывает старые источники. Каждый тип можно завершить один раз, независимо от версии. Источник с весом 0 сохраняется, но не входит в sources текущей выдачи.

Порядок профессий: score DESC, profession_id ASC. Полный набор из трёх не гарантируется; возможен пустой массив professions при существующем профиле. Наличие всех источников может давать is_complete=true даже при пустом рейтинге. Ошибка авторизации — 401.

Исторический результат отдельного теста доступен через `/api/profstart/sessions/{id}/result` с массивом scores.
