# Типы вопросов Анкеты

Системный справочник типов вопросов для конструктора анкет обратной связи. Значения заданы в коде и не хранятся в базе данных.

Используется при создании вопросов анкеты в CMS и при отображении вопросов в точках сбора обратной связи.

---

## Значения справочника

| Код | Название | Описание |
|-----|----------|----------|
| `rating_scale` | Шкала оценки | Числовая шкала (по умолчанию 1–5). Настраиваются `scale_min` и `scale_max` |
| `single_choice` | Одиночный выбор | Выбор одного варианта из списка |
| `multiple_choice` | Множественный выбор | Выбор нескольких вариантов из списка |
| `text` | Текстовый вопрос | Свободный текстовый ответ |
| `profession_choice` | Выбор профессии | Выбор профессии из справочника |

---

## Атрибуты вопроса

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | enum | Тип вопроса (см. таблицу выше) |
| `text` | text | Текст вопроса |
| `media_id` | UUID, nullable | Изображение к вопросу |
| `required` | boolean | Обязательный ли вопрос |
| `order` | integer | Порядок отображения |
| `scale_min` | integer, nullable | Минимальное значение шкалы (для `rating_scale`, по умолчанию 1) |
| `scale_max` | integer, nullable | Максимальное значение шкалы (для `rating_scale`, по умолчанию 5) |
| `condition` | json, nullable | Условие показа (например, `{"operator": "lte", "value": 2}`) |
| `parent_id` | UUID, nullable | ID родительского вопроса для условных вопросов |

---

## Где используется

- **[SurveyQuestion](../entities/survey.md)** — атрибут `type`
- **CMS** — создание вопросов для анкет
- **Обратная связь** — отображение вопросов в точках сбора
