# Возрастные группы ПрофСтарт

Таблица `age_groups` задаёт возрастную доступность версии теста. Возрастная группа передаётся числовым ID записи. Обе границы включительно; min_age и max_age nullable, null означает отсутствие соответствующей границы.

| Начальный ID | Название | min_age | max_age |
|---|---|---|---|
| 1 | 12–14 лет | 12 | 14 |
| 2 | 15–17 лет | 15 | 17 |

Фактические ID читаются из справочника и не выводятся из названия. Состав/возрастная применимость конкретной адаптации задаётся в CMS; исходные диапазоны не подтверждают пригодность каждой методики для этого возраста.

Клиент получает справочник через GET `/profstart/age-groups` (Bearer), CMS — через GET `/cms/profstart/age-groups`. Ответ содержит id, name, min_age, max_age; порядок id ASC.

ProfStartTest.age_group_ids — JSON-список допустимых ID из справочника; пустой массив означает отсутствие возрастного фильтра. Если список непустой, при старте обязательна подходящая age_group_id. TestSession.age_group_id имеет FK на `age_groups`; API результата возвращает его из сессии. Неизвестный ID в CMS, фильтре каталога или при старте — 422. Сервер не определяет возрастную группу автоматически по дате рождения.

Вопросы принадлежат версии и не имеют собственного age_group. Динамическая случайная сборка по возрасту не используется. Для каждого поддерживаемого типа доступны новые старты единственного теста со status=active; наибольший номер версии сам по себе не определяет доступность. Типы без алгоритма расчёта в пользовательский каталог не входят. Одновременный выбор разных возрастных версий требует отдельного расширения.
