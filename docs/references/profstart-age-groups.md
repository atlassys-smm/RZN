# Возрастные группы ПрофСтарт

Справочник возрастных групп для профориентационного теста. Каждая группа содержит свой банк вопросов.

!!! note "Настраиваемая сущность"
    Возрастные версии настраиваются через CMS. В таблице показаны текущие значения; `age_group` хранит числовой ID записи справочника, а не возрастной диапазон или строковый код.

---

## Значения справочника

| ID (int) | Название | Описание |
|----------------|----------|----------|
| 1 | 12–14 лет | Вопросы для школьников среднего возраста |
| 2 | 15–17 лет | Вопросы для старшеклассников |

В таблицах возрастная группа хранится как числовой ID; отображаемое название не передаётся вместо ID. ID могут отличаться при изменении набора возрастных версий.

---

## Где используется

- **[TestQuestion](../entities/test.md)** — атрибут `age_group` (маркировка вопроса)
- **[TestSession](../entities/test.md)** — атрибут `age_group` (выбранная группа при прохождении)
- **[TestResult](../entities/test.md)** — атрибут `age_group` (группа пройденного теста)
- **CMS** — фильтрация вопросов по возрастной группе, конструктор возрастных версий
- **ПрофСтарт** — пользователь выбирает возрастную группу на стартовом экране
- **Аналитика** — распределение прохождений по возрастным группам
