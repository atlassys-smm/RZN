# Возрастные группы ПрофСтарт

Справочник возрастных групп используется для настройки доступности версии теста, выбора пользователя и аналитических фильтров. Возрастная группа хранится числовым ID записи, а не строковым диапазоном.

| Пример ID | Название |
|---|---|
| 1 | 12–14 лет |
| 2 | 15–17 лет |

Фактические ID читаются из справочника и не выводятся из названия. Состав/возрастная применимость конкретной адаптации задаётся в CMS; исходные диапазоны не подтверждают пригодность каждой методики для этого возраста.

ProfStartTest.age_group_ids — список допустимых ID; пустой массив означает отсутствие возрастного фильтра. Если список непустой, при старте обязательна подходящая age_group_id. TestSession хранит выбранный ID, API результата возвращает его из сессии.

Вопросы принадлежат версии и не имеют собственного age_group. Динамическая случайная сборка по возрасту не используется. Для каждого поддерживаемого типа доступны новые старты единственного теста со status=active; наибольший номер версии сам по себе не определяет доступность. Типы без алгоритма расчёта в пользовательский каталог не входят. Одновременный выбор разных возрастных версий требует отдельного расширения.
