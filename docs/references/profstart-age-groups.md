# Возрастные группы ПрофСтарт

Таблица `age_groups` задаёт возрастную доступность версии теста. Возрастная группа передаётся числовым ID записи. Обе границы включительно; min_age и max_age nullable, null означает отсутствие соответствующей границы.

| Начальный ID | Название | min_age | max_age |
|---|---|---|---|
| 1 | 12–14 лет | 12 | 14 |
| 2 | 15–17 лет | 15 | 17 |

Фактические ID читаются из справочника и не выводятся из названия. Состав/возрастная применимость конкретной адаптации задаётся в CMS; исходные диапазоны не подтверждают пригодность каждой методики для этого возраста.

Клиент получает справочник через GET `/profstart/age-groups` (Bearer), CMS — через GET `/cms/profstart/age-groups`. Ответ содержит id, name, min_age, max_age; порядок id ASC.

ProfStartTest.age_group_ids — JSON-список ID из справочника для фильтрации каталога; пустой массив означает отсутствие возрастного фильтра. Клиент может передать age_group_id в GET /profstart/tests. При старте передаётся только test_id; возрастная группа не проверяется, не сохраняется в сессии и не возвращается в результате. Неизвестный ID в CMS или фильтре каталога — 422. Сервер не определяет возрастную группу автоматически по дате рождения.

Вопросы принадлежат версии и не имеют собственного age_group. Динамическая случайная сборка по возрасту не используется. Для каждого типа доступны новые старты единственного теста со status=active; наибольший номер версии сам по себе не определяет доступность. Каталог включает дополнительные типы, опубликованные в CMS. Одновременный выбор разных возрастных версий требует отдельного расширения.
