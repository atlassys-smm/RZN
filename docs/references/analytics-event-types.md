# Типы событий Аналитики

Системный справочник типов событий, собираемых со всех подсистем и внешних ПАК. Значения передаются в поле `payload` события [AnalyticsEvent](../entities/analytics.md).

---

## Общие события

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `session_started` | Начало сессии на терминале | Все |
| `session_completed` | Завершение сессии на терминале | Все |

## События викторины и командной игры

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `quiz_answer` | Ответ на вопрос викторины | `led_platform` |
| `team_game_round_started` | Начало раунда командной игры | `led_platform` |
| `team_game_answer` | Ответ команды в раунде | `led_platform` |

## События ПрофСтарт

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `test_started` | Начало прохождения теста | `profstart` |
| `test_completed` | Завершение теста с результатом | `profstart` |
| `test_answer` | Ответ на вопрос теста | `profstart` |

## События взаимодействия с контентом

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `profession_viewed` | Просмотр карточки профессии | `led_platform`, профиль |
| `profession_selected` | Пользователь выбрал профессию | Все |
| `profession_recommended` | Система рекомендовала профессию | `tree_of_professions`, `profstart` |
| `career_route_generated` | Формирование рекомендаций по профессиям, учебным заведениям и работодателям | Профиль |
| `employer_viewed` | Просмотр информации о работодателе | `regional_map` |
| `educational_institution_viewed` | Просмотр учебного заведения | `regional_map` |

## События Аватар профессий

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `avatar_generated` | Генерация фото в образе профессии | `profession_avatar` |
| `avatar_viewed` | Просмотр аватара | `profession_avatar` |
| `avatar_shared` | Поделиться аватаром (по QR) | `profession_avatar` |

## События обратной связи

| Тип события | Описание | Источники |
|-------------|----------|-----------|
| `survey_submitted` | Отправка анкеты обратной связи | `feedback` |

---

## Структура payload

Каждое событие содержит дополнительные данные в поле `payload`:

| Поле | Тип | Описание |
|------|-----|----------|
| `action_type` | enum | Тип действия: `user_action` (действие пользователя) или `system_action` (действие системы) |
| `entity_type` | string | Тип сущности: `profession`, `industry`, `direction`, `employer`, `educational_institution`, `question`, `survey` |
| `entity_id` | UUID | ID сущности |
| `result` | string | Результат: `correct`, `incorrect`, `completed`, `viewed`, `selected`, `recommended` |
| `duration` | integer | Длительность в миллисекундах |
| `content_version` | string | Версия контента |

---

## Где используется

- **[AnalyticsEvent](../entities/analytics.md)** — события от всех подсистем
- **Аналитика** — приём, агрегация, дашборды
- **Цифровой профиль** — формирование рекомендательной модели
