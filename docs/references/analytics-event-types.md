# Типы событий аналитики

В `event_id` передаётся числовой код `EventType(IntEnum)`; UUID конкретного факта
находится в поле `id`. Параметры действия — в `payload` события
[AnalyticsEvent](../entities/analytics.md). Перечисления определены в
`app/services/analytics/enums.py`.

## Действия

| event_id | EventType | Описание |
|---|---|---|
| 1 | SESSION_STARTED | Фактический переход в активную сессию |
| 2 | PARTICIPANT_JOINED | Новый зарегистрированный участник |
| 3 | ANSWER_EVALUATED | Правильность оценённого ответа участника или команды |
| 4 | SESSION_FINISHED | Завершение игры или теста, причина и длительность; в индивидуальной викторине — results[] с итоговыми личными total_score |
| 5 | PROFESSION_RECOMMENDED | Одна рекомендованная профессия в результате теста ПрофСтарт |
| 6 | ANSWER_SUBMITTED | Личный принятый ответ командной викторины без содержимого; вариант ПрофСтарт и время ответа; в обратной связи — итоговая числовая оценка rating_scale |
| 7 | SURVEY_STARTED | Реальное начало заполнения анкеты |
| 8 | SURVEY_FINISHED | Сохранение готовой анкеты и длительность |
| 9 | SESSION_ABANDONED | Явное прерывание прохождения ПрофСтарт пользователем или оператором |
| 10 | ORGANIZATION_VIEWED | Успешное чтение организации по ID с JWT пользователя, включая гостя |
| 11 | PROFESSION_VIEWED | Успешное чтение профессии по ID с JWT пользователя, снимок industry_id |
| 12 | EDUCATION_PROGRAM_VIEWED | Успешное чтение направления образования по ID с JWT пользователя |
| 13 | AVATAR_GENERATION_FAILED | Задание генерации Аватара завершено ошибкой |
| 14 | AVATAR_GENERATION_EXPIRED | Истёк срок задания или результата FaceAI |
| 15 | AVATAR_UPLOADED | Отдельная загрузка готового изображения, без задания FaceAI |

## Модули

| module_id | ModuleType | Модуль |
|---|---|---|
| 1 | QUIZ_IND | Индивидуальная викторина |
| 2 | QUIZ_TEAM | Командная викторина |
| 3 | VIDEO_SCENARIO | Профессии в действии |
| 4 | PROFSTART | ПрофСтарт |
| 5 | FEEDBACK | Обратная связь |
| 6 | PROFESSION_AVATAR | Аватар профессий |
| 7 | TREE_OF_PROFESSIONS | Древо профессий |
| 8 | REGIONAL_MAP | Интерактивная карта региона |
| 9 | PROFBATTLE | Профбаттл |
| 10 | VIDEO_WINDOWS | Видео-окна |
| 11 | VIDEO_RESUME | Видео-резюме |
| 12 | SCREENSAVER | Заставка |
| 13 | ORGANIZATIONS | Организации |
| 14 | PROFESSIONS | Профессии |
| 15 | EDUCATION_PROGRAMS | Направления образования |

Коды 0 не используются; опубликованные значения не перенумеровываются.
Сейчас QUIZ_IND и QUIZ_TEAM (`module_id=1` и `module_id=2`) отправляют
действия 1–4; QUIZ_TEAM также отправляет личный принятый ответ 6.
ПрофСтарт (`module_id=4`) отправляет старт 1, принятый ответ 6, завершение 4,
явное прерывание 9 и рекомендации 5. Все факты создаются после commit;
[контракт ПрофСтарт](../subsystems/analytics/dashboards/pak-detail/profstart.md#события).
Обратная связь (`module_id=5`) отправляет действия 7, 8 и 6.
Организации (`module_id=13`) отправляют действие 10 через `GET /api/organizations/{id}`
только для пользовательского JWT. Сотрудники и устройства не создают просмотров.
Профессии (`module_id=14`) отправляют действие 11, направления образования
(`module_id=15`) — действие 12. Отрасли считаются по просмотрам профессий через
industry_id; отдельного события просмотра отрасли нет.
Аватар профессий (`module_id=6`) отправляет старт 1, успешное сохранение 4,
ошибку 13, истечение срока 14 и отдельную загрузку 15, только после commit.
[Контракт и расчёты Аватара](../subsystems/analytics/dashboards/pak-detail/profession-avatars.md).
Остальные модули ещё не отправляют события. Новые действия добавляются
при подключении источника. Тип оборудования в событие не передаётся.
Payload и правила подсчёта — в [AnalyticsEvent](../entities/analytics.md).
