# Типы вопросов викторины

Справочник типов вопросов для индивидуальной викторины и командной игры.

---

## Значения справочника

| Значение (int) | Тип | Описание |
|----------------|-----|----------|
| 1 | `single_choice` | Выбор одного варианта; формат `single` |
| 2 | `multiple_choice` | Выбор нескольких вариантов; формат `multiple` |
| 3 | `yes_no` | Да / нет; формат `single` |
| 4 | `image_choice` | Выбор по изображению; формат `single` |
| 5 | `matching` | Сопоставление; формат `matching` |
| 6 | `sorting` | Упорядочивание; формат `sorting` |
| 7 | `profession_by_description` | Сопоставление профессий с описаниями задач; формат `matching` |
| 8 | `recognize_by_image` | Распознавание профессии по изображению; файл прикладывается к вопросу; формат `single` |
| 9 | `recognize_by_video` | Распознавание профессии по видео; файл прикладывается к вопросу; формат `single` |
| 10 | `sequence` | Восстановление последовательности этапов; формат `sorting` |
| 11 | `case_study` | Ситуационный кейс; формат `single` |
| 12 | `role_distribution` | Сопоставление ролей в команде; формат `matching` |
| 13 | `resource_selection` | Выбор набора ресурсов и специалистов; формат `multiple` |
| 14 | `error_finding` | Поиск ошибки в рабочей ситуации; формат `single` |
| 15 | `prediction` | Прогноз развития технологии; формат `single` |
| 16 | `argumentation` | Аргументация и консенсус; формат `single` |
| 17 | `media_round` | Медиараунд с видеофрагментом; файл прикладывается к вопросу; формат `single` |
| 18 | `final_case` | Финальный комплексный кейс; формат `single` |

---

## Где используется

- **[GameQuestion](../entities/quiz.md)** — атрибут `type`
- **CMS** — создание вопросов, фильтрация по типу
- **LED-медиаплатформа** — отображение вопроса в соответствующем формате

Формат ответа задаётся группой типа: single — `option_id`, multiple — `option_ids`,
matching — `pairs`, sorting — упорядоченный `option_ids`. Типов со свободным
текстовым ответом сейчас нет. Поля `text` вопроса и вариантов сохраняются;
`answer.text` можно передавать как дополнительное пояснение, оно не участвует в проверке.
