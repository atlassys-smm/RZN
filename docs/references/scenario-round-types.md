# Типы сценарных раундов

Системный справочник типов раундов для командной игры. Значения заданы в коде и не хранятся в базе данных.

Используется для классификации вопросов ([GameQuestion.round_type_id](../entities/quiz.md)) и настройки оператором при запуске командной игры ([GameSession.settings](../entities/game-session.md)).

---

## Значения справочника

Согласно ТЗ (раздел 3.2.2 "Сценарные раунды"), оператор выбирает от 3 до 8 типов раундов для сессии.

| Значение (int) | Тип | Название | Описание | Множитель баллов |
|----------------|-----|----------|----------|------------------|
| 1 | `quick_start` | Быстрый старт | Короткие вопросы на узнавание профессий | 1.0 |
| 2 | `tools` | Инструменты специалиста | Определение назначения инструментов | 1.0 |
| 3 | `skills` | Навыки и компетенции | Сопоставление задач с навыками | 1.0 |
| 4 | `situation` | Рабочая ситуация | Коллективное решение кейса | 1.0 |
| 5 | `team_building` | Собери команду | Выбор профессиональных ролей | 1.0 |
| 6 | `process` | Построй процесс | Восстановление последовательности | 1.0 |
| 7 | `future` | Профессии будущего | Задания о технологиях и трансформации | 1.0 |
| 8 | `regional` | Региональный выбор | Вопросы о профессиях региона | 1.0 |
| 9 | `final` | Финальный вызов | Комплексное задание с повышенным весом | 1.5 |


---

## Атрибуты (в коде)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer | Числовое значение типа раунда из таблицы выше |
| `name` | string | Название типа раунда |
| `description` | text | Описание типа раунда |
| `order` | integer | Порядок отображения |
| `points_multiplier` | decimal | Множитель баллов для этого типа раунда |

---

## Где используется

- **GameQuestion** — вопросы классифицируются по типу раунда (`round_type_id`)
- **GameSession** — оператор выбирает типы раундов при запуске сессии
- **CMS** — контент-менеджер указывает тип раунда при создании вопроса
- **LED-медиаплатформа** — тип раунда задаётся числовым ID; способы передачи и автоматического выбора вопросов описаны в [игровой сессии](../entities/game-session.md#gamesession)
