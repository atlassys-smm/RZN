# Типы сценарных раундов

Системный справочник типов раундов для командной игры. Значения заданы в коде и не хранятся в базе данных.

Используется для классификации вопросов ([GameQuestion.round_type_id](../entities/quiz.md)) и настройки оператором при запуске командной игры ([GameSession.settings](../entities/game-session.md)).

---

## Значения справочника

Согласно ТЗ (раздел 3.2.2 "Сценарные раунды"), оператор выбирает от 3 до 8 типов раундов для сессии.

| Код | Название | Описание | Множитель баллов |
|-----|----------|----------|------------------|
| `quick_start` | Быстрый старт | Короткие вопросы на узнавание профессий | 1.0 |
| `tools` | Инструменты специалиста | Определение назначения инструментов | 1.0 |
| `skills` | Навыки и компетенции | Сопоставление задач с навыками | 1.0 |
| `situation` | Рабочая ситуация | Коллективное решение кейса | 1.0 |
| `team_building` | Собери команду | Выбор профессиональных ролей | 1.0 |
| `process` | Построй процесс | Восстановление последовательности | 1.0 |
| `future` | Профессии будущего | Задания о технологиях и трансформации | 1.0 |
| `regional` | Региональный выбор | Вопросы о профессиях региона | 1.0 |
| `final` | Финальный вызов | Комплексное задание с повышенным весом | 1.5 |

---

## Атрибуты (в коде)

| Поле | Тип | Описание |
|------|-----|----------|
| `code` | string | Уникальный код типа раунда |
| `name` | string | Название типа раунда |
| `description` | text | Описание типа раунда |
| `order` | integer | Порядок отображения |
| `points_multiplier` | decimal | Множитель баллов для этого типа раунда |

---

## Где используется

- **GameQuestion** — вопросы классифицируются по типу раунда (`round_type_id`)
- **GameSession** — оператор выбирает типы раундов при запуске сессии
- **CMS** — контент-менеджер указывает тип раунда при создании вопроса
- **LED-медиаплатформа** — система подбирает вопросы по выбранным типам раундов
