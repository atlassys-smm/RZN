# Сложность вопросов викторины

Справочник уровней сложности для вопросов викторины.

---

## Значения справочника

| Значение (int) | Уровень | Описание |
|----------------|---------|----------|
| 1 | Лёгкий (`easy`) | Базовые вопросы, не требующие глубоких знаний |
| 2 | Средний (`medium`) | Вопросы, требующие понимания темы |
| 3 | Сложный (`hard`) | Вопросы для продвинутых участников |

---

## Где используется

- **[GameQuestion](../entities/quiz.md)** — атрибут `difficulty`
- **CMS** — создание вопросов, фильтрация по сложности
- **LED-медиаплатформа** — подбор вопросов для раундов разной сложности
