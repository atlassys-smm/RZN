# Режимы игровой сессии

Системный справочник режимов проведения игровой сессии на LED-платформе. Значения заданы в коде и не хранятся в базе данных.

Используется при запуске игровой сессии оператором и определяет формат проведения.

---

## Значения справочника

### `1` — Индивидуальная викторина (`individual`)

Все участники отвечают персонально. Вопросы передаются по `question_ids` либо подбираются по количеству и фильтрам.

| Характеристика | Значение |
|----------------|----------|
| Команды | Не создаются |
| `GameSessionParticipant.team_id` | `null` |
| Рейтинг | По `individual_score` каждого участника |
| Шаблон сценария | Оператор выбирает шаблон или настраивает раунды вручную |

### `2` — Командная игра (`team`)

Профориентационная игра с формированием команд, раундами заданий, обсуждениями и рейтингом.

| Характеристика | Значение |
|----------------|----------|
| Команды | От 2 до 8 команд, не более 10 человек в каждой |
| `GameSessionTeam` | Создаётся для каждой команды |
| Рейтинг | По `GameSessionTeam.score` (баллы команд) |
| Шаблон сценария | Оператор выбирает [шаблон сценария](../entities/scenario-template.md) или собирает раунды вручную |
| Типы раундов | От 3 до 8 типов из [справочника](scenario-round-types.md) |
| капитан | Первый подключившийся к команде; может передать роль другому участнику; при отключении капитана система назначает случайного; оператор может сменить капитана |

---

## Атрибут

| Поле | Тип | Описание |
|------|-----|----------|
| `mode` | enum | Режим сессии: `individual` или `team` |

---

## Где используется

- **[GameSession](../entities/game-session.md)** — атрибут `mode`
- **LED-медиаплатформа** — проведение сессий
- **Оператор** — выбор режима при запуске сессии
