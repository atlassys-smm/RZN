# Статусы сессии ПрофСтарт

| Код | Название | Переход |
|---|---|---|
| `in_progress` | В процессе | Создание сессии |
| `completed` | Завершена | /complete после всех ответов, результат сохранён атомарно |
| `abandoned` | Прервана | /abandon до завершения, итогового результата нет |

completed и abandoned — окончательные. Повтор соответствующей операции идемпотентен. Последний /answer сам по себе не переводит сессию в completed. Обрыв сети не равен abandoned: после восстановления продолжается та же сессия. Автоматический серверный таймаут пока не входит в контракт.
