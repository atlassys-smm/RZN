# Статусы сессии ПрофСтарт

Системный справочник статусов сессии прохождения профориентационного теста. Значения заданы в коде и не хранятся в базе данных.

Используется для отслеживания состояния сессии теста в ПрофСтарт и при просмотре сессий в CMS.

---

## Значения справочника

| Код | Название | Описание |
|-----|----------|----------|
| `in_progress` | В процессе | Тест начат, пользователь отвечает на вопросы |
| `completed` | Завершён | Все вопросы пройдены, результат сформирован |
| `abandoned` | Прерван | Пользователь покинул тест до завершения |

---

## Где используется

- **[TestSession](../entities/test.md)** — атрибут `status`
- **CMS** — фильтрация и отображение сессий ПрофСтарт
- **Аналитика** — расчёт процента завершённых тестов
