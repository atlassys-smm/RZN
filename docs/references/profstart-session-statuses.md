# Статусы сессии ПрофСтарт

| Код | Название | Переход |
|---|---|---|
| `1` (`in_progress`) | В процессе | Создание сессии |
| `2` (`completed`) | Завершена | /answer после последнего вопроса, ответ и результат сохранены атомарно |
| `3` (`abandoned`) | Прервана | /abandon до завершения, итогового результата нет |

completed и abandoned — окончательные. Последний /answer автоматически переводит сессию в completed и сохраняет результат. Повтор принятого ответа не меняет сохранённый результат; повтор /abandon оставляет прежний статус. Результат читается через GET /sessions/{id}/result. Обрыв сети не равен abandoned: после восстановления продолжается та же сессия. Автоматический серверный таймаут пока не входит в контракт.
