# Источники событий аналитики

Системный справочник источников событий аналитики. Источник события характеризуется параметрами:

- **`device_type`** — числовой тип оборудования из `DeviceType(IntEnum)`
- **`software_id`** — числовой код программного комплекса из `SoftwareType(IntEnum)`
- **`module_id`** — числовой код функционального модуля из `ModuleType(IntEnum)`

Значения передаются в событии [AnalyticsEvent](../entities/analytics.md). Enum определены
в `app/services/analytics/enums.py`; коды модулей описаны в [типах событий](analytics-event-types.md).
`device_id` обозначает конкретное устройство, а не его тип.
В отправителе `device_type` и `device_id` равны NULL, если не переданы.
Тип оборудования автоматически пока не определяется; в коде оставлен TODO.

## Где используется

- **[AnalyticsEvent](../entities/analytics.md)** — атрибуты `device_type` и `software_id`
- **Аналитика** — фильтрация и группировка событий по оборудованию и ПО
- **Дашборды** — отчёты по каждому источнику и консолидированные
