# Источники событий аналитики

Источник события определяется функциональным модулем `module_id` из
`ModuleType(IntEnum)`. Конкретное оборудование, если известно, обозначается
`device_id`; при отсутствии данных он равен NULL. Одно устройство может
обслуживать несколько модулей. Тип оборудования и программный комплекс
в событиях не хранятся.

Значения передаются в [AnalyticsEvent](../entities/analytics.md).
Enum определён в `app/services/analytics/enums.py`; действия и коды модулей —
в [типах событий](analytics-event-types.md).

| module_id | Модуль | События подключены |
|---|---|---|
| 1 | Индивидуальная викторина | Да |
| 2 | Командная викторина | Да |
| 3 | Профессии в действии | Нет |
| 4 | ПрофСтарт | Да |
| 5 | Обратная связь | Да |
| 6 | Аватар профессий | Нет |
| 7 | Древо профессий | Нет |
| 8 | Интерактивная карта региона | Нет |
| 9 | Профбаттл | Нет |
| 10 | Видео-окна | Нет |
| 11 | Видео-резюме | Нет |
| 12 | Заставка | Нет |
| 13 | Организации | Да, просмотр по ID с пользовательским JWT |
| 14 | Профессии | Да, просмотр по ID с пользовательским JWT |
| 15 | Направления образования | Да, просмотр по ID с пользовательским JWT |

Фильтры и сравнения используют эти коды напрямую. Индивидуальная и командная
викторины — отдельные категории. Сессия определяется парой
`(module_id, session_id)`, повтор события — `(module_id, id)`.
Названия в сводных отчётах задаёт `analytics.module_sessions`; для неизвестного
кода используется `Модуль #<код>`. Неподключённый модуль не получает фиктивных данных.
