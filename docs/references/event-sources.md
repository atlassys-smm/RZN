# Источники событий аналитики

Системный справочник источников событий аналитики. Значения передаются в поле `source` события [AnalyticsEvent](../entities/analytics.md).

---

## Собственные источники

| Код | Название | Описание |
|-----|----------|----------|
| `led_platform` | LED-медиаплатформа | Собственное ПО LED-платформы: сценарии, викторины, командная игра, просмотр профессий |
| `profstart` | ПрофСтарт | Модуль профориентационного теста (терминал и веб-версия) |
| `feedback` | Обратная связь | Модуль анкет обратной связи |

## Внешние ПАК

| Код | Название | Описание |
|-----|----------|----------|
| `profession_avatar` | Аватар профессий | ПАК генерации фото в образах профессий |
| `tree_of_professions` | Древо профессий | ПАК интерактивного дерева профессий |
| `regional_map` | Интерактивная карта региона | ПАК карты региона с работодателями и учебными заведениями |
| `profbattle` | Профбаттл | ПАК профессиональных баттлов |

---

## Принципы интеграции внешних ПАК

- Отдельный адаптер для каждого внешнего ПАК
- Приоритет: локальный REST API, HTTP API, WebSocket
- При отсутствии API: агент-коллектор, экспортные файлы JSON/CSV, TCP/UDP
- Неблокирующая интеграция — отказ внешнего ПАК не влияет на работу системы
- Минимальные необходимые права учётных данных

---

## Где используется

- **[AnalyticsEvent](../entities/analytics.md)** — атрибут `source`
- **Аналитика** — фильтрация и группировка событий по источникам
- **Дашборды** — отдельные отчёты по каждому источнику и консолидированные
