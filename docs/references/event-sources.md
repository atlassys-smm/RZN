# Источники событий аналитики

Системный справочник источников событий аналитики. Каждое событие характеризуется двумя параметрами:

- **`device_type`** — идентификатор типа физического оборудования
- **`software_id`** — идентификатор программного комплекса, отправляющего аналитику

Значения передаются в событии [AnalyticsEvent](../entities/analytics.md).

---

## Типы оборудования

| Код | Название | Описание | Кол-во |
|-----|----------|----------|--------|
| `avatar_terminal` | Терминал «Аватар профессий» | Основной сценарий — генерация фото; также доступен ПрофСтарт и Обратная связь | 2 |
| `led_screen` | LED-экран | Один экран — только заставки, второй — полный сценарий | 2 |
| `tree_terminal` | Терминал «Древо профессий» | Интерактивное дерево профессий | — |
| `map_terminal` | Терминал «Интерактивная карта» | Карта региона с работодателями и учебными заведениями | — |
| `battle_terminal` | Терминал «Профбаттл» | Профессиональные баттлы | — |
| `video_window` | Терминал «Видео-окна» | Просмотр видео о профессиях | — |
| `video_resume` | Терминал «Видео-резюме» | Запись видео-резюме | — |
| `pwa` | PWA (веб-клиент) | Чужие устройства пользователей | — |

| Код | Название | Описание |

| `regional_map` | Интерактивная карта региона | Карта региона с работодателями и учебными заведениями |
| `profbattle` | Профбаттл | Профессиональные баттлы |
| `video_windows` | Видео-окна | Просмотр видео о профессиях |

## Где используется

- **[AnalyticsEvent](../entities/analytics.md)** — атрибуты `device_type` и `software_id`
- **Аналитика** — фильтрация и группировка событий по оборудованию и ПО
- **Дашборды** — отчёты по каждому источнику и консолидированные
