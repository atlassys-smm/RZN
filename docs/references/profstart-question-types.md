# Типы вопросов ПрофСтарт

Системный справочник типов вопросов для банка вопросов профориентационного теста. Значения заданы в коде и не хранятся в базе данных.

Используется при создании вопросов теста в CMS и при отображении вопросов школьникам на терминале и в веб-версии.

---

## Значения справочника

| Код | Название | Описание |
|-----|----------|----------|
| `single_choice` | Выбор одного варианта | Один правильный или предпочтительный ответ из списка |
| `multiple_choice` | Выбор нескольких вариантов | Несколько вариантов могут быть выбраны одновременно |
| `agreement_scale` | Шкала согласия | Оценка степени согласия с утверждением (например, «полностью согласен» — «полностью не согласен») |
| `image_choice` | Выбор по изображению | Выбор варианта на основе визуального образа (изображения профессий, ситуаций) |
| `ranking` | Ранжирование | Упорядочивание вариантов по предпочтительности |
| `case_study` | Ситуационный кейс | Анализ ситуации с выбором решения |

---

## Атрибуты вопроса

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | enum | Тип вопроса (см. таблицу выше) |
| `text` | text | Текст вопроса |
| `media_id` | integer (int64), nullable | Изображение к вопросу |
| `age_group` | enum | Возрастная группа: `12-14`, `15-17` |
| `order` | integer | Порядок отображения (если фиксированный) |
| `randomize` | boolean | Случайный порядок отображения |

---

## Где используется

- **[TestQuestion](../entities/test.md)** — атрибут `type`
- **CMS** — создание вопросов теста ПрофСтарт
- **ПрофСтарт** — показ вопросов школьникам на терминале и в веб-версии
