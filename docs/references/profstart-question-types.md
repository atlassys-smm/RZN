# Вопросы и ответы ПрофСтарт

Во всех трёх тестах единственный тип вопроса — `single_choice`: пользователь выбирает ровно один answer_option_id.

| Тест | Представление вариантов | Балл ответа |
|---|---|---|
| Соломин | Четыре значения 0, 1, 2, 3 | Выбранное значение; want и can суммируются в одном показателе группы |
| Голланд | Шесть предпочтительных действий | 1 соответствующей RIASEC-группе |
| Деллингер | Пять фигур с картинкой и подписью | 1 группе выбранной фигуры |

Шкала и изображения меняют представление карточек, а не тип вопроса. Нулевой вариант — ответ, не пропуск. Ключ находится в TestAnswerOption.group_id и value. Балл ответа равен value, если значение задано, иначе 1. Клиент прохождения получает value, но не group_id; расчёт выполняется сервером. Картинка передаётся объектом file с подписанными url/preview_url и метаданными; без вложения file=null. В CMS файл варианта загружается через multipart/form-data в поле file, а не через media_id.

```json
{"answer_option_id": 404}
```

POST /api/profstart/answer принимает ответ в текущую собственную in_progress сессию. question_id необязателен: без него выбирается следующий неотвеченный вопрос.

Свободный текст, множественный выбор, ранжирование и клиентские веса не принимаются. Все вопросы обязательны, порядок фиксирован.
