# Вопросы и ответы ПрофСтарт

Во всех трёх тестах единственный тип вопроса — `single_choice`: пользователь выбирает ровно один answer_option_id.

| Тест | Представление вариантов | Вес |
|---|---|---|
| Соломин | Четыре значения 0, 1, 2, 3 | Выбранное значение, ось want или can из вопроса |
| Голланд | Шесть предпочтительных действий | 1 соответствующей RIASEC-группе |
| Деллингер | Пять фигур с картинкой и подписью | 1 группе выбранной фигуры |

Шкала и изображения меняют представление карточек, а не тип вопроса. Нулевой вариант — ответ, не пропуск. Ключ находится в TestAnswerOption.group_id и weight. Клиент прохождения получает варианты без этих полей.

```json
{"question_id": 101, "answer_option_id": 404, "time_spent_ms": 5200}
```

Свободный текст, множественный выбор, ранжирование и клиентские веса не принимаются. Все вопросы обязательны, порядок фиксирован. [Сущности](../entities/test.md) · [Методики](../subsystems/profstart/methods.md) · [API](../api/profstart.md).
