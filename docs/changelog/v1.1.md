# Версия 1.1

**Дата:** 11.09.2026

## Рефакторинг сущностей

- **Аналитика** — поле `source` разделено на `device_type` (тип оборудования) и `software_id` (программный комплекс); добавлены новые типы событий: генерация аватара, просмотр видео, запись видео-резюме
- **Согласия** — сущность разделена на `ConsentType` (тип согласия) и `ConsentVersion` (версия текста); добавлена модель черновиков и публикации; опубликованные версии неизменяемы
- **Викторина** — типы вопросов и уровни сложности вынесены в отдельные справочники

## Декомпозиция CMS

- Страницы CMS (ПрофСтарт, Викторина, Аватары профессий, Согласия, Анкеты) очищены от детальных описаний — оставлены только режимы и действия
- Детальная информация перенесена в специализированные разделы

## Аналитика — детальные дашборды ПАК

Добавлены отдельные страницы для каждого компонента детального дашборда ПАК:

- Аватар профессий
- Видео-окна
- Видео-резюме
- Древо профессий
- Интерактивная карта региона
- Профбаттл
- ПрофСтарт

## ПрофСтарт

- Новая страница «Процесс прохождения» — описание сценариев тестирования
- Новая страница «Результаты» — формирование и отображение результатов

## Новые справочники

- Типы вопросов викторины
- Сложность вопросов викторины
- Обновлён справочник источников событий

## История изменений

- Добавлен раздел «История изменений» с обзорной страницей и детальными страницами версий
