# Версия 1.13

Дата: 24.09.2026 17:00

---

## Изменения

### API — новые эндпоинты

- **Согласия** (`paths/consents.yaml`) — CRUD для типов согласий (`/consents/types`) и версий (`/consents/versions`) с публикацией черновиков
- **Аватары профессий** (`paths/profession-avatars.yaml`) — CRUD для эталонных образов (`/avatars`), загрузка мужского/женского фото
- **Аватары пользователей** (`paths/user-avatars.yaml`) — загрузка аватаров (`/users/{id}/avatars`), получение по QR-токену (`/avatars/qr/{token}`), список своих аватаров (`/me/avatars`)

### API — файлы

- **Скачивание по подписанному URL** — `GET /files/{uuid}?expires={timestamp}&sig={hmac}`
- HMAC-SHA256 подпись, срок действия 24 часа для аватаров
- Убран эндпоинт загрузки из публичного API (загрузка только через CMS)

### Сущности — аватары

- **Переименование**: `ProfessionAvatarTemplate` → `ProfessionAvatar` (упрощение)
- **`profession_id`** — unique (один эталонный аватар на профессию)
- **`UserAvatar.qr_token`** — unique
- Добавлены разделы: signed URLs, хранение файлов по модулям (`/data/uploads/avatars/`, `videos/`, `documents/`, `general/`), API

### Сущности — файлы

- **`File`** — добавлены поля `uuid` (для signed URLs) и `module` (для определения папки хранения: `avatars`, `videos`, `documents`, `general`)
