## Изменения

### Подключение к сессии — только по QR-коду

Убран «Код сессии» (числовой код для ручного ввода) из интерфейсов викторины. Подключение участников — только по QR-коду.

Затронутые файлы:
- `docs/interfaces/led-screen/quiz.md` — убрана строка «Код сессии» из таблицы элементов, обновлено состояние «Ожидание»
- `docs/api/paths/quiz.yaml` — описание endpoint `player-join`
- `docs/api/bundled/openapi.yaml` — аналогично
- `docs/subsystems/led-platform/operator.md` — убран «код» из способов формирования команд

### Общие правила интерфейсов

Создан `docs/interfaces/guidelines.md` — общие конвенции для всех клиентских интерфейсов:

- **Отображение имени** — в публичных интерфейсах полное ФИО запрещено, формат: `Иван И.` (имя + первая буква фамилии)
- **Аватар** — источник: загруженный пользователем в профиле → подтянутый из соц. сети (OAuth) → заглушка

Правила перенесены из `docs/entities/users.md` (раздел «Правила отображения» удалён из сущности User — это не уровень сущности).
