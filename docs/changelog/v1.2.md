# Версия 1.2

**Дата:** 11.09.2026

## Раздел «Концепция»

Добавлен новый раздел верхнего уровня «Концепция» — комплект проектно-демонстрационных материалов по ТЗ (10 календарных дней).

### Структура раздела

| № | Подраздел | Описание |
|---|-----------|----------|
| 1 | Презентация | Дизайнерская презентация 18–25 слайдов |
| 2 | Пояснительная записка | Описание идеи, архитектуры, маршрутов |
| 3 | Архитектурные и блок-схемы | Обзорная и детализированная схемы |
| 4 | Прототипы и UI/UX-концепция | 16+ экранных макетов, кликабельный маршрут |
| 5 | Материалы по регистрации и профилю | Маршрут, sequence-схема, состояния, 4+ экрана |
| 6 | Видеоролик | 60–90 секунд, motion design |
| 7 | Перечень допущений | Условные данные и ограничения |

### Материалы по регистрации и профилю

Начальное наполнение раздела:

- **Модель регистрации** — OAuth 2.0 (Яндекс ID, VK ID), без локальной регистрации по ID/паролю
- **Маршрут пользователя** — два параллельных маршрута: гость и сразу авторизованный
- **Sequence-схема** — диаграммы взаимодействия для полной авторизации и привязки гостевой сессии
- **Состояния** — гостевая сессия (active → bound / expired), профиль (active → deactivated → deleted), согласие
- **Экраны (5 шт.)** — выбор способа входа, согласие на ПДн, привязка гостевых результатов, личный кабинет, предложение авторизации для гостя

## Единая модель пользователя

Удалена отдельная сущность `GuestSession` — гостевой режим встроен в сущность `User`.

### Что изменилось

- **User** — добавлены поля `guest_id`, `guest_expires_at`; статусы расширены: `guest`, `active`, `anonymized`, `deactivated`
- **Все сущности** (аналитика, согласия, аватары профессий, ответы анкет, игровые сессии, тесты) — убрано поле `guest_id`, поле `user_id` теперь всегда заполнено и ссылается на единую запись `User`
- **Идентификация** — описаны 4 сценария: повторный QR, первый контакт OAuth, первый контакт гость, гость авторизуется позже; обновлены endpoints; убран гостевой токен
- **Цифровой профиль** — обновлено описание гостевого режима
