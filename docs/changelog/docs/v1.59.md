## Изменения

### Роль устройства EXTERNAL_APPS

Новая роль устройства `EXTERNAL_APPS` (код 5):
- Назначается при регистрации устройства или обновлении ролей в CMS
- Требуется для `POST /api/analytics/external/events` с Device JWT
- События с Device JWT записываются с ID устройства и доступны в фильтре сводки

### Авторизация внешних событий

`POST /api/analytics/external/events` теперь требует авторизацию:
- Staff access-токен ADMIN или Device JWT активного устройства с ролью EXTERNAL_APPS (5)
- Токен передаётся в заголовке `Authorization: Bearer <token>`
- Для Device JWT сервер заполняет `analytics.events.device_id`
- Для запроса администратором `device_id` равен NULL
- Добавлены ответы `401` и `403`

### Новые модули для внешних событий

Расширен список поддерживаемых модулей:
- **Интерактивная карта региона** (`module_id=8`):
  - `event_id=1` — старт
  - `event_id=4` — подтверждённое завершение
  - `event_id=16` — открытие объекта (`object_code`, `category_code` → `object_category`, `organization_id/name/type`)
  - `event_id=17` — выбор территории (`territory_code` → `territory_id`, `territory_name`)
- **Профбаттл** (`module_id=9`):
  - `event_id=1` — старт кейса (`mode`, `case_code`)
  - `event_id=4` — достижение экрана результата
- Оба события содержат `payload.mode` (individual/group) и `payload.case_code`

### Новые события аналитики

Добавлены коды событий:
- `event_id=16` — `MAP_OBJECT_VIEWED` (открытие карточки объекта интерактивной карты)
- `event_id=17` — `MAP_TERRITORY_SELECTED` (применение фильтра города или округа)

### Привязка анкет к Unity-модулям

Типы анкет можно привязывать к новым модулям:
- `module_id=7` — Древо профессий
- `module_id=8` — Интерактивная карта региона
- `module_id=9` — Профбаттл
- `module_id=16` — Конструктор карьеры

Таблица `SurveyModuleType` расширена для поддержки всех модулей аналитики.

### Служебные аккаунты для Unity-модулей

`POST /api/auth/user/service` расширен для четырёх новых модулей:
- `module=7` — Древо профессий (service_user 11–15)
- `module=8` — Интерактивная карта региона (16–20)
- `module=9` — Профбаттл (21–25)
- `module=16` — Конструктор карьеры (26–30)

Миграция `0105`:
- Добавляет по 5 аккаунтов на каждый новый модуль
- Переименовывает служебные аккаунты в «Анонимный Пользователь»
- При входе имя восстанавливается

Сброс аккаунта:
- Удаляет из PostgreSQL прохождения анкет и ответы (включая незавершённые)
- События аналитики обратной связи в ClickHouse сохраняются
- API возвращает `completed: false` для нового посетителя
