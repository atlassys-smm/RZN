## Изменения

### Обновление справочника профессий

Миграция `0108` обновляет справочник профессий:
- Обновляются названия, перспективы и зарплаты профессий из нового справочника с сохранением ID
- Программы обучения объединяются по названию, уровню, сроку и базе приёма
- Связи учебных заведений и профессий обновляются по новому справочнику
- Устаревшие связи предыдущей загрузки помечаются удалёнными
- Новые рекомендации по обучению учитывают активные программы, учебные заведения и связи

### Демо-пользователи

Новый эндпоинт и команды для создания демо-данных:

**`POST /api/auth/user/demo`** — создание авторизованного демо-пользователя:
- Доступен администратору (staff access-токен)
- Создаёт отдельный аккаунт с `is_guest=false`
- Имя и фамилия выбираются случайно из двух списков по 15 вариантов
- Фамилия получает окончание «-ов» или «-ова» в зависимости от имени
- Записывает согласие и выдаёт обычную пользовательскую сессию
- Refresh-токен устанавливается как HttpOnly cookie `user_refresh`

**Обновлённые демо-команды:**
- `simulate_profstart`, `simulate_quiz`, `simulate_video`, `simulate_feedback`, `simulate_views`, `simulate_avatars` поддерживают `--authorized` и `--date`
- `--authorized` создаёт демо-аккаунт с `is_guest=false` вместо гостя
- `--date` задаёт дату активности (без времени — 12:00 МСК, ISO 8601 с часовым поясом)
- Записи и события начинаются с указанного времени и учитывают время выполнения

**Новые команды Unity:**
- `simulate_unity tree` — события «Древа профессий»
- `simulate_unity map` — события «Интерактивной карты»
- `simulate_unity profbattle` — события «Профбаттла»
- Отправляют события через `POST /api/analytics/external/events`
- Для известных `user_id` внешняя аналитика сохраняет признак `is_guest` из PostgreSQL

**`simulate_user`** — комплексный сценарий:
- Создаёт одного авторизованного пользователя
- Запускает все существующие демо-сценарии и три сценария Unity
- Проводит от 2 до 5 индивидуальных викторин
- Выводит ID пользователя и число завершённых сценариев в консоль

### События «Профессий в действии»

Обновлены события модуля 3:
- Записываются старт показа, подключение пользователя и завершение показа
- Завершение учитывается при ручной остановке через `/stop`

### Карьерный трек для демо-пользователей

Обновлена логика отбора участников:
- ClickHouse выбирает активных участников по событиям с `is_guest = false`
- PostgreSQL исключает служебные аккаунты (`service_user IS NULL`)
- Авторизованный демо-пользователь проходит отбор при наличии события за период и сохранённых рекомендаций с положительными баллами
