## Изменения

### Завершение сессий Профбаттла

Обновлена логика завершения сессий Профбаттла:
- `battle:finished` завершает начатую сессию при подтверждённом выходе, включая досрочный выход
- В аналитике ему соответствует код события 4
- Удалено `battle:completed` — появление экрана результата больше не отправляет отдельное событие
- Добавлено `battle:quit` для подтверждённого выхода до начала сессии

### Обновление документации Профбаттла

Дашборд Профбаттла:
- «Среднее время» — от старта до подтверждённого выхода из сессии (было: до первого показа результата)
- «Доля завершённых» — доля начатых за период сессий с событием завершения (было: дошедших до экрана результата)

События:
- Записываются старт (1) и завершение сессии (4)
- `battle:finished` фиксирует подтверждённый выход из начатого кейса, включая досрочный выход
- При автоматическом сбросе событие завершения не отправляется
