## Изменения

### Викторина: select=answers

Новый параметр `select=answers` для `GET /quiz/sessions/active` и `GET /quiz/sessions/{id}` добавляет корневое поле `answers` с данными голосования текущего вопроса:

**Структура `QuizAnswers`:**

| Поле | Описание |
|------|----------|
| `participant_answers` | Участники, отправившие ответ (включая капитанов); для индивидуальной игры — принятый ответ |
| `team_answers` | Команды с текущим ответом капитана и статусом `submitted` |
| `option_counts` | Счётчики голосов по вариантам (`participant_count`, `team_count`) |

**Видимость по ролям:**
- **User** (командная игра) — видит голоса своей команды и решающий ответ капитана
- **User** (индивидуальная) — видит ответы всех участников сессии
- **StaffUser** — видит все команды
- **Device** — общие счётчики и статусы команд без содержимого ответов

**Особенности:**
- Без `select=answers` поле отсутствует
- До начала и после завершения игры `answers=null`
- `team_answers[].submitted` = true, когда капитан ответил (независимо от `is_final`)
- Отправка с `is_final=true` заменяет предыдущий голос капитана
- `option_counts` считает текущие голоса; один голос = один раз на вариант
- Для текста, сопоставления, порядка и распределения ролей `option_counts` пустой

### Тестовый вход по ID пользователя

`GET /auth/{id}` — временный маршрут для тестирования без пароля и действующего токена:
- Возвращает access JWT и устанавливает refresh cookie
- Создаёт серверную сессию
- `404` — тестовый вход выключен, пользователь не найден или URL не соответствует числовому ID
- `401` — пользователь деактивирован или срок гостя истёк

### Шаблоны викторины: поля вопросов из банка

В ответах CMS с шаблонами викторины вопросы раундов (`rounds[].questions[]`) дополнены полями из банка вопросов:
- `text` — текст вопроса
- `difficulty` — сложность (1/2/3, nullable)
- `age_group` — ID возрастной группы (nullable)
- `points` — баллы за правильный ответ

Поля не копируются в запись связи; берутся из текущего вопроса в банке.
