## Изменения

### Очистка завершённых сессий

Автоматическая очистка истёкших и отозванных сессий:
- API-контейнер запускает фоновую задачу по воскресеньям в 02:00 по Москве
- Хранение — 30 дней с `revoked_at` (отозванные) или `expires_at` (остальные)
- Пачки по 500 сессий, до 20 пачек за запуск
- Refresh-токены удаляются в той же транзакции, что и сессии
- Занятые другим запросом сессии пропускаются
- CLI-команда `python -m app.cli.cleanup_auth_sessions` — просмотр и ручная очистка (`--apply`)

### Бонус за скорость в викторине

- Время ответа фиксируется при приёме ответа
- Паузы исключаются из времени ответа
- Добавление секунд к таймеру не уменьшает время ответа
- Ответы без сохранённого времени оцениваются без бонуса за скорость
- Оптимизация: вопрос, варианты, участники, признак гостя и команды загружаются до цикла обработки ответов

### Обновление превью без основного файла

PUT/PATCH запросы могут принять только `file_preview` для уже прикреплённого файла:
- Основной файл, его UUID и метаданные сохраняются
- При отсутствии вложения возвращается 422
- Новое превью записывается под уникальным именем и доступно после commit
- Уменьшенные копии прежнего превью не используются
- Обновление во всех маршрутах: организации, профессии, викторина, анкеты, заставки LED, аватары профессий, видеосценарии, опросы

### Удаление завершающих точек

- Миграция 0089 убирает завершающие точки в текстах вопросов и вариантов ответов тестов ПрофСтарта (solomin, holland, dellinger)
- Seed-банк обновлён: 90 вариантов Голланда и 42 вопроса Соломина без точек
- Банк викторины перенесён в `app/cli/data/quiz/professions_bank.json`

### Отключена демо-страница Metabase

- Маршруты `GET /demo/metabase` и `POST /api/demo/metabase/query` отключены (возвращают 404)
- HTML демонстрационной страницы сохранён в `app/templates/metabase_demo.html`
