## Изменения

### Модуль 17 — Профиль пользователя

Новый код модуля для привязки анкет:
- `module_id=17` — Профиль пользователя
- Используется для анкет, отображаемых в профиле пользователя
- Добавлен в `SurveyModuleType` enum: `[1, 2, 3, 4, 6, 7, 8, 9, 16, 17]`
- Код 17 используется только для анкет в профиле, не совпадает с кодами аналитики

### Просмотры посетителя

Обновлён вопрос `visitors.views` (переименован из «Просмотры каталога»):
- Просмотры берутся из трёх источников: справочник, Древо профессий, Интерактивная карта
- Древо добавляет профессии, Карта — работодателей и учебные заведения
- События сопоставляются по внутреннему ID объекта
- Открытия из разных источников складываются по одному `entity_id` внутри категории
- Отрасли засчитываются по снимку из события просмотра профессии в справочнике
- Открытия профессий в Древе и организаций на Карте учитываются при наличии `user_id` и сопоставленного ID
- Фильтры `module_id` и `device_id` доступны для `visitors.views` и `visitors.activity`
