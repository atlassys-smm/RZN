## Изменения

### Сторона вариантов ответа в matching-вопросах

В `current_question.question.answer_options[]` добавлено поле `side`:
- `1` — left (левая сторона сопоставления)
- `2` — right (правая сторона сопоставления)
- `null` — сторона не задана (для остальных типов вопросов)

Поле возвращается оператору, LED и участнику через:
- `GET /quiz/sessions/{id}`
- `GET /quiz/sessions/active?device_id=...`

Кеш вопросов сохраняет `side`; старые записи без поля перестраиваются при чтении без очистки состояния игры.

Миграция БД не требуется.
