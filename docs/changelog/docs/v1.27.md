## Новые документы

### Предзаполнение справочных данных
- **`docs/references/data-prepopulation.md`** — описание структуры данных для импорта
- **`docs/data-prepopulation.json`** — готовые данные для миграции (517 КБ)

## Структура данных

### Сущности
- **Industry (Индустрия)** — 11 крупных категорий
- **IndustryBranch (Отрасль)** — 47 детальных отраслей со связью на индустрию
- **Profession (Профессия)** — 94 профессии с описанием, навыками, перспективами
- **Organization (employer)** — 100 работодателей
- **Organization (education)** — 42 учебных заведения
- **EducationProgram (Направление подготовки)** — 78 направлений

### Связи
- Профессия → Работодатель: 300 связей
- Профессия → Направление подготовки: 510 связей
- Направление подготовки → Учебное заведение: через `organization_id`
- Отрасль → Индустрия: через `industry_id`

### Особенности
- Все сущности имеют явные `id`
- Зарплата в числовых полях `min_salary` и `max_salary` (тыс. руб.)
- Численность работников (`employee_count`) — числовое поле
- Данные извлечены из двух Excel-файлов с дедупликацией
