Дата: 18.11.2026 12:00

## Изменения

### Обновлены обложки тестов ПрофСтарта

Основные изображения тестов Соломина, Голланда и Деллингера обновлены:
- PNG с суффиксом `-mobile` используются как превью основного файла
- В CMS `POST` и `PATCH` принимают основной файл как `file`, мобильный — как `file_preview`
- В ответах CMS, пользовательской карточки и каталога ссылка на мобильную версию доступна в `file.preview_url`
- Миграция `0104` записывает основные изображения и мобильные превью за один шаг

### Поиск видеосценариев

`GET /api/cms/video-scenarios` принимает необязательный параметр `query`:
- Поиск по части названия без учёта регистра
- Пробелы по краям убираются, пустое значение игнорируется
- Фильтр применяется вместе с `profession_id` до подсчёта `total` и пагинации
- `total` показывает количество совпадений

### Поиск аватаров профессий

`GET /api/avatars` поддерживает поиск по профессии:
- Параметр `query` ищет по части полного названия профессии без учёта регистра
- Пробелы по краям убираются, пустое значение игнорируется
- Поиск применяется до подсчёта `total` и пагинации
- В каждом элементе списка возвращается объект `profession`
- Новый тип `ProfessionAvatarListItem` включает `ProfessionAvatar` + `profession`
