## Изменения

### Аналитика «Аватар профессий»

Новые события ClickHouse для генерации аватаров:
- `AVATAR_GENERATION_FAILED` (event_id=13) — задание завершено ошибкой
- `AVATAR_GENERATION_EXPIRED` (event_id=14) — истёк срок задания или результата FaceAI
- `AVATAR_UPLOADED` (event_id=15) — отдельная загрузка готового изображения без задания FaceAI
- Модуль `module_id=6`; `session_id` — ID задания AvatarGeneration
- Снимок формируется внутри транзакции; факты отправляются после commit
- Повтор завершения не создаёт дополнительного успеха; блокировка записи защищает от гонки webhook и опроса

**Миграция ClickHouse 0013:**
- `avatar_generations` — одна строка на задание: старт, успех, ошибка, просрочка, длительность, снимок профессии
- `avatar_activity` — события генераций для уникальных пользователей
- `avatar_uploads` — отдельные загрузки готовых изображений
- Представления читают `events_unique`; повтор UUID не увеличивает счётчики

### Восемь графиков Metabase

Дашборд `pak.avatar` — восемь SQL-вопросов вместо текстовых заготовок:

| Ключ | Описание |
|------|----------|
| `avatar.generations` | Число заданий с известным стартом в периоде |
| `avatar.daily` | Задания по дням Europe/Moscow |
| `avatar.average_minutes` | Среднее время успешных заданий, сравнение с предыдущим периодом |
| `avatar.completion` | Доля успешных; категории: успех, в процессе, ошибки, истёк срок |
| `avatar.users` | Уникальные пользователи генераций |
| `avatar.professions` | Рейтинг профессий по числу генераций |
| `avatar.guests` | Распределение гости/OAuth |
| `avatar.uploads` | Счётчик отдельных загрузок готовых изображений |

Фильтры периода, устройства и профессии; снимки `is_guest`, даты Europe/Moscow.
