# Версия 1.4

Дата: 15.09.2026

---

## Изменения

### Концепция — пояснительная записка

Полностью наполнен раздел «Пояснительная записка» (`concept/explanatory-note.md`):

- Основная идея и ценность платформы (для посетителя, оператора, руководителя)
- Сегментация пользователей и ролей (5 ролей, состояния учётной записи)
- Карта основных пользовательских маршрутов
- Описание взаимодействия подсистем

### Сущности

- **Добавлена сущность «Компетенции»** (`entities/competences.md`) — справочник компетенций (Competence) и компетенций пользователя (UserCompetence). Включает 10 компетенций из модуля «Профбаттл», используется в цифровом профиле для формирования карты навыков пользователя

### Внешние ПАК

- **Добавлен раздел «Внешние ПАК»** в навигацию (раздел «Главная»)
- **Перемещён справочник «Профбаттл»** из `references/` в `external-paks/profbattle.md` — детальное описание внешнего ПАК Профбаттл:
  - Концепция: симулятор профессиональных решений с 6 кейсами
  - 10 сквозных компетенций (используют единый справочник платформы)
  - Механика извлечения компетенций (частотный анализ выборов)
- **Добавлено описание «Дерево профессий»** (`external-paks/profession-tree.md`) — интерактивный терминал с навигацией по профессиям: 4 уровня (заставка → отрасль → профессия → карточка), содержание карточки профессии (образование, зарплата, работодатели, учебные заведения, вакансии)
- **Добавлено описание «Интерактивная карта региона»** (`external-paks/interactive-map.md`) — карта Рязанской области с работодателями и учебными заведениями (требует получения механики)

### Аналитика

- **Обновлён дашборд «Профбаттл»** (`subsystems/analytics/dashboards/pak-detail/profbattle.md`):
  - Убрана пометка «требует детального изучения»
  - Добавлены разделы дашборда: по компетенциям, по кейсам, по результатам
  - Добавлен раздел «Интеграция с платформой» с комментарием «Планируется при наличии технической возможности»: технические детали, передаваемые данные, идентификация пользователя, хранение результатов, соответствие кейсов направлениям через веса отнесения
