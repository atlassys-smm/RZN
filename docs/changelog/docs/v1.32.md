## Изменения

### Направления подготовки — уникальность и связи

**Уникальность:** направления подготовки уникальны по точному сочетанию `name`, `education_level`, `duration`, `base_class`. NULL в `base_class` участвует в уникальности.

**Новая таблица `organization_education_programs`:**
- Связывает общее направление с несколькими учебными заведениями
- Уровень, срок и база приёма остаются в `education_programs`
- Миграции 0077–0079 создают связи, переносят данные, устанавливают ограничения уникальности

**CRUD направлений:**
- Больше не принимает и не возвращает `organization_id`
- Для связей добавлен `/organizations/education-programs/links` с полным CRUD
- Создание связи профессии с направлением не требует наличия организаций

**Мягкое удаление:**
- Удаление направления мягко удаляет его связи с организациями и профессиями
- POST удалённого сочетания восстанавливает ID без восстановления зависимых связей

### Рекомендации — education_programs

В `/users/me/recommendations` и `/organizations/recommendations` добавлен массив `education_programs`:
- До 5 направлений по профессиям
- Без дублей по организациям
- Ранжирование по числу совпавших профессий и ID
- Сохранение покрытия профессий
- Наличие связей с организациями не требуется

### Файлы организаций

**Миграция 0080:** `organizations.media_id` (nullable FK → files.id)

**Загрузка:**
- POST/PUT организаций поддерживают multipart/form-data с `file` и `file_preview`
- PUT без файла сохраняет текущее вложение
- Общий механизм файлов: модуль `organizations`, создание превью видео, транзакция

**Ответы:**
- `file` с подписанными ссылками и метаданными во всех ответах организации
- Включая рекомендации и организации по профессии
- Без вложения — `null`

### Фильтр по направлению

`GET /organizations` поддерживает `education_program_id`:
- Полные данные учебных заведений направления с `file`
- Без дублей, по активным связям и направлениям
- Пагинация и совместное применение остальных фильтров
- Неизвестное или удалённое направление — пустой список
