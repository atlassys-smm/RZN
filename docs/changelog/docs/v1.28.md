## Изменения

### Аналитика: ClickHouse + Metabase

Полная переработка подсистемы аналитики — переход от абстрактной модели к реальной реализации на ClickHouse и Metabase.

**Хранение:**
- ClickHouse 26.9.5.2 — таблица `analytics.events` с `ReplacingMergeTree`
- UUID факта в `id`, числовые enum действий и модулей
- Миграции 0001–0009 (викторины, ПрофСтарт, обратная связь, посещаемость, тепловая карта)
- Удалены `software_id` и `device_type` — используется `module_id`

**Доставка событий:**
- `app/services/analytics/emit_event` — очередь в памяти, пакетная HTTP-доставка
- Бизнес-запрос не ждёт ClickHouse (best effort)
- Повторы со стабильными ID

**Metabase 0.63.18.5:**
- 22 дашборда, 70+ SQL-вопросов, 50 текстовых заготовок
- Коллекции: викторина, ПрофСтарт, обратная связь, посещаемость, тепловая карта, сводка ПАК
- Развёртывание через PUT с сохранением ID

### События

**Викторина:**
- Старт с составом участников, регистрация, правильность ответа, окончание
- Завершённость определяется фактом завершения сессии
- Командная игра: `ANSWER_SUBMITTED` после личного ответа, состав команд в окончании

**ПрофСтарт:**
- `SESSION_STARTED=1`, `ANSWER_SUBMITTED=6`, `SESSION_FINISHED=4`, `SESSION_ABANDONED=9`
- `PROFESSION_RECOMMENDED=5` — по одному событию на профессию
- Ответ содержит вопрос, вариант, группу, вклад, время от старта

**Обратная связь:**
- `SURVEY_STARTED=7`, `ANSWER_SUBMITTED=6`, `SURVEY_FINISHED=8`
- Миграция 0060: `device_id` и `started_at` в `survey_responses`

### Справочник аналитики

`GET /api/analytics/catalog` — каталог коллекций, дашбордов и графиков Metabase:
- Требует Bearer access-токен (пользователь, сотрудник или устройство)
- Возвращает `id` и `type` (`collection`/`dashboard`/`question`)
- Читает актуальный реестр без запроса к Metabase

### Типы анкет и варианты ответов

- Миграция 0061: `surveys.external_id` → `type` (IntEnum, `QUALITY_ASSESSMENT=1`)
- Миграция 0062: `survey_answer_options` с `text`, `order`, `profession_id`
- Варианты доступны в `questions[].options` и через CMS CRUD
- `PROFESSION_CHOICE` требует профессию из справочника
- Ответы проверяются по ID вариантов своего вопроса
