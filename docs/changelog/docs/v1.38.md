## Изменения

### PDF-отчет аналитики

`GET /api/analytics/report?period=week|month&date=YYYY-MM-DD` — готовый PDF-отчёт:
- 11 страниц: обзор, посетители, сессии модулей, время и завершённость, викторины, ПрофСтарт, профессии и отрасли, организации и направления, обратная связь, тепловая карта
- Требуется staff access-токен с ролью ADMIN или ANALYST
- Период по МСК: с понедельника ISO-недели или с 1-го числа месяца до выбранной даты включительно
- Сравнение с предыдущим полным календарным периодом (абсолютные значения, проценты, п.п.)
- Будущая дата возвращает 422; сбой ClickHouse — 503
- Векторные графики (ReportLab), шрифты DejaVu, палитра согласована с сайтом: `#0050AA`, `#5AB4E6`, `#E65028`
- Русские имена файлов с UTF-8 `filename*` в `Content-Disposition`
- Аналитическая справка: поведенческий портрет аудитории, профессиональные интересы, вовлечённость, результаты ПрофСтарта, карьерные перспективы
- Пол и возраст из профилей уникальных участников; возраст на последний день периода
- При отсутствии данных портрет и прогноз не формируются
- PDF строится в отдельном потоке, на сервере не сохраняется, `Cache-Control: no-store`

### Пользовательское чтение анкет

Новые эндпоинты в группе «Обратная связь — Пользователь»:
- `GET /api/feedback/surveys?limit=20&offset=0` — список активных анкет `{items, total}` с вопросами и вариантами ответов
- `GET /api/feedback/surveys/{survey_id}` — активная анкета по ID; неактивная или отсутствующая возвращает 404
- Доступ: User JWT либо Device JWT с ролью 4 и действующей QR-привязкой
- Для устройства обязателен `X-Device-Connection-Id`
- Черновики и неактивные версии не возвращаются

### LED-анкета — новый URL

Получение анкеты по типу для LED перенесено на `GET /api/feedback/surveys/type/{type}`:
- Ранее: `/api/feedback/surveys/{type}` (конфликтовало с пользовательским `{survey_id}`)
- Требуется Device JWT с ролью 4
- Обновлён `operationId` в OpenAPI

### Демо-команда simulate_feedback обновлена

- Использует User JWT созданного гостя вместо Device JWT
- `GET /api/feedback/surveys` и `GET /api/feedback/surveys/{survey_id}` для чтения анкеты
- Параметр `--device-id` удалён; `source_id` по умолчанию — `demo-feedback-user-<user_id>`
- Гость создаётся до чтения анкет; валидация вопросов выполняется до start
