## Изменения

### Демо-просмотры для аналитики

CLI-команда `python -m app.cli.simulate_views` для заполнения аналитики:
- Выбирает 10 профессий, 10 организаций и 10 направлений образования
- Открывает каждую карточку от 1 до 10 раз с JWT созданного гостя
- Параметры: `--count`, `--seed`, `--report`, `--base-url`, `--origin`
- JSON-отчёт с планом и прогрессом
- Недостаток записей проверяется до отправки просмотров

### Начальные версии согласий (миграция 0091)

Миграция добавляет начальные версии `0.1` для типов согласий:
- `personal_data` и `contact_request` (поиск по `code` в `consent_types`)
- Короткий тестовый текст, статус `published`
- Даты публикации и начала действия на момент применения
- Если у типа уже есть версия — новая не создаётся
- При откате опубликованные согласия сохраняются

### Формулировки для пользователей до 15 лет

Новое поле `text_under_age` в вопросах и вариантах ПрофСтарта:
- Nullable text; null — использовать обычный `text`
- `GET /profstart/question` автоматически выбирает детскую формулировку:
  - Если пользователю ≤14 лет и `text_under_age` задано — возвращается оно
  - С 15-летия, без даты рождения или без детской формулировки — обычный текст
  - Возраст по `User.birth_date` на текущую дату (Europe/Moscow)
  - Device JWT использует профиль подключённого пользователя
- Миграция 0092 — добавление полей
- Миграция 0093 — заполнение 30 вопросов и 51 варианта из банка 0048
- CMS: POST/PATCH принимают `text_under_age` в multipart
- Пустая строка или `null` очищает поле; копирование версии переносит формулировки
- Суточный кеш хранит обе формулировки; текст выбирается при каждом запросе

### Короткие названия организаций

`Organization.short_name` (nullable, 255 символов):
- По аналогии с `Profession.short_name`
- Возвращается в списке, карточке и вложенных организациях рекомендаций
- POST/PUT принимают в multipart; пустая строка или `null` очищает
- Пропущенное поле PUT сохраняет значение
- Миграция 0094 — добавление поля
- Миграция 0095 — заполнение 142 организаций (100 работодателей, 42 учебных заведения)
- Аббревиатуры: «РГУ имени С.А. Есенина», «РязГМУ», «РГРТУ» и др.

### Объединение дублей профессий (миграция 0096)

Объединение 11 согласованных дублей профессий:
- Швея, Сварщик, Автомеханик, Пожарный, Дизайнер одежды, Event-менеджер, Врач, Агроном, Ветеринар, Кинолог, Машинист поезда
- Оператор швейного производства → Швея
- Создаётся активная профессия с согласованным названием (или используется существующая)
- Старые профессии получают `deleted_at`; строки сохраняются
- Переносятся связи: организации, программы, группы ПрофСтарта, вопросы викторины, видеосценарии, анкеты, аватары, задания генерации
- Источники рекомендаций: ID и названия заменяются на целевые, дубликаты объединяются с максимальным баллом
- Просмотры и правильные ответы суммируются
- Файлы и изображения сохраняются; автоматического обратного разделения нет
