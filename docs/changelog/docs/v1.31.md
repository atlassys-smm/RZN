## Изменения

### Заставки LED — CRUD с загрузкой файлов

Новая сущность `LedScreensaver` для управления медиафайлами заставки LED-экрана.

**Миграция 0076:** таблица `led_screensavers`:
- `id` — автоинкрементный int64
- `name` — обязательное название (1–255 символов)
- `media_id` — обязательная внутренняя ссылка на `files.id`

**API `/api/cms/led/screensavers`:**

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/cms/led/screensavers` | Список заставок (пагинация, сортировка по ID убыв.) |
| GET | `/cms/led/screensavers/{id}` | Заставка по ID |
| POST | `/cms/led/screensavers` | Создание (multipart: name, file, file_preview, file_title, file_description) |
| PUT | `/cms/led/screensavers/{id}` | Обновление (без file сохраняет прежнее вложение) |
| DELETE | `/cms/led/screensavers/{id}` | Удаление заставки (файл сохраняется) |

**Авторизация:**
- Чтение: staff (admin/content_editor/operator) или Device JWT любого активного устройства (роль не проверяется)
- Запись: только staff (admin/content_editor)
- User JWT не допускается для чтения

**Особенности:**
- Файл передаётся через `multipart/form-data` (как вопросы викторины)
- API не принимает `media_id`; возвращает объект `file` с подписанными ссылками (24 часа)
- Превью: JPEG, PNG, WebP, GIF; для видео без превью создаётся первый кадр
- Файл и сущность сохраняются одной транзакцией
- Замена и DELETE сохраняют прежние файлы
