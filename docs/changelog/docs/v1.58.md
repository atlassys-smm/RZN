## Изменения

### События внешних терминалов

Новый эндпоинт `POST /api/analytics/external/events` для приёма событий от внешних модулей:
- «Древо профессий» (`module_id=7`) и «Конструктор карьеры» (`module_id=16`)
- Код события — целое число от 0 до 65535
- Маршрут принимает запросы без Bearer-токена
- API возвращает `202` после постановки события в фоновую очередь аналитики
- Запись в ClickHouse выполняется в фоне
- При недоступности или заполнении очереди — `503`
- Каждый принятый запрос создаёт событие с новым серверным UUID

### Древо профессий

События «Древа профессий» (`module_id=7`):
- `event_id=1` — начало сеанса
- `event_id=11` — открытие карточки профессии
- `event_id=4` — подтверждённое завершение
- API сохраняет `payload.profession_code` и добавляет `profession_id` и `profession_name` из справочника при сопоставлении
- Если известный код Unity не сопоставился с единственной активной профессией, API сохраняет событие и пишет предупреждение
- Необязательный `user_id` сохраняется в `analytics.events.user_id`
- UUID внешнего сеанса передаётся в `session_id` и сохраняется в `analytics.events.external_session_id` и `payload.session_id`

### Конструктор карьеры

События «Конструктора карьеры» (`module_id=16`):
- `event_id=1` — старт
- `event_id=4` — завершение с результатом
- `event_id=6` — ответ этапа (один раз за подтверждённый этап)
- `event_id=9` — прерывание прохождения
- При изменении этапа отправляется новый факт с теми же `session_id` и `stage_id` и увеличенным `stage_revision`
- В payload старта передаются версии сборки и каталога
- В ответе этапа: `stage_id`, `stage_revision`, массив `answers` (каждый элемент содержит `question_id` и `option_ids` или числовое `value`)
- Этапы: `visitor_category`, `interests`, `motives`, `strengths`, `self_assessment` (8 значений), `rhythm` (5 значений)
- Для завершения: `duration_ms`, `result_revision`, `professions` со списком `id`, `name`, `position`, `score`

### Обновления модели аналитики

Новое поле `external_session_id` (Nullable UUID) в `analytics.events`:
- UUID сеанса внешнего модуля
- Числовой `session_id` для внешних событий равен `NULL`
- Представление `analytics.session_events` читает UUID из `payload.session_id` или `payload.attempt_id`
- `analytics.module_sessions` объединяет по `(module_id, session_key)` с префиксом `int:` или `uuid:`
- Длительность внешней сессии — разница между стартом и окончанием

### Дашборд Дерева профессий

Обновлён дашборд «Древа профессий»:
- Расчёт сессий, времени, доли завершения, уникальных пользователей
- Открытия профессий по ID из справочника
