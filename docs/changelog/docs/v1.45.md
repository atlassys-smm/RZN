### Демо-эмуляция генерации аватаров

`POST /api/cms/avatar-generations/simulate` — административный эндпоинт эмуляции:
- Только администратор (роль 1); устройство AVATAR (2) с действующей QR-привязкой
- Весь обмен FaceAI v2 выполняется локальным HTTP-моком без внешних запросов
- Ответы мока: `202 queued`, `200 done`, `200 image/jpeg`
- Задание, селфи и результат сохраняются одной транзакцией сразу со статусом 4
- Фоновый worker не видит незавершённое demo-задание
- Результат — `result_photo` или копия исходного образа (PNG → JPEG)
- Настройки FaceAI не требуются

### CLI-команда simulate_avatars

`python -m app.cli.simulate_avatars` — демо-прохождение без внешнего FaceAI:
- Создаёт гостя, подключает по QR к свободному AVATAR-устройству
- Отправляет запрос локальной эмуляции, проверяет результат и JPEG
- Встроенный синтетический портрет `app/cli/data/avatar/default.png` (используется без `--photo`)
- Параметры: `--template-id`, `--profession-count`, `--device-id`, `--gender`, `--seed`, `--report`, `--download-dir`, `--result-photo`
- `DEMO_ADMIN_LOGIN`, `DEMO_ADMIN_PASS`, `DEMO_API_URL` из `.env`
- JSON-отчёт с ID гостя, устройства, комплектов, заданий и аватаров
