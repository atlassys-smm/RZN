# Версия 1.8

Дата: 23.09.2026 13:45

---

## Изменения

### Миграция идентификаторов: UUID → integer(int64)

Все сущности и API-эндпоинты переведены с UUID на автоинкрементные `integer (int64)`.

Затронутые сущности: профессии, отрасли, направления, компетенции, организации, файлы, пользователи, согласия, анкеты, викторина, игровые сессии, видеосценарии, шаблоны сценариев, аналитика, внешние идентификаторы, аватары профессий, тесты (ПрофСтарт).

Обновлены: OpenAPI-спецификация (`openapi.yaml`, `bundled/openapi.yaml`), описания entities, paths, интерфейсы, справочники.

### Новая сущность: Device (LED-устройства)

Добавлена сущность для регистрации физических LED-устройств, работающих с API от собственного имени.

- **Entity:** `docs/entities/devices.md`
- **CMS-эндпоинты:**
  - `POST /cms/devices` — регистрация устройства (возвращает JWT, привязанный к `device_id`)
  - `GET /cms/devices` — список устройств
  - `GET /cms/devices/{id}` — получить устройство
  - `DELETE /cms/devices/{id}` — отзыв устройства (`is_active = false`)
  - `POST /cms/devices/{device_id}/refresh-token` — перевыпуск JWT
- **Схемы:** `Device`, `DeviceWithToken`, `DeviceTokenResponse`
- Несколько LED-экранов могут работать параллельно с независимыми сессиями показа

### Упрощение фаз интерактивного видео

Фазы показа сокращены с трёх до двух:

- **Было:** `playing → waiting → result`
- **Стало:** `playing → voting`

Фаза показа результата (`result`) удалена — после завершения голосования сразу начинается воспроизведение видео победившей ветки. Обновлены: OpenAPI, WebSocket-документация, интерфейс LED-экрана, screensaver.

### Новый эндпоинт: session-advance

`POST /interactive-video/sessions/{id}/advance` — LED-плеер сигнализирует об окончании воспроизведения текущего видеофрагмента. Сервер определяет дальнейший переход:

- Есть дочерние ветки → фаза `voting` (голосование)
- Нет дочерних веток, есть сценарии в очереди → следующий сценарий
- Нет дочерних веток и сценариев → завершение сессии

Добавлен ответ `403` (сессия принадлежит другому устройству).

### Прочие изменения

- **Порт локального сервера:** `localhost:8080/api/v1` → `localhost:8000/api`
- **`media_id` ветки видеосценария** — обязательное поле; при создании сценария подставляется системная видео-заглушка (`DEFAULT_SCENARIO_VIDEO_ID`)
- **Tiebreaker голосования:** при равенстве голосов побеждает вариант, раньше набравший последний голос (`last_vote_at`)
- **`uploaded_by` в File** — теперь nullable
- **Убрано поле `description`** из схемы Industry
- **`.gitignore`** — добавлен `scripts/__pycache__/`
- Уточнено описание случайного выбора сценариев при создании сессии (`profession_count` игнорируется, если указаны `scenario_ids`)
