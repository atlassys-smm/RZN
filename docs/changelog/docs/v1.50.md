Дата: 13.11.2026 10:00

## Изменения

### Настройки экрана LED

Новая сущность `ScreenSettings` — общие настройки экрана:
- Таблица `screen_settings`: одна запись без ID, 12 колонок с дефолтами
- Миграция 0098 — создание таблицы и начальной записи
- `GET /api/cms/led/settings` — чтение настроек (только администратор)
- `PUT /api/cms/led/settings` — обновление (только администратор)
- camelCase в JSON; длительности дробные >= 0, количество заставок целое >= 1
- Null, нечисловые значения и неизвестные поля отклоняются
- PUT изменяет переданные колонки, сохраняя остальные

### Аватар OAuth — скачивание только при отсутствии

Изменение поведения при OAuth-входе (Яндекс/VK):
- Изображение аватара скачивается и сохраняется только при `users.media_id IS NULL`
- Уже установленная фотография (в том числе загруженная через `PATCH /api/user/info`) сохраняется
- CDN аватара не запрашивается при повторном входе с установленным файлом

### remaining_ms — остаток таймера

Новое поле `remaining_ms` в таймере:
- Неотрицательный остаток в миллисекундах, рассчитанный по времени сервера
- В таймере викторины и `voting_point.timer` видеосессий
- На паузе викторины: `remaining_at_pause × 1000`
- При остановке: `0`
- Пересчитывается для каждого ответа, не сохраняется
- Миграция не требуется

### Смена капитана через User JWT

`PUT /api/quiz/sessions/{id}/teams/{teamId}/captain`:
- Текущий капитан может передать роль участнику той же команды через User JWT
- Оператор и администратор сохраняют свои права
- Device JWT не допускается
- Ответы и отметки решающего ответа не сбрасываются
- Миграция не требуется

### Удаление участника викторины

`DELETE /api/quiz/sessions/{id}/participants/{participantId}`:
- Для оператора и администратора, оба режима викторины (204)
- Удаляется участник и его текущий ответ
- При удалении капитана — выбирается другой участник команды или null
- До закрытия приёма снимается отметка решающего ответа команды удалённого капитана
- Проверка «все ответили» повторяется по оставшемуся составу, включая паузу
- Пустые команды не учитываются
- Начисленные очки и история оценённых ответов сохраняются
- Событие `participant_removed`
- Миграция не требуется

### Ответы на паузе

Приём ответов разрешён на паузе таймера:
- Индивидуальные и командные ответы, включая решающий ответ капитана
- Бонус за скорость учитывается по времени `paused_at`
- Длительность паузы исключена из расчёта
- Остановка по-прежнему закрывает приём
- Правила повторной отправки и закрытия по «все ответили» сохранены
- Миграция не требуется
