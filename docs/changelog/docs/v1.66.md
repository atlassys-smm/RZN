## Изменения

### Демо-сессии для существующих пользователей

Новые эндпоинты для работы с существующими авторизованными пользователями:

**`POST /api/auth/user/demo/session`** — открыть демо-сессию:
- Требуется staff access-токен администратора и доверенный Origin
- Выдаёт токен на срок до 30 минут для HTTP-операций демо-прогона
- Токен привязан к сессии администратора
- Принимает `user_id` существующего активного авторизованного пользователя
- Возвращает `user_id` и `is_guest=false`
- Закрытие через `POST /api/auth/user/demo/session/logout`

**`POST /api/auth/user/demo/session/logout`** — закрыть демо-сессию:
- Закрывает сессию указанных демо-учётных данных
- Требуется доверенный Origin

### Обновление `simulate_user`

Команда `simulate_user` поддерживает параметр `--user-id`:
- Записывает демо-активность для существующего авторизованного пользователя
- Команда открывает отдельную демо-сессию администратора для этого ID и закрывает её по окончании
- Уже пройденные типы тестов ПрофСтарта пропускаются
- При незавершённом прохождении команда пропускает ПрофСтарт и сохраняет прогресс пользователя
- При ошибке викторины или видеопоказа команда пытается завершить созданную сессию по её ID
- Если завершить сессию не удалось, команда выводит её ID и ошибку

### Демо-дата и WebSocket

- Демо-дата применяется только к HTTP-запросам, которые записывают демо-активность или пересчитывают рекомендации
- WebSocket подключается независимо от демо-даты

### Упрощение `visitors.activity`

Карточка `visitors.activity` изменена:
- Одна строка соответствует одному событию (раньше группировка по сессиям)
- Ключ строки — `event_uuid`
- Фронтенд определяет действие по `event_id` и `module_id`
- События сортируются по `occurred_at` от новых к старым, при равном времени — по UUID по убыванию
- Числовой `session_id` или `external_session_id` можно использовать для связи с прохождением
- Начало, ответы и завершение с одним ID занимают разные строки
- `total` — число событий по фильтрам до пагинации
- Упрощена таблица действий: показаны основные типы событий и их поля
