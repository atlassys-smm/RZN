## Изменения

### Доступ устройств к анкетам без роли FEEDBACK

Упрощён доступ к анкетам для устройств:
- Любое активное устройство может читать анкеты, начинать прохождение и отправлять ответы
- Роль устройства больше не проверяется — достаточно Device JWT активного устройства
- Требуется действующая QR-привязка пользователя (`X-Device-Connection-Id`)
- Роль `FEEDBACK` (4) по-прежнему доступна при настройке устройства, но не требуется для доступа

Обновлены эндпоинты:
- `GET /api/feedback/surveys` — список активных анкет
- `GET /api/feedback/surveys/{survey_id}` — анкета по ID
- `POST /api/feedback/surveys/{survey_id}/start` — начало прохождения
- `POST /api/feedback/surveys/{survey_id}/respond` — отправка ответов

Ответы `403` изменены: теперь возвращаются только при отсутствии подключения пользователя.

### Доступ к профессиям сессий

Упрощён доступ к эндпоинтам профессий сессий:
- `GET /api/quiz/sessions/{id}/professions` — ID профессий по вопросам сессии
- `GET /api/interactive-video/sessions/{id}/professions` — ID профессий по сценариям сессии
- Для чтения любой сессии достаточно:
  - User JWT (включая гостевой)
  - Staff JWT сотрудника с любой ролью
  - Device JWT активного устройства с любыми назначенными ролями
- Удалены ответы `403` для недостаточных прав

### Настройка runVideoScenario

Новая настройка экрана `runVideoScenario`:
- Миграция `0106` добавляет булево поле со значением `true` по умолчанию
- Доступна для чтения и изменения через `GET/PUT /api/cms/led/settings`
- Принимает только JSON-значения `true` и `false`
- Управляет запуском видеосценариев на LED-экране
- Теперь в настройках 13 полей (было 12)
