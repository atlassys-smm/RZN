## Изменения

### UUID сессии для внешних модулей

История посетителя объединяет события внешних модулей в сессии по `external_session_id`:
- Древо профессий (`module_id=7`), Интерактивная карта (`module_id=8`), Профбаттл (`module_id=9`)
- Одна строка на прохождение по UUID; начало, завершение и другие действия с тем же UUID входят в эту строку
- Для внутренних модулей используется числовой `session_id`, для внешних — UUID `external_session_id`
- У сессии `completed` означает событие 4, `abandoned` — событие 9, `in_progress` — без зафиксированного окончания
- При известных начале и окончании длительность берётся из события или рассчитывается по разнице времён

### Рекомендации учитывают Древо профессий

Источник `professions/views` объединяет два потока событий:
- Просмотры справочника из `analytics.profession_views`
- Открытия профессий из «Древа профессий» (`module_id=7`, `event_id=11`) в `analytics.events_unique`
- Для «Древа» требуются сопоставленный `payload.profession_id` и `user_id`
- События служебных аккаунтов учитываются по тем же правилам
- Для существующих профилей события «Древа» учитываются с последней сохранённой границы

### Сброс служебных аккаунтов

При повторной выдаче служебного аккаунта:
- Сохранённые рекомендации удаляются
- События просмотров справочника и «Древа профессий» остаются в ClickHouse
- События могут снова учитываться при первой выборке за 30 суток по тому же `user_id`
