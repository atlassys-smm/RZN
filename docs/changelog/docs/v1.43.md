## Изменения

### Ресайз изображений при скачивании

Подписанные ссылки на изображения принимают параметры `width` и `height`:
- Изображение вписывается в заданные границы с сохранением пропорций
- Без увеличения — если файл уже помещается, отдаётся исходник
- Достаточно одного параметра; каждый от 1 до 2048 пикселей
- Параметры не входят в подпись — можно дописать к существующему URL
- Поддерживаемые форматы: JPEG, PNG, WebP, GIF, BMP, TIFF, AVIF, ICO
- Прозрачность и кадры анимации сохраняются
- Лимиты: файл 64 МиБ, изображение 40 млн пикселей, анимация 300 кадров / 64 млн пикселей
- Уменьшенные варианты кэшируются на диске в формате исходника

### Хранение файлов

Новая структура каталогов для загружаемых файлов:
- Путь: `storage/uploads/<module>/<uuid>/`
- В каталоге: исходник, превью и `cache/` для уменьшенных копий
- Имя исходника на диске: `<12 символов SHA-256>.<ext>`
- Расширение берётся из имени загрузки; отображаемое имя хранится в `title`
- Старые файлы читаются по путям из БД
- При удалении записи каталог удаляется вместе с превью и кэшем

### Доступ LED к аналитике

Устройства с ролью `QUIZ_VIDEO` (1) получают доступ к аналитическим эндпоинтам:
- `POST /api/analytics/visitors/profiles` — профили посетителей по ID
- `POST /api/analytics/embed-tokens` — токены встраивания Metabase (срок 24 часа, без ограничения сессией)

### user_id в топ-баллах викторины

Карточка Metabase `quiz.individual.top_scores` возвращает `user_id`:
- Для пакетной загрузки имён и аватарок через `POST /api/analytics/visitors/profiles`
- На графике — обезличенные подписи «Участник 1»…«Участник 5»

### Профиль пользователя в Device auth

`GET /api/device/auth/user` и `POST /api/device/auth/confirm` возвращают:
- `user.gender` (1/2/null) и `user.birth_date` (YYYY-MM-DD/null)
- Незаданные значения — null

### Проверка прохождения обратной связи

`GET /api/feedback/me/completed` — статус прохождения:
- Возвращает `completed: true`, если пользователь отправил хотя бы одну анкету
- Учитывается история всех версий анкет; начатая анкета учитывается после отправки
- Требуется User JWT, включая гостевой
- `Cache-Control: no-store`
