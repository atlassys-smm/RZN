## Викторина: правила отображения баллов

Уточнены правила показа баллов на LED-экране в интерфейсе викторины (`interfaces/led-screen/quiz.md`):

- **Экран ответа** — убраны «Баллы» (начисленные за вопрос) и «Текущий счёт» (обновлённый рейтинг). Оставлены только правильный ответ, методическое пояснение и ответы команд без баллов.
- **Промежуточные результаты** — уточнено: показывается общий накопленный рейтинг (суммарные баллы по всем завершённым раундам), а не изменение за прошедший раунд.
- **Итоговые результаты** — убрана «Статистика по раундам» (баллы в каждом раунде). Оставлены только место, команда/участник и итоговый счёт.

Логика: баллы отображаются только между раундами как накопительный рейтинг. На экране вопроса, экране ответа и в финале — без разбивки по раундам.
