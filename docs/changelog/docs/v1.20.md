## Изменения

### Единая схема загрузки файлов (multipart)

Все эндпоинты, принимающие медиафайлы, переведены с JSON + ID медиа на `multipart/form-data` с непосредственной загрузкой файлов:

- **Вопросы викторины** (`POST/PUT /cms/quiz/questions`) — поле `file`, файлы вариантов в `answer_option_files[n]`
- **Вопросы анкет** (`POST/PUT /cms/surveys/{id}/questions`) — поле `file`
- **Ветки видеосценариев** (`POST/PUT /cms/video-scenarios/{id}/branches`) — поле `file`
- **Аватары профессий** (`POST/PUT /avatars`) — `male_photo`, `female_photo`
- **Аватары пользователей** (`POST /users/{id}/avatars`) — `photo`

ID файлов остаются внутренними связями БД и не передаются в запросах создания/редактирования.

### Объект `file` в ответах API

Вместо `image_url`, `media_url` и ID медиа в ответах возвращается объект `file`:

```json
{
  "file": {
    "preview_url": "/api/files/<uuid>_preview?expires=...&sig=...",
    "url": "/api/files/<uuid>?expires=...&sig=...",
    "mime_type": "video/mp4",
    "title": "Название файла",
    "description": null
  }
}
```

URL подписаны, действуют 24 часа. При отсутствии файла — `null`. У аватаров профессий — `male_file` и `female_file`.

### Превью файлов

- Новое поле `file_preview_path` в сущности File (миграция 0036)
- При загрузке видео без превью — первый кадр извлекается FFmpeg (PNG, таймаут 60с)
- Можно передать `file_preview` (JPEG/PNG/WebP/GIF) вместо автогенерации
- Для вариантов ответа — `answer_option_file_previews[n]`
- `preview_url` в объекте `file` — подписанный URL (суффикс `_preview`), `null` если превью нет
- Зависимость `imageio-ffmpeg` для генерации кадров

### Сценарии сессии для LED

- `GET /interactive-video/sessions/{session_id}/scenarios` — массив сценариев в порядке `settings.scenario_ids`
- Каждый сценарий содержит `id`, `title`, `description`, `profession_id`, `first_branch` (стартовая ветка с объектом `file`)
- LED может использовать `first_branch.file.preview_url` для карточки сценария

### Новый файл paths: surveys.yaml

Вынесен отдельный файл `docs/api/paths/surveys.yaml` с эндпоинтами обратной связи (CMS, LED, пользователь).

### Обновления API

- **Аватары** — метаданные в полях формы (`file_title`, `file_description`, `male_file_title` и т.д.)
