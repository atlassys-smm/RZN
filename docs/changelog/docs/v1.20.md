# Версия 1.20 — ПрофСтарт

Дата: 06.10.2026.

- Описаны сущности, CMS, пользовательское прохождение и аналитика ПрофСтарт; добавлен целевой OpenAPI-контракт.
- Каталог test_types расширяем; удаление типа, используемого активным тестом, запрещено, остальные ссылки защищены FK.
- Тест имеет статусы draft, active, archived; одновременно допускается один активный тест на тип. Публикация новой версии архивирует прежнюю, сохраняя начатые сессии и историю.
- Итоговый расчёт поддерживает solomin, holland, dellinger. Новые типы хранятся в CMS, пользовательский запуск доступен после реализации алгоритма.
- Соломин: по 3 вопроса на каждую из 7 групп и двух осей, всего 42; максимум 9 на группу/ось. Голланд: ровно 15 вопросов. Деллингер: один выбор из пяти фигур.
- У вопросов только single_choice; group_id и weight хранятся в варианте ответа. Черновики существуют только у теста; таблицы сущностей оформлены по одному полю на строку.

[Сущности](../../entities/test.md) · [Методики](../../subsystems/profstart/methods.md) · [API](../../api/profstart.md).

После перепроверки уточнены чтение архивных карточек владельцем, блокировки состава при публикации, инварианты сессий/результатов, повторные ответы, округление и reasons, агрегаты аналитики. Исправлены оставшиеся описания расчёта по Direction; различия с исходным ТЗ вынесены отдельно.
