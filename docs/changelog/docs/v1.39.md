## Изменения

### Привязка вопросов викторины к профессиям

Новое поле `profession_id` (bigint, nullable, FK → professions.id):
- В `GameQuestion` — необязательная привязка вопроса к активной профессии
- В `GameSessionQuestion` — снимок привязки при создании вопроса сессии
- Миграция 0084: добавление поля
- CMS: POST/PUT вопросов принимают `profession_id`; пустое значение или строка `null` снимает привязку; отсутствие поля сохраняет её
- Неизвестная или удалённая профессия возвращает 404
- Исторические записи не импортируются задним числом

### Источник рекомендаций — ответы викторины

Новый источник `quiz/answers` с относительным весом 1:
- Правильные личные ответы на привязанные вопросы накапливаются в Redis
- При полном завершении сессии (finish после последнего вопроса) переносятся в `user_recommendation_sources`
- `group_scores` содержит `answers_count` по `profession_id`
- Оценки: `100 × answers_count / max(answers_count)`, ROUND_HALF_UP
- `source_reference` хранит `last_session_id`
- Досрочный finish не начисляет ответы; повторный finish не начисляет повторно
- Ответ капитана не переносится участникам команды
- Текстовые типы (case_study, prediction, argumentation, final_case) исключены
- Защита от повторной оценки через Redis-набор `session_question_id:participant_id`
- Транзакция охватывает статус сессии и источники всех участников

### Профессии сессий

Новые эндпоинты для получения ID профессий по сессии:

**`GET /api/quiz/sessions/{id}/professions`:**
- До 5 уникальных ID профессий по частоте снимков привязок всех вопросов
- Включая финальный раунд и ещё не показанные вопросы
- Сортировка: частота DESC, profession_id ASC
- Работает для активных и завершённых сессий, без Redis

**`GET /api/interactive-video/sessions/{id}/professions`:**
- Все уникальные ID профессий сценариев из `settings.scenario_ids`
- Без лимита, порядок profession_id ASC
- Сценарии без профессии и отсутствующие сценарии пропускаются

Оба: доступ ADMIN/OPERATOR и устройство роли 1 для собственной сессии; мягко удалённые профессии включаются.
