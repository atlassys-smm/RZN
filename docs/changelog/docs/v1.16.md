## Изменения

### Сборка OpenAPI bundled

- `scripts/bundle_openapi.py` — добавлен `__main__`-блок: скрипт теперь запускается напрямую (`python3 scripts/bundle_openapi.py`) и перегенерирует `docs/api/bundled/openapi.yaml`
- `docs/api/scalar.html` — Scalar переключён с `bundled/openapi.yaml` на `openapi.yaml` (генерируется хуком при каждой сборке MkDocs)
- `docs/api/bundled/openapi.yaml` — перегенерирован из актуальных исходников

**Результат:** при `mkdocs serve` изменения в `docs/api/openapi.yaml` и `docs/api/paths/*.yaml` автоматически подхватываются Scalar в реальном времени.
