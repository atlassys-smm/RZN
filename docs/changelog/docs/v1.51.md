## Изменения

### Расширение доступа к GET настроек экрана

`GET /api/cms/led/settings` теперь доступен:
- Администратору со Staff JWT (роль 1)
- Оператору со Staff JWT (роль 2)
- Активному устройству с Device JWT (независимо от роли устройства)

`PUT /api/cms/led/settings` — только администратору со Staff JWT (роль 1), без изменений.

### Ответы капитанов для Device в select=answers

При `select=answers` в состоянии командной викторины:
- Устройство получает ответы капитанов в `answers.team_answers[].answer`
- Индивидуальные ответы участников скрыты: `participant_answers=[]`
- Правильный ответ доступен устройству только после раскрытия
- Изменение действует для `GET /quiz/sessions/{id}` и `GET /quiz/sessions/active`
