## Изменения

### Короткие названия профессий

Новое поле `short_name` (varchar(255), nullable) в сущности профессии:
- Миграция 0084: добавление nullable-поля `professions.short_name`
- Миграция 0085: заполнение коротких названий из `profession_short_names.json` для 94 активных профессий; сопоставление по полному `name`; удалённые записи не затрагиваются
- Downgrade 0085 очищает только совпадающие с источником значения, сохраняя изменённые вручную
- Поле добавлено в GET списка и карточки, POST и PUT профессии
- Необязательное, от 1 до 255 символов; пустое значение или строка `null` передаёт NULL

- `data-prepopulation.json` дополнен `short_name` для всех 94 профессий

### Metabase JWT — подписанное встраивание графиков

`POST /api/analytics/embed-tokens` — пакет токенов встраивания:
- Требуется staff access-токен с ролью ADMIN или ANALYST
- Принимает от 1 до 100 ключей графиков из реестра
- Возвращает `items: [{key, token}]` и общий `expires_at` (UTC)
- JWT HS256 с `METABASE_EMBEDDING_SECRET_KEY`, срок до 24 часов, не дольше сессии
- JWT содержит `resource.question`, пустой `params: {}` и `exp`
- Подписываются только графики с `enable_embedding=true` (41 график)
- Ошибка одного ключа отклоняет весь пакет; ответ `Cache-Control: no-store`
- Все фильтры (date_from/date_to, time_grain, device_id, module_id, survey_id, source_id) передаются при получении данных графика, не в JWT
- Изменение фильтров не требует перевыпуска токена

### Демо-страница аналитики

`GET /demo/metabase` — страница демонстрации встраивания:
- Вход сотрудника через `POST /api/recommendations_constructor/login` (email/пароль)
- Пакет из 13 JWT кэшируется в памяти вкладки
- 4 вопроса вовлечённости + 9 вопросов обратной связи (50 всего с встраиванием)
- Графики через iframe `{METABASE_URL}/embed/question/{token}`
- Смена периода, модуля, устройства, анкеты не перевыпускает токены

### Данные графиков через API

`POST /api/demo/metabase/query` — получение данных графика:
- Принимает `{token, filters}` в JSON (токен не попадает в URL access log)
- Бэкенд выполняет `GET /api/embed/card/{token}/query` по фиксированному `METABASE_INTERNAL_URL`
- Cookie, пароль администратора и админ-сессия Metabase не используются
- Ответ: `{status: "completed", data: {cols, rows}}`, `Cache-Control: no-store`
- Диагностические сообщения Metabase не раскрываются
