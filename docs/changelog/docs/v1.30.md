## Изменения

### Мягкое удаление справочников (deleted_at)

Миграции 0066–0072 добавляют `deleted_at` (nullable timestamp) во все справочники:
- `industries`, `directions`, `professions`, `organizations`
- `industry_branches`, `education_programs`
- Связи: `profession_employers`, `profession_education_programs`, `profstart_test_group_professions`

**Поведение:**
- Все GET-запросы исключают удалённые записи (`deleted_at IS NULL`)
- DELETE устанавливает `deleted_at` вместо физического удаления
- GET элемента по ID возвращает мягко удалённую запись
- Изменение и повторное удаление недоступны (404)
- Активные зависимости защищены ответом 409

**Миграция 0073:** `organizations.type` преобразуется из строки в integer:
- `OrganizationType.EMPLOYER=1`, `OrganizationType.EDUCATION=2`
- API создания, обновления, ответа и фильтра принимает числовой enum

### Seed профессий и связей

Миграция 0075 загружает данные из `app/migrations/data/professions_data.json`:
- 11 индустрий, 47 отраслей, 94 профессии
- 100 работодателей, 42 учебных заведения, 78 программ обучения
- 300 связей с работодателями, 510 связей с программами
- 386 связей ПрофСтарт (Соломин 188, Голланд 94, Деллингер 104)

**Особенности:**
- Все ID выдаёт автоинкремент; внешние ключи пересчитываются по картам
- Перед вставкой всем строкам девяти таблиц устанавливается `deleted_at=now()`
- `professions.direction_id` допускает NULL (источник не содержит направлений)
- Тексты и зарплаты переносятся как в источнике

### Рекомендации организаций

**`/users/me/recommendations`** дополнен `employers` и `educations`:
- До 5 организаций каждого типа по максимум 3 профессиям итогового рейтинга
- Выше организации с большим числом совпавших профессий
- Учитываются мягко удалённые цепочки
- Проверка покрытия: для каждой профессии хотя бы одна организация

**`GET /organizations/recommendations`** — новый эндпоинт:
- Принимает 1–3 `profession_ids` в query
- Возвращает до 5 работодателей и 5 учебных заведений
- Те же правила, что в профиле рекомендаций
- Профиль пользователя не требуется

### Доступ к справочникам

- Все GET справочников требуют действующий JWT (пользователь, гость, сотрудник, устройство)
- Создание, изменение и удаление — только admin/content_editor
- Новые маршруты: `/industries/branches`, `/professions/employers`, `/professions/education-programs`, `/organizations/education-programs`
- `GET /professions/{id}/employers` и `/professions/{id}/educations` — организации по профессии

### Видео сессии — доступ по User JWT

`GET /interactive-video/sessions/active`:
- Доступен пользователю с User JWT (включая гостя) без присоединения к показу
- `device_id` выбирает устройство; без него — любая активная сессия
- Добавлен доступ сотрудникам любой роли со Staff JWT
- Device JWT требует роль 1

### Досрочное завершение голосования в видео

После ответа всех участников по текущему `participant_count`:
- Голосование завершается досрочно
- Таймер очищается, начинается победившая ветка
- После `votes_updated` отправляется `phase_changed`
- Нулевой счётчик не завершает голосование

### Аватары профессий

Исправлена работа с мягко удалёнными профессиями:
- Поиск шаблона не зависит от `deleted_at`
- GET/PUT/DELETE остаются доступны
- POST проверяет активность профессии (422 для удалённой)
- Сохранена проверка дубликата для активной профессии
