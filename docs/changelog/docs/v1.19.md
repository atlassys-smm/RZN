## Изменения

### Обратная связь — полная переработка API

API анкет обратной связи переработано и расширено. Добавлены три отдельных тега:

- **Обратная связь — CMS** — управление анкетами, вопросами и просмотр ответов
- **Обратная связь — LED** — получение активной анкеты для LED-плееров
- **Обратная связь — Пользователь** — прохождение анкет

#### CMS — анкеты

- `GET /cms/surveys` — список анкет с пагинацией и фильтром `is_active`
- `POST /cms/surveys` — создать анкету (черновик)
- `GET /cms/surveys/{survey_id}` — детали анкеты с вопросами
- `PUT /cms/surveys/{survey_id}` — обновить анкету (нельзя редактировать активную — 422)
- `DELETE /cms/surveys/{survey_id}` — удалить анкету-черновик (нельзя удалить активную или с ответами — 409/422)
- `POST /cms/surveys/{survey_id}/copy` — создать новую версию (копирование в черновик с тем же `external_id`)
- `POST /cms/surveys/{survey_id}/publish` — опубликовать (предыдущая активная с тем же `external_id` автоматически деактивируется)

#### CMS — вопросы

- `POST /cms/surveys/{survey_id}/questions` — добавить вопрос
- `PUT /cms/surveys/{survey_id}/questions/{question_id}` — обновить вопрос
- `DELETE /cms/surveys/{survey_id}/questions/{question_id}` — удалить вопрос
- `PUT /cms/surveys/{survey_id}/questions/reorder` — изменить порядок вопросов

#### CMS — ответы

- `GET /cms/surveys/responses` — список ответов с фильтрами: `survey_id`, `external_id`, `is_active`, `user_id`, `completed_from`/`completed_to`, пагинация

#### LED

- `GET /feedback/surveys/{external_id}` — активная анкета по символьному идентификатору (без авторизации)

#### Пользователь

- `POST /feedback/surveys/{survey_id}/respond` — отправить ответы на анкету

**Удалён:** `GET /feedback/surveys` (старый список анкет — заменён на CMS-эндпоинты и LED-эндпоинт по `external_id`)

### WebSocket URL: убран `/v1/`

Все WebSocket-эндпоинты обновлены с `/api/v1/` на `/api/`:
- `ws://host/api/quiz/sessions/{id}/ws`
- `ws://host/api/interactive-video/sessions/{id}/ws`

Обновлены: `websocket.md`, `README.md`, интерфейсы LED/мобильного/оператора, комментарии в `quiz.yaml` и `interactive-video.yaml`.
