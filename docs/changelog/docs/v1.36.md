## Изменения

### Demo-команды для тестирования

Добавлены CLI-команды для демонстрационного прохождения сценариев через API:

**`simulate_quiz`** — индивидуальная викторина:
- Создаёт гостя, проходит все вопросы, завершает игру
- Стратегии correct/random, seed, JSON-отчёт
- Управление от имени администратора, ответы с токеном гостя

**`simulate_profstart`** — тесты ПрофСтарта:
- Последовательное прохождение всех активных тестов
- Выбор тестов по `--test-code`, стратегии random/first
- Проверка результатов, истории и профиля рекомендаций

**`simulate_video`** — «Профессии в действии»:
- Создаёт гостя и видеосессию, получает Device JWT
- Отправляет голоса и выполняет переходы LED
- Поддержка ссылочных веток, сценариев без выбора

**`simulate_feedback`** — обратная связь:
- Создаёт гостя, начинает и заполняет анкету
- Пять типов вопросов, условия показа
- Проверка сохранённых ответов через CMS API

**Общие параметры:**
- `DEMO_ADMIN_LOGIN`, `DEMO_ADMIN_PASS`, `DEMO_API_URL` из `.env.example`
- `--seed` для повторяемости, `--report` для JSON-отчёта
- Общий HTTP-клиент для demo-команд

### Источник рекомендаций — просмотры профессий

Новый источник `professions/views` с относительным весом 5:
- `group_scores` содержит `profession_id` и накопленное количество просмотров
- `profession_scores` — оценки `100 × views_count / max(views_count)`
- Обновление при GET рекомендаций, если `updated_at` старше 6 часов
- Первый импорт за 30 суток, далее инкрементально
- Миграция 0083: `updated_at` источника

**Стандартные веса (сумма 100):**
- Соломин: 40
- Голланд: 40
- Деллингер: 15
- Просмотры: 5

### Все сценарии — новый эндпоинт

`GET /api/interactive-video/scenarios` — все сценарии без пагинации:
- С `first_branch` и объектом первого файла
- Формат совпадает с `/interactive-video/sessions/{id}/scenarios`
- Доступ: admin/operator или Device JWT с ролью QUIZ_VIDEO (1)
- Выборка одним запросом, по ID по возрастанию

### Событие session_finished при stop

При ручной остановке видео оператором через `/interactive-video/sessions/{id}/stop`:
- Событие `session_finished` отправляется в сокет устройства и всем подключениям сессии
- Повторный stop не дублирует уведомления
- Естественное завершение сохраняет прежнюю рассылку

### PATCH /api/user/info — новые поля

Добавлены поля для пользователей и гостей:
- `gender` (1 — male, 2 — female, null — очистить)
- `birth_date` (YYYY-MM-DD, null — очистить)
- Пропущенные поля сохраняются
- Миграция не требуется

### Формат файла в текущей ветке видео

`current_branch.file` в состоянии интерактивного видео:
- Общий объект файла: `url`, `preview_url`, `mime_type`, `title`, `description`
- Вместо `media_url` с внутренним путём
- `null` при отсутствии файла
- Формат приведён к контракту OpenAPI

### Дашборды — период 7 дней

Период по умолчанию в 61 карточке Metabase сокращён с 30 до 7 календарных дней:
- Включая текущий день, по МСК
- Сравнение с предыдущими 7 днями
- Топ-5 личных результатов викторины сохраняет выборку за вчерашний день
