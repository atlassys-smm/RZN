Дата: 26.10.2026 17:10

## Изменения

### Аналитика просмотров

Новые события для отслеживания просмотров справочников:

**ORGANIZATION_VIEWED (event_id=10, module_id=13):**
- `GET /api/organizations/{id}` создаёт событие только при JWT пользователя (включая гостя)
- Сотрудники и устройства не создают событий
- Сохраняются: organization_id, organization_name, organization_type
- Миграция ClickHouse 0010: представление `organization_views`
- Дашборд `main.organizations`: топ-10 работодателей и учебных заведений, дневная динамика

**PROFESSION_VIEWED (event_id=11, module_id=14):**
- `GET /api/professions/{id}` — просмотр профессии
- Сохраняется снимок отрасли через `industry_id`
- Миграция ClickHouse 0011: представление `profession_views`

**EDUCATION_PROGRAM_VIEWED (event_id=12, module_id=15):**
- `GET /api/organizations/education-programs/{id}` — просмотр направления образования
- Миграция ClickHouse 0011: представление `education_program_views`
- Дашборд `main.professions`: 6 карточек (рейтинги и динамика профессий, отраслей, направлений)

### Итоговые баллы индивидуальной викторины

В `SESSION_FINISHED` индивидуальной викторины добавлен `results[]`:
- Массив с `participant_id`, `user_id`, `total_score` для каждого участника
- Включая нулевые баллы
- Миграция ClickHouse 0012: представление `quiz_individual_results`
- Карточка `quiz.individual.top_scores`: топ-5 лучших результатов

### Дашборд заставки LED

Коллекция Metabase «Для заставки» с дашбордом `led.showcase`:
- Посетители, среднее время, люди с подобранными профессиями
- Популярные профессии и обратная связь
- Топ личных баллов (переиспользуется из индивидуальной викторины)
- Переиспользованы 7 существующих карточек

**Процент времени заставки:**
- `led.screensaver.time_percent` — остаток от 8 часов за день после вычитания сессий
- Исключаются сессии обратной связи (module_id=5)
- Фильтры периода и устройства

### Ссылочные ветки видеосценариев

Новое поле `reference_branch_id` в ветках видеосценариев:
- Ссылка на существующую ветку того же сценария
- Ссылочная ветка не требует собственного видео
- После выбора backend переходит к конечной цели цепочки
- Проверка циклов при сохранении (400 ошибка)
- Миграция PostgreSQL 0081: nullable-ссылка, разрешён nullable `media_id`

### Данные профессии в CMS видеосценариев

`select=profession` в `GET /api/cms/video-scenarios`:
- Список: `GET /api/cms/video-scenarios?select=profession`
- Детали: `GET /api/cms/video-scenarios/{id}?select=profession`
- Без параметра поле `profession` отсутствует
- При отсутствии привязки — `null`; мягко удалённая профессия доступна

### Файлы профессий

Миграция 0082: `professions.media_id` (nullable FK → files.id):
- POST/PUT профессии принимают multipart/form-data с файлом
- Во всех ответах с профессией добавлен `file`
- Приоритет: собственный файл → male_photo_file_id шаблона аватара → null

### Рекомендации — описание профессии

В ответе `GET /api/users/me/recommendations` добавлено `description`:
-Nullable поле из текущего справочника профессий
- Изменение описания не требует пересчёта результатов
- Мягко удалённые профессии также возвращают описание

### Результат ПрофСтарта — список профессий

В `GET /api/profstart/sessions/{id}/result` и `GET /api/profstart/me/results`:
- Полный список `professions` из снимка источника
- Максимум 10 наиболее подходящих (score DESC, profession_id ASC)
- Возвращаются названия, баллы, позиции, пояснения и текущее описание
- Веса общего рейтинга и лимит 3 не применяются
