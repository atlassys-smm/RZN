## Изменения

### Кэширование в Redis

Суточный кэш часто используемых запросов через общий Redis-клиент:

**Викторина** — структура сессии и содержимое вопросов, TTL 1 час:
- При прогретом кэше GET активной игры выполняет 2 SQL вместо 6
- Финальный раунд сбрасывает кэш после commit до рассылки
- Завершение очищает кэш; промах восстанавливается из PostgreSQL

**Видеосценарии** — содержимое сценария и дерево веток, TTL 24 часа:
- Инвалидация по версии после commit при изменениях сценария и веток
- Подписанные ссылки формируются при выдаче

**ПрофСтарт** — банк опубликованной версии теста, TTL 24 часа:
- Вопросы, варианты, метаданные файлов; свежие подписи при выдаче
- CMS и черновики не кэшируются

**Рекомендации пользователя** — персональная подборка, TTL 24 часа:
- Ключ включает user_id, версию ПрофСтарта, отпечаток весов и версию справочников
- Завершение викторины и просмотры не сбрасывают кэш
- Конструктор сотрудника работает без кэша

**Подбор по ID профессий** — `/organizations/recommendations`, TTL 24 часа:
- Ключ по отсортированному списку ID, весам и версии справочников

**Опубликованные анкеты** — список, анкета по ID, LED по типу, TTL 24 часа:
- Публикация новой версии инвалидирует все варианты чтения

### Фоновая генерация превью видео

Видео без превью сохраняется без ожидания FFmpeg:
- После commit запускается asyncio-задача (до 2 одновременно)
- До готовности `preview_url` равен null
- Кэши проверяют готовность по UUID файла без пересчёта содержимого
- Ошибки генерации логируются; исходник сохраняется

### Аналитика посетителей

`POST /api/analytics/visitors/profiles` — профили по списку ID:
- Сотрудники ADMIN/ANALYST; до 100 ID за запрос
- Возвращает имена, фамилии и файлы аватарок из PostgreSQL одним запросом
- Неизвестные ID пропускаются; `Cache-Control: no-store`
- Фронтенд получает статистику из Metabase; API — только имена и аватарки

### Аватарка в участниках сессии

`select=participants` в состоянии сессии викторины:
- Возвращает файл аватарки профиля с подписанной ссылкой
- Для участника без аватарки `file` равен null

### Удалён тестовый маршрут

`GET /auth/{id}` — временный эндпоинт выдачи пользовательского токена по ID без проверки учётных данных — удалён вместе с обработчиком, сервисной функцией и описанием OpenAPI.

### Оптимизации запросов

- **История ПрофСтарта** — пакетная загрузка прохождений, ответов, источников, тестов, вопросов и профессий с медиа
- **Шаблоны викторины** — общее количество через SQL COUNT; шаблоны, раунды и вопросы загружаются только для запрошенной страницы
