## Изменения

### Логотип на аватарах FaceAI

На новые аватары FaceAI накладывается логотип в левом верхнем углу:
- Отступ около 3% от короткой стороны изображения
- Логотип: `app/services/avatar_generations/logo/logo.png`
- Исходный JPEG используется в памяти на время обработки
- В хранилище и ответах API сохраняется JPEG с логотипом
- При ошибке чтения или наложения сохраняется исходный файл, задание завершается успешно
- Итоговый файл хранится без автоматического срока удаления
- Правила применяются к результатам из webhook, резервного скачивания и локальной эмуляции FaceAI

### Content-Disposition для файлов

Подписанные ссылки на файлы поддерживают режимы просмотра и скачивания:
- По умолчанию `Content-Disposition: inline` — открытие в браузере
- Параметр `&type=download` переключает на `attachment` для скачивания
- Параметр не входит в подпись — можно дописать к существующей ссылке
- CDN хранит одну копию для обоих режимов и меняет заголовок при выдаче
- Имя файла берётся из `files.title`
- Если в имени нет расширения, оно добавляется из `files.file_path` или определяется по MIME-типу
- Уменьшенная копия получает расширение своего формата
