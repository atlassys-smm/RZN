## Изменения

### CMS — настройки сессий и баллов

Добавлены эндпоинты для управления стандартными настройками:

- `GET /cms/quiz/settings/defaults` — получить стандартные настройки сессии (team_count, team_capacity, auto_reveal, auto_next, delays и т.д.)
- `PUT /cms/quiz/settings/defaults` — обновить стандартные настройки
- `GET /cms/quiz/settings/scoring` — получить стандартные настройки системы баллов (partial_correct, speed_bonus, streak_bonus, consensus_bonus, final_multiplier, penalty)
- `PUT /cms/quiz/settings/scoring` — обновить стандартные настройки баллов

При создании сессии (`POST /quiz/sessions`) можно переопределить стандартные настройки, передав `settings.scoring` — если не переданы, подставляются стандартные из CMS.

### API — новые эндпоинты и изменения

**Новые:**
- `POST /quiz/sessions/{id}/led/next` — LED-экран вызывает после окончания таймера; автоматически показывает ответ (если `auto_reveal = true`) и переходит к следующему вопросу
- Новый тег **"Викторина - LED"** для эндпоинтов, вызываемых LED-экраном

**Изменённые:**
- `POST /quiz/sessions/{id}/finish` — теперь возвращает `200` с состоянием сессии (было `204`)
- `GET /quiz/sessions/{id}/results` — упрощён (был `results/total` + `results/rounds/{roundIndex}`)

**Удалённые:**
- `GET /quiz/sessions/{id}/results/rounds/{roundIndex}` — результат раунда (заменён на `led/next`)
- `GET /quiz/sessions/{id}/results/total` — объединён с `results`

### Redis: реструктуризация ключей

Ключи Redis для викторины получили префикс `quiz:` и объединены:

| Было | Стало |
|------|-------|
| `session:{id}:timer_ends_at` | `quiz:session:{id}:timer` (hash: `ends_at`, `remaining_at_pause`, `running`) |
| `session:{id}:timer_remaining_at_pause` | ↑ (внутри hash) |
| `session:{id}:timer_running` | ↑ (внутри hash) |
| `session:{id}:answers` | `quiz:session:{id}:answers` |
| `session:{id}:revealed` | `quiz:session:{id}:revealed` (string: "0"/"1") |
| — | `quiz:session:{id}:scores` (hash: результаты проверки ответов) |
| — | `quiz:session:{id}:final_answers` (hash: отметки о решающем ответе капитана) |

### GameSessionAnswer: перенос в Redis

`GameSessionAnswer` перенесён из БД в Redis для производительности. Структура описана в `docs/entities/game-session.md`:

- `quiz:session:{id}:answers` — предварительные ответы участников
- `quiz:session:{id}:scores` — результаты проверки с баллами
- `quiz:session:{id}:final_answers` — отметки о решающем ответе капитана

Логические атрибуты (session_id, participant_id, answer, is_correct, score) сохранены для понимания модели.
