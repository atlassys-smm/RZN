## Изменения

### ПрофСтарт — полная переработка

Три предзаданных профориентационных теста с фиксированными методиками:

| Код | Тест | Задания | Результат |
|-----|------|---------|-----------|
| `solomin` | Анкета «Ориентация» И.Л. Соломина | 42 утверждения (шкала 0–3) | 7 показателей: «Хочу» + «Могу» |
| `holland` | Тест Дж. Голланда (RIASEC) | 15 ситуаций | 6 типов личности |
| `dellinger` | Геометрический тест С. Деллингер | 1 задание (5 фигур) | 5 геометрических групп |

**Структура:**
- Типы тестов (`profstart_test_types`) — коды solomin/holland/dellinger фиксированы, CMS может создавать дополнительные
- Версии тестов — статусы: draft (1), active (2), archived (3); один active на тип
- Группы результата — общие для всех версий типа (7 групп Соломина, 6 Голланда, 5 Деллингера)
- Связи групп с профессиями — через справочник `Profession`
- Вопросы и варианты — редактируются только в draft

**Прохождение:**
- Одновременно допускается одно прохождение `in_progress`
- Каждый тип можно завершить один раз (независимо от версии)
- Вопросы выдаются по одному в установленном порядке
- Последний ответ автоматически завершает сессию

**Результаты:**
- Завершённая сессия хранит метаданные и ссылку на источник показателей
- Источники неизменяемы после завершения
- Сохранённые результаты не меняются при редактировании CMS

### Рекомендации пользователя

Новая сущность `UserRecommendation` — общий профиль рекомендаций:

- **GET `/api/users/me/recommendations`** — итоговый рейтинг (до 3 профессий)
- Веса источников в коде: Соломин 40%, Голланд 40%, Деллингер 20%
- Рейтинг рассчитывается при каждом запросе из снимков источников (не сохраняется)
- При неполном наборе веса нормируются по имеющимся источникам
- Источник определяется парой `source_module`/`source_code`

**Сущности:**
- `UserRecommendation` — профиль пользователя (один на user_id)
- `UserRecommendationSource` — снимок показателей групп и профессий от источника

### API ПрофСтарт

**CMS:**
- Типы и версии тестов (`/api/cms/profstart/test-types`, `/api/cms/profstart/tests`)
- Группы результатов и связи с профессиями (`/api/cms/profstart/test-types/{code}/groups`)
- Вопросы и варианты (`/api/cms/profstart/tests/{id}/questions`)
- Операторские сессии (`/api/cms/profstart/sessions`) — просмотр и прерывание

**Пользователь:**
- Каталог тестов и возрастные группы
- Список своих сессий и текущая сессия
- Последовательная выдача вопросов
- Запись ответов, прерывание, история результатов
