# Версия 1.14

Дата: 25.09.2026 14:30

---

## Изменения

### API — интерактивное видео (исправления)

- **`branches` в `InteractiveVideoScenarioFull`** — изменён с массива (`type: array`) на объект-дерево (`$ref: InteractiveVideoScenarioBranch`, nullable). Теперь спецификация соответствует реализации: корневая ветка с рекурсивно вложенными дочерними через `children`.
- **DELETE ветки** — добавлен метод `DELETE /cms/video-scenarios/{id}/branches/{branchId}` в спецификацию. Ранее эндпоинт был описан в paths-файле, но не подключён в `openapi.yaml` (не отображался в Scalar).

### Сущности — викторина (GameSession)

- **Добавлен `scoring` (JSON)** — настройки системы начисления баллов, сохраняемые в снапшоте при создании сессии:
  - `partial_correct.enabled` — частичный балл за задания с несколькими правильными элементами
  - `speed_bonus.enabled/coefficient/threshold_percent` — бонус за быстрый ответ
  - `streak_bonus.enabled/step/max` — бонус за серию последовательных правильных ответов
  - `consensus_bonus.enabled/coefficient` — бонус за единогласный ответ команды
  - `final_multiplier.enabled/coefficient` — повышающий множитель финального раунда
  - `penalty.enabled/coefficient` — штраф за неправильный ответ
- **Score поля** — `GameSessionTeam.score`, `GameSessionParticipant.individual_score`, `GameSessionAnswer.score` изменены с `integer` на `decimal` (для поддержки дробных баллов)

### Сущности — пользователи (User)

- **Упрощены статусы** — было 4 статуса (`guest`, `active`, `anonymized`, `deactivated`), стало 2 (`active`, `deactivated`)
- **Гостевой режим** — определяется полями `guest_id` и `guest_expires_at`, не является отдельным статусом:
  - Гость с активной сессией: `guest_id IS NOT NULL AND guest_expires_at > now()`
  - Обезличен: `guest_id IS NOT NULL AND guest_expires_at < now()`
- При первом QR создаётся User со `status = active` (не guest)

### Сущности — таймер

- **Новый файл** `entities/timer-state.md` — единое описание работы таймера для викторины и видеосценариев
- **Упрощена структура Redis** — вместо трёх ключей (`timer_remaining`, `timer_running`, `timer_updated_at`) используется один hash `session:{id}:timer` с полями `ends_at` и `remaining_at_pause`
- Принцип работы: абсолютный timestamp `ends_at`, клиент вычисляет `remaining = ends_at - Date.now()`

### Подсистемы — LED-платформа (викторина)

- **Добавлен раздел «Правила начисления баллов»** — описание механики расчёта: базовые баллы, частичный балл, бонусы (скорость, серия, единогласие), финальный множитель, штраф
- **Обновлены формулы** с учётом `decimal` для баллов

### Подсистемы — идентификация и регистрация

- **Обновлена схема состояний** — упрощена в соответствии с новыми статусами User
- **Уточнена логика гостевого режима** — статус всегда `active`, состояние гостя определяется полями

### Подсистемы — цифровой профиль

- **Обновлено описание гостевого режима** — в соответствии с упрощёнными статусами

### Подсистемы — аналитика (посетители)

- **Уточнения** в описании отображения гостей

### Интерфейсы — административный портал (викторина)

### Концепция

- **Регистрация и профиль** — обновлена схема состояний пользователя
