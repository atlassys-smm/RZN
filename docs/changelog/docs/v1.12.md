## Изменения

### Enum → integer для статусов и типов

Строковые enum-значения заменены на числовые коды (integer) во всех сущностях и API-схемах:

**InteractiveVideoSession / GameSession:**
- `status`: `active`/`finished` → `1`/`2`
- `phase`: `playing`/`voting` → `1`/`2`

**File:**
- `type`: `video`/`image`/`document`/`audio` → `1`/`2`/`3`/`4`
- Поле `type` перемещено перед `module_code` в описании сущности

**User:**
- `oauth_provider`: `yandex`/`vk` → `1`/`2`
- `gender`: `male`/`female`/`unknown` → `1`/`2`/`null` (не указан)
- `status`: `guest`/`active`/`deactivated` → `1`/`2`/`3`/`4` (добавлен `anonymized`)

### Возврат кода сессии для подключения

Откат решения из v1.11 — возвращён числовой код сессии как альтернатива QR-коду для подключения участников.

- `docs/interfaces/led-screen/quiz.md` — добавлена строка «Код сессии» в элементы экрана, обновлено состояние «Ожидание»
- `docs/api/paths/quiz.yaml` — описание `player-join`: «по коду (из QR)»
- `docs/subsystems/led-platform/operator.md` — формирование команд через «QR-код, код, выбор или назначение»
