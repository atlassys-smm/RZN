# Версия 1.48

Дата: 11.11.2026 11:00

---

## Изменения

### Описания и изображения ПрофСтарт (миграция 0091)

Seed-миграция `0091` добавляет описания и изображения для тестов:
- Описания шести групп Голланда и пяти групп Деллинера
- Описания и инструкции тестов Соломина, Голланда и Деллингера
- Пять универсальных изображений (circle/rectangle/square/triangle/zigzag) для групп Деллингера и вариантов ответа
- Обложки тестов (solomin-test.jpg, golland-test.jpg, dellinger-test.jpg) заменяют media_id всех существующих версий
- Изображения групп Голланда пока не заданы; существующие media_id сохраняются
- Откат не восстанавливает прежние тексты и ссылки

### Запуск видеопоказа с устройства

`POST /api/interactive-video/sessions` и `POST /api/interactive-video/sessions/{id}/stop` принимают Device JWT:
- Активное устройство с ролью `QUIZ_VIDEO=1` наряду со staff access-токеном
- Устройство запускает показ только на собственном `device_id`
- Остановка только собственной сессии
- Чужие устройства/сессии и неподходящие роли — 403

### Завершение викторины с LED

`POST /api/quiz/sessions/{id}/finish` доступен устройству:
- Device JWT с ролью `QUIZ_VIDEO=1` для собственной сессии
- Наряду с оператором/администратором
- Логика завершения, статусы и события сохраняются

### Отдельный этап итогов викторины

Новый статус `GameSessionStatus.RESULTS=4`:
- После раскрытия последнего ответа `/next` и `/led/next` открывают показ итогов
- Сокет сессии получает `results_started`, затем `session_state`
- Сокет устройства получает `results_started` с module=quiz
- Баллы и Redis сохраняются до finish
- В results сессия доступна через /active и занимает устройство
- Из results доступен один дополнительный финал по can_start_final_round с возвратом в active
- /finish сохраняет завершение и перенос рекомендаций

### Результат последнего голосования видеосессии

Поле `last_voting_result` в состоянии сессии:
- `null` до первого завершённого голосования
- Содержит scenario_id, voted_count, votes (branch_id/text/count), winner_branch_id, auto_selected
- Снимок формируется при закрытии по таймеру либо последнему голосу
- Сохраняется при следующих переходах, заменяется при следующем закрытии
- Данные в Redis; при потере Redis итог не восстанавливается

### Форматы вопросов викторины

Реорганизация типов вопросов:
- Типы 7, 12 переведены на сопоставление `pairs` (matching)
- Типы 11, 14, 15, 16, 18 — на один вариант `option_id` (single)
- Типы 8, 9, 17 остаются single с медиа вопроса
- Тип 10 — порядок (sorting)
- Текстовых типов больше нет; поля text сохранены
- Одно text без структурированного ответа не считается правильным
- Для сопоставления частичный балл учитывает верные пары
- Тип 14 больше не получает частичные баллы
- Правильные ответы бывших текстовых типов учитываются в рекомендациях
- Кэш эталонов переключён на новую версию ключа

### Первоначальное заполнение банка ПрофСтарта

Миграция `0048` при первоначальном заполнении:
- Создаёт тесты solomin, holland, dellinger сразу активными (`status=2`)
- Задаёт `published_at` текущим временем БД
- Существующая версия 1 пропускается
- На БД, где `0048` уже применена, изменение её исходного кода не меняет статусы
