## Изменения

### Конструктор рекомендаций для сотрудника

HTML-страница `/recommendations_constructor` для интерактивного подбора весов тестов.

**Вход:**
- POST `/api/recommendations_constructor/login` — проверка email/пароль сотрудника
- Возвращает access_token без refresh_cookie
- Токен хранится в памяти вкладки, после перезагрузки нужен повторный вход
- Доступ: admin/operator/editor

**Предпросмотр:**
- POST `/api/recommendations_constructor/preview` — расчёт рекомендаций с выбранными весами
- Параметры: `user_id`, `weights` (solomin/holland/dellinger, 0–100)
- Веса действуют только в этом запросе, не меняют SOURCE_WEIGHTS
- Вызывает тот же сервис `get_recommendations`, что пользовательский API
- Возвращает до 3 профессий, до 5 работодателей, 5 учебных заведений, 5 направлений

**Интерфейс:**
- Компактная верхняя панель, параметры и колонки категорий
- Все категории одновременно: вклад тестов, недостающие результаты, профессии, работодатели, учебные заведения, направления
- Карточки свёрнуты по умолчанию, кнопка «Раскрыть все / Свернуть все»

### Загрузка набора викторины

Файл `app/data/quiz/professions_bank.json` — 30 профориентационных вопросов:
- 20 одиночного выбора (`question_type=1`)
- 10 мультивыбора (`question_type=2`)
- Возрастная группа: 12–14 лет (`age_group=1`)
- Пояснения и варианты ответов для каждого вопроса

**Два шаблона:**
- «Мир профессий: техника и цифровые технологии» — 10 одиночных + 5 мультивыбора
- «Мир профессий: люди, природа и город» — 10 одиночных + 5 мультивыбора
- По 3 раунда: «Быстрый старт», «Инструменты», «Навыки»
- Загружаются опубликованными (`status=2`)

**CLI загрузчик:**
- `python -m app.cli.load_quiz_bank` — загрузка в базу
- `--check` — проверка JSON без подключения к БД
- `--path` — другой JSON файл
- Атомарная загрузка, повторяемая без дублей
- Параллельные запуски сериализуются advisory-блокировкой
- Откат при конфликте с существующим контентом
