# Версия 0.21

Дата: 26.10.2026

- Добавлена команда `docker compose exec -T api python -m app.cli.simulate_quiz`:
  создаёт гостя, проходит все вопросы индивидуальной викторины, завершает игру
  и проверяет итоговый рейтинг. Управление выполняется от имени администратора,
  ответы отправляются с токеном гостя; все действия проходят через HTTP API.
- В `.env.example` добавлены DEMO_ADMIN_LOGIN, DEMO_ADMIN_PASS и DEMO_API_URL.
  Поддержаны явный или случайный опубликованный шаблон, подбор активного
  свободного QUIZ_VIDEO-устройства и автоматический выбор действующего согласия.
- Добавлены стратегии correct/random, seed, прогресс и JSON-отчёт, включая ошибки.
  Отчёт можно сохранить на хосте через существующий bind mount контейнера API.
- Общий HTTP-клиент подготовлен для demo-команд остальных модулей. Добавлены
  десять независимых проверок HTTP-сценария без подключения к БД и Redis.
  Обновлена документация; API и миграции не менялись.


- Добавлена команда `docker compose exec -T api python -m app.cli.simulate_profstart`:
  один новый гость последовательно проходит все активные тесты ПрофСтарта через API.
  Поддержаны выбор одного или нескольких тестов, random/first, seed и JSON-отчёт.
  Используются общие DEMO_ADMIN_LOGIN, DEMO_ADMIN_PASS и DEMO_API_URL; устройство
  не требуется для прохождения с User JWT. Проверяются каждый принятый ответ,
  автоматическое завершение, сохранённые результаты, история и общий профиль
  рекомендаций. Добавлены независимые HTTP-проверки и документация;
  маршруты API и миграции не менялись.

- В demo-команду ПрофСтарта добавлен --test-code: один код типа или список через
  запятую. Типы читаются из CMS-справочника profstart_test_types; выбираются
  активные ID тестов в указанном порядке. Ошибки выбора обнаруживаются до
  создания гостя; --test-id и --test-code взаимно исключаются. Обновлены
  документация и независимые HTTP-проверки выбора и форматов параметра.


- Добавлена команда `docker compose exec -T api python -m app.cli.simulate_video`
  для «Профессий в действии»: создаёт гостя и сессию, получает Device JWT через
  API, отправляет голоса гостя и выполняет переходы LED до штатного завершения.
  Поддержаны один или несколько ID сценариев через запятую, случайная подборка,
  свободное QUIZ_VIDEO-устройство, random/first, seed и JSON-отчёт. Учтены
  ссылочные ветки и маршруты без повторных вопросов; сценарии без выбора
  завершаются без голосов. Общий клиент корректно закрывает только staff/user
  AuthSession. Добавлены независимые HTTP-проверки и документация.
  Маршруты API, данные контента и миграции не менялись.


- Добавлена команда `docker compose exec -T api python -m app.cli.simulate_feedback`:
  создаёт гостя, начинает и заполняет активную анкету, затем проверяет сохранённые
  ответы через CMS API. Поддержаны пять типов вопросов, условия показа,
  random/first, seed, выбор анкеты и FEEDBACK-устройства, source_id и JSON-отчёт.
  Используются общие DEMO-переменные и отдельные клиенты администратора, гостя
  и устройства. Start/respond сохраняют один response_id; запрос проверки
  ограничен новым гостем. Добавлены независимые HTTP-проверки и документация.
  API, существующие анкеты и миграции не менялись.


- При ручной остановке «Профессий в действии» оператором/администратором
  через `/interactive-video/sessions/{id}/stop` событие session_finished
  отправляется в сокет устройства и всем подключениям сокета самой сессии.
  Повторный stop не дублирует уведомления; естественное завершение сохраняет
  прежнюю рассылку. Отключённые сокеты сессии удаляются без прерывания рассылки.
  Добавлены независимые REST-проверки обоих каналов, повторов, конкуренции,
  естественного завершения и отключённых клиентов; обновлена документация WebSocket.

- В `PATCH /api/user/info` добавлены пол (`gender`: 1/2) и дата рождения
  (`birth_date`: YYYY-MM-DD), в том числе для гостей. Пропущенные поля
  сохраняются, `null` очищает пол или дату; ограничения имени и фамилии
  сохранены. GET/PATCH возвращают оба поля. Обновлены OpenAPI и документация;
  добавлены независимые проверки API. Миграция не требуется.

- Период по умолчанию в 61 карточке аналитики Metabase сокращён с 30 до 7
  календарных дней, включая текущий, по МСК. Обновлены SQL, описания и
  документация; сравнение рассчитывается с предыдущими 7 днями. Топ-5
  личных результатов викторины сохраняет выборку за вчерашний день.
