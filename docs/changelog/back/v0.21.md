# Версия 0.21

Дата: 26.10.2026

- В CMS веток видеосценариев добавлен необязательный `reference_branch_id` на существующую ветку того же сценария. Ссылочная ветка сохраняет свой текст ответа и не требует видео. Поле возвращается в ответах веток и дереве.
- После выбора ссылки backend сразу переходит к конечной цели цепочки, используя её видео, вопрос и дочерние варианты. Позиция цели сохраняется для восстановления после потери Redis. Голоса учитываются за исходный вариант.
- Добавлены проверки цели и циклов, в том числе через обычные переходы. Ссылочные ветки — дочерние листья; стартовая ветка остаётся обычной. В PUT отсутствие поля сохраняет ссылку, пустое значение снимает её при наличии собственного видео.
- Проверка циклов с ошибкой 400 выполняется при сохранении в CMS. Во время показа обход циклических ссылок завершается без ошибки: используется последнее встреченное собственное видео или повторяется текущая ветка, если у ссылок видео нет. Добавлены API-проверки самоссылки, замкнутой цепочки и возврата к предыдущему видео.
- Миграция PostgreSQL 0081 добавляет nullable-ссылку и индекс, разрешает nullable `media_id`; существующие ветки не изменяются. Удаление сценария учитывает внутренние ссылки.
- Обновлены исходные схемы OpenAPI, описание CMS и сущности. Добавлены API-тесты ссылочных веток, переходов по таймеру и досрочному голосованию, цепочек, общего поддерева и восстановления.
