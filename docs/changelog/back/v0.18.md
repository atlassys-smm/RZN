# Версия 0.18

Дата: 22.10.2026

- Направления подготовки уникальны по точному сочетанию name, education_level, duration,
  base_class. NULL в base_class участвует в уникальности; близкие названия не объединяются.
- Новая таблица organization_education_programs связывает общее направление с несколькими
  учебными заведениями. Уровень, срок и база приёма остаются в education_programs.
- Миграции 0077–0079 создают связи организаций, переносят данные
  и устанавливают ограничения уникальности. Применённые старые миграции не изменяются.
  profession_education_programs.education_program_id и его FK/индекс сохраняются;
  повторные пары профессия/объединённое направление сводятся к одной строке.
- Профессия связана с общим направлением независимо от организации. Рекомендации
  и /professions/{id}/educations включают все учебные заведения этого направления.
  Отвязка одной организации не изменяет связь профессии с направлением.
- CRUD направлений больше не принимает и не возвращает organization_id. Для связей
  добавлен /organizations/education-programs/links с полным CRUD. Создание связи
  профессии с направлением не требует наличия организаций.
- Удаление общего направления мягко удаляет его связи с организациями и профессиями.
  POST удалённого сочетания или пары восстанавливает ID без восстановления зависимых связей.
- Обновлены регрессионные API-проверки, документация и исходный/bundled OpenAPI.
- downgrade миграций 0078–0079 выводит сообщение в консоль вместо RuntimeError
  и не выполняет обратное преобразование схемы и данных. Для уточнения связи
  профессии новая ревизия не создавалась.
- В /users/me/recommendations и /organizations/recommendations добавлен отдельный
  массив education_programs: до пяти направлений по профессиям, без дублей по организациям.
  Направления ранжируются по числу различных совпавших профессий и ID, с сохранением
  покрытия профессий; наличие связей с организациями не требуется.
- Миграция 0080 добавляет nullable organizations.media_id, внешний ключ на files.id и индекс.
- POST/PUT организаций поддерживают загрузку файла и превью в multipart/form-data;
  PUT без файла сохраняет текущее вложение.
- file с подписанными ссылками и метаданными возвращается во всех ответах организации,
  включая рекомендации и организации по профессии. Без вложения возвращается null.
- Используется общий механизм файлов: модуль organizations, создание превью видео,
  общая транзакция и очистка новых загрузок при ошибке.
- Добавлены API-проверки загрузки, замены, выдачи файла, работы полей формы и отката;
  обновлены исходный и bundled OpenAPI.
