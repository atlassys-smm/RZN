# 0.49 — Обновление справочника профессий

25.11.2026

- Миграция `0108` обновляет названия, перспективы и зарплаты профессий из нового справочника с сохранением ID.
- Программы обучения объединяются по названию, уровню, сроку и базе приёма. Связи учебных заведений и профессий обновляются по новому справочнику. Устаревшие связи предыдущей загрузки помечаются удалёнными.
- Новые рекомендации по обучению учитывают активные программы, учебные заведения и связи.
