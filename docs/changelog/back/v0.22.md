# Версия 0.22

Дата: 27.10.2026

- Добавлен источник рекомендаций professions/views с относительным весом 5.
  group_scores содержит profession_id и накопленное количество просмотров;
  profession_scores — оценки 100 × просмотры / максимум и основания.
- Просмотры читаются из ClickHouse с правами reader: первый импорт за 30 суток,
  далее строго при возрасте более 6 часов — события [updated_at, начало выборки).
  Интервалы UTC с точностью до миллисекунд; старые счётчики сохраняются.
- Миграция 0083 добавляет updated_at источника; прежние записи получают created_at.
  Успешная пустая выборка кэшируется; ошибки не меняют счётчики и курсор.
  Конкурентные обновления одного пользователя сериализованы.
- Просмотры необязательны для полноты и не влияют на рейтинг при пустом снимке.
  В API источника добавлен updated_at; конструктор поддерживает отдельный вес views.
  Обновлены исходный OpenAPI, документация и проверки API, включая конкуренцию.
- Подключения ClickHouse для чтения и записи вынесены в отдельный сервис
  app/services/clickhouse/service.py; HTTP-запросы чтения и обработка сетевых
  ошибок не зависят от источника рекомендаций. SQL просмотров остаётся в
  user_recommendations, доставка аналитики использует общую фабрику writer.
- Стандартные веса приведены к сумме 100: Соломин 40, Голланд 40,
  Деллингер 15, просмотры 5. Обновлены конструктор, OpenAPI и проверки расчёта.
- В состоянии интерактивного видео current_branch.file возвращает общий объект
  файла (url, preview_url, mime_type, title, description) либо null вместо
  media_url с внутренним путём. Формат приведён к существующему контракту OpenAPI;
  обновлены проверки состояния и переходов по ссылочным веткам.

- Добавлен GET /api/interactive-video/scenarios: все сценарии по ID без пагинации,
  с first_branch и объектом первого файла в формате списка сценариев сессии.
  Выборка выполняется одним запросом; без ветки/файла возвращается null.
  Доступен admin/operator и активному устройству с ролью QUIZ_VIDEO.
  Обновлены OpenAPI, документация и проверки списка, файлов и доступа.
