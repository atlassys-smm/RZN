## Инфраструктура

- Добавлена папка `changelog/` для ведения истории изменений

- Перед PR в `master` разработчик добавляет запись в changelog
- Дата берётся из времени последнего коммита в ветке
- Секции: API, Модели, Инфраструктура, Исправления (только применимые)
