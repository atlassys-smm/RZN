# Версия 0.13

Дата: 16.10.2026

---

## Викторина

- Вместо `auto_reveal` и `auto_next` используются nullable-задержки `auto_reveal_delay`, `auto_next_delay`, `between_rounds_delay`: `null` отключает действие, `0` выполняет его сразу, положительное число задаёт ожидание в секундах. Удалённые флаги и отрицательные задержки отклоняются API.
- В запросах создания сессии явный `null` сохраняется; пропущенные поля наследуются из CMS. В обновлении стандартных настроек пропущенные поля остаются без изменений.
- Задержки отсчитывает клиент перед вызовом API. Новые проверки времени на бэкенд не добавлены, дополнительные временные метки в Redis не сохраняются. Между раундами используется только `between_rounds_delay`; сессию после последнего вопроса завершает оператор.
- Миграция `0058` переносит стандартные настройки и JSON-снимки существующих сессий: включённый автопоказ становится задержкой `0`, выключенные действия — `null`, включённый автопереход сохраняет свою задержку. Старые флаги удаляются после переноса. Миграция требует применения перед использованием обновлённого API.

- При переносе капитана оператором новый капитан старой команды выбирается случайно из оставшихся участников; у опустевшей команды `captain_id` становится `null`.
- В целевой команде без капитана роль получает перенесённый участник; действующий капитан сохраняется. Перенос и назначения сохраняются одной транзакцией, конкурирующие операции состава сессии выполняются последовательно.
- После переноса отправляется только `participant_team_changed`; клиент по нему обновляет составы и капитанов команд. Повторный перенос в ту же команду не меняет состояние и не отправляет события; заполненная целевая команда отклоняет перенос без изменений.
