# 0.31 — Начальные шаблоны аватаров профессий

06.11.2026

- Подготовлена seed-миграция 0090: 19 пар мужских и женских шаблонов аватаров.
  Активные профессии связываются по полному названию, используются фактические ID БД.
- При отсутствии активных профессий создаются «Военнослужащий», «Крановщик»
  и «Пилот» с кратким названием и отраслью. Выбранные отрасли соответственно:
  «Экономика, право и безопасность», «Строительство и архитектура»,
  «Транспорт и логистика». Фактические ID отраслей определяются по названиям.
  Существующие активные профессии используются без изменения полей.
- Все 38 JPG сохранены в `app/migrations/data/profession/images`.
  Сопоставления, отрасли и причины выбора вынесены в `avatar_templates.json` и README.
- Ревизия 0090 обновлена по запросу пользователя без создания новой миграции:
  38 картинок из `avatars_generation` загружаются как основные, первоначальные
  38 картинок — как превью в `file_preview_path`. Основные исходники сохранены
  в `app/migrations/data/profession/images/originals/{male,female}`.
- У всех 19 сопоставленных шаблонов, включая существующие, заменяются ссылки
  на мужской и женский файлы. Старые записи и физические файлы сохраняются
  для ранее созданных аватаров. Повторный запуск не создаёт дубликатов.
- Откат этой seed-миграции не удаляет профессии, записи и изображения.

- Исходники превью перенесены в `app/migrations/data/profession/images/preview/{male,female}`.
