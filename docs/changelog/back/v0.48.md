# 0.48 — Сохранение рекомендаций и отчёт по карьерным маршрутам

25.11.2026

- Последняя персональная подборка хранится в `user_recommendations_result`.
- Новый источник, изменение `updated_at` источника, весов или справочников и
  истечение суток запускают пересчёт при запросе рекомендаций.

- Добавлены отчёты по сохранённым рекомендациям за выбранную неделю или месяц в JSON и PDF.
- В карьерный трек попадают посетители, у которых были действия в выбранном периоде.
- Отдельно рассчитываются охват участников и доля маршрутов с учётом баллов
  профессий. Организации ранжируются отдельно для обучения и работы.
- Границы календарных периодов совпадают с основным аналитическим отчётом.
- Распределение по зарплатным диапазонам доступно в JSON и PDF.
- Карточки профессий используют исходные границы зарплаты из `salary_range`.
- Администратор и аналитик могут запросить рекомендации конкретного пользователя по `user_id`.
