# 0.41 — Справочник типов анкет

18.11.2026

- Добавлен справочник `survey_types` с полями `id`, `name` и `deleted_at`.
  CMS позволяет получать список и отдельный тип, создавать, переименовывать и удалять типы.
- При активной анкете удаление её типа возвращает `409`. Мягкое удаление сохраняет тип,
  старые анкеты, ответы и связи с модулями. Удалённые типы доступны для просмотра истории.
  Публикация и удаление блокируют одну запись типа, чтобы проверка действовала при одновременных запросах.
- Миграции `0101–0103` создают справочник, сохраняют ID `1` для «Оценки качества» и добавляют
  внешние ключи на тип для анкет и связей с модулями. Поля `type` и `survey_type` остаются числовыми.
- В пользовательских списке и получении анкеты по ID добавлен `completed` для
  текущего пользователя и версии анкеты. Список поддерживает фильтр `type`,
  который можно сочетать с `module_id`.
- LED получает анкеты после QR-привязки через общий список с фильтром `type`.
  Отдельный маршрут `GET /api/feedback/surveys/type/{type}` удалён.
