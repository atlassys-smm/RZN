# 0.46 — Доступ устройств к анкетам и настройки экрана

24.11.2026

- Любое активное устройство может читать анкеты, начинать прохождение и
  отправлять ответы независимо от назначенных ролей.
- Для доступа по Device JWT требуется действующая QR-привязка пользователя.
  Роль `FEEDBACK` (4) по-прежнему доступна при настройке устройства.
- Миграция `0106` добавляет настройку экрана `runVideoScenario` со значением
  `true` по умолчанию. Она доступна для чтения и изменения через `/api/cms/led/settings`.
