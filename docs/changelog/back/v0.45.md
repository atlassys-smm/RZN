# 0.45 — Внешние события и анкеты Unity-модулей

23.11.2026

- Добавлена роль устройства `EXTERNAL_APPS` с кодом 5. Её можно назначить
  при регистрации устройства или при обновлении его ролей в CMS.
- `POST /api/analytics/external/events` принимает Device JWT активного
  устройства с этой ролью или access-токен сотрудника с ролью `ADMIN`.
  События с Device JWT записываются с ID устройства и доступны в фильтре сводки.
- Типы анкет можно привязывать к «Древу профессий» (7), интерактивной карте
  региона (8), Профбаттлу (9) и «Конструктору карьеры» (16).
- Аналитика «Интерактивной карты» принимает открытия объектов и выбор территорий,
  использует числовые коды категорий и территорий и считает рейтинги по ID организаций.
- Профбаттл отправляет старт кейса и достижение результата. Дашборд считает
  сессии по режимам, длительность, долю завершённых и уникальных пользователей с
  фильтрами по периоду, режиму игры и коду кейса.
- В истории посетителя события Древа, Карты и Профбаттла объединяются в
  сессию по внешнему UUID. Доступны статус и длительность прохождения.
- `POST /api/auth/user/service` выдаёт служебные аккаунты четырём Unity-модулям.
  Миграция 0105 добавляет по пять аккаунтов на модуль и переименовывает
  служебные аккаунты в «Анонимный Пользователь». При входе это имя восстанавливается.
  Сброс аккаунта удаляет из PostgreSQL его прохождения анкет и ответы, включая
  незавершённые прохождения. События аналитики обратной связи в ClickHouse сохраняются.
- Рекомендации учитывают открытия профессий в «Древе», если известны ID профессии
  и пользователя.
