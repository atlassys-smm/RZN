# Версия 0.11

Дата: 12.10.2026

---

## Голосование викторины в состоянии сессии

- `GET /quiz/sessions/active` и `GET /quiz/sessions/{id}` поддерживают `select=answers`.
  В ответ добавляется корневой блок `answers` с `participant_answers`, `team_answers`
  и `option_counts`. Без параметра блок отсутствует и дополнительные данные голосования
  не загружаются. До старта и после завершения игры `answers=null`.
- Пользователь в командной игре видит голоса и решающий ответ своей команды;
  в индивидуальной игре — ответы участников этой сессии. Сотрудник видит все команды.
  LED получает общие счётчики и статусы команд без содержимого ответов.
- `participant_count` считает текущие голоса участников, включая капитанов;
  `team_count` — голоса капитанов команд. Один голос учитывается один раз на вариант.
- `team_answers` отображает текущий ответ капитана, `submitted` означает наличие его ответа.
  Отдельного хранения решающих ответов нет; отправка с `is_final=true` заменяет голос капитана.
- Сохранены исходные обработка отправки ответов, Redis-маркеры и начисление баллов:
  в командной игре учитывается текущий голос капитана, в индивидуальной — ответы участников.
- Участники и команды загружаются списками; `select=teams&select=participants`
  использует те же данные, без повторных SELECT. Существующие WebSocket-события остаются
  уведомлениями только с полем `type`.
- Обновлены исходный и собранный OpenAPI, инструкции мобильного клиента, LED и оператора.
  Добавлены API-проверки выбора данных, видимости, типов ответов, перехода к следующему
  вопросу, начисления баллов и повторного использования списков.
- В ответах CMS с шаблонами викторины вопросы раундов дополнены полями `text`, `difficulty`, `age_group` и `points` из банка вопросов.
