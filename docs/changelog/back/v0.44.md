# 0.44 — События внешних терминалов

20.11.2026

- `POST /api/analytics/external/events` принимает события «Древа профессий»
  (`module_id=7`) и «Конструктора карьеры» (`module_id=16`). Код события
  передаётся целым числом от 0 до 65535.
- «Древо профессий» передаёт начало сеанса (1), открытие карточки (11) и
  подтверждённое завершение (4). API сохраняет `payload.profession_code` и
  добавляет `profession_id` и `profession_name` из справочника при сопоставлении.
- Необязательный `user_id` из запроса сохраняется в колонке `analytics.events.user_id`.
- UUID внешнего сеанса передаётся в поле `session_id` и сохраняется в
  `analytics.events.external_session_id` и `payload.session_id`.
- Дашборд «Древа профессий» рассчитывает сессии, время, долю завершения,
  уникальных пользователей и открытия профессий по ID из справочника.
- Если известный код Unity из словаря не сопоставился с единственной активной
  профессией, API сохраняет событие и пишет предупреждение.
- «Конструктор карьеры» передаёт старт, ответ, результат и прерывание
  прохождения. Ответы одного этапа входят в одно событие с массивом `answers`.
- Требования к авторизации маршрута изменены в [версии 0.45](v0.45.md).
- API возвращает `202` после постановки события в общую очередь аналитики.
  Запись в ClickHouse работает в фоне. Сервер назначает новый UUID события
  каждому принятому запросу. При недоступности или заполнении очереди API возвращает `503`.
