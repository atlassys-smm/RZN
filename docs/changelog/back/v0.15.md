# Версия 0.15

Дата: 20.10.2026

## Чтение групп ПрофСтарт пользователем

- Добавлены GET `/api/profstart/test-types/{test_code_type}/groups` и GET `/api/profstart/test-types/{test_code_type}/groups/{group_id}` для отображения информации о группах на экране результата.
- Используются существующие сервисы и схемы CMS: список с пагинацией и карточка группы; неизвестный тип или группа другого типа возвращают 404.
- Чтение доступно по User JWT (включая гостя) и Device JWT активного устройства с ролью ПрофСтарт (3), без QR-привязки. Добавлены API-тесты получения данных и авторизации. Миграции не требуются.

## Изображения тестов и групп ПрофСтарт

- Две отдельные миграции: `0063` добавляет nullable `media_id` и FK на `files` в `profstart_tests`, `0064` — в `profstart_test_groups`. Существующие записи получают null, данные сохраняются.
- Создание и PATCH тестов и групп в CMS переведены на multipart/form-data по образцу вопросов викторины: `file`, `file_preview`, `file_title`, `file_description`; `age_group_ids` передаётся JSON-массивом в текстовом поле.
- Все ответы с тестами и группами в CMS и пользовательских маршрутах содержат объект `file` с подписанными ссылками и метаданными или null. При копировании теста сохраняется ссылка на файл; PATCH без нового файла сохраняет вложение. Превью без нового файла возвращает 422; при ошибке новые файлы откатываются вместе с транзакцией.
- Обновлены схемы и исходный OpenAPI, описания сущностей и API-тесты загрузки, замены, чтения и сохранения изображений.

## Возрастные группы в коде

- Таблица age_groups и её ORM-модель заменены enum AgeGroup: 1 — 12–14 лет, 2 — 15–17 лет. Каждое значение хранит id, name, min_age и max_age.
- Миграция 0065 удаляет таблицу age_groups. Внешних ключей на неё нет; значения age_group_ids тестов и age_group вопросов викторины не переносятся и не изменяются.
- Пользовательский и CMS-справочники сохраняют маршруты и формат ответов; список и проверка неизвестных/повторяющихся ID используют enum без запросов к таблице.
- Фикстуры больше не создают записи age_groups. Обновлены затронутые API-тесты и документация.

## Каталог ПрофСтарт и статус прохождения

- GET `/api/profstart/tests` по умолчанию возвращает все активные тесты, включая завершённые и тесты без сессий.
- Добавлен фильтр `session_status=1/2/3` и одноимённое nullable-поле в элементах каталога. Статус берётся из последней сессии текущего пользователя по типу теста среди всех версий по started_at DESC, id DESC; сессий этого типа нет — null. При смене активной версии сохраняется статус прохождения типа.
- Сессии других пользователей и типов не учитываются; архивные версии того же типа учитываются. Устройство без QR-привязки получает null и пустой список при фильтре статуса; с привязкой используется история подключённого пользователя. Поле status сохраняет состояние публикации версии. Правила повторного старта не меняются; миграции не требуются.
- Обновлены OpenAPI, описание прохождения и целевые API-тесты каталога и персонализации устройств.

## Список вопросов сессии викторины для оператора

- Добавлен GET `/api/quiz/sessions/{session_id}/questions` для admin/operator: все вопросы всех раундов сессии в порядке раундов и вопросов, включая добавленный финальный раунд. Возвращаются ID записи сессии и исходного вопроса, текст, данные раунда и порядка.
- Вычисляемый GameSessionQuestionStatus: 1 — пройден, 2 — текущий, 3 — будущий. До старта все вопросы будущие; pause/reveal/stop сохраняют текущий вопрос до перехода. После досрочного finish не показанные вопросы остаются будущими, текущий становится пройденным. Завершение до старта оставляет все вопросы будущими.
- GET не меняет состояние игры, повторения одного вопроса сохраняются отдельными элементами. Обновлены OpenAPI, описание интерфейса оператора, сущности и целевые API-тесты. Миграции не требуются.
