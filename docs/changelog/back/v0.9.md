# Версия 0.9

Дата: 07.10.2026

---

## ПрофСтарт

Реализовано управление профориентационными тестами и их прохождение. Расчёт результатов поддерживает `solomin`, `holland` и `dellinger`; дополнительные типы доступны для управления в CMS.

- CMS управляет типами, версиями, группами, вопросами, вариантами ответов с весами и связями профессий. Вопросы и варианты поддерживают загрузку файлов.
- Версии имеют статусы `draft`, `active`, `archived`. Вопросы и варианты редактируются только в черновике. Публикация проверяет состав и архивирует предыдущую активную версию того же типа; копирование создаёт новый черновик.
- Группы и связи профессий общие для всех версий типа и редактируются независимо от статуса теста. Основные коды и категории групп защищены; код группы уникален внутри типа. Изменения применяются к новым результатам.
- Возрастные группы задают доступность тестов. Начальные диапазоны — 12–14 и 15–17 лет; версия может быть доступна без возрастных ограничений.
- Пользователь получает каталог, список своих сессий и текущую сессию. Одновременно допускается одно прохождение `in_progress`; каждый тип можно полностью пройти один раз, независимо от версии. Вопросы выдаются по одному в установленном порядке; начатую архивную версию можно продолжить.
- Последний ответ автоматически завершает сессию и сохраняет результат. Повтор принятого ответа не меняет прогресс, пока сессия `in_progress`. Доступны прерывание, отдельное получение результата и история.
- Результат содержит показатели групп и рекомендации профессий. У Соломина «Хочу» и «Могу» объединяются в семь показателей; профессии с неполной парой `subject`/`labor` не рекомендуются. Сохранённые результаты не меняются при редактировании CMS.
- Общий профиль пользователя хранит до трёх рекомендаций и обновляется после завершения нового типа или изменения весов CMS. Неизменяемые источники сохраняют показатели всех групп в JSON и соответствие профессиям; общий подбор учитывает также неведущие группы. Веса типов — по умолчанию 40/40/20%, сумма — 100%; при неполном наборе они нормируются, а вес 0 отключает влияние. Основной маршрут — `/api/users/me/recommendations`; совместимое представление ПрофСтарта сохранено.

Миграции `0037–0052` создают таблицы модуля, общий профиль рекомендаций, справочник возрастов и начальный банк трёх тестов с изображениями Деллингера. Тесты создаются черновиками; связи профессий задаются через CMS, затем проверяется готовность состава.

Пользовательские маршруты проверяют Bearer-токен и владельца данных. Отдельная проверка административных прав в backend CMS отсутствует.

## Временный маршрут авторизации

GET `/api/auth/{id}` выдаёт JWT существующего пользователя без авторизации. Маршрут предназначен для тестирования и должен быть удалён перед запуском в production.
