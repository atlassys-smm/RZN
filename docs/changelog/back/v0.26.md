# 0.26 - PDF-отчет аналитики

28.10.2026

- GET /api/analytics/report?period=week|month для ADMIN и ANALYST.
- 11 страниц: графики из существующих SQL Metabase, сравнение с предыдущим
  календарным периодом в абсолютных значениях, процентах и п.п.
- Явная отметка неполного текущего периода и нулевой базы;
  сбой ClickHouse возвращает 503.
- Векторные графики, шрифты DejaVu, ReportLab; исходные данные не меняются.

- Палитра PDF согласована с сайтом: #0050AA, #5AB4E6 и #E65028.
- Русские имена скачиваемых отчетов с периодом и датой; UTF-8 filename* в Content-Disposition.
- Выбор через обязательные period и date вместо number/year: с начала недели
  или месяца до выбранной даты включительно, сравнение с предыдущим полным периодом.
- Весь выбранный день учитывается целиком, включая сегодняшнюю дату;
  даты в PDF, отметка формирования и русские имена файлов выводятся без времени.
- Увеличены шрифты таблиц, основного текста, подписей графиков и пояснений.
- В конце добавлена текстовая аналитическая справка: поведенческий портрет аудитории,
  интересы, качество взаимодействия и условный сценарий числа сессий на следующий период.
  При отсутствии данных портрет и численный прогноз не формируются.
- Аналитическая справка изложена через наблюдаемые результаты, практические приоритеты и прогноз без оценок ограничений сравнения.
- Итоговая справка посвящена группе участников: профессиональные интересы, вовлеченность,
  результаты ПрофСтарта и возможные образовательные и карьерные траектории.
  Прогноз количества сессий заменен перспективами профессионального развития;
  возрастная рамка обозначена как сценарий целевой аудитории.
- В текст существующей страницы выводов добавлен фактический состав участников по полу и возрасту.
  Сведения берутся из профилей уникальных посетителей выбранных периодов; возраст рассчитывается
  на последнюю дату каждого периода. В выводах указаны преобладающие пол и возрастная группа;
  сценарный возраст заменен фактическими сведениями; в тексте используются только заполненные поля.

## 30.10.2026 — Пользовательское чтение анкет

- Добавлены GET /api/feedback/surveys и GET /api/feedback/surveys/{survey_id}
  в группе «Обратная связь - Пользователь».
- Список с limit/offset и получение по ID используют существующий сервис анкет,
  возвращают только активные анкеты с вопросами и вариантами ответов.
- Доступ по User JWT либо Device JWT с ролью 4 и действующей QR-привязкой;
  отсутствующие и неактивные анкеты по ID возвращают 404.
- Обновлены исходный и bundled OpenAPI. LED-запрос по типу перенесён на /api/feedback/surveys/type/{type}.
  Клиенты LED должны использовать новый URL.
- simulate_feedback получает список и вопросы анкеты по User JWT созданного гостя
  через GET /api/feedback/surveys и GET /api/feedback/surveys/{survey_id}.
  Подбор FEEDBACK-устройства, выпуск Device JWT и параметр --device-id удалены;
  source_id по умолчанию — demo-feedback-user-<user_id>.
- Гость создаётся перед чтением анкеты; валидация вопросов выполняется до start.
  Администратор проверяет сохранённые ответы; весь поток заполнения использует User JWT.
