# 0.26 - PDF-отчет аналитики

28.10.2026

- GET /api/analytics/report?period=week|month для ADMIN и ANALYST.
- 11 страниц: графики из существующих SQL Metabase, сравнение с предыдущим
  календарным периодом в абсолютных значениях, процентах и п.п.
- Явная отметка неполного текущего периода и нулевой базы;
  сбой ClickHouse возвращает 503.
- Векторные графики, шрифты DejaVu, ReportLab; исходные данные не меняются.

- Палитра PDF согласована с сайтом: #0050AA, #5AB4E6 и #E65028.
- Русские имена скачиваемых отчетов с периодом и датой; UTF-8 filename* в Content-Disposition.
- Выбор через обязательные period и date вместо number/year: с начала недели
  или месяца до выбранной даты включительно, сравнение с предыдущим полным периодом.
- Весь выбранный день учитывается целиком, включая сегодняшнюю дату;
  даты в PDF, отметка формирования и русские имена файлов выводятся без времени.
- Увеличены шрифты таблиц, основного текста, подписей графиков и пояснений.
- В конце добавлена текстовая аналитическая справка: поведенческий портрет аудитории,
  интересы, качество взаимодействия и условный сценарий числа сессий на следующий период.
  При отсутствии данных портрет и численный прогноз не формируются.
- Аналитическая справка изложена через наблюдаемые результаты, практические приоритеты и прогноз без оценок ограничений сравнения.
