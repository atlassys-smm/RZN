# Версия 0.17

Дата: 22.10.2026

## Заставки LED

- Добавлена таблица `led_screensavers`: автоинкрементный `id`, обязательные `name`
  и `media_id` → `files.id`. Отдельная миграция `0076` после `0075`.
- Добавлены GET списка, GET по ID, POST, PUT и DELETE `/api/cms/led/screensavers`.
  Список — `items`/`total`, `limit`/`offset`, ID по убыванию.
- POST требует название и файл; POST/PUT принимают multipart с `file`,
  `file_preview`, `file_title`, `file_description`, как вопросы викторины.
  В ответах объект `file` с подписанными ссылками; `media_id` не принимается API.
- Чтение — admin/content_editor/operator или любое активное устройство с Device JWT,
  независимо от роли и наличия ролей. User JWT не допускается.
  Изменение — только admin/content_editor со staff access JWT.
  Без нового файла PUT сохраняет вложение и метаданные. Замена и DELETE
  сохраняют прежние файлы; новые файлы и сущность записываются атомарно.
- Добавлены изолированные API-проверки с SQLite в памяти и временными файлами,
  описание сущности, исходный и bundled OpenAPI.
