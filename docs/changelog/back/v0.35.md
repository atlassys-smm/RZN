# 0.35 — Стороны вариантов ответа в состоянии викторины

11.11.2026

- В `current_question.question.answer_options[]` добавлено поле `side`: `1` — left, `2` — right, `null` — сторона не задана. Поле получают оператор, LED и участник через оба GET-маршрута состояния и ответы игровых действий.
- Кеш вопросов сохраняет `side`; старые записи без поля перестраиваются при чтении без очистки состояния игры.
- Обновлены OpenAPI и API-тесты. Миграция БД не требуется.
