# 0.40 — Логотип на аватарах FaceAI

18.11.2026

- На новые аватары FaceAI накладывается логотип в левом верхнем углу
  с отступом около 3% от короткой стороны изображения.
- Исходный JPEG используется в памяти на время обработки. В хранилище и
  в ответах API используется JPEG с логотипом. При ошибке чтения или
  наложения сохраняется исходный файл, а задание завершается успешно.
  Итоговый файл хранится без автоматического срока удаления.
- Правила применяются к результатам из webhook, резервного скачивания и
  локальной эмуляции FaceAI.
- При скачивании к имени файла добавляется расширение из хранилища, если в
  заголовке файла подходящего расширения нет.
