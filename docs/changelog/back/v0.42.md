# 0.42 — Обложки тестов ПрофСтарта и поиск видеосценариев

18.11.2026

- У тестов Соломина, Голланда и Деллингер обновлены основные изображения.
  PNG с суффиксом `-mobile` используются как превью основного файла.
- В CMS `POST` и `PATCH` принимают основной файл как `file`, мобильный — как `file_preview`.
  В ответах CMS, пользовательской карточки и каталога ссылка на мобильную версию доступна в `file.preview_url`.
- Миграция `0104` записывает основные изображения и мобильные превью за один шаг.

- `GET /api/cms/video-scenarios` принимает необязательный `query` для поиска по части
  названия без учёта регистра. Поиск сочетается с фильтром `profession_id`, а `total`
  показывает количество совпадений до пагинации.
