# 0.50 — Демо-пользователи, даты прохождений и события Unity

- Команды `simulate_profstart`, `simulate_quiz`, `simulate_video`,
  `simulate_feedback`, `simulate_views` и `simulate_avatars` поддерживают
  `--authorized` и `--date`. Дата без времени означает 12:00 МСК. Для
  времени ISO 8601 можно указать свой часовой пояс. Записи и события
  начинаются с указанного времени и учитывают время выполнения.
- `POST /api/auth/user/demo` доступен администратору и выдаёт пользовательскую
  сессию для отдельного аккаунта с `is_guest=false`. Имя и фамилия выбираются
  случайно из двух списков по 15 вариантов. Фамилия получает окончание
  «-ов» или «-ова» в зависимости от имени. CLI использует `X-Demo-Date`
  для даты активности и подтверждает её staff access-токеном администратора
  в `X-Demo-Authorization`. Сроки действия токенов, таймеры и
  планирование фоновых задач используют реальное время. Единый обработчик
  SQLAlchemy проставляет даты записей активности в сессии текущего запроса.
- `simulate_unity tree`, `simulate_unity map` и `simulate_unity profbattle`
  отправляют события через API внешней аналитики. Для известных
  `user_id` внешняя аналитика сохраняет признак `is_guest` из PostgreSQL.
- Для «Профессий в действии» записываются старт показа, подключение
  пользователя и завершение показа.
- `simulate_user` создаёт одного авторизованного пользователя, запускает
  все существующие демо-сценарии и три сценария Unity, проводит от 2 до 5
  индивидуальных викторин и выводит ID пользователя и число завершённых
  сценариев в консоль.

- Для карьерного трека ClickHouse выбирает активных участников по событиям
  с is_guest = false, а PostgreSQL исключает служебные аккаунты.

```bash
docker compose exec -T api python -m app.cli.simulate_quiz --authorized --date 2026-11-20
docker compose exec -T api python -m app.cli.simulate_unity map --authorized --views 5
docker compose exec -T api python -m app.cli.simulate_user --date 2026-11-20T14:30:00+03:00 --seed 42
```
