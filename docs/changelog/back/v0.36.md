# 0.36 — Демо-просмотры и начальные версии согласий

11.11.2026

- Добавлена команда `python -m app.cli.simulate_views`: по умолчанию выбирает
  по 10 профессий, организаций и направлений образования и открывает каждую
  карточку от 1 до 10 раз с JWT созданного гостя для заполнения аналитики.
- Параметры `--count`, `--seed`, `--base-url`, `--origin`, `--report`;
  общий HTTP-клиент и настройки остальных демо-команд. Недостаток записей
  проверяется до отправки просмотров. JSON-отчёт сохраняет план и прогресс;
  автоматических повторов запросов нет.
- Добавлены изолированные HTTP-тесты и инструкция запуска демо-просмотров;
  команда не меняет контракты API и схему БД.

- Миграция PostgreSQL `0091` добавляет в `consent_versions` начальные версии
  `0.1` для типов `personal_data` и `contact_request`, найденных по `code`
  в `consent_types`. Каждая версия содержит короткий тестовый текст,
  статус `published`, даты публикации и начала действия на момент применения.
  Если у типа уже есть любая версия, новая не создаётся; существующие тексты
  и публикации сохраняются. При откате опубликованные согласия сохраняются,
  поскольку на них могут ссылаться принятия согласий и ответы анкет.
