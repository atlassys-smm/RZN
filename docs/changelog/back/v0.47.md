# 0.47 — Завершение сессий Профбаттла

24.11.2026

- `battle:finished` завершает начатую сессию при подтверждённом выходе,
  включая досрочный выход. В аналитике ему соответствует код 4.
- Удалено `battle:completed`. Появление экрана результата больше не отправляет
  отдельное событие.
- Добавлено `battle:quit` для подтверждённого выхода до начала сессии.
