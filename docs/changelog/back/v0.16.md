# Версия 0.16

Дата: 21.10.2026

## Подготовка справочников к загрузке данных

- Миграции `0066`–`0071`: детальные отрасли, сведения о профессиях и организациях,
  направления подготовки, связи профессий с работодателями и программами обучения.
- `professions.direction_id` допускает NULL: источник не содержит профессиональных направлений.
- Все новые таблицы, включая связи, имеют автоинкрементный BigInteger `id`.
  Исходные ID из JSON не закрепляются в базе; загрузка должна пересчитать внешние ключи.
- `0072`: nullable `deleted_at` в существующих справочниках `industries`, `directions`,
  `professions`, `organizations`; новые таблицы получают это поле при создании.
  Все справочные GET исключают удалённые записи; DELETE устанавливает deleted_at.
- `0073`: `organizations.type` преобразуется из строки в integer:
  `OrganizationType.EMPLOYER=1`, `OrganizationType.EDUCATION=2`. Неизвестные старые значения
  останавливают преобразование. API создания, обновления, ответа и фильтра принимает числовой enum.
- ORM и исходный OpenAPI согласованы с числовым типом организации и nullable `direction_id`.
  Дополнительные поля доступны в запросах создания, изменения и ответах справочников.
- `0075_seed_professions_data.py`: загрузка фиксированной копии `app/migrations/data/professions_data.json`.
  Перед вставкой всем строкам девяти таблиц (`industries`, `directions`, `industry_branches`,
  `professions`, `organizations`, `education_programs`, `profession_employers`,
  `profession_education_programs`, `profstart_test_group_professions`) устанавливается `deleted_at=now()`.
- Загружаются 11 индустрий, 47 отраслей, 94 профессии, 100 работодателей, 42 учебных заведения,
  78 программ обучения, 300 связей с работодателями и 510 связей с программами.
  Все ID выдаёт автоинкремент; внешние ключи пересчитываются по картам исходный ID → новый ID.
  Работодатели и учебные заведения используют отдельные карты. Для программ без ID исходным
  идентификатором служит позиция в массиве с единицы.
- Старые `directions` также помечаются удалёнными; новых профессиональных направлений в источнике нет,
  поэтому у загруженных профессий `direction_id=NULL`.
- Downgrade `0075` устанавливает `deleted_at=now()` всем текущим строкам этих девяти таблиц,
  включая добавленные после загрузки. Старые записи не восстанавливаются, физического удаления
  и сброса последовательностей нет. Upgrade выполняется в общей транзакции Alembic и требует
  подключения: offline SQL для вставок с возвращаемыми ID не поддерживается.
- Тексты и зарплаты переносятся как в источнике, без исправления известных ошибок данных.
  Индустрия работодателя определяется через отрасль; дополнительные исходные `industry_id`/`industry`
  работодателя не переносятся.
- Полный CRUD отраслей, направлений подготовки и обеих таблиц связей; GET по ID индустрии и
  профессионального направления. Списки и total фильтруют deleted_at, удалённые ID дают 404.
- DELETE профессии/работодателя/программы помечает связанные строки удалёнными. Активные
  зависимости защищены ответом 409. Восстановление пары связей через POST сохраняет её ID.
- Проверяются активность внешних ссылок, тип организации и диапазон зарплат. Поддерживается
  очистка nullable-полей явным null. ПрофСтарт, рекомендации, выбор профессии в анкете и
  отображение профессии в видеосценарии учитывают deleted_at.
- Обновлены разделы «Профессии» и «Организации» исходного и bundled OpenAPI; добавлены API-тесты.

- Миграции `0066`–`0075` применены к рабочей БД `ryazan` 21.10.2026 после резервного копирования.
  Проверены активные количества всех восьми справочников, отсутствие некорректных связей
  и ответ 404 для прежних ID через работающий API.


- `0074_add_profstart_group_profession_deleted_at`: поле `deleted_at` для связей ПрофСтарта.
  Их GET и расчёт рекомендаций учитывают мягкое удаление; DELETE сохраняет строку,
  POST восстанавливает удалённую пару с прежним ID. Удаление профессии также помечает эти связи.
- Seed переименован в `0075_seed_professions_data`; добавлены 386 связей для 94 профессий:
  Соломин 188, Голланд 94, Деллингер 104, в том числе 10 для `dellinger.rectangle`.
  Прямоугольник — редакционная подборка для профессионального поиска; пояснение и источник
  добавлены в описание методик. Исходный JSON и фиксированная копия миграции согласованы.
- Старая применённая загрузка `0074` отменена штатным downgrade до `0073`; ровно 1182 её записи физически удалены
  после проверки значений и зависимостей. Новые `0074`–`0075` применены в той же транзакции
  после резервного копирования. 82 исторические связи ПрофСтарта сохранены с `deleted_at`.
  Число строк справочников не увеличилось из-за замены seed; ID выданы заново без сброса sequences.
- Обновлены документация сущности и OpenAPI методов привязки профессий ПрофСтарта.

- Исправлена выдача общего рейтинга: мягко удалённые профессии остаются в ранее сохранённых
  рекомендациях с названием и баллами снимка источника. Фильтр deleted_at применяется при
  новом подборе профессий, а не при чтении истории. Добавлены API-регрессии для обоих случаев.

- Новые справочные маршруты сгруппированы: `/industries/branches`, `/professions/employers`,
  `/professions/education-programs` (связи), `/organizations/education-programs` (программы).
  Для списков, создания и операций по ID обновлены маршруты, OpenAPI и API-тесты.
  Статические пути регистрируются перед маршрутами родителей с параметром ID.
