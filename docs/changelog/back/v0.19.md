# Версия 0.19

Дата: 22.10.2026

- Добавлена HTML-страница `/recommendations_constructor` на бэкенде: вход сотрудника
  по логину и паролю, ID пользователя и веса Соломина/Холланда/Деллингер 40/40/20
  по умолчанию. Токен хранится в памяти вкладки, refresh-cookie не устанавливается.
- Добавлен защищённый предпросмотр рекомендаций с весами на один запрос без
  изменения профиля и стандартных настроек. Новый маршрут вызывает тот же сервис
  `get_recommendations`, что пользовательский API; отдельный расчёт убран, веса
  передаются аргументом и не влияют на параллельные запросы.
- Интерфейс одновременно показывает все категории отдельными разделами: вклад
  тестов, недостающие результаты, профессии, работодателей, учебные организации
  с файлами и направления обучения.
- Уплотнён интерфейс конструктора: небольшая верхняя панель, компактные параметры
  и колонки категорий. Расчёты, описания, контакты и файлы свёрнуты по умолчанию
  и доступны через раскрытие карточек.
- Добавлена общая кнопка «Раскрыть все / Свернуть все» для подробностей всех
  профессий, организаций и направлений с учётом состояния отдельных карточек.
- Сервис конструктора размещён в `app/services/recommendations_constructor/service.py`.
- Документированы API входа и предпросмотра; добавлены проверки доступа,
  изменения рейтинга, нормализации весов и сохранности обычных рекомендаций.

- Добавлен JSON-набор викторины: 30 профориентационных вопросов с вариантами ответов
  и пояснениями, из них 20 одиночного выбора и 10 мультивыбора.
- Два опубликованных шаблона по 15 вопросов включают весь набор: в каждом три раунда
  по пять вопросов, 10 одиночных и 5 мультивыбора.
- Добавлен Python CLI app.cli.load_quiz_bank для запуска через Docker API.
  Режим --check проверяет JSON без подключения к БД.
- Загрузка атомарна и повторяема без дублей; параллельные вызовы сериализуются.
  Отличающийся существующий контент не перезаписывается, конфликт отменяет весь импорт.
- Добавлены проверки структуры, импорта через CMS API, подсчёта ответов, повторного
  и параллельного запуска, сохранности правок CMS и полного отката при конфликте.
  Миграции и автоматическая загрузка при старте приложения не добавлялись.
