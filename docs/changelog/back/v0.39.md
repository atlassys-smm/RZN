# 0.39 — PDF-отчеты и редактирование сотрудников

17.11.2026

- В верхнем колонтитуле PDF слева выводится «Аналитика», справа — тип
  периода, номер календарной недели для недельного отчета и фактические даты
  от начала периода до даты, переданной в GET /api/analytics/report.
- Для недельного и месячного отчета год выводится после конечной даты;
  если период пересекает границу года, год указывается у обеих дат.
- Добавлен `PATCH /api/staff/{staff_id}` для администратора: частичное
  изменение имени, фамилии, email, роли и статуса сотрудника. Email
  нормализуется как при создании; занятый адрес возвращает `409`.
- Смена роли учитывается со следующего запроса. Блокировка отзывает все
  сессии сотрудника; после разблокировки требуется новый вход.
- Собственную роль понизить и заблокировать себя нельзя (`409`). Права
  администратора повторно проверяются после блокировки записей в БД.
- Обновлены OpenAPI, описания сотрудников и авторизации. Добавлены API-тесты
  редактирования, прав доступа, валидации, смены роли и блокировки.
- В `GET /api/cms/devices` добавлен необязательный фильтр `is_active`:
  true — активные устройства, false — неактивные. Без параметра сохраняется
  полный список и прежний порядок по дате создания.
