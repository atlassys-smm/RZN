# 0.39 — Колонтитул PDF-отчета аналитики

17.11.2026

- В верхнем колонтитуле PDF слева выводится «Аналитика», справа — тип
  периода, номер календарной недели для недельного отчета и фактические даты
  от начала периода до даты, переданной в GET /api/analytics/report.
- Для недельного и месячного отчета год выводится после конечной даты;
  если период пересекает границу года, год указывается у обеих дат.
