# Версия 0.20

Дата: 23.10.2026

- `GET /api/organizations/{id}` создаёт событие ORGANIZATION_VIEWED=10 только
  при авторизации JWT пользователя, включая гостя. Сотрудники, устройства,
  ошибки и списки просмотрами не считаются. Каждый успешный повторный GET
  учитывается отдельно, без view_id.
- Добавлен модуль аналитики ORGANIZATIONS=13 и представление ClickHouse
  organization_views (миграция 0010). В событиях сохраняются ID, название
  и тип организации, пользователь и признак гостя.
- Подключены четыре карточки Metabase main.organizations: рейтинги топ-10
  работодателей и учебных заведений, дневная динамика фиксированного топ-5
  каждого типа. Общий период по московскому времени; нулевые дни не пропускаются.
- Обновлены OpenAPI и правила аналитики; добавлены API-проверки авторизации
  просмотров и проверки SQL на встроенных данных без записи рабочих событий.

- Добавлены пользовательские просмотры профессий (PROFESSION_VIEWED=11) и направлений
  образования (EDUCATION_PROGRAM_VIEWED=12). В событии профессии сохраняется
  снимок отрасли через industry_id; служебные JWT просмотров не создают.
- Миграция ClickHouse 0011 добавляет profession_views и education_program_views.
- В main.professions подключены шесть карточек: рейтинги топ-10 и дневная динамика
  топ-5 профессий, отраслей и направлений образования. Отрасли считаются по просмотрам
  профессий. Направления учитываются по ID независимо от совпадения названий
  и числа связанных учебных заведений.
- Обновлены OpenAPI, статусы реализации дашбордов и контракты событий;
  добавлены API-проверки и безопасные SQL-проверки на встроенных данных.

- Добавлены коллекция Metabase «Для заставки» и дашборд «Показатели для заставки»
  с ключом led.showcase по исходным требованиям публичного LED-режима:
  посетители, среднее время, люди с подобранными профессиями, популярные профессии
  и обратная связь. Переиспользованы семь существующих карточек с общими фильтрами
  дат; топ личных баллов подключён отдельной общей карточкой. В документации указаны ограничения
  существующих расчётов и выбор периода для посетителей сегодня/за месяц.

- В SESSION_FINISHED индивидуальной викторины добавлен results[] со снимком
  participant_id, user_id и сохранённого total_score. Командные события и
  ANSWER_EVALUATED не меняются; повторное завершение не создаёт новый факт.
- Миграция ClickHouse 0012 добавляет quiz_individual_results. Карточка
  quiz.individual.top_scores показывает топ-5 лучших результатов пользователей
  по дате завершения и переиспользуется в индивидуальной викторине и «Для заставки».
  Старые события без результатов исключаются; нулевые баллы учитываются.
  По умолчанию топ выбирается за полный вчерашний день по Europe/Moscow.

- GET /api/cms/video-scenarios поддерживает select=profession для получения
  вложенного profession с полными данными связанной профессии; profession_id сохранён.
  Без select=profession поле отсутствует и профессии не загружаются; при выборе
  без привязки возвращается null. Профессии загружаются вместе со списком.
  Обновлены схемы API, документация и проверки select, фильтрации, пагинации и пустых связей.
