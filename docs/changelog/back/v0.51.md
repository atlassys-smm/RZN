# 0.51 — Демо-дата и завершение демо-сессий

26.11.2026

- Демо-дата применяется только к HTTP-запросам, которые записывают демо-активность
  или пересчитывают рекомендации. WebSocket подключается независимо от демо-даты.
- При сбое общего демо-прогона команда пытается завершить созданную викторину
  или видеопоказ по полученному ID сессии. Ошибка завершения выводится в консоль.
- `simulate_user --user-id` записывает демо-активность для существующего
  авторизованного пользователя. Команда использует отдельный ограниченный
  токен и сохраняет ранее пройденные тесты ПрофСтарта.
- Карточка `visitors.activity` показывает историю посетителя по событиям.
  Начало, действия и завершение одной сессии отображаются отдельными строками.
