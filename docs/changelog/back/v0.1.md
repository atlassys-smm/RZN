Дата: 24.09.2026 10:33

## Инфраструктура

- Инициализация проекта: FastAPI + Docker + docker-compose
- Подключён submodule `docs` (документация из `docs_esp`)
- Alembic для миграций (10 миграций: devices, files, industries, directions, users, professions, video scenarios, sessions, votes)
- Добавлен Redis (подключение через `REDIS_URL`)
- Структура проекта: плоская → доменная (`app/models/users/`, `app/services/files/`, `app/api/video_scenario/` и т.д.)

## API

- `app/api/professions/` — CRUD профессий, отраслей, направлений
- `app/api/files/` — загрузка и управление файлами
- `app/api/devices/` — управление LED-устройствами
- `app/api/video_scenario/scenarios.py` — CRUD интерактивных видео-сценариев
- `app/api/video_scenario/sessions.py` — создание и управление сессиями, advance по фазам
- WebSocket: `app/websocket/video_scenario/` — менеджер подключений для интерактивного видео

## Модели

- `Device` — LED-устройство (name, ip, type, screen)
- `File` — файлы (type, module_code, path)
- `User` — пользователи (oauth, gender, status)
- `Profession` / `Industry` / `Direction` — справочники профессий
- `InteractiveVideoScenario` — сценарий интерактивного видео (с ветвлениями)
- `InteractiveVideoSession` — сессия интерактивного видео (status, phase, current_branch)
- Удалены старые модели: `VideoSession`, `VideoScenario`, `user.py` (заменены доменными)

## Enum → integer

- `User.status`: `guest`/`active`/`deactivated` → `1`/`2`/`3`/`4`
- `User.gender`: `male`/`female`/`unknown` → `1`/`2`/`null`
- `User.oauth_provider`: `yandex`/`vk` → `1`/`2`
- `File.type`: `video`/`image`/`document`/`audio` → `1`/`2`/`3`/`4`
- `InteractiveVideoSession.status`: `active`/`finished` → `1`/`2`
- `InteractiveVideoSession.phase`: `playing`/`voting` → `1`/`2`
- `InteractiveVideoScenario.status`: строка → integer
- Enum-файлы перенесены в доменные папки (`app/models/users/enums.py`, `app/models/files/enums.py`, `app/models/video_scenario/enums.py`)
