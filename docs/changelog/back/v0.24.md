# Версия 0.24

Дата: 28.10.2026

- Миграция `0084` добавляет nullable `professions.short_name` (varchar(255));
  поле также добавлено в ORM и описание сущности.
- Миграция `0085` заполняет короткие названия из фиксированной копии
  `app/migrations/data/profession_short_names.json` для 94 профессий источника.
  Сопоставление выполняется по полному `name`, поскольку `0075` выдала новые ID.
  Обновляются только строки с `deleted_at IS NULL`; новые профессии не создаются,
  остальные поля и связи сохраняются. Для отсутствующих в источнике имён
  `short_name` остаётся NULL.
- Downgrade `0085` очищает только совпадающие с источником короткие названия
  активных профессий, сохраняя удалённые записи и изменённые вручную значения.
  Миграции применены к рабочей БД `ryazan` 28.10.2026: заполнены 94 активные
  профессии; 19 удалённых записей, ID и остальные поля сохранены.
- `short_name` добавлено в GET списка и карточки профессии, POST и PUT.
  Поле необязательное, от 1 до 255 символов; пустое значение или строка `null`
  передаёт NULL. Пропуск поля при редактировании сохраняет прежнее значение.
  Обновлены исходный и bundled OpenAPI и описание сущности.
- Добавлены изолированные проверки API с БД в памяти: создание, получение,
  редактирование, очистка, сохранение пропущенного поля и ограничение длины.
- Изолированные проверки API: 12 новых и 24 существующих теста успешно пройдены;
  рабочая БД проверена после применения миграций.

- Добавлен `POST /api/analytics/embed-tokens`: принимает только от 1 до 100
  ключей графиков, ответ — список key/token и общий expires_at.
  Доступ ADMIN/ANALYST, штатная проверка staff-сессии; HS256 с отдельным
  METABASE_EMBEDDING_SECRET_KEY, срок до 24 часов и не дольше сессии.
- JWT содержит только resource.question, пустой params и exp. Все фильтры —
  date_from/date_to, time_grain, device_id, module_id, survey_id и source_id —
  передаются при получении данных. В шаблонах и 41 существующем графике
  Metabase они переведены в enabled; SQL и ID графиков сохранены.
- Подпись ограничена развёрнутыми графиками с enable_embedding=true;
  неизвестный/неопубликованный график отклоняет пакет целиком.
  Ответ не кэшируется; секреты, служебные сессии Metabase и произвольные ID
  не возвращаются. Существующий секрет Metabase подключён к API.
- Обновлены исходный и bundled OpenAPI, документация интеграции и проверки
  авторизации, JWT и отказа принимать фильтры в запросе выдачи токенов.
- Проверки: 33 изолированных API-теста; JWT всех 41 графиков не содержат
  фильтров. На работающем Metabase проверена загрузка двух периодов по одному
  токену с фактической передачей date_from/date_to в запрос.
- Демо аналитики перенесено в app/templates/metabase_demo.html и GET /demo/metabase.
  «Вход сотрудника» использует тот же Bearer-вход, что конструктор рекомендаций.
  Один пакет из 13 JWT кэшируется в памяти; фильтры меняются без перевыпуска.
- Добавлен POST /api/demo/metabase/query: получение data.cols/data.rows по embed
  JWT через фиксированный Metabase, без административных учётных данных и cookie.
  JWT передаётся в JSON, диагностические сообщения с секретами не возвращаются.
- Для подписанного встраивания разрешены 9 существующих вопросов feedback.*;
  SQL и ID сохранены. Всего доступны 50 вопросов с подписанным встраиванием.
- Проверки: 45 изолированных API-теста; JavaScript-проверка входа, пакета токенов,
  iframe, таблиц, повторного использования токенов и выхода. На работающем API
  успешно получены данные всех 13 вопросов демо.
- В браузере проверены вход сотрудника, четыре iframe, девять таблиц и смена
  периода без перевыпуска токенов; отменённый вход не восстанавливает сессию вкладки.
