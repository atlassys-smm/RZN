# 0.32 — Список и удаление сотрудников

06.11.2026

- Добавлен `GET /api/staff` только для администратора: список активных и
  заблокированных сотрудников, `limit`/`offset`, общее число до пагинации,
  стабильный порядок по ID. Хеши паролей и токены не возвращаются.
- Добавлен `DELETE /api/staff/{staff_id}` только для администратора: физическое
  удаление учётной записи. В одной транзакции удаляются её refresh-токены,
  связанные сессии авторизации, затем сотрудник. Остальные сотрудники, сессии
  и пользовательские данные не затрагиваются. Email можно зарегистрировать повторно.
- Удалённому сотруднику недоступны вход и выданные access/refresh-токены.
  Статуса DELETED нет; остаются ACTIVE=1 и BLOCKED=2. Миграция БД не требуется.
- Удаление своей учётной записи возвращает `409`, отсутствующей или уже удалённой — `404`.
  Администратор и удаляемый сотрудник блокируются в порядке ID, чтобы конкурирующие
  запросы не позволили двум администраторам одновременно удалить друг друга.
- Обновлены документация/OpenAPI и проверки прав, пагинации, физических связей,
  удаления токенов и сессий, запрета старых токенов и повторной регистрации email.
