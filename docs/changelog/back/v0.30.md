# 0.30 — Очистка сессий, бонус за скорость и обновление превью

03.11.2026

- API-контейнер по воскресеньям в 02:00 по Москве удаляет сессии, с момента
  истечения или отзыва которых прошло 30 дней. Связанные refresh-токены удаляются в той же
  транзакции. Размер пачки — до 500 сессий, до 20 пачек за запуск.
- Добавлена CLI-команда в контейнере API для просмотра числа подходящих записей
  и ручного запуска очистки с флагом `--apply`.
- Время ответа для бонуса фиксируется при приёме ответа. Паузы исключаются
  из времени ответа, а добавление секунд к таймеру его не уменьшает.
- Ответы без сохранённого времени оцениваются без бонуса за скорость.
- В запросах обновления можно загрузить только превью существующего вложения,
  включая варианты викторины и мужской/женский образ аватара. Основной файл,
  его UUID и метаданные сохраняются. При отсутствии вложения возвращается 422.
- В seed-банке ПрофСтарта убраны завершающие точки у 90 вариантов ответов теста Голланда
  и 42 вопросов анкеты Соломина.
- Банк викторины перенесён в app/cli/data/quiz/professions_bank.json. CLI загрузки использует новый путь.
- Миграция 0089 убирает только завершающие точки в текстах вопросов и вариантов
  ответов всех версий тестов solomin, holland и dellinger.
- Отключены маршруты GET /demo/metabase и POST /api/demo/metabase/query.
  Исходный HTML демонстрационной страницы сохранён.
- Подсчёт баллов викторины загружает вопрос, варианты, участников, признак гостя
  и команды до цикла обработки ответов. Повторные SQL-чтения из _save_answer убраны.
- API-тесты превью шаблонов аватаров и LED-заставок приведены к контракту
  отдельного обновления превью с сохранением исходного файла. В изолированных
  SQLite-тестах LED-заставок публикация готовности превью в Redis подменена.
- Изолированы фабрики БД в двух WebSocket-тестах и фоновая очистка сессий
  в тесте lifespan. Общая pytest-фикстура блокирует подключения SQLAlchemy
  вне тестовой БД и SQLite, а также Redis вне REDIS_URL_TEST.
