## Изменения

### Два LED-экрана на мероприятии

Добавлено описание двух LED-экранов в `docs/subsystems/led-platform/index.md`:

| | Большой LED (амфитеатр) | Малый LED (вход) |
|---|---|---|
| **Расположение** | Амфитеатр | Вход на мероприятие |
| **Режимы** | Заставка + Викторина | Только заставка |
| **Управление** | Оператор управляет с планшета | Автономная работа |

Малый LED может запускать сессию «Профессии в действии» — всегда с одной профессией (`profession_count = 1`).

### Поле `module_code` для файлов

В сущность `File` (`docs/entities/files.md`) добавлено поле `module_code` — символьный код модуля, к которому относится файл (например, `quiz`, `video_scenario`, `profession`, `survey`, `team_game`, `profstart`).

### Автоисключение пустых команд

Добавлено бизнес-правило для командной игры: при начале игры команды с нулевым количеством участников автоматически исключаются из сессии. Если после исключения остаётся менее 2 команд — игра не может быть начата.

Зафиксировано в:
- `docs/subsystems/led-platform/quiz.md` — этап подготовки командной сессии
- `docs/entities/game-session.md` — примечание к `GameSessionTeam`

### Обновлённые файлы

- `docs/subsystems/led-platform/index.md` — описание двух LED-экранов
- `docs/entities/files.md` — поле `module_code`
- `docs/entities/game-session.md` — примечание об автоисключении пустых команд
- `docs/subsystems/led-platform/quiz.md` — бизнес-правило автоисключения
