# Версия 1.3

**Дата:** 14.09.2026

## Архитектурные и блок-схемы

Наполнен раздел «Архитектурные и блок-схемы»:

- **Обзорная схема** — пользователи (Пользователь, Оператор, Администратор), устройства, приложения и модули, backend-сервер, хранилище данных
- **Детализированная схема** — клиентский уровень, уровень прикладных сервисов (API приложение, Сервис идентификации, Хранилище событий), OAuth-провайдеры, внешние ПАК, сервер базы данных, файловый сервер
- **Описание слоёв** — таблицы компонентов клиентского уровня, backend-сервисов, схем базы данных
- **Ключевые принципы** — разделение узлов, модульность, безопасность, масштабируемость

## Перечень допущений

Наполнен раздел «Перечень допущений»:

- **Предложения по улучшению концепции** — OAuth 2.0 вместо ID/пароль, единая модель User, 24 часа на авторизацию гостя, обязательное согласие на ПДн, автономность ПК для LED-экрана
- **Условные данные для прототипа** — вымышленные профессии, вопросы, имена команд, показатели аналитики
- **Данные, необходимые для наполнения** — перечень профессий региона, учебные заведения, работодатели, пользовательское соглашение
- **Ограничения и зависимости** — наполнение справочников и интеграция выполняются при наличии технической возможности и предоставленных данных от Заказчика
