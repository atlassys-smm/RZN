## Изменения

### Новая сущность: InteractiveVideoSession (Сессия показа)

Добавлено описание сущности сессии показа «Профессии в действии» в `docs/entities/video-scenario.md`.

Сессия хранит:
- `device_id` — LED-устройство
- `status` — активна/завершена
- `settings` — настройки показа (scenario_ids, voting_duration, result_display_duration)

### Реструктуризация настроек сессии

`scenario_ids` перенесён в `settings` — всё что настраивается при создании сессии, хранится в одном объекте.

**Было:**
```json
{
  "scenario_ids": [5, 12, 7],
  "settings": { "voting_duration": 30 }
}
```

**Стало:**
```json
{
  "settings": {
    "scenario_ids": [5, 12, 7],
    "voting_duration": 30,
    "result_display_duration": 5
  }
}
```

При создании сессии (`POST /interactive-video/sessions`) фронтенд передаёт либо `scenario_ids` (ручной выбор), либо `profession_count` (случайный выбор N). Бэкенд конвертит `profession_count` → `scenario_ids` перед сохранением.

### Упрощение InteractiveVideoState

Состояние показа для LED-экрана теперь содержит:
- `settings` — полный объект настроек (scenario_ids, voting_duration, result_display_duration)
- `current_scenario` — напрямую объект сценария (без обёртки `{ scenario: {...} }`)
- `current_branch` — текущая ветка с атрибутами и дочерними ветками

### Убраны избыточные поля

Удалены поля, которые легко вычисляются клиентом:

| Поле | Где было | Как вычислить |
|------|----------|---------------|
| `current_scenario_index` | Session, State | Позиция `current_scenario.id` в `settings.scenario_ids` |
| `current_scenario.index` | State | То же самое |
| `winner_branch_id` | State (voting_point) | Максимум по `votes[*].count` |
| `total_voters` | State (voting_point) | Сумма `votes[*].count` |
| `prompt` | State (voting_point) | Атрибут `current_branch.prompt` |

### Реструктуризация current_branch и voting_point

**`current_branch`** теперь содержит:
- `id`, `media_url`, `prompt`, `profession_name` — атрибуты ветки
- `children` — варианты выбора (дочерние ветки с `branch_id` и `text`)

**`voting_point`** теперь содержит только процесс голосования:
- `timer` — таймер (`ends_at`)
- `votes` — распределение голосов
