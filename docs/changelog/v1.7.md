### Prism Mock-сервер

Добавлена возможность запуска mock-сервера на основе OpenAPI-спецификации:

```bash
npm install
npm run mock
```

Сервер запускается на `http://127.0.0.1:4010` и генерирует динамические ответы на основе `docs/api/bundled/openapi.yaml`.
