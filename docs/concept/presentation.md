## Слайд 6: Маршрут 1 — Подключение по QR

**Заголовок:** Быстрый старт без регистрации

**Текст:**
Самый простой способ начать взаимодействие с платформой:
1. LED-экран или устройство (например, «Аватар профессии») показывает QR-код для подключения
2. Участник сканирует код камерой смартфона
3. Попадает в лобби сессии
4. Выбирает команду (для командной игры) или сразу начинает (для индивидуальной)

Подключение к сессии не требует авторизации. Гостевой режим действует 24 часа — за это время можно создать профиль и сохранить результаты.

**Визуал:** схема процесса подключения с иконками

## Слайд 7: Маршрут 2 — Командная викторина

**Заголовок:** Соревнование команд на большом LED-экране

**Текст:**
Оператор запускает сессию, формирует команды, участники подключаются по QR-коду:
- LED-экран показывает вопрос с медиа-контентом и таймером
- Команды обсуждают вопрос в мобильных клиентах
- Капитан подтверждает финальный ответ
- Система автоматически подсчитывает баллы
- Промежуточный рейтинг после каждого раунда
- Финальный экран определяет победителя и показывает связанные профессии

**Визуал:** скриншоты экранов викторины из прототипа (LED + мобильный клиент)

## Слайд 11: Регистрация и создание профиля

**Заголовок:** От гостевого режима к постоянному профилю

**Текст:**
Гибкая идентификация с постепенным углублением:
1. **QR-код** — быстрое подключение к сессии без регистрации
2. **Гостевой режим** — 24 часа для создания профиля и привязки результатов
3. **OAuth 2.0** — вход через Яндекс ID или VK ID для постоянного доступа
4. **Единый профиль** — все активности сохраняются автоматически

**Визуал:** схема процесса идентификации с переходами между состояниями

## Слайд 20: Риски и допущения

**Заголовок:** Что учтено в проекте

**Текст:**
**Предложения по улучшению концепции:**
- OAuth 2.0 вместо ID/пароль — быстрее для пользователя, нет необходимости запоминать пароли
- Гостевой режим 24 часа — баланс между удобством и защитой ПДн
- Обязательное согласие на обработку ПДн для всех (OAuth и гость)
- Автономность ПК для LED — оператор управляет только планшетом

**Условные данные в прототипе:**
- Профессии, отрасли, компетенции
- Примеры вопросов викторины и «ПрофСтарт»
- Имена команд и пользователей, показатели аналитики

**Данные для наполнения (требуются от Заказчика):**
- Перечень профессий региона
- Учебные заведения и направления подготовки
- Работодатели региона
- Пользовательское соглашение

**Ограничения:**
- Интеграция с внешними ПАК при технической возможности партнёров
