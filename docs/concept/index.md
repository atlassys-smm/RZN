# Концепция демонстративного материала

Комплект проектно-демонстрационных материалов, подтверждающий понимание предметной области, системность проектного подхода, качество UI/UX-решений и техническую реализуемость архитектуры.

!!! info "Срок выполнения"
    **10 календарных дней** с даты заключения контракта.

!!! note
    Создание production-кода, рабочего сервера, фактических интеграций и подключения к оборудованию **не требуется**. Допускаются кликабельные прототипы, анимированные макеты и условные данные.

## Единый демонстрационный сценарий

Все материалы строятся на основе сквозного сценария:

1. LED-экран приглашает группу школьников принять участие в профориентационной игре
2. Оператор выбирает «Командную работу», формирует 4 команды, запускает сессию
3. Участники подключаются по QR-коду, выбирают команду и получают роль
4. Команды выполняют профориентационное задание и подают один итоговый ответ
5. Система показывает решение, рейтинг и связанные профессии; итоговый экран результатов
6. Один из участников переходит к «ПрофСтарт» на интерактивной панели, проходит фрагмент теста в гостевом режиме
7. Пользователь создаёт учётную запись и подтверждает привязку результата к профилю
8. Пользователь выполняет вход на другом терминале — видит личный кабинет с сохранённым результатом
9. В аналитику поступают обезличенные события; сотрудник видит обновление дашборда
10. Оператор завершает сессию, устройства возвращаются в режим ожидания
