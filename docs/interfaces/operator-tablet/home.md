# Главный экран

Точка входа. Оператор выбирает режим для запуска на LED-экране. Показывается только когда на LED нет активной сессии — в остальных случаях планшет находится на соответствующих экранах управления сессией.

---

## Элементы

### Плитки режимов

Крупные карточки для выбора:

| Плитка | Действие |
|--------|----------|
| Командная игра | → [Настройка сессии](team-game-setup.md) |
| Индивидуальная викторина | → Настройка индивидуальной викторины |
| Профессии в действии | → [Профессии в действии](professions.md) |

---

## Возврат на главный экран

Оператор завершает любую активность (сессия, показ профессий) через соответствующую кнопку на экране управления. После завершения LED автоматически возвращается в режим ожидания, планшет — на главный экран.
