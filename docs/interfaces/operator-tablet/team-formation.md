# Формирование команд

Участники подключаются через QR-код на LED-экране и выбирают команду. Оператор управляет составом.

---

## Список команд

Команды создаются на экране [Настройка сессии](team-game-setup.md) с автоматически сгенерированными названиями. Ограничения на число команд и участников описаны в [GameSession](../../entities/game-session.md#gamesession) и [GameSessionTeam](../../entities/game-session.md#gamesessionteam).

Для каждой команды отображается:

- Название (редактируемое)
- Количество участников / лимит
- Список участников
- Пометка капитана (значок или бейдж)

---

## Подключение участников

Участники подключаются через QR-код на LED-экране и самостоятельно выбирают команду из доступных (где есть свободные места). Оператор видит обновлённый список при каждом подключении.

---

## Действия оператора {#team-actions}

| Действие | Описание |
|----------|----------|
| Переименовать команду | Изменить название команды |
| Перенести участника | Переместить участника из одной команды в другую |
| Назначить капитана | Сменить капитана команды (выбрать из участников команды) |

Операции доступны оператору через `PATCH /quiz/sessions/{id}/teams/{teamId}`, `PATCH /quiz/sessions/{id}/participants/{participantId}/team` и `PUT /quiz/sessions/{id}/teams/{teamId}/captain`.

При переносе капитана в другую команду новый капитан старой команды выбирается случайно из оставшихся участников. Если участников не осталось, `captain_id` старой команды становится `null`. Если в целевой команде нет капитана, им становится перенесённый участник (даже если до переноса он не был капитаном); существующий капитан целевой команды сохраняется.

После переноса приходит только `participant_team_changed`; клиент по нему обновляет составы и капитанов обеих команд. Повторный перенос в ту же команду не меняет состояние и не отправляет события. Перенос в заполненную команду отклоняется без изменения капитанов.

---

## Состояния

| Состояние | Поведение |
|-----------|----------|
| Участники не подключились | Кнопка «Начать игру» неактивна |
| Минимальный состав собран | Кнопка «Начать игру» активна, когда выполнены условия старта из [GameSessionTeam](../../entities/game-session.md#gamesessionteam) |
