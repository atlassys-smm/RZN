# Итоговые результаты

Экран подведения итогов. Рейтинг отображается на LED-экране. Оператор принимает решение: финальный раунд или завершение.

---

## Элементы

### Рейтинг

**Командная игра:**

| Элемент | Описание |
|---------|----------|
| Место | Позиция в рейтинге |
| Название команды | С цветом команды |
| Итоговый счёт | Суммарные баллы за все раунды |
| Статистика по раундам | Баллы каждой команды в каждом раунде |

**Индивидуальная викторина:**

| Элемент | Описание |
|---------|----------|
| Место | Позиция в рейтинге |
| Участник | Имя |
| Индивидуальный счёт | Суммарные баллы |

---

## Действия

| Действие | Описание |
|----------|----------|
| Финальный раунд | Запуск финального раунда → возврат на [Управление раундом](round-control.md) |
| Принять итоги | Завершение сессии, возврат на [главный экран](home.md). LED возвращается в режим ожидания |

---

## Примечания

- Результаты сессии автоматически сохраняются и передаются в аналитику
- Рейтинг отображается на LED автоматически
