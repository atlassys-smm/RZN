# Интерфейс оператора (планшет)

Панель управления LED-медиаплатформой. Веб-интерфейс на планшете сотрудника Центра.

---

## Навигация

Оператор работает в режиме «мастера»: главный экран → выбор режима → пошаговое прохождение сценария. Возврат на главный экран доступен с любого экрана через кнопку «Вернуть на заставку».

```
Авторизация → Главный экран
├── Командная игра → Настройка сессии → Формирование команд → Управление раундом → Итоговые результаты
├── Индивидуальная викторина → Настройка сессии → Управление раундом → Итоговые результаты
└── Профессии в действии
```

## Взаимодействие с LED-экраном

Планшет оператора — устройство управления. Основной контент отображается на LED-экране:

- Вопросы и задания → на LED
- Ответы и таймеры → на LED
- Промежуточные и итоговые результаты → на LED
- QR-код для подключения участников → на LED

Оператор видит на планшете элементы управления и статусную информацию, необходимую для принятия решений.
