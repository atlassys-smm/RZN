# Управление раундом

Универсальный экран активной сессии. Используется для индивидуальной викторины и командной игры.

---

## Элементы управления

### Информация о раунде

| Элемент | Описание |
|---------|----------|
| Номер раунда | Текущий раунд из общего количества (например, «Раунд 2 из 6») |
| Тип раунда | Название типа текущего раунда |
| Прогресс вопросов | Текущий вопрос из общего количества в раунде |

### Таймер

Основной элемент управления во время раунда.

| Действие | Описание |
|----------|----------|
| Пауза | Остановить таймер, возобновить повторным нажатием |
| Завершить досрочно | Остановить таймер и перейти к следующему вопросу / завершить раунд |
| Добавить время | Увеличить оставшееся время таймера |

Таймер отображается на LED-экране.

### Статус приёма ответов

Индикация: сколько команд (или участников) отправили ответ.

---

## Показ ответа

После завершения приёма ответов (таймер или досрочное завершение):

### На LED-экране
- Правильный ответ
- Методическое пояснение

### На планшете оператора
- Правильный ответ
- Методическое пояснение
- Кнопка **«Следующий вопрос»** → переход к следующему вопросу
- Кнопка **«Пропустить»** → пропустить показ ответа и перейти дальше

Методическое пояснение берётся из поля `explanation` вопроса ([GameQuestion](../../entities/quiz.md)).

---

## Командный режим — дополнительные элементы

Доступна панель управления командами — та же, что на экране [формирования команд](team-formation.md#шаг-2-управление-командами): переименование, перенос участников, смена капитана.

---

## Состояния между раундами

После последнего вопроса текущего раунда:

- Результаты отображаются на LED-экране
- На планшете — кнопка **«Следующий раунд»** → запуск следующего раунда
- После последнего раунда — кнопка **«Итоги»** → переход к [итоговым результатам](final-results.md)

---

## Индивидуальная викторина

Экран работает в том же режиме, но без командной части:

- Нет панели управления командами
- Отображается общая статистика: количество ответивших, процент правильных ответов
- После последнего раунда — кнопка «Итоги» → переход к [итоговым результатам](final-results.md)
- По итогам — рейтинг участников (кто сколько баллов набрал)
