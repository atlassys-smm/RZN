# Настройка сессии

Первый экран создания сессии. Оператор выбирает режим и состав раундов. Используется для командной игры и индивидуальной викторины.

---

## Переключатель режима сессии

Сегментированный контрол (два таба) в верхней части экрана:

- **Командная игра** — сессия с формированием команд
- **Индивидуальная викторина** — персональные ответы, индивидуальный рейтинг

По умолчанию активна «Командная игра».

## Настройки командного режима

Отображаются только при выборе «Командная игра»:

| Параметр | Описание |
|----------|----------|
| Количество команд | Настраивается по ограничениям [GameSession](../../entities/game-session.md#gamesession) |
| Лимит участников в команде | Опционально; ограничения состава см. в [GameSessionTeam](../../entities/game-session.md#gamesessionteam) |

## Переключатель источника сценария

Под переключателем режима — выбор способа формирования раундов:

- **Шаблон** — выбор готового сценария
- **Ручной** — самостоятельный подбор раундов

По умолчанию активен «Шаблон».

---

## Режим «Шаблон»

Шаблон заполняет предпросмотр подготовленными раундами и вопросами. Структура шаблона и правила переноса раундов в сессию описаны в [сущности шаблона](../../entities/scenario-template.md#scenariotemplate) и [сущности игровой сессии](../../entities/game-session.md#gamesession). Если финальный раунд не включён, игра завершается после последнего обычного раунда.

### Список шаблонов

Вертикальный список карточек. Каждая карточка содержит:

- **Название шаблона** — заголовок карточки (например, «IT-направление»)
- **Описание** — одна строка: тематика, возрастная группа
- **Количество раундов** — бейдж «6 раундов»
- **Состояние выбора** — невыбранная карточка / выбранная карточка (подсветка, галочка)

### Панель предпросмотра

Появляется внизу экрана при выборе шаблона:

- Нумерованный список раундов: порядковый номер, тип раунда, количество вопросов
- Кнопка «Далее →» — переход к [формированию команд](team-formation.md)

Если шаблон не выбран — кнопка «Далее» неактивна.

---

## Режим «Ручной»

Для каждого раунда оператор настраивает тип и подбор вопросов. Допустимые типы перечислены в [справочнике раундов](../../references/scenario-round-types.md), а способы выбора вопросов и формат данных описаны в [сущности игровой сессии](../../entities/game-session.md#gamesession).

### Доступные типы раундов

Сетка карточек типов раундов из [справочника](../../references/scenario-round-types.md). Каждая карточка:

- **Название типа раунда** — заголовок (например, «Быстрый старт», «Ситуационный кейс»)
- **Краткое описание** — одна строка
- **Чекбокс** — выбран / не выбран

Оператор отмечает нужные типы. Допустимое количество типов раундов см. в [справочнике](../../references/scenario-round-types.md). Счётчик выбранных отображается рядом с заголовком секции.

### Настройка вопросов для каждого выбранного типа

Под списком типов — для каждого выбранного типа отображается строка:

- **Название типа раунда** — слева
- **Степпер** (− / +) — количество вопросов для этого типа раунда, минимум 1

Порядок строк соответствует порядку чекбоксов в списке выше — раунды идут в порядке выбора.

### Кнопка «Далее →»

Переход к следующему шагу. Неактивна, если количество выбранных типов не соответствует диапазону из [справочника раундов](../../references/scenario-round-types.md).
