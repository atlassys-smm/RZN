# Авторизация

Экран входа в систему. Оператор вводит учётные данные для доступа к панели управления.

---

## Элементы

| Элемент | Описание |
|---------|----------|
| Поле «Логин» | Имя пользователя или email |
| Поле «Пароль» | Скрытый ввод |
| Кнопка «Войти» | Авторизация в системе |

---

## Состояния

| Состояние | Поведение |
|-----------|----------|
| Начальное | Поля пустые, кнопка «Войти» неактивна |
| Заполнены поля | Кнопка «Войти» активна |
| Ошибка авторизации | Сообщение «Неверный логин или пароль», поля очищаются |
| Успешная авторизация | Переход на [Главный экран](home.md) |

---

## Примечания

- Авторизация происходит через подсистему идентификации
- После успешного входа оператор получает доступ к управлению LED-медиаплатформой
