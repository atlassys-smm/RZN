# Профессии в действии

Интерактивный видеосценарий на LED-экране. Система показывает видеоролики о профессиях с точками голосования, где зрители выбирают вариант продолжения.

---

## Воспроизведение видео

Видео занимает весь экран. В углу постоянно отображается QR-код — зрители могут подключиться в любой момент и проголосовать в следующей точке выбора.

В начале ролика отображается название профессии.

---

## Точка голосования

В определённые моменты видео приостанавливается. На экране появляются:

### Появление

Видео останавливается, поверх затемнённого фона:

| Элемент | Расположение | Описание |
|---------|--------------|----------|
| Вопрос / ситуация | Верхняя часть экрана | Текст описания выбора (например, «Что сделает разработчик в этой ситуации?») |
| Варианты продолжения | Центр экрана | 2–4 карточки с текстом варианта, расположены горизонтально |
| Таймер | Под вариантами или рядом | Крупный обратный отсчёт |
| QR-код | Угол экрана | Остаётся видимым для подключения новых зрителей |

### Варианты продолжения

Каждый вариант — карточка с текстом. Пока голосование идёт — карточки нейтральные, без индикации лидерства.

### Голосование

Зрители выбирают вариант на мобильных устройствах. На LED-экране:

- Таймер отсчитывает оставшееся время
- Счётчик голосов обновляется в реальном времени (общее количество проголосовавших)
- Сами варианты не раскрывают промежуточные результаты — только общее число голосов

---

## Завершение голосования

Таймер достигает нуля. На экране:

### Результат

| Элемент | Описание |
|---------|----------|
| Варианты | Карточки вариантов, победивший подсвечен |
| Количество голосов | Число голосов за каждый вариант (столбчатая диаграмма или числа на карточках) |
| Победитель | Подсветка + текст «Выбрано: ...» |

Результат показывается несколько секунд, затем — переход к продолжению видео.

### Продолжение

Видео возобновляется с того фрагмента, который соответствует победившему варианту. QR-код снова виден в углу — зрители могут подключиться к следующей точке голосования.

---

## Если никто не голосовал

Если таймер истёк и голосов нет — система выбирает вариант автоматически. На экране отображается пометка «Автоматический выбор», затем видео продолжается.

---

## Завершение показа

После прохождения всех точек выбора в видеосценарии LED автоматически возвращается в режим [заставки](screensaver.md).

Оператор может завершить показ досрочно через панель управления.
