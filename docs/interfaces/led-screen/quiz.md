# Викторина

Экраны LED-экрана во время викторины: подключение, вопросы, ответы, результаты. Единый набор экранов для индивидуальной и командной игры — отличается состав отображаемой информации.

---

## Получение состояния

LED-экран подключается к WebSocket `ws://host/api/v1/quiz/sessions/{id}/ws` для получения обновлений в реальном времени:
- Текущий вопрос и таймер
- Количество ответивших
- Результаты голосования
- Правильный ответ
- Рейтинг команд/участников

При подключении сервер отправляет полное состояние (`session_state`). Далее — только изменения.

Альтернативно можно использовать REST `GET /quiz/sessions/{id}` для получения текущего состояния (например, при переподключении).

## Подключение участников

Показывается после настройки сессии на планшете оператора, до начала раундов.

### Общие элементы

| Элемент | Описание |
|---------|----------|
| QR-код | Ссылка на мобильный клиент для подключения |
| Код сессии | Числовой код для ручного ввода (альтернатива QR) |
| Название режима | «Командная игра» или «Индивидуальная викторина» |

### Командная игра

На экране отображаются команды, созданные при настройке сессии. По мере подключения участников они распределяются по командам.

| Элемент | Описание |
|---------|----------|
| Список команд | Карточки команд с названиями и цветами |
| Количество участников в команде | Обновляется при каждом подключении (например, «3 / 10») |
| Имена участников | Появляются в карточке команды по мере подключения |

### Индивидуальная викторина

| Элемент | Описание |
|---------|----------|
| Счётчик участников | Общее число подключившихся, обновляется в реальном времени |

### Состояния

| Состояние | Поведение |
|-----------|----------|
| Ожидание | QR-код и код отображаются, никто не подключился |
| Участники подключаются | Команды заполняются (командная) / счётчик растёт (индивидуальная) |

## Экран вопроса

Основной экран во время раунда.

### Отображается

| Элемент | Описание |
|---------|----------|
| Номер раунда | «Раунд 2 из 6» |
| Тип раунда | Название типа (например, «Быстрый старт») |
| Текст вопроса | Крупно, по центру |
| Медиа | Изображение или видео (если есть в вопросе) |
| Варианты ответов | Нумерованные карточки (если вопрос с вариантами) |
| Таймер | Обратный отсчёт, крупно |

### Состояния

| Состояние | Поведение |
|-----------|----------|
| Показ вопроса | Текст и медиа, таймер запущен |
| Приём ответов | Индикатор количества ответивших (команд/участников) |
| Таймер истёк | Переход к показу ответа |

---

## Экран ответа

Показывается после завершения приёма ответов (таймер или досрочное завершение оператором).

### Отображается

| Элемент | Описание |
|---------|----------|
| Правильный ответ | Подсветка правильного варианта |
| Методическое пояснение | Текст из поля `explanation` вопроса |
| Баллы | Начисленные баллы (командам или участникам) |

### Командная игра — дополнительно

| Элемент | Описание |
|---------|----------|
| Ответы команд | Список: команда → выбранный вариант (до раскрытия правильного) |
| Текущий счёт | Обновлённый рейтинг команд |

### Индивидуальная викторина — дополнительно

| Элемент | Описание |
|---------|----------|
| Статистика | Количество правильных / неправильных ответов |
| Текущий рейтинг | Обновлённый рейтинг участников |

---

## Промежуточные результаты

Показываются после завершения раунда, перед следующим.

| Элемент | Описание |
|---------|----------|
| Рейтинг | Позиции команд или участников с баллами |
| Визуализация | Столбчатая диаграмма или нумерованный список |

---

## Итоговые результаты

Финальный экран сессии.

### Командная игра

| Элемент | Описание |
|---------|----------|
| Место | Позиция в рейтинге |
| Команда | Название с цветом |
| Итоговый счёт | Суммарные баллы |
| Статистика по раундам | Баллы в каждом раунде |

### Индивидуальная викторина

| Элемент | Описание |
|---------|----------|
| Место | Позиция в рейтинге |
| Участник | Имя |
| Индивидуальный счёт | Суммарные баллы |
