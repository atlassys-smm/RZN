# Заставка (режим ожидания)

Режим по умолчанию, когда на LED-экране нет активной сессии. Вариации контента автоматически чередуются по циклу.

---

## Принцип работы

Заставка — это зацикленный плейлей вариаций. Каждая вариация показывается отведённое время, затем происходит переход к следующей. Цикл непрерывный.

---

## Вариации

### Видеоплейлист

Зацикленный показ видеороликов, карточек профессий и анонсов.

| Параметр | Описание |
|----------|----------|
| Контент | Видеоролики, карточки профессий, анонсы мероприятий |
| Порядок | Последовательный, зацикленный |
| Источник | CMS — библиотека медиа |

→ [Библиотека медиа в CMS](../../subsystems/cms/references.md)

!!! warning "Подлежит разработке"
    Механика формирования видеоплейлиста — откуда берутся видео, как подбираются и в каком порядке показываются — ещё не определена и подлежит разработке.

---

### «Профессии в действии»

Интерактивный видеосценарий в режиме ожидания.

- Система берёт случайную профессию и показывает видеоролик о ней
- Видео воспроизводится, в углу — QR-код для подключения
- В определённые моменты видео приостанавливается, на экране появляются варианты продолжения и таймер
- Зрители подключаются по QR и голосуют с мобильных устройств
- По истечении таймера показывается результат голосования (какой вариант победил), затем видео продолжается с выбранным сценарием
- Если никто не голосовал — система выбирает продолжение автоматически

→ [Профессии в действии — подробное описание экранов](professions-active.md) | [Видеосценарии в CMS](../../subsystems/cms/video-scenarios.md)

---

### «Мой карьерный маршрут»

Анимированный экран с QR-кодом, приглашающий перейти в цифровой профиль для получения персональных рекомендаций.

| Элемент | Описание |
|---------|----------|
| Анимация | Визуализация карьерного пути |
| QR-код | Ссылка на личный кабинет / цифровой профиль |
| Текст | Призыв перейти и получить рекомендации |

---

### Публичная аналитика

Агрегированные показатели платформы без персональных данных.

| Элемент | Описание |
|---------|----------|
| Популярность профессий | Какие профессии выбирают чаще |
| Количество сессий | Общее число проведённых викторин |
| Активность | Общая активность участников |

→ [Публичный LED-дашборд](../../subsystems/analytics/led-dashboard.md)
