# LED-экран — Основное приложение

Полноэкранное приложение на медиасервере, выводящее контент на LED-экран. Не имеет элементов управления — всё взаимодействие через панель оператора и мобильные устройства участников.

---

## Экраны по сценариям

### Заставка

Режим по умолчанию. Автоматически циклически переключает вариации контента.

→ [Заставка](screensaver.md)

### Викторина

Экраны во время викторины: подключение участников, вопросы, таймеры, ответы, результаты.

→ [Викторина](quiz.md)

### Профессии в действии

Интерактивный видеосценарий с точками голосования. QR-код виден во время воспроизведения — зрители могут подключиться в любой момент.

→ [Профессии в действии](professions-active.md)
