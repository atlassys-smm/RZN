# Подключение к сессии

Первый экран после сканирования QR-кода на LED-экране. Участник входит в сессию и (для командной игры) выбирает команду.

---

## Элементы

| Элемент | Описание |
|---------|----------|
| Название сессии | Информация о текущей сессии |
| Режим | «Командная игра» или «Индивидуальная викторина» |
| Список команд | Доступные команды с количеством мест (только для командной игры) |
| Кнопка «Подключиться» | Подтверждение входа в сессию |

---

## Сценарии

### Индивидуальная викторина

| Шаг | Действие |
|-----|----------|
| 1 | Участник сканирует QR-код |
| 2 | Авторизуется или входит как гость (система выдаёт выдуманное имя) |
| 3 | Нажимает «Подключиться» |
| 4 | Ожидает начала игры |

### Командная игра

| Шаг | Действие |
|-----|----------|
| 1 | Участник сканирует QR-код |
| 2 | Авторизуется или входит как гость (система выдаёт выдуманное имя) |
| 3 | Выбирает команду из списка (где есть свободные места) |
| 4 | Нажимает «Подключиться» |
| 5 | Ожидает начала игры |

---

## Состояния

| Состояние | Поведение |
|-----------|----------|
| Подключение | Форма ввода имени и выбора команды |
| Ожидание начала | «Вы подключены. Ожидайте начала игры» |
| Сессия уже началась | «Подключение невозможно, сессия уже началась» |
| Все команды заполнены | «К сожалению, все команды заполнены» |
