# Подключение к сессии

Первый экран после сканирования QR-кода на LED-экране. Участник входит в сессию и (для командной игры) выбирает команду.

QR должен вести на страницу фронтенда с ID сессии. Фронтенд восстанавливает вход через refresh cookie или показывает выбор гостевого входа/OAuth и обязательное согласие. Гость создаётся через `/api/auth/user/guest`; OAuth запускается отдельным фронтендом и завершается через `/api/auth/user/oauth/{provider}`; параметры и схема фронтенда описаны в [авторизации](../../subsystems/auth-sessions.md#oauth-яндекс-id-vk-id). Затем вызывается `/join` с `Authorization: Bearer <access_token>`, без тела. Повторный `/join` безопасен: возвращает прежнего участника.

В викторине ответ `/join` содержит participant_id, session_id, mode и команды. Токена в нём больше нет. Выбор команды — `/team/{team_id}/join` без тела; ответ — `/answer` с answer и is_final. ID участника сервер получает из авторизации. В видео `/join` возвращает ID текущего User, голосование `/vote` принимает только branch_id, `/voting` не требует ID в query.

---

## Элементы

| Элемент | Описание |
|---------|----------|
| Название сессии | Информация о текущей сессии |
| Режим | «Командная игра» или «Индивидуальная викторина» |
| Список команд | Доступные команды с количеством мест (только для командной игры) |
| Кнопка «Подключиться» | Подтверждение входа в сессию |

---

## Сценарии

### Индивидуальная викторина

| Шаг | Действие |
|-----|----------|
| 1 | Участник сканирует QR-код |
| 2 | Авторизуется или входит как гость (система выдаёт выдуманное имя) |
| 3 | Нажимает «Подключиться» |
| 4 | Ожидает начала игры |

### Командная игра

| Шаг | Действие |
|-----|----------|
| 1 | Участник сканирует QR-код |
| 2 | Авторизуется или входит как гость (система выдаёт выдуманное имя) |
| 3 | Выбирает команду из списка (где есть свободные места) |
| 4 | Нажимает «Подключиться» |
| 5 | Ожидает начала игры |

---

## Состояния

| Состояние | Поведение |
|-----------|----------|
| Подключение | Форма ввода имени и выбора команды |
| Ожидание начала | «Вы подключены. Ожидайте начала игры» |
| Сессия уже началась | «Подключение невозможно, сессия уже началась» |
| Все команды заполнены | «К сожалению, все команды заполнены» |
