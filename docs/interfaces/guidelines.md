# Общие правила интерфейсов

Конвенции, обязательные для всех клиентских интерфейсов платформы (LED-экран, мобильный клиент, планшет оператора, админ-портал).

---

## Отображение имени

В публичных интерфейсах полное ФИО выводить **запрещено**. Формат отображения — **имя + первая буква фамилии**:

```
Иван И.
```

Поле `name` (из сущности User) хранится как получено из OAuth-провайдера. Разбиение на имя и фамилию и форматирование выполняется на стороне клиента.

---

## Аватар

Источник изображения — в порядке приоритета:

1. Аватар, загруженный пользователем в профиле
2. Аватар, подтянутый из соц. сети при OAuth-авторизации (Яндекс ID / VK ID)

Если аватар отсутствует — отображается заглушка (инициалы или дефолтный аватар платформы).
