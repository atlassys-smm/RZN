# Пользователи и журнал изменений

Управление учётными записями сотрудников и история всех изменений контента.

---

## Пользователи

### Список

Таблица: имя, email, роль, статус, дата последней активности. Фильтрация по роли, статусу. Поиск по имени и email.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Имя | string | да |
| Фамилия | string | да |
| Email | string | да |
| Роль | enum | да |
| Статус | enum | да |

### Роли

| Роль | Права |
|------|-------|
| **Администратор** | Полный доступ ко всем разделам, управление пользователями |
| **Контент-менеджер** | Создание и редактирование контента |
| **Оператор** | Запуск сценариев, просмотр контента |
| **Просмотр отчётов** | Только просмотр аналитики и отчётов |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новая учётная запись |
| Редактировать | Изменить имя, email, роль |
| Заблокировать | Запретить вход в систему |
| Разблокировать | Восстановить доступ |
| Сбросить пароль | Отправить ссылку для сброса на email |
| Удалить | Только если нет связанных действий в журнале |

### Вход в систему

- Вход по email и паролю
- При первом входе — обязательная смена временного пароля
- Восстановление пароля через email
- Минимальные требования: 8 символов, буквы и цифры

---

## Журнал изменений

История всех изменений контента: кто, когда, что изменил.

### Список

Таблица: дата и время, пользователь, действие, объект, изменения. Фильтрация по пользователю, типу объекта, действию, периоду. Поиск по названию объекта.

### Отображаемые поля

| Поле | Описание |
|------|----------|
| Дата и время | Когда произошло изменение |
| Пользователь | Кто внёс изменение (имя и email) |
| Действие | Тип действия |
| Объект | Тип и название изменённого объекта |
| Изменения | Diff полей: было → стало |

### Фильтры

| Фильтр | Описание |
|--------|----------|
| Период | Дата с — дата по |
| Пользователь | Конкретный сотрудник |
| Тип объекта | Вопрос, Шаблон, Видеосценарий, Профессия и т.д. |
| Действие | Создание, Редактирование, Удаление, Публикация |

### Типы действий

| Действие | Описание |
|----------|----------|
| Создание | Объект создан |
| Редактирование | Изменены поля объекта |
| Удаление | Объект удалён |
| Публикация | Перевод из черновика в опубликованный |
| В черновик | Перевод из опубликованного в черновик |

### Детали изменения

При клике на запись — детальная карточка:
- Полная информация об объекте до и после
- Список изменённых полей с предыдущими и текущими значениями
- Для вопросов: изменения в вариантах ответов
- Для шаблонов: изменения в структуре раундов
- Для видеосценариев: изменения в дереве веток

Журнал хранится бессрочно. Записи не удаляются даже при удалении объекта.
