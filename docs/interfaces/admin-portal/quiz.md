# Викторина

Управление банком вопросов и шаблонами сценариев для LED-платформы.

---

## Вопросы

### Список

Таблица: текст вопроса, тип, сложность, возрастная группа, тип раунда, баллы. Фильтрация по типу, сложности, возрастной группе, типу раунда.

### Карточка вопроса

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Тип вопроса | integer (ID из справочника) | да |
| Текст вопроса | text | да |
| Медиа-файл | → File | нет |
| Сложность | integer (ID из справочника) | нет |
| Возрастная группа | integer (ID из справочника) | нет |
| Время на ответ | integer | да |
| Баллы | integer | да |
| Методическое пояснение | text | нет |
| Тип раунда | integer (ID из справочника) | нет |
| Теги | json | нет |

### Варианты ответов

Каждый вопрос содержит один или несколько вариантов:

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Текст | text | да |
| Медиа-файл | → File | нет |
| Правильный | boolean | да |
| Порядок | integer | да |
| Сторона сопоставления | integer (`1` — left, `2` — right) | только для matching |

Эталон ответа настраивается по формату конкретного типа вопроса; поля `answer_key` и сторона `left`/`right` для вариантов сопоставления описаны в [сущности вопроса](../../entities/quiz.md).

### Типы вопросов

| ID | Тип | Описание |
|----|-----|----------|
| 1 | `single_choice` | Выбор одного варианта; формат `single` |
| 2 | `multiple_choice` | Выбор нескольких вариантов; формат `multiple` |
| 3 | `yes_no` | Да / нет; формат `single` |
| 4 | `image_choice` | Выбор по изображению; формат `single` |
| 5 | `matching` | Сопоставление; формат `matching` |
| 6 | `sorting` | Упорядочивание; формат `sorting` |
| 7 | `profession_by_description` | Сопоставление профессий с описаниями задач; формат `matching` |
| 8 | `recognize_by_image` | Распознавание профессии по изображению; файл прикладывается к вопросу; формат `single` |
| 9 | `recognize_by_video` | Распознавание профессии по видео; файл прикладывается к вопросу; формат `single` |
| 10 | `sequence` | Восстановление последовательности; формат `sorting` |
| 11 | `case_study` | Ситуационный кейс; формат `single` |
| 12 | `role_distribution` | Сопоставление ролей в команде; формат `matching` |
| 13 | `resource_selection` | Выбор набора ресурсов и специалистов; формат `multiple` |
| 14 | `error_finding` | Поиск ошибки в рабочей ситуации; формат `single` |
| 15 | `prediction` | Прогноз развития технологии; формат `single` |
| 16 | `argumentation` | Аргументация и консенсус; формат `single` |
| 17 | `media_round` | Медиараунд с видеофрагментом; файл прикладывается к вопросу; формат `single` |
| 18 | `final_case` | Финальный комплексный кейс; формат `single` |


Формат ответа задаётся группой типа: single — `option_id`, multiple — `option_ids`,
matching — `pairs`, sorting — упорядоченный `option_ids`. Типов со свободным
текстовым ответом сейчас нет. Поля `text` вопроса и вариантов сохраняются;
`answer.text` можно передавать как дополнительное пояснение, оно не участвует в проверке.

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый вопрос с вариантами ответов |
| Редактировать | Изменить текст, тип, параметры, варианты ответов |
| Удалить | Удаление вопроса |

## Шаблоны сценариев

### Список

Таблица: название шаблона, количество раундов, количество вопросов, статус. Фильтрация по статусу.

### Карточка шаблона

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Описание | text | нет |
| Статус | integer (`1` — draft, `2` — published) | да |

В API передаётся числовой статус: `1` — черновик (`draft`), `2` — опубликован (`published`).

### Структура шаблона

Поля редактора раундов и вопросов соответствуют сущностям [ScenarioTemplateRound](../../entities/scenario-template.md#scenariotemplateround) и [ScenarioTemplateRoundQuestion](../../entities/scenario-template.md#scenariotemplateroundquestion):

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Тип раунда | integer (ID из справочника) | да |
| Порядок | integer | да |
| Вопросы | → GameQuestion[] | да |

### Работа с вопросами в раунде

Для каждого раунда администратор выбирает конкретные вопросы из банка. Доступны фильтры:

- Тип вопроса
- Сложность
- Возрастная группа
- Теги (профессия, отрасль, компетенция)
- Тип раунда

Вопросы можно перетаскивать для изменения порядка.


Формат ответа задаётся группой типа: single — `option_id`, multiple — `option_ids`,
matching — `pairs`, sorting — упорядоченный `option_ids`. Типов со свободным
текстовым ответом сейчас нет. Поля `text` вопроса и вариантов сохраняются;
`answer.text` можно передавать как дополнительное пояснение, оно не участвует в проверке.

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый шаблон сценария |
| Редактировать | Изменить название, описание, раунды и вопросы |
| Опубликовать | Перевести из черновика в опубликованный |
| В черновик | Вернуть из опубликованного в черновик |
| Удалить | Не влияет на ранее созданные сессии |

### Ограничение редактирования

Редактирование вопросов, шаблонов сценариев и настроек системы баллов **запрещено**, если существует хотя бы одна активная игровая сессия (статус `waiting` или `active`).

При попытке редактирования система отображает сообщение: «Редактирование недоступно — есть активные сессии. Завершите сессии перед внесением изменений».

## Настройки системы баллов

Глобальные настройки системы начисления баллов. Администратор настраивает коэффициенты, пороги и переключатели для всех механизмов. Настройки применяются ко всем новым сессиям; оператор может переопределить их при запуске конкретной сессии.

Каждый механизм имеет переключатель (вкл/выкл). При выключении коэффициент не учитывается в расчёте (принимается за 1.0 для множителей или 0 для штрафов).

| Механизм | Переключатель | Параметры | Описание |
|----------|:---:|-----------|----------|
| Частичный балл | ✅ / ❌ | — | Пропорциональный балл за задания с несколькими правильными элементами |
| Бонус за скорость | ✅ / ❌ | Коэффициент (по умолчанию 1.5), порог % (по умолчанию 50%) | Множитель при ответе быстрее порога от времени на вопрос |
| Бонус за серию | ✅ / ❌ | Шаг коэффициента (по умолчанию 0.05), предельный коэффициент (по умолчанию 2.0) | Рост множителя за каждый последовательный правильный ответ |
| Бонус за консенсус | ✅ / ❌ | Коэффициент (по умолчанию 1.2) | Множитель при единогласном правильном ответе команды |
| Множитель финального раунда | ✅ / ❌ | Коэффициент (по умолчанию 1.5) | Повышенный вес баллов в финальном раунде |
| Штраф за неправильный ответ | ✅ / ❌ | Коэффициент (по умолчанию 0.0) | Доля баллов вопроса, вычитаемая при неправильном ответе |

→ Механика расчёта — в подсистеме [Правила начисления баллов](../../subsystems/led-platform/quiz.md#правила-начисления-баллов)
