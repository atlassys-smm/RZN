# Викторина

Управление банком вопросов и шаблонами сценариев для LED-платформы.

---

## Вопросы

### Список

Таблица: текст вопроса, тип, сложность, возрастная группа, тип раунда, баллы. Фильтрация по типу, сложности, возрастной группе, типу раунда.

### Карточка вопроса

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Тип вопроса | integer (ID из справочника) | да |
| Текст вопроса | text | да |
| Медиа-файл | → File | нет |
| Сложность | integer (ID из справочника) | нет |
| Возрастная группа | integer (ID из справочника) | нет |
| Время на ответ | integer | да |
| Баллы | integer | да |
| Методическое пояснение | text | нет |
| Тип раунда | integer (ID из справочника) | нет |
| Теги | json | нет |

### Варианты ответов

Каждый вопрос содержит один или несколько вариантов:

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Текст | text | да |
| Медиа-файл | → File | нет |
| Правильный | boolean | да |
| Порядок | integer | да |
| Сторона сопоставления | integer (`1` — left, `2` — right) | только для matching |

Эталон ответа настраивается по формату конкретного типа вопроса; поля `answer_key` и сторона `left`/`right` для вариантов сопоставления описаны в [сущности вопроса](../../entities/quiz.md).

### Типы вопросов

| ID | Тип | Описание |
|----|-----|----------|
| 1 | `single_choice` | Выбор одного варианта |
| 2 | `multiple_choice` | Выбор нескольких вариантов |
| 3 | `yes_no` | Да / нет |
| 4 | `image_choice` | Выбор по изображению |
| 5 | `matching` | Сопоставление |
| 6 | `sorting` | Упорядочивание |
| 7 | `profession_by_description` | Выбор профессии по описанию задач |
| 8 | `recognize_by_image` | Распознавание профессии по изображению |
| 9 | `recognize_by_video` | Распознавание профессии по видео |
| 10 | `sequence` | Восстановление последовательности |
| 11 | `case_study` | Ситуационный кейс |
| 12 | `role_distribution` | Распределение ролей в команде |
| 13 | `resource_selection` | Выбор набора ресурсов и специалистов |
| 14 | `error_finding` | Поиск ошибки в рабочей ситуации |
| 15 | `prediction` | Прогноз развития технологии |
| 16 | `argumentation` | Аргументация и консенсус |
| 17 | `media_round` | Медиараунд с видеофрагментом |
| 18 | `final_case` | Финальный комплексный кейс |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый вопрос с вариантами ответов |
| Редактировать | Изменить текст, тип, параметры, варианты ответов |
| Удалить | Удаление вопроса |

## Шаблоны сценариев

### Список

Таблица: название шаблона, количество раундов, количество вопросов, статус. Фильтрация по статусу.

### Карточка шаблона

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Описание | text | нет |
| Статус | integer (`1` — draft, `2` — published) | да |

В API передаётся числовой статус: `1` — черновик (`draft`), `2` — опубликован (`published`).

### Структура шаблона

Поля редактора раундов и вопросов соответствуют сущностям [ScenarioTemplateRound](../../entities/scenario-template.md#scenariotemplateround) и [ScenarioTemplateRoundQuestion](../../entities/scenario-template.md#scenariotemplateroundquestion):

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Тип раунда | integer (ID из справочника) | да |
| Порядок | integer | да |
| Вопросы | → GameQuestion[] | да |

### Работа с вопросами в раунде

Для каждого раунда администратор выбирает конкретные вопросы из банка. Доступны фильтры:

- Тип вопроса
- Сложность
- Возрастная группа
- Теги (профессия, отрасль, компетенция)
- Тип раунда

Вопросы можно перетаскивать для изменения порядка.

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый шаблон сценария |
| Редактировать | Изменить название, описание, раунды и вопросы |
| Опубликовать | Перевести из черновика в опубликованный |
| В черновик | Вернуть из опубликованного в черновик |
| Удалить | Не влияет на ранее созданные сессии |
