# Аналитика посетителей

Раздел состоит из списка посетителей и карточки выбранного посетителя.
Фронтенд получает статистику из Metabase. Имена, фамилии и аватарки загружаются
одним запросом к API по ID посетителей на открытой странице.

## Список посетителей

| Блок | Ключ Metabase | Что показывает |
|---|---|---|
| Активные посетители | `main.attendance.visitors` | Число уникальных посетителей |
| Авторизованные посетители | `main.attendance.users` | Число посетителей с последним известным типом «Пользователь» |
| Гости | `main.attendance.guests` | Число посетителей с последним известным типом «Гость» |
| Динамика посещаемости | `main.attendance.dynamics` | Линия уникальных посетителей по дням или неделям |
| Таблица посетителей | `visitors.list` | ID, тип, первая и последняя активность, число активных дней и модули |

Таблица фильтруется по периоду, типу, модулю, устройству или точному ID.
Показываются сначала посетители с самой свежей активностью. Для пагинации
фронтенд передаёт `limit` и `offset` в Metabase. Из полученных строк фронтенд
берёт `user_id` и вызывает `POST /api/analytics/visitors/profiles`. Если профиль
для ID отсутствует, строка показывается с ID.

## Карточка посетителя

Карточка открывается для пользователя или гостя. В шапке показываются ID,
имя, фамилия и аватарка при наличии. Фронтенд запрашивает профиль по одному ID
и передаёт его как фильтр `user_id` при запросах данных Metabase.

| Блок | Ключ Metabase | Визуализация |
|---|---|---|
| Сводка за период | `visitors.summary` | Тип, первая и последняя активность, число активных дней и событий |
| Активность по дням | `visitors.daily` | Линейный график количества событий |
| Активность по модулям | `visitors.modules` | Столбчатая диаграмма количества событий |
| Просмотры каталога | `visitors.views` | Топ-10 по профессиям, отраслям, программам, учебным заведениям и работодателям |
| История взаимодействий | `visitors.activity` | Таблица сессий и отдельных событий с пагинацией |

У записей сессий доступны даты, статус и длительность, если они зафиксированы.
Для индивидуальной викторины можно показать личный итог, для ПрофСтарта —
прогресс и баллы по группам, для анкет — числовые оценки, для генерации
аватара — профессию и статус. Полные ответы завершённых анкет доступны через
`GET /api/cms/surveys/responses?user_id=…`.

Период применяется ко всем блокам активности. Обе даты включительны по Москве.
Для профиля достаточно ID.
