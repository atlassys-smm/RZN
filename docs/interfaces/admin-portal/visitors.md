# Аналитика посетителей

Список посетителей платформы с фильтрами, показателями и возможностью открыть цифровой профиль.

---

## Список посетителей

### Таблица

| Колонка | Описание | Визуализация |
|---------|----------|--------------|
| ID | Уникальный идентификатор | Текст |
| Тип | Пользователь / Гость | Бейдж (цветной) |
| Имя | Имя пользователя или «Гость» | Текст |
| Первый визит | Дата и время | Дата |
| Последний визит | Дата и время | Дата |
| Количество визитов | Общее количество | Число |
| Общее время | Суммарное время взаимодействия | Минуты |
| ПАК | С какими ПАК взаимодействовал | Теги (бейджи) |
| Интересы | Профессии/направления | Теги |

Таблица с сортировкой по колонкам.

### Действия

| Действие | Описание |
|----------|----------|
| Открыть профиль | Переход к цифровому профилю (для авторизованных) |
| Подробнее | Детальный просмотр активности |

---

## Фильтры

| Фильтр | Описание |
|--------|----------|
| Тип | Все, авторизованные, гости |
| Период первого визита | Сегодня, неделя, месяц, произвольный |
| Период последнего визита | Сегодня, неделя, месяц, произвольный |
| Количество визитов | Мин / макс |
| ПАК | Конкретный или все |
| Интересы | Профессия, отрасль, направление |

### Поиск

- По имени пользователя
- По ID

### Сортировка

- По дате первого визита
- По дате последнего визита
- По количеству визитов
- По общему времени взаимодействия

---

## Детальный просмотр посетителя

Открывается при клике на «Подробнее».

### История взаимодействий

Список всех сессий с датами. Для каждой сессии:

| Поле | Описание |
|------|----------|
| ПАК | Бейдж |
| Длительность | Минуты |
| Основные действия | Выбранные профессии, просмотренные видео, результаты |

### Статистика

| Показатель | Визуализация |
|------------|--------------|
| Общее количество визитов | Карточка |
| Общее время взаимодействия | Карточка (минуты) |
| Взаимодействия по ПАК | Мини-столбчатая диаграмма |
| Топ-5 профессий | Горизонтальная столбчатая диаграмма |
| Топ-3 направления | Список с процентами |
| Рекомендуемые профессии | Список |

### Временная шкала

Визуальный таймлайн всех взаимодействий с возможностью фильтрации по ПАК и периоду.

---

## Переход к цифровому профилю

Для авторизованных пользователей — кнопка «Открыть профиль» с переходом к полному цифровому профилю (история, результаты тестов, рекомендации).

Для гостей — профиль недоступен, только просмотр активности.

---

## Производительность

| Параметр | Значение |
|----------|----------|
| Загрузка списка (100 записей) | не более 2 секунд |
| Применение фильтра | не более 1 секунды |
| Открытие детального просмотра | не более 2 секунд |
