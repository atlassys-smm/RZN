# Дашборды

Аналитические дашборды административного портала. Доступны в разделе «Аналитика» бокового меню.

---

## Общие требования

| Параметр | Значение |
|----------|----------|
| Отображение в дашборде | не позднее 60 секунд после события |
| Дашборд за 12 месяцев | не более 5 секунд загрузки |
| Выгрузка | CSV, XLSX, PDF (с графиками и текстовыми выводами) |

---

## Главный Dashboard

Общая аналитика по всему ЦЗН.

### Посещаемость

| Показатель | Визуализация |
|------------|--------------|
| Количество посетителей за период | Карточка с числом |
| Уникальные пользователи | Карточка с числом |
| Уникальные гости | Карточка с числом |
| Новые vs повторные визиты | Карточки с числами |
| Динамика посещаемости | Линейный график по дням/неделям |

### Вовлечённость

| Показатель | Визуализация |
|------------|--------------|
| Среднее время взаимодействия | Карточка (минуты) + сравнение с периодом |
| Доля завершённых сессий | Круговая диаграмма или процент с прогресс-баром |
| Среднее количество действий на посетителя | Карточка с числом |

### Обратная связь

| Показатель | Визуализация |
|------------|--------------|
| Количество заполненных анкет | Карточка + сравнение с периодом |
| Средняя оценка | Карточка с числом |
| Количество контактных заявок | Карточка с числом |

### Востребованность профессий

| Показатель | Визуализация |
|------------|--------------|
| Рейтинг профессий (топ-10) | Таблица с сортировкой |
| Рейтинг отраслей (топ-10) | Таблица с сортировкой |
| Рейтинг направлений (топ-10) | Таблица с сортировкой |
| Динамика интереса к профессиям | Линейный график (топ-5) |

### Востребованность работодателей и учебных заведений

| Показатель | Визуализация |
|------------|--------------|
| Рейтинг работодателей (топ-10) | Таблица с сортировкой |
| Рейтинг учебных заведений (топ-10) | Таблица с сортировкой |
| Динамика интереса к работодателям | Линейный график (топ-5) |
| Динамика интереса к учебным заведениям | Линейный график (топ-5) |

### Тепловая диаграмма

| Показатель | Визуализация |
|------------|--------------|
| Активность по времени суток | Тепловая карта (часы × дни недели) |
| Пиковые нагрузки | Подсветка на тепловой карте |

### Фильтры

- **Период:** сегодня, неделя, месяц, произвольный диапазон
- **ПАК:** все или конкретный

## Автоматическая генерация выводов

Дашборды генерируют текстовые выводы на основе данных:

- «Самая популярная профессия — X (Y выборов)»
- «Среднее время прохождения сценария — Z минут»
- «Доля завершённых сессий — N%»
- «Наибольший интерес проявлен к отрасли X»
- Рекомендации по улучшению контента
