# Дашборды

Аналитические дашборды административного портала. Доступны в разделе «Аналитика» бокового меню.

Колонка «Реализовано» отражает наличие расчёта и визуализации в Metabase:
✅ — подключено в описанном охвате; ❌ — не реализовано. Наличие графика не означает
готовность его встраивания в интерфейс административного портала.

---

## Общие требования

| Параметр | Значение |
|----------|----------|
| Отображение в дашборде | не позднее 60 секунд после события |
| Дашборд за 12 месяцев | не более 5 секунд загрузки |
| Выгрузка | CSV, XLSX, PDF (с графиками и текстовыми выводами) |

## Автоматическая генерация выводов

Текстовые выводы планируется формировать в интерфейсе из результатов уже
существующих графиков.

| Текстовый вывод | Откуда брать данные | Правила интерпретации |
|---|---|---|
| «Чаще всего рекомендована профессия X — в Y прохождениях» | Детальная аналитика → ПрофСтарт → «Рекомендуемые профессии (топ-10)», `profstart.professions_top10`; поля `profession` и `recommendations` | Брать максимальное число результатов с профессией. Это рекомендации тестов, а не выбор посетителя. При равенстве использовать формулировку «одна из наиболее часто рекомендуемых профессий». Для исходного вывода «Самая популярная профессия — X (Y выборов)» готового источника пользовательских выборов пока нет |
| «Среднее время сессии — Z минут» | Сводная аналитика по модулям → Общие показатели → «Среднее время сессии», `summary.common.average_minutes` | Общий результат по выбранным модулям. Для конкретного сценария использовать его карточку: `quiz.individual.duration`, `quiz.team.duration`, `profstart.average_minutes` или `feedback.average_minutes`. Не усреднять средние разных модулей |
| «Доля завершённых сессий — N%» | Сводная аналитика по модулям → Общие показатели → «Доля завершённых сессий», `summary.common.completion_percent`; поле `percent` | Использовать готовую долю с теми же датами, ПАК и устройствами. Для сравнения ПАК есть `summary.comparison.completion_percent`. Не усреднять проценты разных модулей |

- «Наибольший интерес проявлен к отрасли X»
- Рекомендации по улучшению контента
