# Аватары профессий

Эталонные образы профессий для ПАК «Аватары». Для каждой профессии — мужской и женский образ.

---

## Список

Таблица: профессия, отрасль, направление, статус загрузки. Фильтрация по отрасли, направлению, статусу. Поиск по названию профессии.

## Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Профессия | → Profession | да |
| Мужское фото | → File | нет |
| Женское фото | → File | нет |

Отрасль и направление отображаются автоматически из справочника профессий.

## Действия

| Действие | Описание |
|----------|----------|
| Загрузить мужское фото | Загрузить эталонное изображение |
| Загрузить женское фото | Загрузить эталонное изображение |
| Заменить фото | Заменить загруженное изображение |
| Удалить фото | Удалить загруженное изображение |

## Статус загрузки

| Статус | Описание |
|--------|----------|
| Готово | Загружены оба пола |
| Частично | Загружен только один пол |
| Не загружено | Изображения отсутствуют |

## Требования к изображениям

| Параметр | Значение |
|----------|----------|
| Формат исходного эталона | JPEG (JPG), PNG; для передачи в FaceAI |
| Разрешение | не менее 1024×1024 |
| Пропорции | 1:1 или 3:4 |
| Фон | Однотонный или прозрачный |

Для каждого образа предусмотрено отдельное превью. В FaceAI передаётся исходный
эталон, а не превью. Требования к интеграции и статус реализации описаны в
[подсистеме аватаров](../../subsystems/profession-avatars/index.md#генерация-через-faceai).
