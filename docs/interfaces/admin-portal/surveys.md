# Анкеты и согласия

Управление анкетами обратной связи и версионируемыми согласиями на обработку персональных данных.

---

## Анкеты

### Создание анкеты

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Название | string | да | Например, «Оценка видеорезюме» |
| Описание | text | нет | |
| Символьный идентификатор | string | да | `external_id` для подхвата на устройствах |

### Типы вопросов

| Тип | Описание |
|-----|----------|
| `rating_scale` | Оценочная шкала (1–5, настраивается) |
| `single_choice` | Выбор одного варианта |
| `multiple_choice` | Выбор нескольких вариантов |
| `text` | Текстовое поле |
| `profession_choice` | Выбор профессий из справочника |

### Настройка вопроса

| Параметр | Описание |
|----------|----------|
| Тип вопроса | Из списка выше |
| Текст вопроса | Формулировка |
| Обязательность | Да / нет |
| Порядок отображения | Число или перетаскивание |
| Условие показа | Привязка к ответу на родительский вопрос |

### Условные вопросы

Вопрос показывается только при определённом ответе на родительский вопрос.

Пример: «Что именно неудобно?» — показать, если оценка ≤ 2.

| Поле | Описание |
|------|----------|
| `parent_id` | ID родительского вопроса |
| `condition` | Оператор и значение: `{"operator": "lte", "value": 2}` |

Доступные операторы: `eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `in`.

### Жизненный цикл

```
Создание (черновик)
    ↓ (публикация)
Активная (is_active = true)
    ↓ (создать новую версию)
Новая версия (черновик) → публикация → старая деактивируется
```

Не может быть двух активных анкет с одинаковым `external_id`.

При смене версии текущие прохождения завершаются по старой версии — ответы привязываются к `survey_id` той версии, которую проходил пользователь.

### Генерация QR-ссылок

1. Выбрать анкету
2. Нажать «Сгенерировать QR-ссылку»
3. Указать срок жизни JWT (7 дней, 30 дней, бессрочно)
4. Система генерирует ссылку вида: `https://platform.example.com/feedback?token=...`
5. Скачать QR-код или скопировать ссылку

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новая анкета |
| Редактировать | Изменить вопросы и настройки (только черновик) |
| Опубликовать | Сделать активной |
| Создать новую версию | Копирование текущей активной в черновик |
| Деактивировать | Снять с публикации |
| Сгенерировать QR-ссылку | Создать ссылку с JWT |

## Согласия

Версионируемые тексты согласий на обработку персональных данных.

### Создание согласия

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Тип | enum | да | `personal_data` / `contact_request` |
| Заголовок | string | да | Название согласия |
| Версия | string | да | Например, `1.0`, `2.0` |
| Текст | text | да | Полный юридический текст |
| Дата вступления в силу | date | да | `effective_from` |

### Версионирование

При создании новой версии старая автоматически деактивируется. Существующие записи о принятии сохраняются.

### Использование в анкетах

При настройке анкеты с контактной заявкой:
1. Включить опцию «Требовать согласие на обработку ПДн»
2. Выбрать активную версию согласия
3. Пользователь видит текст и ставит галочку
4. Без согласия отправка контактных данных невозможна

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новое согласие |
| Редактировать | Изменить текст (только неактивное) |
| Создать новую версию | Копирование в новую версию с новым текстом |
| Деактивировать | Снять с публикации |
