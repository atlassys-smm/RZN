# Административный портал

Единый веб-портал для сотрудников с двумя модулями: управление контентом (CMS) и аналитика. Один вход, одна навигация.

---

## Платформа

| Параметр | Значение |
|----------|----------|
| Платформа | Веб-интерфейс, браузер сотрудника |
| Обслуживает | Система администрирования (CMS), Аналитика и отчётность |
| Пользователи | Администратор, контент-менеджер, оператор, аналитик, технический специалист |

---

## Навигация

Боковое меню с двумя блоками — контент и аналитика:

```
📋 Справочники
├── Отрасли
├── Направления
├── Профессии
├── Учебные заведения
└── Работодатели

🎮 Контент ПАК
├── Викторина
│   ├── Вопросы
│   └── Шаблоны сценариев
├── Аватары профессий
├── Профессии в действии
└── ПрофСтарт

📝 Анкеты
📄 Согласия
👥 Пользователи
📜 Журнал изменений

───

📊 Аналитика
├── Главный Dashboard
├── Сводная по ПАК
├── Детальная по ПАК
│   ├── LED-медиаплатформа
│   ├── ПрофСтарт
│   ├── Аватар профессий
│   ├── Древо профессий
│   ├── Интерактивная карта региона
│   ├── Профбаттл
│   └── Обратная связь
├── Посетители
└── Аналитика анкет
```
