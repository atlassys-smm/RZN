# Справочники

Базовая справочная информация, от которой зависит весь остальной контент платформы.

---

## Отрасли

Справочник отраслей экономики. Группирует профессии и работодателей.

### Список

Таблица: название, количество профессий, количество работодателей.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новая отрасль |
| Редактировать | Изменить название |
| Удалить | Только если нет привязанных профессий и работодателей |

---

## Направления

Справочник профессиональных направлений (8 направлений). Используется в ПрофСтарт для расчёта результатов.

### Список

Таблица: название, описание, количество профессий.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Описание | text | нет |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новое направление |
| Редактировать | Изменить название и описание |
| Удалить | Только если нет привязанных профессий |

---

## Профессии

Центральная сущность, связывающая отрасль и направление. Используется в викторине, ПрофСтарт, аватарах, аналитике, цифровом профиле.

### Список

Таблица: название, отрасль, направление. Фильтрация по отрасли и направлению, поиск по названию.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Описание | text | нет |
| Отрасль | → Industry | да |
| Направление | → Direction | да |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новая профессия |
| Редактировать | Изменить поля карточки |
| Копировать | Дубликат профессии |
| Архивировать | Скрыть из активного справочника |
| Разархивировать | Вернуть из архива |
| Удалить | Только если нет привязанных записей |

---

## Учебные заведения

Справочник школ, колледжей, вузов. Используется в карте региона, аналитике и профиле.

### Список

Таблица: название, тип, адрес. Фильтрация по типу и направлениям подготовки, поиск по названию.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Тип | enum | да |
| Адрес | text | нет |
| Координаты | json | нет |
| Описание | text | нет |
| Сайт | string | нет |
| Телефон | string | нет |
| Направления подготовки | → Direction[] | нет |

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новое учебное заведение |
| Редактировать | Изменить поля карточки |
| Удалить | Если нет привязанных записей |
