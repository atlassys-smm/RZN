## Редактор дерева веток

Основная часть карточки — редактор дерева веток. Каждая ветка — видеофрагмент, дочерние ветки — варианты выбора после него.

**Стартовая ветка** — всегда первая в списке, не имеет текста варианта.

**Дочерние ветки** — варианты выбора. Каждая имеет текст варианта и видеофайл.

### Элементы ветки

| Элемент | Описание |
|---------|----------|
| Название файла | Имя загруженного видео |
| Кнопка замены | Загрузить другое видео |
| Поле «Текст варианта» | Текст для дочерних веток |
| Кнопка «Удалить» | Удалить ветку и все дочерние |
| Кнопка «Раскрыть» | Показать дочерние варианты |
| Кнопка «+ Добавить вариант» | Добавить дочернюю ветку |

### Работа с редактором

1. При создании сценария стартовая ветка создаётся автоматически
2. Видео загружается через кнопку замены в каждой ветке
3. Варианты выбора добавляются кнопкой «+ Добавить вариант» под каждой веткой
4. Навигация по дереву — кнопка «Раскрыть» (рекурсивно)
5. Ветка без дочерних элементов — конец сценария
6. Удаление ветки удаляет все дочерние; стартовую удалить нельзя
7. Порядок вариантов — перетаскиванием

## Предпросмотр

Имитация прохождения сценария с возможностью делать выборы и переходить между ветками.

## Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый видеосценарий |
| Редактировать | Изменить название, профессию, структуру веток |
| Сохранить | Сохранить все изменения |
| Копировать | Дубликат сценария |
| Удалить | Только если сценарий не используется в активных сессиях |
