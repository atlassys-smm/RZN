# Видеосценарии и аватары профессий

Управление интерактивными видеосценариями и эталонными образами профессий.

---

## Профессии в действии

Интерактивные видеосценарии с точками выбора для LED-платформы.

### Список

Таблица: название, профессия, количество веток, дата создания. Фильтрация по профессии, поиск по названию.

### Карточка видеосценария

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Название | string | да |
| Описание | text | нет |
| Профессия | → Profession | нет |

### Редактор дерева веток

Основная часть карточки — редактор дерева веток. Каждая ветка — видеофрагмент, дочерние ветки — варианты выбора после него.

**Стартовая ветка** — всегда первая в списке, не имеет текста варианта.

**Дочерние ветки** — варианты выбора. Каждая имеет текст варианта и видеофайл.

#### Элементы ветки

| Элемент | Описание |
|---------|----------|
| Название файла | Имя загруженного видео |
| Кнопка замены | Загрузить другое видео |
| Поле «Текст варианта» | Текст для дочерних веток |
| Кнопка «Удалить» | Удалить ветку и все дочерние |
| Кнопка «Раскрыть» | Показать дочерние варианты |
| Кнопка «+ Добавить вариант» | Добавить дочернюю ветку |

#### Работа с редактором

1. При создании сценария стартовая ветка создаётся автоматически
2. Видео загружается через кнопку замены в каждой ветке
3. Варианты выбора добавляются кнопкой «+ Добавить вариант» под каждой веткой
4. Навигация по дереву — кнопка «Раскрыть» (рекурсивно)
5. Ветка без дочерних элементов — конец сценария
6. Удаление ветки удаляет все дочерние; стартовую удалить нельзя
7. Порядок вариантов — перетаскиванием

### Предпросмотр

Имитация прохождения сценария с возможностью делать выборы и переходить между ветками.

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый видеосценарий |
| Редактировать | Изменить название, профессию, структуру веток |
| Сохранить | Сохранить все изменения |
| Копировать | Дубликат сценария |
| Удалить | Только если сценарий не используется в активных сессиях |

## Аватары профессий

Эталонные образы профессий для генерации аватаров пользователей. Для каждой профессии — мужской и женский образ.

### Список

Таблица: профессия, отрасль, направление, статус загрузки. Фильтрация по отрасли, направлению, статусу. Поиск по названию профессии.

### Карточка

| Поле | Тип | Обязательное |
|------|-----|:---:|
| Профессия | → Profession | да |
| Мужское фото | → File | нет |
| Женское фото | → File | нет |

Отрасль и направление отображаются автоматически из справочника профессий.

### Действия

| Действие | Описание |
|----------|----------|
| Загрузить мужское фото | Загрузить эталонное изображение |
| Загрузить женское фото | Загрузить эталонное изображение |
| Заменить фото | Заменить загруженное изображение |
| Удалить фото | Удалить загруженное изображение |

### Статус загрузки

| Статус | Описание |
|--------|----------|
| Готово | Загружены оба пола |
| Частично | Загружен только один пол |
| Не загружено | Изображения отсутствуют |

### Требования к изображениям

| Параметр | Значение |
|----------|----------|
| Формат | PNG, JPG, WebP |
| Разрешение | не менее 1024×1024 |
| Пропорции | 1:1 или 3:4 |
| Фон | Однотонный или прозрачный |
