# Экран вопроса

Все вопросы имеют type=single_choice. Экран показывает текст, блок («Хочу»/«Могу» при необходимости), номер и прогресс. Число вопросов берётся из версии сессии, без предположения о 20 вопросах.

| Тест | Управление |
|---|---|
| Соломин | Четыре кнопки шкалы 0–3; один вариант |
| Голланд | Шесть карточек предпочтительных действий; один вариант |
| Геометрический | Пять изображений фигур с подписями; один вариант |

«Далее» активируется после выбора, в том числе нулевого ответа. Клиент отправляет question_id, answer_option_id и time_spent_ms. Следующий экран показывается после подтверждения; повтор запроса при сетевой ошибке не даёт повторного начисления.

У принятого ответа нет редактирования; порядок фиксирован. Кнопка выхода вызывает /abandon и не показывает частичный итог. После обрыва клиент восстанавливает прогресс по сессии. Последнее подтверждение даёт ready_to_complete=true, затем вызывается /complete.

group_id и weight вариантов не передаются пользовательскому клиенту. Свободный текст, множественный выбор, drag-and-drop и вложенные кейсы не используются.
