# Экран вопроса

Вложения вопроса и вариантов приходят в объекте file; изображение открывается по file.url, превью — по file.preview_url при наличии. При восстановлении сессии клиент получает свежие подписанные ссылки; media_id не выдаётся.

Все вопросы имеют type=single_choice. Экран показывает текст, блок («Хочу»/«Могу» при необходимости), номер и прогресс. Число вопросов берётся из версии сессии.

| Тест | Управление |
|---|---|
| Соломин | Четыре кнопки шкалы 0–3; один вариант |
| Голланд | Шесть карточек предпочтительных действий; один вариант |
| Геометрический | Пять изображений фигур с подписями; один вариант |

Вопрос загружается через GET /profstart/question из текущей собственной сессии in_progress; ID сессии не передаётся. Повтор чтения возвращает тот же следующий неотвеченный вопрос и не меняет прогресс.

«Далее» активируется после выбора, в том числе нулевого ответа. Клиент отправляет POST /profstart/answer с answer_option_id. question_id необязателен: если поле отсутствует или равно null, сервер выбирает следующий неотвеченный вопрос; клиент также может передать ID показанного вопроса явно. Следующий вопрос запрашивается после подтверждения сохранения. Пока сессия in_progress, повтор принятого варианта возвращает сохранённый ответ без повторного начисления и продвижения. После завершения повтор последнего ответа получает 409; восстановление описано на [экране расчёта](loading.md).

У принятого ответа нет редактирования; порядок фиксирован. Кнопка выхода вызывает POST /profstart/sessions/{id}/abandon и не показывает частичный итог. После обрыва клиент восстанавливает прогресс по сессии. Подтверждение последнего ответа содержит status=2 (completed), next_question_id=null. Клиент получает результат через GET /profstart/sessions/{id}/result и переходит к его отображению. Сам результат в /answer не возвращается.

group_id вариантов не передаётся пользовательскому клиенту. Поле value приходит в составе варианта; баллы рассчитывает сервер. Свободный текст, множественный выбор, drag-and-drop и вложенные кейсы не используются.
