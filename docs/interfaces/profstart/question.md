# Экран вопроса

Основной экран прохождения теста.

---

## Элементы

- **Прогресс-бар** — показывает, сколько вопросов осталось
  - Например: "Вопрос 5 из 20"
  - Визуальный прогресс-бар (заполненная полоса)
- **Текст вопроса** — крупным шрифтом
- **Медиа-файл** (опционально) — изображение к вопросу
- **Варианты ответа** — зависят от типа вопроса:
  - **Одиночный выбор** — карточки с вариантами, можно выбрать один
  - **Множественный выбор** — карточки с чекбоксами, можно выбрать несколько
  - **Шкала согласия** — слайдер или кнопки "Полностью согласен" → "Полностью не согласен"
  - **Выбор изображения** — карточки с изображениями
  - **Ранжирование** — перетаскивание элементов (drag-and-drop)
  - **Ситуационный кейс** — текст ситуации + вопросы к ней
- **Кнопка "Далее"** — переход к следующему вопросу

---

## Поведение

- При выборе варианта ответа — визуальная подсветка выбранного
- Кнопка "Далее" активируется после выбора ответа
- При нажатии "Далее" — переход к следующему вопросу (≤500 мс)
- Если это последний вопрос — кнопка меняется на "Завершить тест"

---

## Типы вопросов

| Тип | Описание | Элементы управления |
|-----|----------|---------------------|
| `single_choice` | Выбор одного варианта | Карточки с вариантами |
| `multiple_choice` | Выбор нескольких вариантов | Карточки с чекбоксами |
| `agreement_scale` | Шкала согласия | Слайдер или кнопки |
| `image_choice` | Выбор по изображению | Карточки с изображениями |
| `ranking` | Ранжирование | Drag-and-drop |
| `case_study` | Ситуационный кейс | Текст + вопросы |

---

## Особенности

- Нельзя вернуться к предыдущему вопросу
- Нельзя прервать тест — только пройти целиком
- Время на ответ не ограничено (но отслеживается для аналитики)
