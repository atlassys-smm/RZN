# Экран загрузки

Экран отображается пока идёт расчёт результата.

---

## Элементы

- **Анимация загрузки** — спиннер или прогресс-бар
- **Текст:** "Обрабатываем ваши ответы..."
- **Текст:** "Это займёт несколько секунд"

---

## Поведение

- Показывается не более 3 секунд (по ТЗ)
- После завершения расчёта — автоматический переход на экран результата

---

## Особенности

- Экран загрузки нужен, чтобы пользователь понимал, что система работает
- Анимация должна быть приятной и не раздражающей
- После завершения расчёта — плавный переход на экран результата
