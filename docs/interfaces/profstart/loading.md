# Расчёт результата

При отправке последнего ответа через POST /profstart/sessions/{id}/answer клиент показывает индикатор до получения подтверждения. Сервер атомарно сохраняет ответ и результат и возвращает status=2 (completed). После подтверждения клиент получает результат через GET /profstart/sessions/{id}/result. Повтор того же ответа не вызывает повторный расчёт. После восстановления соединения клиент читает статус сессии и запрашивает сохранённый результат.

Целевое время расчёта — до 3 секунд, формирования итогового экрана — до 5 секунд. При сетевой ошибке клиент предлагает повторить запрос той же сессии; новый тест не создаётся. При 409 из-за неполного набора читает состояние и возвращает к следующему вопросу. Ошибка не подменяется произвольным результатом.

После успешного ответа открывается [экран результата](result.md).
