# Экран результата

Экран отображения результатов теста.

!!! danger "Модель оценки не определена"
    Механика формирования цифрового профориентационного портрета **требует доработки**. Без определённой модели расчёта нет данных для вывода на экран результата.

    См. [ПрофСтарт — Цифровой профориентационный портрет](../../subsystems/profstart/index.md).

---

## Элементы (предварительно)

- **Заголовок:** "Ваш результат"
- **Визуальная диаграмма** — выраженность профессиональных направлений
- **Ведущие направления** — список направлений с описанием
- **Рекомендуемые профессии** (опционально) — список профессий
- **Кнопка "Завершить"** — завершение сессии
- **Таймер** — обратный отсчёт до автоматического скрытия

---

## Поведение

- Результат показывается на экране
- Через заданное время (или по кнопке "Завершить") — возврат на стартовый экран
- Результат сохраняется в системе:
  - Для авторизованных пользователей — в профиле
  - Для гостей — обезличенно для аналитики

---

## Особенности

### Киоск (терминал)

- Результат показывается на экране
- Автоматическое скрытие через заданное время
- Или по кнопке "Завершить"
- Возврат на стартовый экран для следующего пользователя

### Веб-версия (личный кабинет)

- Результат сохраняется в личном кабинете
- Можно посмотреть результат позже
- Можно пройти тест повторно
