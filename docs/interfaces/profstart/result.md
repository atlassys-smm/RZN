# Экран результата

Показывает код test_code_type, версию, дату и показатели групп. Название при необходимости читается через GET /profstart/tests/{test_id}; архивная карточка доступна владельцу существующей сессии. Просмотр истории не запускает новый тест.

| Тест | Представление |
|---|---|
| Соломин | Семь общих показателей по сумме «Хочу» и «Могу», шкала 0–18; отдельно категории предмета и характера труда |
| Голланд | Шесть типов RIASEC, исходные суммы и все ведущие при равенстве |
| Геометрический | Одна выбранная фигура и краткое пояснение; без диаграммы силы пяти черт |

Общий профиль с максимум тремя профессиями загружается отдельно через GET /users/me/recommendations. В коде задано влияние Соломина/Голланда/Деллингер — 40/40/20%; актуальные настройки и ID использованных результатов приходят в ответе. При неполном наборе показываются недостающие тесты и эффективные веса имеющихся результатов. Для каждой профессии можно показать score и contributions по всем использованным тестам. До первого завершённого теста общий профиль равен null; существующий профиль может содержать пустой список профессий. Общий рейтинг рассчитывается при каждом запросе из сохранённых источников и весов, заданных в коде; история отдельных результатов сохраняется.

Для профессии общего подбора выводятся название, связанные группы и их числовые вклады. Пустой список не заменяется случайными рекомендациями. Прямоугольник сопровождается описанием переходного состояния; рекомендации берутся из его связей в CMS, как для остальных групп.

Баллы соответствия — правила проекта, не вероятность профессионального успеха. Общая формулировка: результаты помогают исследовать интересы и не определяют пригодность.

На киоске «Завершить» либо таймаут, заданный клиентом, скрывает результат и очищает контекст. Этот таймаут не удаляет запись. В профиле, включая гостевой контекст, результат доступен владельцу; история завершений и прерванные попытки сохраняются раздельно.

[Расчёт](../../subsystems/profstart/results.md) · [API](../../api/profstart.md).

Для дополнительных типов отображаются показатели всех заданных групп по тем же полям scores и принятые ответы из answers (question_id, answer_option_id, answered_at). Показатели групп и профессий сохраняются в источнике; без настройки SOURCE_WEIGHTS такой источник не участвует в итоговом рейтинге.
