# Экран результата

Показывает код test_code_type, версию, дату, показатели и профессии. Название при необходимости читается через GET /profstart/tests/{test_id}; архивная карточка доступна владельцу существующей сессии. Просмотр истории не запускает новый тест.

| Тест | Представление |
|---|---|
| Соломин | Семь общих показателей по сумме «Хочу» и «Могу», шкала 0–18; отдельно категории предмета и характера труда |
| Голланд | Шесть типов RIASEC, исходные суммы и все ведущие при равенстве |
| Геометрический | Одна выбранная фигура и краткое пояснение; без диаграммы силы пяти черт |

Общий рейтинг профессий загружается отдельно через GET /profstart/me/recommendations. По умолчанию влияние Соломина/Голланда/Деллингер — 40/40/20%; актуальные настройки и ID использованных результатов приходят в ответе. При неполном наборе показываются недостающие тесты и эффективные веса имеющихся результатов. Для каждой профессии можно показать score и contributions по всем использованным тестам. При отсутствии результатов рейтинг пуст. Общий рейтинг обновляется после нового прохождения или изменения весов CMS; история отдельных результатов сохраняется.

Для профессии отдельного теста выводятся название, связанные группы и их числовые вклады. Пустой список не заменяется случайными рекомендациями. Прямоугольник сопровождается описанием переходного состояния; рекомендации берутся из его связей в CMS, как для остальных групп.

Баллы соответствия — правила проекта, не вероятность профессионального успеха. Общая формулировка: результаты помогают исследовать интересы и не определяют пригодность.

На киоске «Завершить» либо таймаут, заданный клиентом, скрывает результат и очищает контекст. Этот таймаут не удаляет запись. В профиле, включая гостевой контекст, результат доступен владельцу; история и повторные попытки сохраняются раздельно.
