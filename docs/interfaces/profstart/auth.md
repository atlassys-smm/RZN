# Экран авторизации

Экран выбора способа прохождения: с авторизацией или как гость.

---

## Элементы

- **Заголовок:** "Как вы хотите пройти тест?"
- **Вариант 1: Войти в аккаунт**
  - QR-код для сканирования телефоном
  - Текст: "Отсканируйте QR-код, чтобы войти"
  - Ссылка для ручного ввода (опционально)
- **Вариант 2: Пройти как гость**
  - Кнопка "Продолжить без входа"
  - Пояснение: "Результат будет сохранён обезличенно"

---

## Поведение

- При выборе "Войти в аккаунт" — показывается QR-код
- После сканирования QR-кода — переход на экран вопроса
- При выборе "Пройти как гость" — переход на экран вопроса

---

## Особенности

### Киоск (терминал)

- QR-код для авторизации через мобильное устройство
- Гостевой режим для тех, кто не хочет авторизовываться

### Веб-версия (личный кабинет)

- Пользователь уже авторизован в личном кабинете
- Экран авторизации не показывается
- Сразу переход на экран вопроса
