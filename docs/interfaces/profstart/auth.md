# Идентификация участника

Киоск предлагает вход через общий сервис идентификации или продолжение гостем. QR используется существующим auth-сценарием; после сканирования клиент ждёт подтверждённый контекст пользователя, а не начинает тест лишь по факту сканирования.

Гость также имеет User и user_id. Пояснение: «Результат доступен в текущем гостевом профиле; после входа он останется у этого пользователя». Согласия и срок гостевого контекста определяет общая [подсистема идентификации](../../subsystems/identification.md).

В личном кабинете используется текущий контекст. При выходе на киоске данные и контекст прошлого участника очищаются. Один device-токен не предоставляет доступ к произвольным результатам пользователей.
