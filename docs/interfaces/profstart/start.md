# Стартовый экран

Показывает три типа и их последние опубликованные версии: Соломин, тест на основе Голланда, геометрический тест. Источник — GET /profstart/tests; недоступный по возрасту или неопубликованный тест не запускается.

Карточка содержит название, краткое описание, число заданий. После выбора показывается инструкция. Возрастная группа выбирается карточкой из действующего справочника; при непустом age_group_ids она обязательна. Нет доступных версий — понятное сообщение без кнопки старта.

«Начать» устанавливает контекст участника, затем создаёт отдельную сессию выбранного test_id. Все три теста не запускаются одним общим набором. Повторное прохождение допустимо; оно создаёт новую попытку.
