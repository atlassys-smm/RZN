# Стартовый экран

Показывает три поддерживаемых типа и их активные версии: Соломин, тест на основе Голланда, геометрический тест. Источник — GET /profstart/tests; недоступный по возрасту или неактивный тест не запускается. Типы, добавленные CMS без алгоритма расчёта, не показываются; прямой старт возвращает 422 unsupported_test_type.

Карточка содержит название, краткое описание, число заданий. После выбора показывается инструкция. Возрастная группа выбирается карточкой из действующего справочника; при непустом age_group_ids она обязательна. Нет доступных версий — понятное сообщение без кнопки старта.

«Начать» устанавливает контекст участника, затем создаёт отдельную сессию выбранного test_id. Все три теста не запускаются одним общим набором. Повторное прохождение допустимо; оно создаёт новую попытку после завершения или прерывания текущей. Перед стартом клиент читает GET /profstart/me/sessions/active: существующую in_progress предлагает продолжить, при отсутствии сервер возвращает null. Пока такая сессия есть, новый старт любого типа возвращает 409. Список всех собственных попыток доступен через GET /profstart/me/sessions.
