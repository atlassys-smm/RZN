# Стартовый экран

Экран приветствия и выбора возрастной группы.

---

## Элементы

- **Логотип "ПрофСтарт"** — в верхней части экрана
- **Краткое описание теста** — текст о назначении теста
- **Выбор возрастной группы** — инфографика (не конкретный возраст)
  - Например: "Школьник 5–7 класса" / "Школьник 8–11 класса"
  - Визуальные карточки с иконками или иллюстрациями
- **Кнопка "Начать тест"** — активируется после выбора возрастной группы

---

## Поведение

- При выборе возрастной группы активируется соответствующая карточка
- Кнопка "Начать тест" становится активной после выбора
- При нажатии "Начать тест" — переход на экран авторизации

---

## Особенности

- Возрастная группа выбирается инфографикой, не конкретным возрастом
- Карточки должны быть крупными и понятными
- Визуальный стиль должен привлекать внимание школьников
