# Стартовый экран

Показывает активные версии встроенных и дополнительных типов тестов. Уже завершённые типы не показываются. Источник — GET /profstart/tests с необязательным возрастным фильтром; неактивный тест не запускается. Типы, добавленные и опубликованные через CMS, доступны для прохождения; результат содержит ответы и показатели групп, а показатели групп и связанных профессий сохраняются в источнике. Участие в итоговом рейтинге задаётся в SOURCE_WEIGHTS.

Карточка содержит название, краткое описание, число заданий. После выбора показывается инструкция. Возрастная группа может выбираться из действующего справочника для фильтрации каталога. В запрос старта она не передаётся. Нет доступных версий — понятное сообщение без кнопки старта.

«Начать» устанавливает контекст участника, затем создаёт отдельную сессию выбранного test_id. Все три теста не запускаются одним общим набором. Полностью пройти тип можно один раз, включая новые версии. После прерывания можно создать новую попытку. Перед стартом клиент читает GET /profstart/me/sessions/active: существующую in_progress предлагает продолжить, при отсутствии сервер возвращает null. Пока такая сессия есть, новый старт любого типа возвращает 409. Список всех собственных попыток доступен через GET /profstart/me/sessions.
