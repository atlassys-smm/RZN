# ПрофНавигатор 62

**Единая цифровая профориентационная платформа для Центра занятости населения Рязанской области**

---

## О проекте

ПрофНавигатор 62 — это программно-аппаратный комплекс, объединяющий интерактивное ПО большого LED-экрана, командные профориентационные сценарии, модуль «ПрофСтарт», единый сервис регистрации и цифрового профиля пользователя, локальную аналитику ПАК и систему обратной связи.

## Основные компоненты

| Компонент | Описание |
|-----------|----------|
| **LED-медиаплатформа** | Интерактивное ПО большого LED-экрана для проведения викторин, голосований, командных игр |
| **Командная работа** | Модуль командной профориентационной игры с формированием команд, ролями и рейтингом |
| **ПрофСтарт** | Интерактивный профориентационный тест школьника с цифровым портретом и рекомендациями |
| **Единая регистрация** | Сервис регистрации, аутентификации и цифрового профиля пользователя |
| **Аналитика** | Консолидированная аналитика собственного ПО и внешних ПАК |
| **Обратная связь** | Автономный модуль сбора оценок и комментариев посетителей |

## Интегрируемые ПАК

- Древо профессий
- Интерактивная карта региона
- Профбаттл
