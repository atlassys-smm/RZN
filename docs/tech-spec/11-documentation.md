# 11. Требования к документированию

По итогам оказания услуг Исполнитель предоставляет документацию на русском языке.

## Организационные документы

- акт сдачи-приемки оказанных услуг
- промежуточные акты (если предусмотрено контрактом)
- руководство по эксплуатации ПАК
- руководство оператора
- руководство администратора

## Техническая документация

- полный исходный код программного обеспечения
- схема базы данных
- миграции базы данных
- конфигурационные файлы
- lock-файлы зависимостей
- воспроизводимая инструкция сборки
- установочные пакеты и/или контейнеры
- сценарий развёртывания локального стенда
- спецификация серверных API
- документация протокола OIDC/OAuth или эквивалента
- схемы аналитических событий и правила версионирования
- три рабочих адаптера внешних ПАК
- тестовые заглушки и наборы контрольных событий

## Руководства

- руководство администратора
- руководство оператора
- руководство методиста и контент-менеджера
- руководство технического специалиста

## Безопасность и регламенты

- модель угроз и описание реализованных мер защиты
- матрица ролей и прав
- регламенты согласий, удаления и обезличивания
- регламент резервного копирования и восстановления

## Тестирование

- автоматизированные тесты критической логики
- контрольные наборы ответов для проверки «ПрофСтарт»
- программа и протокол приёмочных испытаний
- перечень сторонних компонентов и лицензий

## Форматы передачи

| Результат | Формат |
|-----------|--------|
| Исходные коды и конфигурации | архив |
| Резервная копия | архив с инструкцией |
| Мультимедийный контент | на электронном носителе |
| Документы | бумажные носители + электронные версии |

!!! note
    Электронные версии передаются на согласованном накопителе и/или через защищённый канал передачи данных.
