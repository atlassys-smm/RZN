# 5. Требования к оборудованию и инфраструктуре

## 5.1. Общий состав

Для развертывания ПАК используются:

- медиасервер
- устройство оператора
- сетевое оборудование
- средства беспроводного доступа
- источник бесперебойного питания
- средства передачи видеосигнала
- кабельно-коммутационная инфраструктура
- интерфейсные устройства
- при необходимости — считыватели, карточки/метки и контроллеры NFC/RFID/QR

!!! note
    Оборудование предоставляется Заказчиком либо приобретается им отдельно. Исполнитель выполняет обследование, настройку, подключение и интеграцию.

---

## 5.2. Требования к инфраструктуре ПАК

### Подсистемы инфраструктуры

- локальное дисковое пространство для статистики, журналов, отчётов и резервных копий
- сетевая инфраструктура для объединения медиасервера, устройства оператора, LED-процессора и точек доступа
- средства вывода видеосигнала на процессор LED-экрана
- система локального звукового сопровождения (при наличии)
- источник бесперебойного питания для медиасервера и сетевого оборудования
- средства удалённого сервисного доступа
- при необходимости — подсистема NFC/RFID/QR-считывателей

### Требования к сети

- необходимая пропускная способность
- устойчивость при одновременном подключении посетителей
- разделение служебного и гостевого доступа
- контроль доступа к административным сервисам
- возможность расширения комплекса
- двусторонняя связь аналитического сервера с внешними ПАК
- автономность пользовательских функций каждого ПАК

### Серверная инфраструктура

- размещение сервиса регистрации и базы профилей
- при использовании ВМ — гарантированные ресурсы, постоянный адрес, синхронизация времени

---

## 5.3. Кабельно-коммутационная инфраструктура

| Параметр | Требование |
|----------|-----------|
| Кабельные трассы | скрытый или аккуратный открытый способ в кабель-каналах |
| Видеосигнал | HDMI ≥2.0 или DisplayPort ≥1.4 |
| ЛВС | не ниже CAT 5e UTP; для длинных линий — не ниже CAT 6A FTP |
| Длинные дистанции | активные оптические линии или специализированные передатчики |
| Электропитание | 220 В, 50 Гц |
| Маркировка | все кабели и порты промаркированы |

---

## 5.4. Оборудование точек обратной связи

При использовании существующего терминала — работа на его сенсорном экране и вычислительном устройстве при подтверждённой совместимости.

**Для отдельной точки:**

| Параметр | Требование |
|----------|-----------|
| Дисплей | сенсорный, диагональ ≥10"; от 21" — Full HD, ≥300 кд/м² |
| Процессор | 64-разрядный, ≥4 ядер, ≥3,4 ГГц, декодирование 4K |
| Память | ≥8 ГБ RAM |
| Накопитель | SSD ≥256 ГБ |
| Корпус | устойчивый, исключающий доступ к коммутации |
| Сеть | Ethernet |
| Запуск | автоматический полноэкранный режим |

---

## 5.5. Оборудование точек профориентационного тестирования

| Параметр | Требование |
|----------|-----------|
| Панель | интерактивная, диагональ ≥21,5" |
| Разрешение | ≥Full HD; от 43" — предпочтительно 4K UHD |
| Касания | ≥10 одновременных (тест использует одиночное) |
| Защита | защитное стекло для интенсивной эксплуатации |
| Процессор | 64-разрядный, ≥4 ядер, ≥3,4 ГГц, декодирование 4K |
| Память | ≥8 ГБ RAM |
| Накопитель | SSD ≥256 ГБ |
| Сеть | Ethernet |
| Корпус | исключающий доступ к коммутации |

!!! note
    Камера, микрофон, сканер документов и биометрические устройства для базового теста **не требуются**.
