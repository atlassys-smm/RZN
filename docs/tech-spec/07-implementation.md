# 7. Порядок создания и ввода в эксплуатацию ПАК

## 7.1. Исходные данные

До начала разработки Заказчик предоставляет (не позднее **5 рабочих дней** с даты заключения контракта):

- подтверждение возможности встроить единый вход и локальную очередь событий в каждый внешний ПАК
- фактическое разрешение, частоту, контроллер и схему подключения LED
- утверждённую методику «ПрофСтарт»: веса, шкалы, пороги, контрольные ответы
- правовую модель профилей несовершеннолетних, тексты согласий и сроки хранения
- расчёт количества терминалов, сессий, событий и объёма медиаконтента
- перечень устройств, ОС и браузеров
- требования RPO/RTO и допустимое время недоступности backend-сервера
- утверждённые границы редактирования CMS и макеты интерфейсов

!!! note
    При нарушении срока предоставления исходных данных сроки выполнения работ подлежат соразмерному переносу.

### 7.1.1. Перечень основных услуг

1. **Концепция демонстративного материала** (10 дней) — презентация, архитектура, блок-схемы, прототипы, модель регистрации, видеоролик
2. **Предпроектное обследование** — изучение действующих ПАК, LED, правовой модели, методики, сети
3. **Технический фундамент** — backend, сервис идентификации, роли, БД, API, событийный контур, мониторинг
4. **Основные пользовательские сценарии** — LED-медиаплатформа, мобильные клиенты, панель оператора, CMS
5. **Модули «ПрофСтарт» и обратной связи** — тест, портрет, анкеты, контактные заявки
6. **Интеграции и аналитика** — адаптеры ПАК, нормализация, дашборды, отчёты
7. **Сквозная приёмка и ввод** — испытания, восьмичасовой прогон, опытная эксплуатация

### 7.1.2. Детализированный состав работ

- разработка Концепции демонстративного материала
- обследование объекта и параметров LED-экрана
- анализ целевой аудитории и материалов Заказчика
- обследование трёх действующих ПАК
- согласование перечня событий и методики расчёта
- разработка единой модели данных и справочников
- разработка аналитического хранилища, дашбордов и отчётов
- разработка креативной концепции и прототипов
- проектирование командной игры
- проектирование модели учётной записи и цифрового профиля
- разработка сервиса регистрации и аутентификации
- внедрение единого входа во все ПАК
- разработка ПО и интерфейсов
- разработка и адаптация стартового контента
- настройка оборудования
- монтаж и подключение
- интеграция с LED-экраном
- автономное размещение модуля обратной связи
- настройка анкет и справочников
- интеграция с внешними ПАК
- функциональное, интеграционное и нагрузочное тестирование
- опытная эксплуатация
- обучение сотрудников
- передача документации

- правила командной игры
- прототипы экранов и панели оператора
- визуальная концепция
- демонстрация прототипа командного раунда
- демонстрация на тестовом оборудовании
- демонстрация с полным сценарным пакетом

## 7.3. Форматы передачи результатов

| Результат | Формат |
|-----------|--------|
| Концепция | PPTX/PDF, DOCX/PDF, PDF/SVG/PNG, MP4 |
| ПО | установочный комплект, zip/exe |
| Исходные коды | формат среды разработки, архив |
| Видеоролики | MP4, MOV |
| Аудио | WAV, OGG, MP3 |
| Графика | PNG, JPG, SVG, PSD |
| Сервис регистрации | установочный комплект, код, схема БД, API |
| Данные и конфигурации | JSON, CSV, XML |
| Анкеты и согласия | JSON/XML с версиями |
| Выгрузки | XLSX, CSV, PDF |
| API и схемы событий | OpenAPI/JSON Schema |
| Аналитическая модель | JSON, CSV, XLSX, PDF/DOCX |
| Сценарные пакеты | документированный архив |
| Конфигурация «ПрофСтарт» | JSON, CSV, XLSX |
| Резервная копия | архив с инструкцией |
