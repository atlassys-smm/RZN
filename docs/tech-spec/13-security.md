# 13. Требования к безопасности

## 13.1. Общие требования

Исполнитель оказывает услуги в соответствии с требованиями применимых нормативных правовых и технических актов РФ, требованиями производителя LED-экрана и правилами эксплуатации объекта.

## 13.2. Требования к безопасности

### Информационная безопасность

- соблюдение законодательства об информации, защите детей и персональных данных
- сбор контактных данных только с отдельного информированного действия
- раздельный доступ к обезличенной аналитике и контактным заявкам
- исключение отображения персональных данных и комментариев на публичном LED
- очистка пользовательских данных после завершения анкеты или тайм-аута
- добровольность регистрации и гостевое использование
- отсутствие паролей в открытом виде, на экранах и в аналитике
- автоматический выход и очистка после сессии
- раздельная обработка учётных данных, профилей, заявок и аналитики
- отдельный порядок для несовершеннолетних
- защита административных интерфейсов
- безопасное размещение оборудования и кабелей
- отсутствие острых и незакреплённых элементов
- отсутствие системных окон и паролей на LED
- экстренное завершение сценария
- отсутствие произвольных имён и текстов без модерации

### Безопасность «ПрофСтарт»

- результат не представляется как медицинский диагноз
- отсутствие дискриминационных ограничений
- отсутствие сбора персональных и биометрических данных
- предупреждение о рекомендательном характере
- согласование методических материалов

## 13.3. Технические требования

| Требование | Описание |
|-----------|----------|
| Раздельное хранение | Базы или схемы для учётных данных, профилей, согласий, заявок, контента, аналитики |
| ID профиля | Псевдонимизированные персональные данные |
| Публичные отчёты | Только по агрегированным данным |
| Межсервисный обмен | TLS или выделенный защищённый сегмент |
| Секреты | Не в исходном коде и журналах |
| Срок хранения статистики | Настраиваемый, по умолчанию 36 месяцев |
| Несовершеннолетние | Отдельные согласия и правила |
| Запрет вывода на LED | Профили, контакты, комментарии, токены, служебная информация |
