# Техническое задание на ЕПК «ПрофНавигатор 62»

## Обзор документа

Техническое задание на создание единой цифровой профориентационной платформы «ПрофНавигатор 62» для Центра занятости населения Рязанской области.

**Объект закупки:** оказание услуг по разработке, настройке и вводу в эксплуатацию единого программно-аппаратного комплекса, объединяющего:

- интерактивное ПО большого LED-экрана
- командные профориентационные сценарии
- модуль «ПрофСтарт» (профориентационный тест школьника)
- единый сервис регистрации и цифрового профиля пользователя
- локальную аналитику ПАК
- систему обратной связи
