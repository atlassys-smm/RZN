# 12. Объем гарантий и сроки

## 12.1. Гарантийный срок

Не менее **12 календарных месяцев** с даты подписания акта сдачи-приемки оказанных услуг.

## 12.2. Область гарантии

| Объект | Срок |
|--------|------|
| Настройка, подключение и интеграция оборудования | ≥12 месяцев |
| Программное обеспечение | ≥12 месяцев |
| Интеграционные адаптеры, хранилище, дашборды, отчёты | ≥12 месяцев |
| Модуль обратной связи, конструктор анкет, контактные заявки | ≥12 месяцев |
| Сервис регистрации, профили, личный кабинет, API | ≥12 месяцев |
| Мультимедийный контент и сценарии | ≥12 месяцев |
| Монтажные и пусконаладочные работы | ≥12 месяцев |
| Модуль «ПрофСтарт», банк вопросов, алгоритм, портрет | ≥12 месяцев |

## 12.3. Гарантийные обязательства

Исполнитель гарантирует функционирование ПО, интеграционных адаптеров, хранилища, модулей обратной связи и «ПрофСтарт», сервиса регистрации, конструктора анкет, контактных заявок, дашбордов и отчётов в соответствии с назначением, согласованными схемами событий и приёмочными критериями в течение гарантийного срока.

## 12.4. Устранение недостатков

При обнаружении недостатков, препятствующих штатной эксплуатации, Исполнитель обязан провести диагностику и устранить их за свой счёт в сроки, согласованные с Заказчиком с учётом критичности неисправности.

## 12.5. Критическая неисправность

!!! warning
    Критической считается неисправность, при которой невозможно:

    - запустить основное приложение
    - вывести изображение на LED-экран
    - провести активную сессию
    - сохранить результаты

Для критической неисправности Исполнитель должен приступить к дистанционной диагностике **не позднее следующего рабочего дня** после получения уведомления.
