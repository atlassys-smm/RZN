# Командная игра

Описание сущностей для командной профориентационной игры.

Используется в сценарии: **Командная работа**.

---

## TeamGameRound (Раунд командной игры)

Раунд в командной профориентационной игре. Каждый раунд содержит набор вопросов/заданий для команд.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор раунда |
| `name` | string | Название раунда (например, "Быстрый старт", "Инструменты специалиста") |
| `description` | text, nullable | Описание раунда |
| `type` | enum | Тип раунда: `quick_start`, `tools`, `skills`, `situation`, `team_building`, `process`, `future`, `regional`, `final` |
| `order` | integer | Порядок раунда в игре |
| `time_limit` | integer, nullable | Время на раунд в секундах |
| `points_multiplier` | decimal | Множитель баллов для этого раунда |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **TeamGameRound → TeamGameQuestion**: раунд имеет множество вопросов/заданий

### Где используется

- **CMS** — создание и управление раундами
- **LED-медиаплатформа** — проведение раундов командной игры

---

## TeamGameQuestion (Вопрос/задание командной игры)

Вопрос или задание для раунда командной игры. Может быть разных типов (12 типов заданий из ТЗ).

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор вопроса |
| `round_id` | UUID | ID раунда |
| `type` | enum | Тип задания: `profession_by_description`, `recognize_by_image`, `recognize_by_video`, `matching`, `sequence`, `case_study`, `role_distribution`, `resource_selection`, `error_finding`, `prediction`, `argumentation`, `media_round`, `final_case` |
| `text` | text | Текст вопроса/задания |
| `media_id` | UUID, nullable | ID файла (изображение или видео) |
| `time_limit` | integer, nullable | Время на задание в секундах |
| `points` | integer | Баллы за правильное выполнение |
| `explanation` | text, nullable | Методическое пояснение к правильному ответу |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **TeamGameQuestion → TeamGameRound**: вопрос принадлежит одному раунду (`round_id`)
- **TeamGameQuestion → File**: вопрос может иметь медиа-файл (`media_id`)
- **TeamGameQuestion → TeamGameAnswerOption**: вопрос имеет множество вариантов ответа

### Где используется

- **CMS** — создание вопросов/заданий для раундов
- **LED-медиаплатформа** — показ заданий командам

## TeamGameAnswerOption (Вариант ответа командной игры)

Вариант ответа для вопроса/задания командной игры.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор варианта |
| `question_id` | UUID | ID вопроса |
| `text` | text | Текст варианта ответа |
| `media_id` | UUID, nullable | ID файла (изображение) |
| `is_correct` | boolean | Является ли вариант правильным |
| `order` | integer | Порядок отображения |

### Связи

- **TeamGameAnswerOption → TeamGameQuestion**: вариант принадлежит одному вопросу (`question_id`)
- **TeamGameAnswerOption → File**: вариант может иметь медиа-файл (`media_id`)

### Где используется

- **CMS** — создание вариантов ответов
- **LED-медиаплатформа** — показ вариантов командам

### Примечания

Типы заданий командной игры (12 типов):

1. `profession_by_description` — выбор профессии по описанию задач
2. `recognize_by_image` — распознавание профессии по изображению
3. `recognize_by_video` — распознавание профессии по видео
4. `matching` — сопоставление профессий, компетенций, инструментов
5. `sequence` — восстановление последовательности этапов процесса
6. `case_study` — ситуационный кейс с выбором решения
7. `role_distribution` — распределение ролей в команде
8. `resource_selection` — выбор набора ресурсов и специалистов
9. `error_finding` — поиск ошибки в рабочей ситуации
10. `prediction` — командный прогноз развития технологии
11. `argumentation` — задание на аргументацию и консенсус
12. `media_round` — медиараунд с видеофрагментом
13. `final_case` — финальный комплексный кейс
