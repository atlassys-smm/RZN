# Аватар профессий

Описание сущностей для хранения эталонных образов профессий и сгенерированных аватаров пользователей в образах профессий.

---

## ProfessionAvatarTemplate (Эталонный образ профессии)

Эталонное изображение профессии — шаблон, в который подставляется лицо пользователя. Для каждой профессии хранятся два варианта: мужской и женский. Используется ПАК «Аватар профессий» как основа для генерации.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор шаблона |
| `profession_id` | UUID | ID профессии, для которой хранится эталонный образ |
| `male_photo_file_id` | UUID | ID файла — эталонное фото мужчины |
| `female_photo_file_id` | UUID | ID файла — эталонное фото женщины |
| `created_at` | timestamp | Дата и время создания записи |
| `updated_at` | timestamp | Дата и время последнего обновления |

### Связи

- **ProfessionAvatarTemplate → Profession**: шаблон привязан к конкретной профессии (`profession_id`)
- **ProfessionAvatarTemplate → File** (мужское фото): эталонное фото мужчины (`male_photo_file_id`)
- **ProfessionAvatarTemplate → File** (женское фото): эталонное фото женщины (`female_photo_file_id`)

### Где используется

- **ПАК «Аватар профессий»** — выбор эталонного образа по полу пользователя для генерации аватара
- **CMS** — управление и загрузка эталонных образов профессий

---

## ProfessionAvatar (Аватар профессии)

Сгенерированное изображение пользователя в образе определённой профессии. Создаётся ПАК «Аватар профессий» на основе эталонного шаблона (`ProfessionAvatarTemplate`) и сохраняется в профиле пользователя. Доступно по QR-коду или в личном кабинете.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор аватара |
| `user_id` | UUID, nullable | ID пользователя (если авторизован) |
| `guest_id` | UUID, nullable | ID гостевой сессии (если не авторизован) |
| `profession_id` | UUID | ID профессии, в образе которой сгенерирован аватар |
| `image_file_id` | UUID | ID файла (изображение аватара) |
| `qr_token` | string | Уникальный токен для доступа по QR-коду |
| `created_at` | timestamp | Дата и время создания аватара |

### Связи

- **ProfessionAvatar → User**: аватар может быть привязан к пользователю (`user_id`)
- **ProfessionAvatar → GuestSession**: аватар может быть привязан к гостевой сессии (`guest_id`)
- **ProfessionAvatar → Profession**: аватар связан с конкретной профессией (`profession_id`)
- **ProfessionAvatar → ProfessionAvatarTemplate**: аватар сгенерирован на основе эталонного шаблона профессии
- **ProfessionAvatar → File**: аватар хранится как файл (`image_file_id`)

### Где используется

- **ПАК «Аватар профессий»** — генерация и сохранение аватаров на основе эталонных образов
- **Цифровой профиль** — отображение аватаров в профиле пользователя
- **Личный кабинет** — просмотр и управление аватарами
- **Аналитика** — учёт генерации и просмотра аватаров

### Доступ по QR

- Каждый аватар имеет уникальный `qr_token`
- QR-код генерируется на основе токена (например, `https://profnavigator62.ru/avatar/{qr_token}`)
- По QR-коду можно получить доступ к аватару без авторизации (публичный доступ)
- Срок действия QR-кода — настраиваемый (по умолчанию бессрочно)

### Примечания

- Если пользователь не авторизован, аватар привязывается к `guest_id`
- После авторизации аватар может быть привязан к `user_id` (аналогично гостевым сессиям)
- Пользователь может иметь множество аватаров в разных профессиях
- Аватары отображаются в цифровом профиле как часть истории интересов
