# Аватары профессий

Описание сущностей для хранения эталонных образов профессий и сгенерированных аватаров пользователей в образах профессий.

---

## ProfessionAvatar (Эталонный образ профессии)

Эталонное изображение профессии — шаблон, в который подставляется лицо пользователя. Для каждой профессии хранятся два варианта: мужской и женский. Используется ПАК «Аватар профессий» как основа для генерации.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор |
| `profession_id` | integer (int64, unique) | ID профессии (один аватар на профессию) |
| `male_photo_file_id` | integer (int64) | ID файла — эталонное фото мужчины |
| `female_photo_file_id` | integer (int64) | ID файла — эталонное фото женщины |
| `created_at` | timestamp | Дата и время создания |
| `updated_at` | timestamp | Дата и время последнего обновления |

### Связи

- **ProfessionAvatar → Profession**: привязка к профессии (`profession_id`, unique)
- **ProfessionAvatar → File** (мужское фото): `male_photo_file_id`
- **ProfessionAvatar → File** (женское фото): `female_photo_file_id`

### Где используется

- **ПАК «Аватар профессий»** — выбор эталонного образа по полу пользователя для генерации
- **CMS** — управление эталонными образами профессий

---

## UserAvatar (Аватар пользователя)

Сгенерированное изображение пользователя в образе определённой профессии. Создаётся ПАК «Аватар профессий» на основе эталонного шаблона (`ProfessionAvatar`) и сохраняется в профиле пользователя.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор |
| `user_id` | integer (int64) | ID пользователя (гостя или авторизованного) |
| `profession_id` | integer (int64) | ID профессии, в образе которой сгенерирован аватар |
| `image_file_id` | integer (int64) | ID файла (изображение аватара) |
| `qr_token` | string (unique) | Уникальный токен для доступа по QR-коду |
| `created_at` | timestamp | Дата и время создания |

### Связи

- **UserAvatar → User**: привязка к пользователю (`user_id`)
- **UserAvatar → Profession**: связь с профессией (`profession_id`)
- **UserAvatar → File**: изображение аватара (`image_file_id`)

### Где используется

- **ПАК «Аватар профессий»** — терминал сохраняет сгенерированный аватар
- **Личный кабинет** — пользователь просматривает свои аватары (`GET /me/avatars`)
- **Публичный доступ** — по QR-коду (`GET /avatars/qr/{qr_token}`)

## Доступ к файлам

### Signed URLs

Файлы аватаров доступны по подписанным URL с ограниченным сроком действия:

- **Формат**: `/api/files/{uuid}?expires={timestamp}&sig={hmac}`
- **Генерация**: HMAC-SHA256 подпись на основе `file_uuid:expires`
- **Срок действия**: 24 часа (86400 секунд) для аватаров пользователей
- **Ключ подписи**: `JWT_SECRET_KEY` из конфигурации

### Публичный доступ по QR

- Каждый `UserAvatar` имеет уникальный `qr_token`
- Эндпоинт: `GET /avatars/qr/{qr_token}`
- Возвращает аватар с подписанным URL для скачивания изображения
- QR-код генерируется на терминале: `https://profnavigator62.ru/avatar/{qr_token}`

## Хранение файлов

Файлы организуются по модулям в отдельных папках:

```
/data/uploads/
├── avatars/       # Аватары профессий и пользователей
├── videos/        # Видеоконтент
├── documents/     # Документы
└── general/       # Прочие файлы
```

Модель `File` содержит поле `module` для определения папки хранения.

## API

### Эталонные образы (CMS)

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/avatars` | Список эталонных образов |
| `POST` | `/avatars` | Создать (multipart: profession_id, male_photo, female_photo) |
| `GET` | `/avatars/{profession_id}` | Получить по профессии |
| `PUT` | `/avatars/{profession_id}` | Обновить фото |
| `DELETE` | `/avatars/{profession_id}` | Удалить |

### Пользовательские аватары

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/users/{user_id}/avatars` | Терминал сохраняет аватар (multipart) |
| `GET` | `/me/avatars` | Список своих аватаров (с signed URLs) |
| `GET` | `/me/avatars/{avatar_id}` | Детали своего аватара |
| `DELETE` | `/me/avatars/{avatar_id}` | Удалить свой аватар |
| `GET` | `/avatars/qr/{qr_token}` | Публичный доступ по QR |

### Файлы

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/files/{uuid}?expires=...&sig=...` | Скачать файл по подписанному URL |
