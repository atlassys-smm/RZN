# Профессии, отрасли и направления

Описание сущностей для справочника профессий, отраслей и профессиональных направлений.

---

## Profession (Профессия)

Справочник профессий. Используется в различных модулях системы: викторины, тесты, командные игры, рекомендации, аналитика.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор профессии |
| `name` | string | Название профессии |
| `description` | text, nullable | Описание профессии |
| `industry_id` | integer (int64) | ID индустрии, к которой относится профессия |
| `direction_id` | integer (int64), nullable | ID профессионального направления; может быть не назначено |
| `skills` | text, nullable | Ключевые навыки |
| `prospects` | text, nullable | Перспективы карьеры |
| `min_salary` | integer, nullable | Минимальная зарплата, тыс. руб. |
| `max_salary` | integer, nullable | Максимальная зарплата, тыс. руб. |
| `deleted_at` | timestamp with time zone, nullable | Отметка удаления |

### Связи

- **Profession → Industry**: профессия принадлежит одной индустрии (`industry_id`)
- **Profession → Direction**: профессия может принадлежать одному направлению (`direction_id`)
- **Profession → File**: профессия может иметь связанные файлы (изображения, видео)

### Где используется

- **CMS** — управление справочником профессий
- **LED-медиаплатформа** — отображение профессий в сценариях, голосование за профессии (генерируется динамически)
- **ПрофСтарт** — рекомендации профессий по результатам теста
- **Командная игра** — вопросы о профессиях
- **Цифровой профиль** — выбранные профессии в профиле
- **Аналитика** — анализ интереса к профессиям
- **Обратная связь** — выбор интересующих профессий в анкете

## Industry (Индустрия)

Справочник крупных индустрий экономики. Группирует профессии и детальные отрасли.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор индустрии |
| `name` | string | Название индустрии |
| `deleted_at` | timestamp with time zone, nullable | Отметка удаления |

### Связи

- **Industry → Profession**: одна индустрия имеет множество профессий

### Где используется

- **CMS** — управление справочником индустрий
- **Аналитика** — анализ интереса к индустриям
- **Цифровой профиль** — выбранные индустрии в профиле

---

## Direction (Профессиональное направление)

Общий справочник профессиональных направлений платформы.

!!! note "Новая модель ПрофСтарт"
    В трёх предзаданных тестах показатели рассчитываются по отдельным `TestGroup`, а профессии подбираются через `TestGroupProfession`. `Direction` остаётся общим справочником платформы; его восемь направлений не являются шкалами этих тестов. См. [группы результатов](test.md).

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор направления |
| `name` | string | Название направления |
| `description` | text, nullable | Описание направления |
| `deleted_at` | timestamp with time zone, nullable | Отметка удаления |

### Связи

- **Direction → Profession**: одно направление имеет множество профессий

### Где используется

- **CMS** — управление справочником направлений
- **ПрофСтарт** — связь с профессиями через отдельные группы тестов; `Direction` остаётся метаданными профессии
- **Аналитика** — анализ интереса к направлениям
- **Цифровой профиль** — рекомендуемые направления в профиле

### Примечания

В системе предусмотрено не менее 8 профессиональных направлений:

1. Естественно-научное
2. Инженерно-техническое
3. Информационно-математическое
4. Социально-коммуникативное
5. Гуманитарно-языковое
6. Художественно-творческое
7. Организационно-предпринимательское
8. Практико-производственное

## Иерархия

```
Industry (Индустрия)
  └── Profession (Профессия)
        └── Direction (Направление)
```

Профессия принадлежит одной индустрии и может быть отнесена к одному профессиональному направлению. Индустрия и профессиональное направление — разные способы группировки профессий. Детальная отрасль классифицирует работодателей.

## IndustryBranch (Детальная отрасль)

Индустрии хранятся в существующей `industries`, детальные отрасли — в `industry_branches`.
Профессиональные направления `directions` и направления подготовки `education_programs` — разные справочники.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Идентификатор |
| `name` | string | Название |
| `industry_id` | integer (int64) | FK → `industries.id` |
| `created_at` | timestamp with time zone | Дата создания |
| `deleted_at` | timestamp with time zone, nullable | Отметка удаления |

## Связи профессий

`profession_employers` связывает профессии с организациями типа `1` (работодатель).
`profession_education_programs` связывает профессии с направлениями подготовки.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Идентификатор связи в обеих таблицах |
| `profession_id` | integer (int64) | FK → `professions.id` в обеих таблицах |
| `employer_id` | integer (int64) | FK → `organizations.id`, только `profession_employers` |
| `education_program_id` | integer (int64) | FK → `education_programs.id`, только `profession_education_programs` |
| `created_at` | timestamp with time zone | Дата создания в обеих таблицах |
| `deleted_at` | timestamp with time zone, nullable | Отметка удаления в обеих таблицах |

Каждая пара связанных сущностей уникальна, в том числе после отметки удаления: повторное
добавление такой связи должно восстанавливать существующую строку.

Все справочные API исключают строки с `deleted_at`. DELETE помечает строку удалённой; GET по ID, PUT и повторный DELETE возвращают для неё 404.

## API справочников и мягкое удаление

| Ресурс | Запросы |
|--------|---------|
| `/industries` | GET списка, POST; `/industries/{id}`: GET, PUT, DELETE |
| `/directions` | GET списка, POST; `/directions/{id}`: GET, PUT, DELETE |
| `/industries/branches` | GET списка, POST; `/industries/branches/{id}`: GET, PUT, DELETE |
| `/professions` | GET списка, POST; `/professions/{id}`: GET, PUT, DELETE |
| `/professions/employers` | GET списка, POST; `/professions/employers/{id}`: GET, PUT, DELETE |
| `/professions/education-programs` | GET списка, POST; `/professions/education-programs/{id}`: GET, PUT, DELETE |

GET доступны публично; POST/PUT/DELETE — редактору контента и администратору. Все новые сведения из JSON доступны в ответах и запросах изменения. Пропущенные поля PUT сохраняются, явный null очищает nullable-поля.

Удалённые строки не попадают в списки и total; GET/PUT/DELETE по удалённому ID возвращают 404. Новые ссылки проверяются на доступность и тип организации. Удаление профессии, работодателя или программы помечает их связи удалёнными. Индустрию, направление, отрасль или учебное заведение с активными зависимостями удалить нельзя (409). Повторный POST удалённой пары восстанавливает её с тем же ID; изменение на уже существующую пару возвращает 409.
