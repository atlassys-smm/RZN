# Заставки LED

`LedScreensaver` — именованный медиафайл для заставки LED-экрана. Таблица `led_screensavers`.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64) | Первичный ключ, автоинкремент |
| `name` | string (1–255 символов) | Обязательное название заставки |
| `media_id` | integer (int64) | Обязательная внутренняя ссылка на `files.id` |

Файл передаётся через `multipart/form-data` при создании или изменении заставки.
API не принимает `media_id`; возвращает `id`, `name` и объект `file` с полями
`url`, `preview_url`, `mime_type`, `title`, `description`. Подписанные ссылки действуют
24 часа и обновляются при чтении. [Общий механизм файлов](files.md).

## API

Все пути имеют префикс `/api`.

| Метод | Путь | Результат |
|-------|------|-----------|
| GET | `/cms/led/screensavers` | `items`, `total`; `limit` 1–100 (20 по умолчанию), `offset` ≥ 0; новые ID первыми |
| GET | `/cms/led/screensavers/{screensaver_id}` | Заставка по ID |
| POST | `/cms/led/screensavers` | Создание, 201 |
| PUT | `/cms/led/screensavers/{screensaver_id}` | Частичное обновление, 200 |
| DELETE | `/cms/led/screensavers/{screensaver_id}` | Удаление заставки, 204 |

Чтение доступно сотрудникам admin/content_editor/operator со staff access JWT
и любому активному устройству с Device JWT: роль устройства не проверяется,
включая устройства без ролей. Запись — только сотрудникам admin/content_editor.
Без действующей авторизации, для неизвестного/неактивного устройства или User JWT — 401;
без нужной роли сотрудника — 403.
Неизвестный ID — 404, неверные поля формы — 422.

POST требует `name` и бинарное поле `file`. Необязательные поля: `file_preview`
(JPEG, PNG, WebP, GIF), `file_title`, `file_description`. Для видео без явного превью
создаётся первый кадр. PUT принимает те же поля необязательно: без нового `file`
прежнее вложение и его метаданные сохраняются. Превью без нового файла — 422.
Файл и заставка сохраняются в одной транзакции; новые загрузки убираются при ошибке.
Замена вложения и удаление заставки сохраняют прежние записи файлов и их содержимое.
