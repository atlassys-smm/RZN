# Компетенции

Справочник компетенций — сквозных навыков и качеств, которые формируются у пользователя в результате взаимодействия с различными модулями платформы.

---

## Competence (Компетенция)

Справочник компетенций. Используется для формирования профиля навыков пользователя в цифровом профиле, а также в модуле «Профбаттл» для оценки результатов прохождения кейсов.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор компетенции |
| `name` | string | Название компетенции |
| `description` | text, nullable | Описание компетенции |

### Связи

- **Competence → UserCompetence**: пользователь может иметь множество компетенций с частотами/уровнями

### Где используется

- **CMS** — управление справочником компетенций
- **Профбаттл** — 10 компетенций для оценки результатов прохождения кейсов
- **Цифровой профиль** — карта компетенций пользователя (агрегированный профиль по всем модулям)
- **Аналитика** — анализ развития компетенций пользователей

### Примечания

На текущий момент в справочнике запланированы 10 компетенций (из модуля «Профбаттл»):

1. Аналитическое мышление
2. Логическое мышление
3. Ответственность
4. Принятие решений
5. Коммуникация
6. Командная работа
7. Лидерство
8. Внимание к деталям
9. Системное мышление
10. Ориентация на результат

Справочник расширяемый — в будущем могут быть добавлены новые компетенции из других модулей платформы.

---

## UserCompetence (Компетенция пользователя)

Агрегированный профиль компетенций пользователя, формируемый по результатам взаимодействия с различными модулями платформы.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор |
| `user_id` | integer (int64) | ID пользователя |
| `competence_id` | integer (int64) | ID компетенции из справочника |
| `value` | integer | Частота/уровень проявления компетенции |
| `source` | string | Источник данных (например, `profbattle`) |
| `created_at` | timestamp | Дата последнего обновления |

### Связи

- **UserCompetence → User**: компетенция принадлежит одному пользователю
- **UserCompetence → Competence**: ссылка на компетенцию из справочника

### Примечания

- Значения суммируются по всем источникам (например, если пользователь прошёл несколько кейсов в Профбаттл)
- Используется для формирования карты компетенций в цифровом профиле
- Может отображаться в виде диаграммы (радар, столбчатая диаграмма)
