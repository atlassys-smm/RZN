# Профессии в действии

Описание сущностей для интерактивных видеосценариев с точками выбора.

Используется в сценарии: **Профессии в действии**.

---

## InteractiveVideoScenario (Видеосценарий)

Интерактивный видеосценарий с точками выбора. Видео воспроизводится на LED-платформе, в конце каждого фрагмента пользователь делает выбор, который влияет на дальнейший ход видео.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор сценария |
| `title` | string | Название сценария |
| `description` | text, nullable | Описание сценария |
| `profession_id` | integer (int64), nullable | ID профессии из справочника (связь с направлением) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **InteractiveVideoScenario → InteractiveVideoScenarioBranch**: сценарий имеет множество веток. Стартовая ветка определяется как ветка с `parent_id = null` — её `media_id` является стартовым видео сценария.
- **InteractiveVideoScenario → Profession**: сценарий может быть привязан к профессии (`profession_id`)

### Где используется

- **CMS** — создание и управление видеосценариями
- **LED-медиаплатформа** — воспроизведение видеосценариев с интерактивными выборами

---

## InteractiveVideoScenarioBranch (Ветка видеосценария)

Ветка видеосценария — фрагмент видео с вариантами выбора. После воспроизведения видеофрагмента пользователю показываются варианты выбора (дочерние ветки). Если дочерних веток нет — сценарий завершается.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор ветки |
| `scenario_id` | integer (int64) | ID видеосценария |
| `parent_id` | integer (int64), nullable | ID родительской ветки (null для стартовой записи) |
| `media_id` | integer (int64) | ID видеофайла для этой ветки. Обязательное поле — видео есть у каждой ветки без исключений |
| `prompt` | text, nullable | Текст вопроса в точке выбора. Заполняется для веток с дочерними вариантами (стартовая и промежуточные). Пустой/null для конечных веток. |
| `text` | text, nullable | Текст-подпись варианта выбора (то, что видит пользователь при выборе из родительской ветки). Заполняется для дочерних веток. Пустой/null для стартовой. |

### Связи

- **InteractiveVideoScenarioBranch → InteractiveVideoScenario**: ветка принадлежит одному сценарию (`scenario_id`)
- **InteractiveVideoScenarioBranch → InteractiveVideoScenarioBranch**: ветка может иметь родительскую ветку (`parent_id`) и дочерние ветки
- **InteractiveVideoScenarioBranch → File**: ветка может иметь видеофайл (`media_id`)

### Где используется

- **CMS** — создание дерева веток видеосценария
- **LED-медиаплатформа** — воспроизведение видео и показ вариантов выбора

### Примечания

- **Стартовая ветка** — ветка с `parent_id = null`. Её `media_id` — это первое видео сценария. Может содержать `prompt` — вопрос, который показывается после первого видео перед первым выбором.
- **Видео обязательно у всех веток** — при создании сценария стартовой ветке автоматически подставляется системное видео-заглушка (`DEFAULT_SCENARIO_VIDEO_ID` из конфигурации), пока редактор CMS не заменит его реальным роликом. У остальных веток `media_id` всегда передаётся явно при создании (`POST /cms/video-scenarios/{id}/branches`).
- **Ветвление** — глубина дерева и количество вариантов на каждом уровне не ограничены: у любой ветки (включая дочерние) может быть свой набор дочерних веток со своей точкой голосования.
- **Варианты выбора** — дочерние ветки (у которых `parent_id` = id текущей ветки). Текст варианта берётся из поля `text` дочерней ветки.
- **Конец сценария** — ветка без дочерних веток. Система определяет это автоматически. У конечной ветки `prompt` не заполняется.
- **Логика воспроизведения**: воспроизводится видео текущей ветки → если есть `prompt`, показывается текст вопроса → в конце показываются варианты выбора (дочерние ветки с их `text` и превью) → пользователь выбирает → воспроизводится видео выбранной ветки → и так далее.
- **Определение победителя голосования**: побеждает вариант с наибольшим числом голосов. При равенстве голосов у нескольких вариантов побеждает тот, что раньше набрал свой последний голос (сравнивается время последнего голоса каждого варианта — `votes.last_vote_at`). Голоса, поступившие после истечения таймера, не учитываются.
