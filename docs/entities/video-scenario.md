# Профессии в действии

Описание сущностей для интерактивных видеосценариев с точками выбора.

Используется в сценарии: **Профессии в действии**.

---

## VideoScenario (Видеосценарий)

Интерактивный видеосценарий с точками выбора. Видео воспроизводится на LED-платформе, в конце каждого фрагмента пользователь делает выбор, который влияет на дальнейший ход видео.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор сценария |
| `title` | string | Название сценария |
| `description` | text, nullable | Описание сценария |
| `profession_id` | UUID, nullable | ID профессии из справочника (связь с направлением) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **VideoScenario → VideoScenarioBranch**: сценарий имеет множество веток. Стартовая ветка определяется как ветка с `parent_id = null` — её `media_id` является стартовым видео сценария.
- **VideoScenario → Profession**: сценарий может быть привязан к профессии (`profession_id`)

### Где используется

- **CMS** — создание и управление видеосценариями
- **LED-медиаплатформа** — воспроизведение видеосценариев с интерактивными выборами

---

## VideoScenarioBranch (Ветка видеосценария)

Ветка видеосценария — фрагмент видео с вариантами выбора. После воспроизведения видеофрагмента пользователю показываются варианты выбора (дочерние ветки). Если дочерних веток нет — сценарий завершается.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор ветки |
| `scenario_id` | UUID | ID видеосценария |
| `parent_id` | UUID, nullable | ID родительской ветки (null для стартовой записи) |
| `media_id` | UUID, nullable | ID видеофайла для этой ветки |
| `text` | text, nullable | Текст-подпись варианта выбора (то, что видит пользователь при выборе из родительской ветки) |

### Связи

- **VideoScenarioBranch → VideoScenario**: ветка принадлежит одному сценарию (`scenario_id`)
- **VideoScenarioBranch → VideoScenarioBranch**: ветка может иметь родительскую ветку (`parent_id`) и дочерние ветки
- **VideoScenarioBranch → File**: ветка может иметь видеофайл (`media_id`)

### Где используется

- **CMS** — создание дерева веток видеосценария
- **LED-медиаплатформа** — воспроизведение видео и показ вариантов выбора

### Примечания

- **Стартовая ветка** — ветка с `parent_id = null`. Её `media_id` — это первое видео сценария.
- **Варианты выбора** — дочерние ветки (у которых `parent_id` = id текущей ветки). Текст варианта берётся из поля `text` дочерней ветки.
- **Конец сценария** — ветка без дочерних веток. Система определяет это автоматически.
- **Логика воспроизведения**: воспроизводится видео текущей ветки → в конце показываются варианты выбора (дочерние ветки с их `text` и превью) → пользователь выбирает → воспроизводится видео выбранной ветки → и так далее.
