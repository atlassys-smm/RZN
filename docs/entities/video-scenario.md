# Видеосценарий

Описание сущностей для интерактивных видеосценариев с точками выбора.

Используется в сценарии: **Профессии в действии**.

---

## VideoScenario (Видеосценарий)

Интерактивный видеосценарий с точками выбора. Видео воспроизводится на LED-платформе, в определённые моменты пользователь делает выбор, который влияет на дальнейший ход видео.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор сценария |
| `title` | string | Название сценария |
| `description` | text, nullable | Описание сценария |
| `video_id` | UUID | ID основного видео (из File) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **VideoScenario → File**: сценарий имеет основное видео (`video_id`)
- **VideoScenario → VideoScenarioBranch**: сценарий имеет множество точек выбора (корневые ветки, у которых `parent_id` = null)

### Где используется

- **CMS** — создание и управление видеосценариями
- **LED-медиаплатформа** — воспроизведение видеосценариев с интерактивными выборами

---

## VideoScenarioBranch (Точка выбора в видеосценарии)

Точка выбора в видеосценарии. Может иметь родительскую ветку (для иерархии) и дочерние варианты выбора.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор ветки |
| `scenario_id` | UUID | ID видеосценария |
| `parent_id` | UUID, nullable | ID родительской ветки (null для корневых) |
| `timestamp` | integer | Время в видео (в секундах), когда появляется выбор |
| `text` | text, nullable | Текст, сопровождающий выбор |
| `media_id` | UUID, nullable | ID файла (изображение или видео для этой ветки) |
| `is_ending` | boolean | Является ли эта ветка конечной (завершение сценария) |

### Связи

- **VideoScenarioBranch → VideoScenario**: ветка принадлежит одному сценарию (`scenario_id`)
- **VideoScenarioBranch → VideoScenarioBranch**: ветка может иметь родительскую ветку (`parent_id`) и дочерние ветки
- **VideoScenarioBranch → File**: ветка может иметь медиа-файл (`media_id`)

### Где используется

- **CMS** — создание точек выбора и иерархии веток
- **LED-медиаплатформа** — показ вариантов выбора в определённые моменты видео

### Примечания

- Дочерние варианты выбора определяются через `parent_id`
- Если `is_ending` = true, то это конечная точка сценария
- Видео может переходить к разным сегментам в зависимости от выбора пользователя
