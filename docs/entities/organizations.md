# Учебные заведения и работодатели

Описание сущностей для справочника учебных заведений и работодателей.

---

## EducationalInstitution (Учебное заведение)

Справочник учебных заведений. Используется в ПАК «Интерактивная карта региона» и аналитике.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор |
| `name` | string | Название учебного заведения |
| `type` | enum | Тип: `school`, `college`, `university`, `courses`, `other` |
| `address` | text, nullable | Адрес |
| `coordinates` | json, nullable | Координаты на карте (широта, долгота) |
| `description` | text, nullable | Описание |
| `website` | string, nullable | URL сайта |
| `phone` | string, nullable | Контактный телефон |
| `direction_ids` | json, nullable | Список ID направлений, по которым ведётся обучение |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **EducationalInstitution → Direction**: учебное заведение может быть связано с несколькими направлениями подготовки
- **EducationalInstitution → ExternalIdentifier**: внешние идентификаторы из ПАК

### Где используется

- **ПАК «Интерактивная карта региона»** — отображение на карте
- **Аналитика** — рейтинг учебных заведений по интересам
- **Цифровой профиль** — выбранные учебные заведения в профиле

---

## Employer (Работодатель)

Справочник работодателей. Используется в ПАК «Интерактивная карта региона» и аналитике.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор |
| `name` | string | Название организации |
| `industry_id` | UUID, nullable | ID отрасли |
| `address` | text, nullable | Адрес |
| `coordinates` | json, nullable | Координаты на карте (широта, долгота) |
| `description` | text, nullable | Описание |
| `website` | string, nullable | URL сайта |
| `phone` | string, nullable | Контактный телефон |
| `vacancies_count` | integer, nullable | Количество открытых вакансий |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **Employer → Industry**: работодатель принадлежит отрасли
- **Employer → ExternalIdentifier**: внешние идентификаторы из ПАК

### Где используется

- **ПАК «Интерактивная карта региона»** — отображение на карте
- **Аналитика** — рейтинг работодателей по просмотрам
- **Цифровой профиль** — выбранные работодатели в профиле
