# Согласия

Версионируемые юридические тексты, которые принимает пользователь при взаимодействии с платформой. Каждое изменение текста создаёт новую версию — в хранилище фиксируется, по какой именно версии давалось согласие.

---

## Consent (Согласие)

Шаблон согласия с версионированием. При изменении текста создаётся новая версия, предыдущие сохраняются.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор шаблона согласия |
| `type` | enum | Тип согласия: `personal_data` (обработка ПДн), `contact_request` (контактная заявка) |
| `title` | string | Заголовок (например, «Согласие на обработку персональных данных») |
| `version` | string | Версия текста (например, `1.0`, `1.1`, `2.0`) |
| `text` | text | Полный текст согласия |
| `is_active` | boolean | Является ли данная версия действующей |
| `effective_from` | timestamp | Дата, с которой версия вступает в силу |
| `created_at` | timestamp | Дата создания версии |
| `updated_at` | timestamp | Дата обновления версии |

### Связи

- **Consent → ConsentAcceptance**: согласие может быть принято пользователем множество раз (по одной записи на каждый факт принятия)

### Где используется

- **CMS** — создание и редактирование текстов согласий, управление версиями
- **Идентификация и регистрация** — показ согласия при регистрации пользователя, фиксация принятия
- **Обратная связь** — показ согласия при оставлении контактной заявки
- **Личный кабинет** — управление согласиями пользователя
- **Цифровой профиль** — хранение истории принятых согласий

---

## ConsentAcceptance (Факт принятия согласия)

Запись о том, что конкретный пользователь принял конкретную версию согласия в определённый момент времени.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор записи |
| `consent_id` | UUID | ID шаблона согласия |
| `user_id` | UUID, nullable | ID пользователя (если авторизован) |
| `guest_id` | UUID, nullable | ID гостевой сессии (если не авторизован) |
| `accepted_at` | timestamp | Дата и время принятия |
| `ip_address` | string, nullable | IP-адрес на момент принятия |

### Связи

- **ConsentAcceptance → Consent**: запись относится к одному шаблону согласия (`consent_id`)
- **ConsentAcceptance → User**: запись может быть привязана к пользователю (`user_id`)
- **ConsentAcceptance → GuestSession**: запись может быть привязана к гостевой сессии (`guest_id`)

### Где используется

- **Обратная связь** — фиксация согласия при отправке контактной заявки
- **Цифровой профиль** — хранение истории согласий пользователя
- **Аналитика** — аудит принятых согласий
