# Шаблон сценария

Описание сущностей для шаблонов сценариев командной игры на LED-платформе.

Шаблон сценария — это заранее подготовленный набор раундов с конкретными вопросами, привязанными к определённой тематике или направлению. Администратор создаёт шаблоны в CMS, оператор выбирает готовый шаблон при запуске командной игры вместо ручного подбора вопросов.

Используется в сценарии: **Командная игра**.

→ [Игровая сессия](game-session.md) | [Вопросы викторины](quiz.md) | [Управление в CMS](../subsystems/cms/quiz.md#шаблоны-сценариев)

## ScenarioTemplate (Шаблон сценария)

Заранее подготовленный набор раундов с конкретными вопросами для командной игры. Создаётся администратором в CMS для определённых направлений, отраслей или тематик. Оператор выбирает готовый шаблон при запуске сессии вместо ручного подбора вопросов.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор шаблона |
| `name` | string | Название шаблона (например, «IT-направление», «Медицина», «Строительство») |
| `description` | text, nullable | Описание: для какой тематики, возрастная группа, особенности |
| `status` | enum | Статус: `draft` (черновик), `published` (опубликован) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **ScenarioTemplate → ScenarioTemplateRound**: шаблон содержит от 3 до 8 раундов
- **ScenarioTemplate → GameSession**: шаблон может быть использован в сессиях (`GameSession.scenario_template_id`)

### Где используется

- **CMS** — создание и управление шаблонами сценариев
- **LED-медиаплатформа** — оператор выбирает шаблон при запуске командной игры

## ScenarioTemplateRound (Раунд шаблона сценария)

Раунд в составе шаблона сценария. Определяет тип раунда и набор конкретных вопросов, которые будут использованы вместо автоматического подбора.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор раунда |
| `template_id` | UUID | ID шаблона сценария |
| `round_type_id` | string | Код типа раунда из [справочника](../references/scenario-round-types.md) |
| `order` | integer | Порядок раунда в сценарии |

### Связи

- **ScenarioTemplateRound → ScenarioTemplate**: раунд принадлежит одному шаблону (`template_id`)
- **ScenarioTemplateRound → ScenarioTemplateRoundQuestion**: раунд содержит набор вопросов
- **ScenarioTemplateRound → ScenarioRoundType**: тип раунда из справочника (`round_type_id`)

---

## ScenarioTemplateRoundQuestion (Вопрос раунда шаблона)

Конкретный вопрос, закреплённый за раундом в шаблоне сценария. Позволяет администратору вручную подобрать вопросы для каждого раунда вместо автоматического выбора системой.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор |
| `round_id` | UUID | ID раунда шаблона |
| `question_id` | UUID | ID вопроса из банка вопросов ([GameQuestion](quiz.md)) |
| `order` | integer | Порядок отображения вопроса в раунде |

### Связи

- **ScenarioTemplateRoundQuestion → ScenarioTemplateRound**: запись принадлежит одному раунду (`round_id`)
- **ScenarioTemplateRoundQuestion → GameQuestion**: ссылка на конкретный вопрос (`question_id`)

### Где используется

- **CMS** — администратор подбирает вопросы для каждого раунда шаблона
- **LED-медиаплатформа** — при запуске сессии по шаблону система берёт вопросы из связанных `ScenarioTemplateRoundQuestion`
