# Шаблон сценария

Описание сущностей для шаблонов сценариев индивидуальной викторины и командной игры на LED-платформе.

Шаблон сценария — это заранее подготовленный набор раундов с конкретными вопросами, привязанными к определённой тематике или направлению. Администратор создаёт шаблоны в CMS, оператор выбирает готовый шаблон при запуске индивидуальной викторины или командной игры.

Используется в сценариях: **Индивидуальная викторина**, **Командная игра**.

→ [Игровая сессия](game-session.md) | [Вопросы викторины](quiz.md#gamequestion) | [Управление в CMS](../subsystems/cms/quiz.md#scenario-templates)

## ScenarioTemplate (Шаблон сценария) {#scenariotemplate}

Заранее подготовленный набор раундов с конкретными вопросами для игровой сессии. Создаётся администратором в CMS для определённых направлений, отраслей или тематик. Оператор выбирает опубликованный шаблон при запуске сессии; его типы раундов и конкретные `question_id` передаются в сессию. Формат сессии и автоматический подбор вопросов описаны в [сущности игровой сессии](game-session.md#gamesession).

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор шаблона |
| `name` | string | Название шаблона (например, «IT-направление», «Медицина», «Строительство») |
| `description` | text, nullable | Описание: для какой тематики, возрастная группа, особенности |
| `status` | integer | Статус: `1` — draft (черновик), `2` — published (опубликован) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **ScenarioTemplate → ScenarioTemplateRound**: шаблон содержит раунды в количестве, соответствующем диапазону из [справочника типов раундов](../references/scenario-round-types.md)
- **ScenarioTemplate → GameSession**: клиент оператора передаёт раунды и вопросы выбранного шаблона в `rounds` при создании сессии; внешняя связь с шаблоном в `GameSession` не хранится. Редактирование шаблона не меняет уже созданные сессии

### Где используется

- **CMS** — создание и управление шаблонами сценариев
- **LED-медиаплатформа** — оператор выбирает шаблон при запуске сессии любого режима

## ScenarioTemplateRound (Раунд шаблона сценария) {#scenariotemplateround}

Раунд в составе шаблона сценария. Определяет тип раунда и набор конкретных вопросов, которые будут использованы вместо автоматического подбора. После запуска сессии её раунды и вопросы не редактируются.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор раунда |
| `template_id` | integer (int64) | ID шаблона сценария |
| `round_type_id` | integer | Числовой ID типа раунда из [справочника](../references/scenario-round-types.md) |
| `order` | integer | Порядок раунда в сценарии |

### Связи

- **ScenarioTemplateRound → ScenarioTemplate**: раунд принадлежит одному шаблону (`template_id`)
- **ScenarioTemplateRound → ScenarioTemplateRoundQuestion**: раунд содержит набор вопросов
- **ScenarioTemplateRound → ScenarioRoundType**: тип раунда из справочника (`round_type_id`)

## ScenarioTemplateRoundQuestion (Вопрос раунда шаблона) {#scenariotemplateroundquestion}

Конкретный вопрос, закреплённый за раундом в шаблоне сценария. Позволяет администратору вручную подобрать вопросы для каждого раунда вместо автоматического выбора системой.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор |
| `round_id` | integer (int64) | ID раунда шаблона |
| `question_id` | integer (int64) | ID вопроса из банка вопросов ([GameQuestion](quiz.md)) |
| `order` | integer | Порядок отображения вопроса в раунде |

### Связи

- **ScenarioTemplateRoundQuestion → ScenarioTemplateRound**: запись принадлежит одному раунду (`round_id`)
- **ScenarioTemplateRoundQuestion → GameQuestion**: ссылка на конкретный вопрос (`question_id`)

### Где используется

- **CMS** — администратор подбирает вопросы для каждого раунда шаблона
- **LED-медиаплатформа** — при запуске сессии по шаблону система берёт вопросы из связанных `ScenarioTemplateRoundQuestion`
