# Ответы пользователей

Описание сущностей для хранения результатов прохождения анкет.

---

## SurveyResponse (Ответ на анкету)

Прохождение анкеты пользователем или гостем. Начатая анкета имеет started_at и пустой completed_at; после отправки та же запись содержит время завершения и ответы.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор ответа |
| `survey_id` | integer (int64) | ID анкеты, по которой проходили |
| `source_id` | string | XML_ID устройства (ПАК, веб) |
| `consent_version_id` | integer (int64), nullable | ID версии согласия, которое принял пользователь |
| `user_id` | integer (int64) | ID пользователя (гостя или авторизованного) — всегда заполнен |
| `device_id` | integer (int64), nullable | Авторизованное устройство, если известно |
| `started_at` | timestamp, nullable | Реальное начало заполнения; NULL для старых результатов и старого запроса |
| `completed_at` | timestamp, nullable | Завершение; NULL, пока анкета не отправлена |
| `duration` | integer | Время прохождения в секундах |

### Связи

- **SurveyResponse → Survey**: ответ относится к одной анкете (`survey_id`)
- **SurveyResponse → ConsentVersion**: ответ может содержать ссылку на принятую версию согласия (`consent_version_id`)
- **SurveyResponse → User**: ответ привязан к пользователю (`user_id`) — гостю или авторизованному
- **SurveyResponse → SurveyAnswer**: ответ имеет множество ответов на конкретные вопросы

### Где используется

- **Обратная связь** — сохранение результатов анкет
- **Аналитика** — анализ обратной связи с разбивкой по источникам
- **Цифровой профиль** — привязка ответов к профилю пользователя

---

## SurveyAnswer (Ответ на вопрос анкеты)

Ответ пользователя на конкретный вопрос анкеты.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer (int64, автоинкремент) | Уникальный идентификатор ответа |
| `response_id` | integer (int64) | ID ответа на анкету |
| `question_id` | integer (int64) | ID вопроса |
| `value` | text | Значение ответа (число, текст, JSON для множественного выбора) |

### Связи

- **SurveyAnswer → SurveyResponse**: ответ принадлежит одному ответу на анкету (`response_id`)
- **SurveyAnswer → SurveyQuestion**: ответ относится к одному вопросу (`question_id`)

### Где используется

- **Обратная связь** — сохранение ответов на конкретные вопросы
- **Аналитика** — анализ ответов по вопросам
