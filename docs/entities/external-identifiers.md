# Внешние идентификаторы

Описание сущности для сопоставления внешних идентификаторов из ПАК с нашими сущностями.

---

## ExternalIdentifier (Внешний идентификатор)

Сопоставление внешнего идентификатора из ПАК с нашей сущностью (профессия, отрасль, направление). Один объект может иметь множество внешних идентификаторов из разных источников.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор записи |
| `entity_type` | enum | Тип нашей сущности: `profession`, `industry`, `direction` |
| `entity_id` | UUID | ID нашей сущности |
| `source` | string | Источник внешнего идентификатора: `tree_of_professions`, `regional_map`, `profbattle`, `profession_avatar` |
| `external_id` | string | Идентификатор сущности во внешней системе |
| `external_name` | string, nullable | Название сущности во внешней системе (для справки) |
| `created_at` | timestamp | Дата создания записи |
| `updated_at` | timestamp | Дата обновления записи |

### Связи

- **ExternalIdentifier → Profession**: сопоставление с профессией (если `entity_type` = `profession`)
- **ExternalIdentifier → Industry**: сопоставление с отраслью (если `entity_type` = `industry`)
- **ExternalIdentifier → Direction**: сопоставление с направлением (если `entity_type` = `direction`)

### Где используется

- **Аналитика** — нормализация данных от внешних ПАК
- **Интеграционные адаптеры** — сопоставление внешних идентификаторов с нашими сущностями при приёме событий

### Примеры

| entity_type | entity_id | source | external_id | external_name |
|-------------|-----------|--------|-------------|---------------|
| `profession` | `uuid-our-123` | `tree_of_professions` | `tp-456` | `Программист` |
| `profession` | `uuid-our-123` | `regional_map` | `rm-789` | `IT-специалист` |
| `industry` | `uuid-ind-001` | `tree_of_professions` | `tp-ind-10` | `Информационные технологии` |

### Примечания

- Одна наша сущность может иметь множество внешних идентификаторов из разных ПАК
- Один внешний идентификатор из одного источника соответствует одной нашей сущности (уникальность по паре `source` + `external_id`)
- Мы предоставляем внешним ПАК наши справочники, чтобы они использовали наши идентификаторы напрямую
- Если ПАК использует свои идентификаторы, адаптер создаёт записи `ExternalIdentifier` для сопоставления
