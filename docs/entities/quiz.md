# Викторина (GameQuestion)

Описание сущностей для вопросов и ответов в викторинах на LED-платформе.

Используется в сценариях: **Индивидуальная викторина**, **Командная игра** (раунды).

Индивидуальная викторина и командная игра используют одну и ту же сущность вопроса. Разница только в организации: в индивидуальной викторине вопросы формируются случайным образом и все отвечают совместно, в командной игре вопросы привязаны к раундам и команды отвечают отдельно.

---

## GameQuestion (Вопрос викторины)

Вопрос для викторины на LED-платформе. Используется как в индивидуальной викторине, так и в раундах командной игры.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор вопроса |
| `type` | enum | Тип вопроса (см. ниже) |
| `text` | text | Текст вопроса |
| `media_id` | UUID, nullable | ID файла (изображение или видео) |
| `difficulty` | enum, nullable | Сложность: `easy`, `medium`, `hard` |
| `age_group` | enum, nullable | Возрастная группа: `12-14`, `15-17`, `adult` |
| `time_limit` | integer, nullable | Время на ответ в секундах |
| `points` | integer | Баллы за правильный ответ |
| `explanation` | text, nullable | Методическое пояснение к правильному ответу |
| `round_type_id` | string, nullable | Код типа раунда из [справочника](../references/scenario-round-types.md) (для классификации вопросов) |
| `tags` | json, nullable | Теги (профессия, отрасль, компетенция) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Типы вопросов

| Тип | Описание |
|-----|----------|
| `single_choice` | Выбор одного варианта |
| `multiple_choice` | Выбор нескольких вариантов |
| `yes_no` | Да/нет |
| `image_choice` | Выбор по изображению |
| `matching` | Сопоставление |
| `sorting` | Упорядочивание |
| `profession_by_description` | Выбор профессии по описанию задач |
| `recognize_by_image` | Распознавание профессии по изображению |
| `recognize_by_video` | Распознавание профессии по видео |
| `sequence` | Восстановление последовательности этапов |
| `case_study` | Ситуационный кейс |
| `role_distribution` | Распределение ролей в команде |
| `resource_selection` | Выбор набора ресурсов и специалистов |
| `error_finding` | Поиск ошибки в рабочей ситуации |
| `prediction` | Прогноз развития технологии |
| `argumentation` | Аргументация и консенсус |
| `media_round` | Медиараунд с видеофрагментом |
| `final_case` | Финальный комплексный кейс |

### Связи

- **GameQuestion → File**: вопрос может иметь медиа-файл (`media_id`)
- **GameQuestion → GameAnswerOption**: один вопрос имеет множество вариантов ответа
- **GameQuestion → ScenarioRoundType**: вопрос может быть классифицирован по типу раунда (`round_type_id`)

### Где используется

- **CMS** — создание и управление вопросами
- **LED-медиаплатформа** — показ вопросов в индивидуальной викторине и командной игре
- **Аналитика** — анализ ответов по вопросам

## GameAnswerOption (Вариант ответа викторины)

Вариант ответа для вопроса викторины.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор варианта |
| `question_id` | UUID | ID вопроса |
| `text` | text | Текст варианта ответа |
| `media_id` | UUID, nullable | ID файла (изображение) |
| `is_correct` | boolean | Является ли вариант правильным |
| `order` | integer | Порядок отображения |

### Связи

- **GameAnswerOption → GameQuestion**: вариант принадлежит одному вопросу (`question_id`)
- **GameAnswerOption → File**: вариант может иметь медиа-файл (`media_id`)

### Где используется

- **CMS** — создание вариантов ответов
- **LED-медиаплатформа** — показ вариантов участникам
