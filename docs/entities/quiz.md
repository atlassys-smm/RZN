# Викторина (LED-викторины)

Описание сущностей для вопросов и ответов в индивидуальных викторинах на LED-платформе.

Используется в сценариях: **Угадай профессию**, **Профессиональный вызов**.

---

## QuizQuestion (Вопрос викторины)

Вопрос для индивидуальной викторины на LED-платформе.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор вопроса |
| `type` | enum | Тип вопроса: `single_choice`, `multiple_choice`, `yes_no`, `image_choice`, `matching`, `sorting` |
| `text` | text | Текст вопроса |
| `media_id` | UUID, nullable | ID файла (изображение или видео) |
| `difficulty` | enum, nullable | Сложность: `easy`, `medium`, `hard` |
| `age_group` | enum, nullable | Возрастная группа: `12-14`, `15-17`, `adult` |
| `time_limit` | integer, nullable | Время на ответ в секундах |
| `points` | integer | Баллы за правильный ответ |
| `tags` | json, nullable | Теги (профессия, отрасль, компетенция) |
| `created_at` | timestamp | Дата создания |
| `updated_at` | timestamp | Дата обновления |

### Связи

- **QuizQuestion → File**: вопрос может иметь медиа-файл (`media_id`)
- **QuizQuestion → QuizAnswerOption**: один вопрос имеет множество вариантов ответа

### Где используется

- **CMS** — создание и управление вопросами
- **LED-медиаплатформа** — показ вопросов в викторинах
- **Аналитика** — анализ ответов по вопросам

---

## QuizAnswerOption (Вариант ответа викторины)

Вариант ответа для вопроса викторины.

### Атрибуты

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Уникальный идентификатор варианта |
| `question_id` | UUID | ID вопроса |
| `text` | text | Текст варианта ответа |
| `media_id` | UUID, nullable | ID файла (изображение) |
| `is_correct` | boolean | Является ли вариант правильным |
| `order` | integer | Порядок отображения |

### Связи

- **QuizAnswerOption → QuizQuestion**: вариант принадлежит одному вопросу (`question_id`)
- **QuizAnswerOption → File**: вариант может иметь медиа-файл (`media_id`)

### Где используется

- **CMS** — создание вариантов ответов
- **LED-медиаплатформа** — показ вариантов участникам
