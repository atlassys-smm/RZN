# Дерево профессий

Интерактивный терминал с навигацией по профессиям от крупных отраслей к конкретным специальностям.

---

## Уровни навигации

### Первый уровень — Заставка

Дерево с двумя кнопками:
- **Путеводитель** — самостоятельный выбор отрасли и профессии
- **Предсказание** — рекомендация системы

Два режима работы:
- Самостоятельный выбор пользователем
- Рекомендация на основе предпочтений

### Второй уровень — Выбор сферы

Пользователь выбирает крупную отрасль. Примеры веток дерева:
- IT и интернет
- Электроника и электротехника
- Строительство и архитектура

### Третий уровень — Выбор профессии внутри сферы

Внутри выбранной отрасли — список специальностей (листья дерева).

**Пример:** внутри «Строительство и архитектура»:
- Арматурщик
- Стропальщик
- Бетонщик
- Каменщик
- Печник
- Сварщик-сеточник

### Четвёртый уровень — Карточка профессии

Открывается подробная информация о выбранной профессии.

---

## Содержание карточки профессии

### Верхний блок
- **Образование** — уровень образования (например, среднее)
- **Средняя зарплата** — например, 100 тыс. руб.
- **Востребованность** — например, высокая

### Основной блок
- **Описание профессии** — подробное описание деятельности

### Блок «Где работать?»
Конкретные работодатели с адресами:
- Рязанский завод ЖБИ №1
- Рязанский завод ЖБИ №3
- Мостотрест

### Дополнительные блоки
- **Кому подходит?** — характеристики подходящего кандидата
- **Направления подготовки** — связанные профессиональные направления
- **Где учиться?** — учебные заведения

### Расширенная информация
- **Потенциальные вакансии** — список вакансий с картой
- **Истории карьерного пути** — примеры карьерных траекторий
- **Трудовые действия** — конкретные действия, которые выполняет специалист
