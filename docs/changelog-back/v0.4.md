# Версия 0.4

Дата: 24.09.2026

---

## Изменения

### Исправления миграций

- **Миграция 0016** — заменены SQLite-функции (`randomblob()`, `hex()`) на PostgreSQL-совместимый `gen_random_uuid()` для генерации UUID файлов. Без этого исправления API не запускался на PostgreSQL.

### Новые миграции

- **0018** — seed видео-заглушки для интерактивных сценариев (`Placeholder video` в таблице `files`, `module = 'scenarios'`). Идемпотентная миграция — не дублирует запись при повторном запуске.

### Конфигурация

- **`DEFAULT_SCENARIO_VIDEO_ID`** — переменная окружения для указания ID видео-заглушки. По умолчанию `1` (создаётся миграцией 0018).
