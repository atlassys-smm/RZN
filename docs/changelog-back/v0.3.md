# Версия 0.3

Дата: 24.09.2026 16:50

---

## Изменения

### Новые модели

- **Согласия** — `ConsentType`, `ConsentVersion`, `ConsentAcceptance` (версионируемые тексты согласий с черновиками и публикацией)
- **Организации** — `Organization` (единая сущность для учебных заведений и работодателей с типом `education`/`employer`)
- **Аватары профессий** — `ProfessionAvatarTemplate` (эталоны мужского/женского образа профессии)
- **Аватары пользователей** — `UserAvatar` (сгенерированные аватары пользователей в образах профессий, с `qr_token` для доступа по QR)

### Новые API

- **`/api/consents`** — CRUD для типов согласий и версий (с публикацией черновиков)
- **`/api/organizations`** — CRUD для организаций (фильтрация по типу, координаты)
- **`/api/profession-avatars`** — загрузка/обновление эталонных фото профессий (мужское/женское)
- **`/api/users/{user_id}/avatars`** — загрузка аватаров пользователей, получение по QR-токену

### Обновления API

- **`/api/professions`** — пагинация (`limit`/`offset`), фильтры (`direction_id`, `industry_id`, `search`), timestamps в ответах
- **Отрасли и направления** — добавлены PUT/DELETE, пагинация, timestamps
- **`/api/files`** — подписанные URL для доступа к файлам (`signed_urls.py`)

### Обновления моделей

- **`File`** — добавлены поля `uuid` (для signed URLs) и `module` (для определения папки хранения: `avatars`, `videos`, `documents`, `general`)

### Утилиты

- **`pagination.py`** — `PaginationParams`, `PaginatedResponse[T]` (generic пагинация)
- **`signed_urls.py`** — генерация подписанных URL с HMAC-SHA256 и сроком действия

### Миграции (0010–0017)

- 0010: timestamps для таблиц профессий
- 0011: таблица организаций
- 0012: таблицы согласий (types, versions, acceptances)
- 0013: seed направлений (8 профессиональных направлений)
- 0014: seed типов согласий (ПДн, контактная заявка)
- 0015: шаблоны аватаров профессий
- 0016: uuid module для файлов
- 0017: аватары пользователей

### Инфраструктура

- **CORS** — добавлен `http://localhost:5173` (Vite dev server)
