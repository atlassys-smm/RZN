# Викторина

Игровые сессии на LED-платформе. Вопросы с вариантами ответов на LED-экране, участники отвечают с мобильных устройств.

---

## Режимы

### Индивидуальная викторина

Основной режим — раунды с разными типами вопросов, как в командной игре. Отличие: участники отвечают персонально, рейтинг индивидуальный.

- Состав раундов и способ выбора вопросов настраиваются через [экран настройки сессии](../../interfaces/operator-tablet/team-game-setup.md); модель данных описана в [GameSession](../../entities/game-session.md#gamesession)
- Каждый участник отвечает самостоятельно за себя
- Сессию создаёт оператор; участники подключаются к ней через QR-код на LED-экране
- По итогам — индивидуальный рейтинг участников

### Командная игра

Основной сценарный режим. Профориентационная игра на LED-экране:

- Формирование команд; ограничения состава см. в [GameSession](../../entities/game-session.md#gamesession) и [GameSessionTeam](../../entities/game-session.md#gamesessionteam)
- Источник сценария и ручная настройка раундов описаны на [экране настройки сессии](../../interfaces/operator-tablet/team-game-setup.md)
- Раунды заданий, обсуждения, приём ответов
- Участники отправляют предварительные ответы; капитан видит ответы команды и отдельно отправляет решающий ответ, который засчитывается команде
- Рейтинг и итоговый результат

**Капитан:**
- Первый подключившийся к команде становится капитаном
- Текущий капитан может передать роль другому участнику команды
- Если капитан отключился от игры, система назначает случайного капитана из участников команды
- Оператор может сменить капитана, выбрав нового из списка участников команды

Для одного LED-устройства может существовать не более одной незавершённой сессии (status `1` — waiting или `2` — active). Разные устройства могут проводить сессии одновременно.

## Статусы сессии

| Статус | Описание |
|--------|----------|
| Значение | Статус | Описание |
|----------|--------|----------|
| 1 | `waiting` | Формирование команд. Игра ещё не началась. |
| 2 | `active` | Игра идёт. Оператор управляет раундами и вопросами. |
| 3 | `finished` | Сессия завершена. Показан финальный рейтинг. |

---

## Этапы командной сессии

### Подготовка (status `1`, waiting)

1. Создание сессии оператором → status `1` (waiting)
2. Подключение и формирование команд
3. Инструктаж
4. Оператор нажимает «Начать игру» → status `2` (active)
5. Команды с нулевым количеством участников автоматически исключаются из сессии. Игра может начаться, если после исключения осталось не менее 2 команд и в каждой не менее 2 участников

### Проведение (status `2`, active)

5. Раунды заданий (количество типов — по [справочнику](../../references/scenario-round-types.md)):
   - Показ вопроса на LED
   - Обсуждение в командах
   - Приём ответов (таймер вопроса)
   - Показ правильного ответа с методическим пояснением
   - Автоматическая проверка зачётных ответов и начисление баллов
6. Показ промежуточных результатов раунда (если `show_intermediate_results = true`)
7. Пауза между раундами (`between_rounds_delay`)
8. Следующий раунд

### Завершение

9. После последнего вопроса последнего раунда — показ финальных результатов
10. Оператор нажимает «Завершить» → status `3` (finished)
11. Сохранение статистики и возврат в режим ожидания

## Настройки сессии

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `auto_reveal` | Автоматический показ правильного ответа по истечении времени. Если `false` — оператор нажимает «Показать ответ» | `true` |
| `auto_next` | Автоматический переход к следующему вопросу после показа ответа | `false` |
| `auto_next_delay` | Задержка автоперехода в секундах | `5` |
| `between_rounds_delay` | Пауза между раундами в секундах | `10` |
| `show_intermediate_results` | Показывать промежуточный рейтинг после каждого раунда | `true` |
| `scoring` | json | Настройки системы баллов — см. ниже |

### Настройки баллов (scoring)

Параметры системы начисления баллов сохраняются в снапшоте сессии при создании. Во время активной сессии изменение невозможно.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `partial_correct.enabled` | boolean | `true` | Учитывать частичный балл за задания с несколькими правильными элементами |
| `speed_bonus.enabled` | boolean | `true` | Начислять бонус за быстрый ответ |
| `speed_bonus.coefficient` | decimal | `1.5` | Множитель балла при быстром ответе |
| `speed_bonus.threshold_percent` | integer | `50` | Процент времени на вопрос, в течение которого ответ считается быстрым (0–100) |
| `streak_bonus.enabled` | boolean | `true` | Начислять бонус за серию последовательных правильных ответов |
| `streak_bonus.step` | decimal | `0.05` | Шаг увеличения коэффициента за каждый последовательный правильный ответ |
| `streak_bonus.max` | decimal | `2.0` | Предельный коэффициент серии (максимум, выше которого не начисляется) |
| `consensus_bonus.enabled` | boolean | `true` | Начислять бонус за единогласный ответ команды |
| `consensus_bonus.coefficient` | decimal | `1.2` | Множитель при условии, что все участники команды проголосовали за правильный вариант |
| `final_multiplier.enabled` | boolean | `true` | Применять повышающий множитель финального раунда |
| `final_multiplier.coefficient` | decimal | `1.5` | Множитель баллов в финальном раунде |
| `penalty.enabled` | boolean | `false` | Вычитать баллы за неправильный ответ |
| `penalty.coefficient` | decimal | `0.0` | Доля баллов текущего вопроса, вычитаемая при неправильном ответе (0.0 = нет штрафа, 0.5 = половина, 1.0 = все баллы) |

→ Подробное описание механики — в разделе [Правила начисления баллов](#правила-начисления-баллов)

## Правила начисления баллов

Механизм расчёта балла за ответ команды или участника. Каждый механизм можно включить или выключить через настройки сессии (`scoring`) без изменения кода.

### Базовый балл

Базовый балл за правильный ответ хранится в вопросе викторины (`GameQuestion.points`). Это отправная точка для всех последующих множителей.

### Частичный балл

Для заданий с несколькими правильными элементами (множественный выбор, сопоставление и т.п.) начисляется пропорциональная часть баллов:

```
частичный_балл = базовый_балл × (правильных_выбрано / всего_правильных)
```

Пример: в вопросе 10 вариантов, 3 правильных. Участник выбрал 2 правильных → `points × 2/3`.

Применяется только при `partial_correct.enabled = true`.

### Бонус за скорость

Если ответ дан быстрее порога (`speed_bonus.threshold_percent` процентов от времени на вопрос), балл умножается на `speed_bonus.coefficient`.

Пример: время на вопрос 60 сек, порог 50%, коэффициент 1.5. Ответ за 25 сек (раньше 30 сек) → `балл × 1.5`.

Применяется только при `speed_bonus.enabled = true`.

### Бонус за последовательность (серия)

За каждый последовательный правильный ответ коэффициент увеличивается на `streak_bonus.step`. Счётчик серии сбрасывается при неправильном ответе.

| Последовательный правильный ответ | Коэффициент |
|-----------------------------------|-------------|
| 1-й | 1.0 |
| 2-й | 1.0 + step |
| 3-й | 1.0 + 2 × step |
| N-й | min(1.0 + (N−1) × step, max) |

Пример: step = 0.05, max = 2.0. Пятый правильный подряд → `min(1.0 + 4 × 0.05, 2.0) = 1.2`.

Применяется только при `streak_bonus.enabled = true`.

### Командный бонус за консенсус

Если все участники команды проголосовали за один вариант и он оказался правильным, балл умножается на `consensus_bonus.coefficient`.

Применяется только при `consensus_bonus.enabled = true`.

### Повышающий коэффициент финального раунда

В финальном раунде (`round_type = final`) балл умножается на `final_multiplier.coefficient`.

Применяется только при `final_multiplier.enabled = true`.

### Штраф за неправильный ответ

При неправильном ответе из текущего счёта вычитается `penalty.coefficient × points` текущего вопроса.

| Коэффициент штрафа | Эффект |
|--------------------|--------|
| 0.0 | Штрафа нет |
| 0.5 | Вычитается 50% баллов вопроса |
| 1.0 | Вычитается 100% баллов вопроса |

Применяется только при `penalty.enabled = true`.

### Тай-брейк

Тай-брейк по дополнительному вопросу **не используется**. Для разрешения равных результатов достаточно финального раунда с повышенным множителем.

### Формула расчёта

Итоговый балл за ответ:

```
score = base_points
      × partial       (если partial_correct.enabled, иначе 1.0)
      × speed         (если speed_bonus.enabled и ответ быстрый, иначе 1.0)
      × streak        (если streak_bonus.enabled, иначе 1.0)
      × consensus     (если consensus_bonus.enabled и единогласие, иначе 1.0)
      × final_round   (если final_multiplier.enabled и раунд = final, иначе 1.0)
      − penalty       (если penalty.enabled и ответ неправильный, иначе 0)
```

## Сущности

- **GameSession** — игровая сессия (режим, настройки, тайминги)
- **GameSessionTeam** — команда (название, цвет, капитан, счёт)
- **GameSessionParticipant** — участник (пользователь/гость, команда, счёт)
- **GameQuestion** — вопрос викторины (тип, текст, медиа, сложность, тип раунда, методическое пояснение)
- **GameAnswerOption** — вариант ответа
- **ScenarioTemplate** — шаблон сценария (набор раундов с вопросами для тематической сессии)
- **ScenarioTemplateRound** — раунд шаблона (тип раунда + порядок)
- **ScenarioTemplateRoundQuestion** — вопрос в раунде шаблона (конкретный вопрос из банка)

## Взаимодействие

- **Получает контент** из CMS (вопросы, медиа)
- **Отправляет события** в Аналитику (результаты сессий, ответы команд, тайминги)
- **Использует Идентификацию** для авторизации участников и привязки событий к профилям
