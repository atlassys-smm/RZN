# Викторина

Игровые сессии на LED-платформе. Вопросы с вариантами ответов на LED-экране, участники отвечают с мобильных устройств.

---

## Режимы

### Индивидуальная викторина

Основной режим — раунды с разными типами вопросов, как в командной игре. Отличие: участники отвечают персонально, рейтинг индивидуальный.

- Оператор выбирает опубликованный шаблон или вручную задаёт раунды (от 3 до 8 типов) с конкретными `question_id` либо параметрами автоматического выбора. Клиент передаёт в API создания сессии готовый массив `rounds`
- Каждый участник отвечает самостоятельно за себя
- Сессию создаёт оператор; участники подключаются к ней через QR-код на LED-экране
- По итогам — индивидуальный рейтинг участников

### Командная игра

Основной сценарный режим. Профориентационная игра на LED-экране:

- Формирование команд (от 2 до 8 команд, состав — от 2 до 10 человек)
- Оператор выбирает шаблон сценария из подготовленных в CMS или собирает раунды вручную
- Если выбран шаблон — клиент берёт заранее подобранные вопросы для каждого раунда и передаёт их в `rounds`; ID шаблона в сессии не сохраняется
- Шаблоны доступны для обоих режимов; в запросе создания сессии для каждого раунда (от 3 до 8) передаются либо `question_ids`, либо `question_count` и `question_filters` (`difficulty`, `age_group`, `tags`)
- Раунды заданий, обсуждения, приём ответов
- Участники отправляют предварительные ответы; капитан видит ответы команды и отдельно отправляет решающий ответ, который засчитывается команде
- Рейтинг и итоговый результат

**Капитан:**
- Первый подключившийся к команде становится капитаном
- Текущий капитан может передать роль другому участнику команды
- Если капитан отключился от игры, система назначает случайного капитана из участников команды
- Оператор может сменить капитана, выбрав нового из списка участников команды

Для одного LED-устройства может существовать не более одной незавершённой сессии (status `1` — waiting или `2` — active). Разные устройства могут проводить сессии одновременно.

## Статусы сессии

| Статус | Описание |
|--------|----------|
| Значение | Статус | Описание |
|----------|--------|----------|
| 1 | `waiting` | Формирование команд. Игра ещё не началась. |
| 2 | `active` | Игра идёт. Оператор управляет раундами и вопросами. |
| 3 | `finished` | Сессия завершена. Показан финальный рейтинг. |

---

## Этапы командной сессии

### Подготовка (status `1`, waiting)

1. Создание сессии оператором → status `1` (waiting)
2. Подключение и формирование команд
3. Инструктаж
4. Оператор нажимает «Начать игру» → status `2` (active)
5. Команды с нулевым количеством участников автоматически исключаются из сессии. Игра может начаться, если после исключения осталось не менее 2 команд и в каждой не менее 2 участников

### Проведение (status `2`, active)

5. Раунды заданий (от 3 до 8):
   - Показ вопроса на LED
   - Обсуждение в командах
   - Приём ответов (таймер вопроса)
   - Показ правильного ответа с методическим пояснением
   - Автоматическая проверка зачётных ответов и начисление баллов
6. Показ промежуточных результатов раунда (если `show_intermediate_results = true`)
7. Пауза между раундами (`between_rounds_delay`)
8. Следующий раунд

### Завершение

9. После последнего вопроса последнего раунда — показ финальных результатов
10. Оператор нажимает «Завершить» → status `3` (finished)
11. Сохранение статистики и возврат в режим ожидания

## Настройки сессии

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `auto_reveal` | Автоматический показ правильного ответа по истечении времени. Если `false` — оператор нажимает «Показать ответ» | `true` |
| `auto_next` | Автоматический переход к следующему вопросу после показа ответа | `false` |
| `auto_next_delay` | Задержка автоперехода в секундах | `5` |
| `between_rounds_delay` | Пауза между раундами в секундах | `10` |
| `show_intermediate_results` | Показывать промежуточный рейтинг после каждого раунда | `true` |

## Сущности

- **GameSession** — игровая сессия (режим, настройки, тайминги)
- **GameSessionTeam** — команда (название, цвет, капитан, счёт)
- **GameSessionParticipant** — участник (пользователь/гость, команда, счёт)
- **GameQuestion** — вопрос викторины (тип, текст, медиа, сложность, тип раунда, методическое пояснение)
- **GameAnswerOption** — вариант ответа
- **ScenarioTemplate** — шаблон сценария (набор раундов с вопросами для тематической сессии)
- **ScenarioTemplateRound** — раунд шаблона (тип раунда + порядок)
- **ScenarioTemplateRoundQuestion** — вопрос в раунде шаблона (конкретный вопрос из банка)

## Взаимодействие

- **Получает контент** из CMS (вопросы, медиа)
- **Отправляет события** в Аналитику (результаты сессий, ответы команд, тайминги)
- **Использует Идентификацию** для авторизации участников и привязки событий к профилям
