# LED-медиаплатформа

Ядро системы. Управление LED-экранами мероприятия.

---

## Экраны

На мероприятии работают два LED-экрана с разными ролями:

| | Большой LED (амфитеатр) | Малый LED (вход) |
|---|---|---|
| **Расположение** | Амфитеатр | Вход на мероприятие |
| **Режимы** | Заставка + Викторина | Только заставка |
| **Управление** | Оператор управляет с планшета | Автономная работа |

**Большой LED** — основной экран. Оператор запускает и переключает режимы (заставка ↔ викторина) с планшета. В режиме заставки может быть запущена сессия «Профессии в действии».

**Малый LED** — навигационный экран у входа. Работает только в режиме заставок, без интерактива. Может запустить сессию «Профессии в действии» — всегда с одной профессией (`profession_count = 1`).

---

## Основные режимы

LED-медиаплатформа работает в трёх основных режимах:

- **[Заставка](screensaver.md)** — режим ожидания с вариациями контента (видеоплейлист, «Профессии в действии», «Мой карьерный маршрут», публичная аналитика)
- **[Викторина](quiz.md)** — игровые сессии (индивидуальная викторина и командная игра)
- **[Оператор](operator.md)** — панель управления для сотрудников
