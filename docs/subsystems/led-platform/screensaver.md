# Заставка (режим ожидания)

Режим по умолчанию, когда не идёт активная сессия. Несколько вариаций контента, которые можно назначать и комбинировать.

---

## Вариации контента

### Видеоплейлист

Зацикленный показ видеороликов, карточек профессий, анонсов.

!!! warning "Подлежит разработке"
    Механика формирования видеоплейлиста — откуда берутся видео, как подбираются и в каком порядке показываются — ещё не определена и подлежит разработке.

### «Профессии в действии»

Интерактивный видеосценарий с точками выбора.

- Система берёт случайную профессию и показывает видеоролик о ней
- QR-код всегда виден на экране, чтобы новые зрители могли подключиться в любой момент
- В определённые моменты видео зрители голосуют за вариант продолжения через мобильные устройства
- Если таймер истёк и никто не выбрал — система выбирает продолжение сама
- Если голоса есть — побеждает вариант с большинством голосов
- Оператор может запустить эту вариацию целенаправленно и указать, сколько профессий нужно показать
- Оператор может выбрать конкретные видеосценарии или доверить выбор системе

**API:**
- Запуск показа: `POST /interactive-video/sessions`
- Остановка показа: `POST /interactive-video/sessions/{id}/stop`
- Получение состояния (для LED): `GET /interactive-video/sessions/{id}/state`

→ [Сущности видеосценария](../../entities/video-scenario.md)

### «Мой карьерный маршрут»

Анимированный экран с QR-кодом перехода в цифровой профиль для получения персональных рекомендаций.

### Публичная аналитика

Агрегированные показатели платформы (популярность профессий, количество сессий, активность) без персональных данных и служебной информации.

→ [Публичный LED-дашборд](../analytics/led-dashboard.md)

---

## Взаимодействие

- **Получает контент** из CMS (видеоплейлисты, видеосценарии, карточки профессий)
- **Отправляет события** в Аналитику (просмотры, голосования, подключения по QR)
- **Использует Идентификацию** для привязки действий зрителей к профилям
