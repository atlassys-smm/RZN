# Викторина

Управление контентом викторин на LED-платформе: банк вопросов и шаблоны сценариев для командной игры.

---

## Вопросы

Управление банком вопросов для индивидуальной викторины и командной игры. Одна и та же сущность вопроса используется в обоих сценариях. Разница в организации: в индивидуальной викторине вопросы формируются случайным образом, в командной игре вопросы привязываются к раундам.

### Режимы

- **Список** — таблица: текст вопроса, тип, сложность, возрастная группа, тип раунда, баллы; фильтрация по типу, сложности, возрастной группе, типу раунда; поиск по тексту
- **Карточка** — создание / редактирование вопроса с вариантами ответов

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый вопрос с вариантами ответов |
| Редактировать | Изменить текст, тип, параметры, варианты ответов |
| Копировать | Дубликат вопроса (для быстрого создания похожих) |
| Удалить | Удаление вопроса |

### Поля карточки вопроса

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Тип вопроса | enum | да | См. таблицу типов ниже |
| Текст вопроса | text | да | Формулировка вопроса |
| Медиа-файл | → File | нет | Изображение или видео к вопросу |
| Сложность | enum | нет | `easy`, `medium`, `hard` |
| Возрастная группа | enum | нет | `12-14`, `15-17`, `adult` |
| Время на ответ | integer (сек) | нет | Ограничение времени на ответ |
| Баллы | integer | да | Баллы за правильный ответ |
| Методическое пояснение | text | нет | Пояснение к правильному ответу |
| Тип раунда | → [RoundType] | нет | Код типа раунда из справочника |
| Теги | json | нет | Профессия, отрасль, компетенция |

### Типы вопросов

| Тип | Описание |
|-----|----------|
| `single_choice` | Выбор одного варианта |
| `multiple_choice` | Выбор нескольких вариантов |
| `yes_no` | Да / нет |
| `image_choice` | Выбор по изображению |
| `matching` | Сопоставление |
| `sorting` | Упорядочивание |
| `profession_by_description` | Выбор профессии по описанию задач |
| `recognize_by_image` | Распознавание профессии по изображению |
| `recognize_by_video` | Распознавание профессии по видео |
| `sequence` | Восстановление последовательности этапов |
| `case_study` | Ситуационный кейс |
| `role_distribution` | Распределение ролей в команде |
| `resource_selection` | Выбор набора ресурсов и специалистов |
| `error_finding` | Поиск ошибки в рабочей ситуации |
| `prediction` | Прогноз развития технологии |
| `argumentation` | Аргументация и консенсус |
| `media_round` | Медиараунд с видеофрагментом |
| `final_case` | Финальный комплексный кейс |

### Варианты ответов

Каждый вопрос содержит один или несколько вариантов ответов.

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Текст | text | да | Текст варианта ответа |
| Медиа-файл | → File | нет | Изображение к варианту |
| Правильный | boolean | да | Является ли вариант правильным |
| Порядок | integer | да | Порядок отображения |

## Шаблоны сценариев

Управление шаблонами для командной игры. Шаблон сценария — это заранее подготовленный набор раундов с конкретными вопросами, привязанными к определённой тематике или направлению.

Оператор при запуске командной игры выбирает готовый шаблон вместо ручного подбора вопросов. Это позволяет проводить тематические сессии, заточенные под конкретные отрасли, профессии или возрастные группы.

### Режимы

- **Список** — таблица: название шаблона, количество раундов, количество вопросов, статус; фильтрация по статусу; поиск по названию
- **Карточка** — создание / редактирование шаблона с раундами и вопросами

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый шаблон сценария |
| Редактировать | Изменить название, описание, раунды и вопросы |
| Копировать | Дубликат шаблона (для создания похожего) |
| Опубликовать | Перевести из черновика в опубликованный (доступен оператору) |
| В черновик | Вернуть из опубликованного в черновик |
| Удалить | Только если шаблон не использовался в проведённых сессиях |

### Поля карточки шаблона

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Название | string | да | Название шаблона (например, «IT-направление», «Медицина», «Строительство») |
| Описание | text | нет | Для какой тематики, возрастная группа, особенности |
| Статус | enum | да | `draft` (черновик) / `published` (опубликован) |

### Структура шаблона

Шаблон состоит из **раундов** (от 3 до 8), каждый раунд содержит **конкретные вопросы** из банка вопросов.

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Тип раунда | → [RoundType] | да | Код типа раунда из [справочника](../../references/scenario-round-types.md) |
| Порядок | integer | да | Порядок раунда в сценарии |
| Вопросы | → [GameQuestion][] | да | Конкретные вопросы из банка вопросов |

### Работа с вопросами в раунде

Для каждого раунда администратор выбирает конкретные вопросы из банка вопросов. Доступны фильтры:

- Тип вопроса
- Сложность (`easy`, `medium`, `hard`)
- Возрастная группа (`12-14`, `15-17`, `adult`)
- Теги (профессия, отрасль, компетенция)
- Тип раунда

Вопросы можно перетаскивать для изменения порядка. Можно добавить любое количество вопросов — система использует их все в рамках раунда.

### Пример шаблона

**Шаблон: «IT-направление»**

| Порядок | Тип раунда | Вопросы |
|---------|-----------|---------|
| 1 | `quick_start` | 5 вопросов на узнавание IT-профессий |
| 2 | `tools` | 4 вопроса об инструментах разработчика, сисадмина, тестировщика |
| 3 | `skills` | 4 вопроса о навыках и компетенциях в IT |
| 4 | `situation` | 2 ситуационных кейса из IT-отрасли |
| 5 | `process` | 3 вопроса на восстановление процессов (CI/CD, разработка) |
| 6 | `future` | 3 вопроса о технологиях будущего |
| 7 | `final` | 1 комплексный финальный кейс |

### Взаимосвязь с оператором

При запуске командной игры оператор видит список опубликованных шаблонов:

1. Оператор выбирает шаблон из списка
2. Система загружает раунды и вопросы из шаблона
3. Далее — стандартный процесс: формирование команд, раунды, рейтинг

Если подходящего шаблона нет, оператор может собрать раунды вручную (выбор типов раундов + автоподбор вопросов).
