# Администрирование согласий

Управление версионируемыми согласиями на обработку персональных данных в CMS.

---

## Назначение

Согласия — это юридические тексты, которые принимает пользователь при оставлении контактных данных в анкетах обратной связи. Каждое изменение текста создаёт новую версию — в хранилище фиксируется, по какой именно версии давалось согласие.

---

## Создание согласия

1. **Основные поля:**
   - Тип согласия:
     - `personal_data` — согласие на обработку персональных данных
     - `contact_request` — согласие на обработку контактной заявки
   - Заголовок (например, «Согласие на обработку персональных данных»)
   - Версия (например, `1.0`, `1.1`, `2.0`)
   - Текст согласия (полный юридический текст)
   - Дата вступления в силу (`effective_from`)

2. **Активация:**
   - Новое согласие создаётся со статусом `is_active = true`
   - При создании новой версии старая автоматически деактивируется

---

## Версионирование

При изменении текста согласия:

1. Нажать «Создать новую версию» у текущего согласия
2. Отредактировать текст
3. Указать новую версию и дату вступления в силу
4. Сохранить

**Результат:**
- Старая версия: `is_active = false`, все существующие записи о принятии сохранены
- Новая версия: `is_active = true`, новые пользователи принимают уже её

---

## Фиксация принятия согласия

Когда пользователь принимает согласие при отправке анкеты:

- В `SurveyResponse` сохраняется `consent_id` — идентификатор той версии согласия, которую показал пользователю
- В `ConsentAcceptance` создаётся запись: кто, когда, какую версию принял

Это обеспечивает юридическую значимость: можно доказать, что пользователь принял конкретную версию согласия в конкретный момент времени.

---

## Использование в анкетах

При настройке анкеты с контактной заявкой:

1. Включить опцию «Требовать согласие на обработку ПДн»
2. Выбрать активную версию согласия
3. При прохождении анкеты пользователь видит текст согласия и ставит галочку
4. Без согласия отправка контактных данных невозможна

→ [Сущность согласия](../../entities/consent.md)

## Связь с аналитикой

В аналитике анкет можно видеть:
- По какой версии согласия оставляли контактные данные
- Когда были приняты согласия (аудит)
