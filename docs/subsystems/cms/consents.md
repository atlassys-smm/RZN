# Администрирование согласий

Управление типами и версиями согласий в CMS.

---

## Назначение

Согласия — это юридические тексты, которые принимает пользователь при оставлении контактных данных в анкетах обратной связи. Каждый тип согласия может иметь множество версий.

---

## Типы согласий

Тип согласия — это сущность, объединяющая все версии одного документа. Например:
- «Согласие на обработку ПДн»
- «Договор-оферта»
- «Согласие на контактную заявку»

### Создание типа

1. Код (например, `personal_data`, `offer_agreement`)
2. Название
3. Описание (необязательно)

---

## Версии согласий

Каждый тип согласия может иметь множество версий. Версия содержит текст согласия.

### Жизненный цикл версии

1. **Черновик** — версия без номера, можно редактировать текст
2. **Публикация** — системе присваивается номер версии (автоинкремент: 0.1, 0.2, 0.3...), устанавливается дата вступления в силу
3. **Опубликованная версия** — редактировать нельзя, можно только создать новую версию

### Создание новой версии

1. В карточке типа согласия нажать «Создать новую версию»
2. Отредактировать текст
3. Сохранить как черновик
4. Опубликовать — номер версии назначается автоматически

### Активная версия

Активная версия — последняя опубликованная. Именно её видит пользователь при прохождении анкеты.

---

## Фиксация принятия согласия

Когда пользователь принимает согласие при отправке анкеты:

- В `SurveyResponse` сохраняется `consent_version_id` — идентификатор той версии согласия, которую показал пользователю
- В `ConsentAcceptance` создаётся запись: кто, когда, какую версию принял

Это обеспечивает юридическую значимость: можно доказать, что пользователь принял конкретную версию согласия в конкретный момент времени.

---

## Использование в анкетах

При настройке анкеты с контактной заявкой:

1. Включить опцию «Требовать согласие»
2. Выбрать тип согласия (система автоматически покажет активную версию)
3. При прохождении анкеты пользователь видит текст активной версии и ставит галочку
4. Без согласия отправка контактных данных невозможна
