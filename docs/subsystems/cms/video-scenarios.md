# Профессии в действии

Управление интерактивными видеосценариями для LED-платформы. Видеосценарий — это дерево видеофрагментов с точками выбора: после каждого фрагмента зритель выбирает вариант, и воспроизводится следующий фрагмент.

---

## Режимы

- **Список** — таблица: название, профессия, количество веток, дата создания; фильтрация по профессии; поиск по названию
- **Карточка** — создание / редактирование видеосценария с редактором дерева веток

---

## Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый видеосценарий |
| Редактировать | Изменить название, профессию, структуру веток |
| Сохранить | Сохранить все изменения сценария (название, профессию, дерево веток) |
| Копировать | Дубликат сценария (для создания похожего) |
| Удалить | Только если сценарий не используется в активных сессиях |

### Сохранение

Все изменения в карточке видеосценария (название, профессия, дерево веток) сохраняются вместе при нажатии кнопки **«Сохранить»**. До сохранения изменения существуют только в интерфейсе и не записываются в базу.

При создании нового сценария кнопка «Сохранить» создаёт сценарий и все его ветки. При редактировании — обновляет изменённые поля и структуру веток (добавленные, изменённые, удалённые).

---

## Карточка видеосценария

### Основные поля

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Название | string | да | Название сценария (например, «День разработчика», «Как устроена больница») |
| Описание | text | нет | Краткое описание: о чём сценарий, для какой аудитории |
| Профессия | → Profession | нет | Привязка к профессии из справочника |

---

## Редактор дерева веток

Основная часть карточки — редактор дерева веток. Каждая ветка — это видеофрагмент, а дочерние ветки — варианты выбора после него.

### Структура редактора

Редактор представляет собой список веток текущего уровня с возможностью раскрыть каждую и увидеть её дочерние варианты.

**Стартовая ветка** — всегда первая в списке, не имеет текста варианта (это начало сценария).

**Дочерние ветки** — варианты выбора. Каждая имеет текст варианта (то, что увидит пользователь) и видеофайл.

### Элементы ветки

Каждая ветка в редакторе содержит:

| Элемент | Описание |
|---------|----------|
| Название файла | Имя загруженного видео |
| Кнопка замены | Загрузить другое видео вместо текущего |
| Поле «Текст варианта» | Текст, который увидит пользователь при выборе этой ветки (для дочерних веток) |
| Кнопка «Удалить» | Удалить ветку и все её дочерние ветки |
| Кнопка «Раскрыть» | Показать дочерние варианты выбора (если есть) |
| Кнопка «+ Добавить вариант» | Добавить дочернюю ветку (вариант выбора после этого видео) |

### Работа с редактором

1. **Создание сценария** — заполняются название, описание, выбирается профессия. Стартовая ветка создаётся автоматически.

2. **Загрузка видео** — для каждой ветки загружается видеофайл через кнопку замены.

3. **Добавление вариантов выбора** — под каждой веткой кнопка «+ Добавить вариант». При нажатии открывается форма: загрузка видео + поле «Текст варианта».

4. **Навигация по дереву** — кнопка «Раскрыть» показывает дочерние варианты. Можно раскрывать ветки рекурсивно.

5. **Конец сценария** — ветка без дочерних элементов автоматически является концом сценария. Кнопка «+ Добавить вариант» отсутствует или создаёт новый вариант.

6. **Удаление** — удаление ветки удаляет все её дочерние ветки. Стартовую ветку удалить нельзя.

7. **Порядок вариантов** — дочерние варианты можно перетаскивать для изменения порядка отображения.
