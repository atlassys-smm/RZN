# Журнал изменений

История всех изменений контента в системе: кто, когда, что изменил. Позволяет отследить действия сотрудников и при необходимости откатить изменения.

---

## Режимы

- **Список** — таблица: дата и время, пользователь, действие, объект (тип и название), изменения; фильтрация по пользователю, типу объекта, действию, периоду; поиск по названию объекта

---

## Отображаемые поля

| Поле | Описание |
|------|----------|
| Дата и время | Когда произошло изменение |
| Пользователь | Кто внёс изменение (имя и email) |
| Действие | Тип действия: создание, редактирование, удаление, публикация |
| Объект | Тип и название изменённого объекта (например, «Вопрос: Какой инструмент использует...») |
| Изменения | Что конкретно изменилось (diff полей: было → стало) |

---

## Фильтры

| Фильтр | Описание |
|--------|----------|
| Период | Дата с — дата по |
| Пользователь | Конкретный сотрудник |
| Тип объекта | Вопрос, Шаблон сценария, Видеосценарий, Профессия и т.д. |
| Действие | Создание, Редактирование, Удаление, Публикация |

---

## Типы отслеживаемых действий

| Действие | Описание |
|----------|----------|
| Создание | Объект создан |
| Редактирование | Изменены поля объекта (отображаются конкретные изменения) |
| Удаление | Объект удалён |
| Публикация | Объект переведён из черновика в опубликованный |
| В черновик | Объект переведён из опубликованного в черновик |

---

## Детали изменения

При клике на запись в журнале открывается детальная карточка:

- Полная информация об объекте до и после изменения
- Список изменённых полей с предыдущими и текущими значениями
- Для вопросов: изменения в вариантах ответов
- Для шаблонов: изменения в структуре раундов и вопросах
- Для видеосценариев: изменения в дереве веток

---

## Хранение

Журнал изменений хранится бессрочно. Записи не удаляются даже при удалении самого объекта (сохраняется факт удаления).
