# ПрофСтарт

Управление контентом профориентационного теста: банк вопросов и варианты ответов.

---

## Вопросы

Управление банком вопросов для профориентационного теста. Вопросы маркируются по возрастным группам — тест формируется динамически из вопросов выбранной возрастной группы.

### Режимы

- **Список** — таблица: текст вопроса, тип, возрастная группа, порядок
- **Карточка** — создание / редактирование вопроса с вариантами ответов

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый вопрос с вариантами ответов |
| Редактировать | Изменить текст, тип, параметры, варианты ответов |
| Копировать | Дубликат вопроса (для быстрого создания похожих) |
| Удалить | Удаление вопроса |

### Карточка вопроса

Карточка выводит атрибуты сущности [TestQuestion](../../entities/test.md): текст вопроса, тип, медиа-файл, возрастная группа, порядок, случайный порядок.

- **Тип вопроса** — из [справочника типов вопросов](../../references/profstart-question-types.md)
- **Возрастная группа** — из [справочника возрастных групп](../../references/profstart-age-groups.md)

!!! warning "Весовые коэффициенты"
    Поле для весовых коэффициентов по направлениям **не реализовано**. Механика расчёта результатов требует доработки (см. [ПрофСтарт — Цифровой профориентационный портрет](../../subsystems/profstart/index.md)).

### Варианты ответов

Каждый вопрос содержит один или несколько вариантов ответов — сущность [TestAnswerOption](../../entities/test.md#testansweroption-вариант-ответа-теста-профстарт).
