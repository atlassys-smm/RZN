# ПрофСтарт

Управление контентом профориентационного теста: банк вопросов, варианты ответов, просмотр сессий и результатов.

---

## Вопросы

Управление банком вопросов для профориентационного теста. Вопросы маркируются по возрастным группам — тест формируется динамически из вопросов выбранной возрастной группы.

### Режимы

- **Список** — таблица: текст вопроса, тип, возрастная группа, порядок; фильтрация по типу, возрастной группе; поиск по тексту
- **Карточка** — создание / редактирование вопроса с вариантами ответов

### Действия

| Действие | Описание |
|----------|----------|
| Создать | Новый вопрос с вариантами ответов |
| Редактировать | Изменить текст, тип, параметры, варианты ответов |
| Копировать | Дубликат вопроса (для быстрого создания похожих) |
| Удалить | Удаление вопроса |

### Поля карточки вопроса

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Тип вопроса | enum | да | См. таблицу типов ниже |
| Текст вопроса | text | да | Формулировка вопроса |
| Медиа-файл | → File | нет | Изображение к вопросу |
| Возрастная группа | enum | да | `12-14`, `15-17` |
| Порядок | integer | нет | Порядок отображения (если фиксированный) |
| Случайный порядок | boolean | нет | Случайный порядок отображения |

!!! warning "Весовые коэффициенты"
    Поле для весовых коэффициентов по направлениям **не реализовано**. Механика расчёта результатов требует доработки (см. [ПрофСтарт — Цифровой профориентационный портрет](../../subsystems/profstart/index.md)).

### Типы вопросов

| Тип | Описание |
|-----|----------|
| `single_choice` | Выбор одного варианта |
| `multiple_choice` | Выбор нескольких вариантов |
| `agreement_scale` | Шкала согласия |
| `image_choice` | Выбор по изображению |
| `ranking` | Ранжирование |
| `case_study` | Ситуационный кейс |

### Варианты ответов

Каждый вопрос содержит один или несколько вариантов ответов.

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Текст | text | да | Текст варианта ответа |
| Медиа-файл | → File | нет | Изображение к варианту |
| Порядок | integer | да | Порядок отображения |

## Сессии

Просмотр сессий прохождения теста.

### Режимы

- **Список** — таблица: дата, пользователь (или "гость"), возрастная группа, статус, длительность, интерфейс; фильтрация по дате, возрастной группе, статусу, интерфейсу

### Действия

| Действие | Описание |
|----------|----------|
| Просмотр | Детальная информация о сессии |
| Экспорт | Выгрузка данных сессии |

### Поля списка сессий

| Поле | Тип | Описание |
|------|-----|----------|
| Дата начала | timestamp | Дата и время начала теста |
| Пользователь | string / "Гость" | Имя пользователя или пометка "Гость" |
| Возрастная группа | enum | `12-14`, `15-17` |
| Статус | enum | `in_progress`, `completed`, `abandoned` |
| Длительность | integer (мин) | Длительность прохождения |
| Интерфейс | enum | `kiosk`, `web` |

## Результаты

Просмотр результатов завершённых тестов.

!!! danger "Структура результата не определена"
    Конкретное содержимое результата и механика расчёта **требуют доработки**. Необходимо определить, какие данные хранятся и как визуализировать результат.
    
    См. [ПрофСтарт — Цифровой профориентационный портрет](../../subsystems/profstart/index.md).

### Режимы

- **Список** — таблица: дата, пользователь (или "гость"), возрастная группа, статус результата; фильтрация по дате, возрастной группе

### Действия

| Действие | Описание |
|----------|----------|
| Просмотр | Детальная информация о результате |

### Поля списка результатов

| Поле | Тип | Описание |
|------|-----|----------|
| Дата | timestamp | Дата и время завершения теста |
| Пользователь | string / "Гость" | Имя пользователя или пометка "Гость" |
| Возрастная группа | enum | `12-14`, `15-17` |
| Статус | enum | `draft`, `final` |
