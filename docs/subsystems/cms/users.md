# Пользователи

Управление учётными записями сотрудников системы администрирования.

---

## Режимы

- **Список** — таблица: имя, email, роль, статус (активен / заблокирован), дата последней активности; фильтрация по роли, статусу; поиск по имени и email
- **Карточка** — создание / редактирование учётной записи

---

## Действия

| Действие | Описание |
|----------|----------|
| Создать | Новая учётная запись сотрудника |
| Редактировать | Изменить имя, email, роль |
| Заблокировать | Запретить вход в систему (учётная запись сохраняется) |
| Разблокировать | Восстановить доступ |
| Сбросить пароль | Отправить ссылку для сброса пароля на email |
| Удалить | Удалить учётную запись (только если нет связанных действий в журнале) |

---

## Поля карточки пользователя

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Имя | string | да | Имя сотрудника |
| Фамилия | string | да | Фамилия сотрудника |
| Email | string | да | Email для входа и уведомлений |
| Роль | enum | да | Роль в системе (см. ниже) |
| Статус | enum | да | `active` (активен) / `blocked` (заблокирован) |
| Дата создания | timestamp | — | Автоматически |
| Последняя активность | timestamp | — | Автоматически |

---

## Роли

| Роль | Права |
|------|-------|
| **Администратор** | Полный доступ ко всем разделам, управление пользователями |
| **Контент-менеджер** | Создание и редактирование контента (справочники, вопросы, шаблоны, аватары, видеосценарии) |
| **Оператор** | Запуск сценариев, просмотр контента |
| **Просмотр отчётов** | Только просмотр аналитики и отчётов |

---

## Вход в систему

- Вход по email и паролю
- При первом входе — обязательная смена временного пароля
- Восстановление пароля через email
- Минимальные требования к паролю: 8 символов, буквы и цифры
