# Аватары профессий

Управление эталонными образами профессий для ПАК «Аватар профессий». Для каждой профессии загружаются два эталонных изображения — мужской и женский образ. Эти шаблоны используются для генерации аватаров посетителей в образах профессий.

---

## Режимы

- **Список** — таблица: профессия, мужское фото, женское фото
- **Карточка** — загрузка и замена эталонных изображений для профессии

---

## Карточка профессии (раздел аватаров)

Карточка выводит атрибуты сущности [Profession](../../entities/professions.md) и связанные аватары.

Для сохранения записи необходимо загрузить оба пола (мужское и женское фото).

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Профессия | → [Profession] | да | Профессия из справочника (выбирается из списка) |
| Мужское фото | → File | да | Эталонное изображение мужчины в образе профессии |
| Женское фото | → File | да | Эталонное изображение женщины в образе профессии |
