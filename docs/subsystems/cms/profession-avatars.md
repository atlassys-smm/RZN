# Аватары профессий

Управление эталонными образами профессий для ПАК «Аватар профессий». Для каждой профессии загружаются два эталонных изображения — мужской и женский образ. Эти шаблоны используются для генерации аватаров посетителей в образах профессий.

---

## Режимы

- **Список** — таблица: профессия, отрасль, направление, статус загрузки (оба пола / только мужской / только женский / не загружено); фильтрация по отрасли, направлению, статусу; поиск по названию профессии
- **Карточка** — загрузка и замена эталонных изображений для профессии

---

## Действия

| Действие | Описание |
|----------|----------|
| Загрузить мужское фото | Загрузить эталонное изображение мужчины для профессии |
| Загрузить женское фото | Загрузить эталонное изображение женщины для профессии |
| Заменить фото | Заменить уже загруженное изображение |
| Удалить фото | Удалить загруженное изображение |

---

## Карточка профессии (раздел аватаров)

| Поле | Тип | Обязательное | Описание |
|------|-----|:---:|----------|
| Профессия | → Profession | да | Профессия из справочника (выбирается из списка) |
| Отрасль | string | — | Отображается автоматически из справочника профессий |
| Направление | string | — | Отображается автоматически из справочника профессий |
| Мужское фото | → File | нет | Эталонное изображение мужчины в образе профессии |
| Женское фото | → File | нет | Эталонное изображение женщины в образе профессии |

---

## Требования к изображениям

| Параметр | Значение |
|----------|----------|
| Формат | PNG, JPG, WebP |
| Разрешение | не менее 1024×1024 |
| Пропорции | 1:1 (квадрат) или 3:4 (портрет) |
| Фон | Однотонный или прозрачный |
| Качество | Высокое, без артефактов сжатия |

---

## Статус загрузки

Для каждой профессии отображается статус готовности:

| Статус | Описание |
|--------|----------|
| Готово | Загружены оба пола |
| Частично | Загружен только один пол |
| Не загружено | Изображения отсутствуют |
