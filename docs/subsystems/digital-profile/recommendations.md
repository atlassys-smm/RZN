# Мой карьерный маршрут

Подбор профессий, учебных заведений и работодателей на основе данных профиля пользователя. Все данные берутся из справочников CMS.

---

## Источники данных для подбора

Рекомендации формируются на основе:

- **Результаты ПрофСтарт** — сохранённые профессии и связанные группы из отдельных результатов трёх тестов
- **Выбранные профессии** — из сценариев LED-платформы, тестов, анкет
- **Интересы** — типы задач и деятельности, выявленные по ответам пользователя

---

## Категории рекомендаций

### Профессии

Подбираются из [справочника профессий](../../entities/professions.md) на основе:

- Связей групп результата ПрофСтарт с профессиями ([формула](../profstart/results.md)); группы не подменяют `Direction`
- Отраслей, которые пользователь выбирали в сценариях
- Компетенций и интересов

### Учебные заведения

Подбираются из [справочника учебных заведений](../../entities/organizations.md):

- Фильтрация по направлениям подготовки (`direction_ids`)
- Соответствие ведущим профессиональным направлениям пользователя
- Отображается: название, тип, адрес, сайт, направления обучения

### Работодатели

Подбираются из [справочника работодателей](../../entities/organizations.md):

- Фильтрация по отрасли (`industry_id`)
- Соответствие профессиональным интересам пользователя
- Отображается: название, отрасль, адрес, сайт, количество вакансий

---

## Рекомендательная модель

!!! danger "Требуется доработка"
    Общая модель, объединяющая разные активности, учебные заведения и работодателей, **требует доработки**. Подбор профессий внутри одного результата ПрофСтарт описан отдельно и не является этой общей моделью. Необходимо определить:

    - Какие данные профиля влияют на подбор (результаты ПрофСтарт, выбранные профессии, прохождения)
    - Формула ранжирования и веса источников
    - Сколько рекомендаций показывать в каждой категории
    - Порядок отображения категорий
