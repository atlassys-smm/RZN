# Профиль

Раздел просмотра персональных данных пользователя.

---

## Данные пользователя

Пользователь видит данные, полученные из OAuth-провайдера при авторизации:

- Имя
- Email
- Аватар
- Пол (при доступности у провайдера)
- Дата рождения (при доступности у провайдера)

Данные предоставляются провайдером (Яндекс ID или VK ID) и не редактируются напрямую в личном кабинете.
