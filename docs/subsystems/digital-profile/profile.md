# Профиль

Раздел управления персональными данными, согласиями и учётной записью.

---

## Данные пользователя

Пользователь видит данные, полученные из OAuth-провайдера при авторизации:

- Имя
- Email
- Аватар
- Пол (при доступности у провайдера)
- Дата рождения (при доступности у провайдера)

Данные предоставляются провайдером (Яндекс ID или VK ID) и не редактируются напрямую в личном кабинете.

---

## Согласия

Управление согласиями на обработку персональных данных:

- Просмотр принятых версий согласий с датами принятия
- Согласия версионируются в CMS — при публикации новой версии пользователю предлагается принять обновлённое согласие

→ [Согласия в CMS](../cms/consents.md)
