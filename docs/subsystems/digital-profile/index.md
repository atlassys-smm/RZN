# Цифровой профиль и личный кабинет

Единый веб-портал (PWA) — личное пространство пользователя платформы. Агрегирует результаты всех активностей, формирует сводный профессиональный портрет, показывает прогресс и подбирает рекомендации по профессиям, учебным заведениям и работодателям.

---

## Назначение

- Сводный цифровой профиль пользователя на основе всех прохождений и активностей
- Личный кабинет с визуализацией интересов, прогресса и рекомендаций
- Каталог активностей центра с отметками о прохождении
- Рекомендации по профессиям, учебным заведениям и работодателям
- Управление профилем, согласиями и персональными данными

---

## Цифровой профиль

Модель данных, объединяющая всю информацию о пользователе из различных источников:

- **Результаты LED-сессий** — викторины, командные игры, голосование, карьерный маршрут
- **Результаты ПрофСтарт** — профессиональный портрет, ведущие направления, компетенции
- **Выбранные профессии и отрасли** — из сценариев, тестов, анкет
- **История активностей** — все прохождения с датами и результатами
- **Согласия** — принятые версии согласий на обработку персональных данных

Профиль формируется автоматически по мере взаимодействия пользователя с платформой. Каждое событие привязывается к ID профиля.

## PWA

Личный кабинет реализован как Progressive Web App:

- **Установка:** пользователь может установить приложение на устройство через браузер (добавить на главный экран)
- **Без оффлайн-режима:** все данные загружаются с сервера, кэширование не используется
- **Без установки:** если пользователь не установил PWA, портал работает как обычная адаптивная веб-страница в браузере
- **Адаптивность:** интерфейс адаптируется под десктоп, планшет и мобильное устройство

## Гостевой режим

Пользователь может взаимодействовать с платформой без авторизации (гостевой режим по QR-коду). В этом случае:

- Результаты привязываются к `guest_id` гостевой сессии
- Гость может просматривать личный кабинет, но на **каждой странице** ему предлагается пройти полноценную авторизацию
- При первой авторизации через OAuth (Яндекс ID или VK ID) гостевые результаты автоматически привязываются к профилю пользователя

→ [Подробное описание гостевого режима](../identification.md#гостевой-режим)

## Взаимодействие с другими подсистемами

### Получает данные

- **LED-медиаплатформа:**
  - Результаты сессий (викторины, командные игры, голосования, карьерный маршрут)
  - Выбранные профессии и отрасли

- **ПрофСтарт:**
  - Результаты тестирования
  - Профессиональный портрет и ведущие направления

- **Обратная связь:**
  - Ответы на анкеты (привязка к профилю авторизованного пользователя)

- **Система администрирования (CMS):**
  - Справочник профессий, отраслей и направлений
  - Справочник учебных заведений
  - Справочник работодателей
  - Список активностей центра
  - Версии согласий на обработку персональных данных

- **Идентификация и регистрация:**
  - Аутентификация пользователей (OAuth 2.0)
  - Данные профиля из OAuth-провайдера

### Отправляет данные

- **Аналитика:**
  - События взаимодействия с личным кабинетом (просмотры, переходы)

---

## Ограничения и безопасность

- Данные несовершеннолетних хранятся с минимизацией
- Результаты носят информационно-рекомендательный характер
- Пароли не хранятся (аутентификация через OAuth-провайдеров)
- Автоматический выход при бездействии на публичных устройствах
- Согласия версионируются, каждая версия фиксируется с датой принятия
