# Дашборд профиля

Главная страница личного кабинета. Сводный профессиональный портрет пользователя, визуализация компетенций и общий прогресс прохождения активностей.

---

## Назначение

Дать пользователю единую картину: кто он с профессиональной точки зрения, какие у него сильные стороны, какой прогресс в прохождении активностей центра.

---

## Содержание

### Профессиональный портрет

Для ПрофСтарт показываются отдельные результаты трёх методик:

- **Соломин** — семь групп на независимых осях «Хочу» и «Могу»; отдельно предмет и характер труда.
- **Голланд** — шесть типов RIASEC и все ведущие группы при равенстве.
- **Геометрический тест** — выбранная фигура и пояснение сокращённого сценария.
- **Профессии** — сохранённые рекомендации и связанные группы.

Источник — [история пользователя в API ПрофСтарт](../../api/profstart.md). Показываются название/версия и дата каждой попытки; разные тесты не складываются в общий балл. Группы ПрофСтарт не заменяют восемь `Direction`. Общая модель объединения с LED-активностями требует отдельного описания.

### Компетенции

!!! danger "Модель оценки не определена"
    Механика расчёта и визуализации компетенций **требует доработки**.

ПрофСтарт не рассчитывает компетенции по текущей модели: его данные — предпочтения и самооценка, не измерение навыков. Для общей визуализации компетенций рассматриваются другие источники:

- Выбранные профессии в сценариях LED-платформы
- Результаты командных игр

### Прогресс

Общая статистика прохождения активностей:

- Сколько активностей пройдено из общего количества доступных
- Дата последнего взаимодействия
- Краткая сводка по каждому типу активности

→ [Подробное описание каталога активностей](activities.md)

## Для гостей

Неавторизованный пользователь видит дашборд с ограниченным набором данных — только результаты текущей гостевой сессии. На каждой странице отображается предложение пройти авторизацию для сохранения результатов и доступа к полному профилю.
