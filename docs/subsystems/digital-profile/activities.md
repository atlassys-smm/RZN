# Каталог активностей

Полный список активностей, доступных в центре занятости, с отметками о прохождении. Мотивирует пользователя попробовать все доступные активности.

---

## Список активностей

| Активность | Описание |
|------------|----------|
| **LED-викторина** | Индивидуальная викторина на большом LED-экране |
| **Командная игра** | Командная профориентационная игра на LED-экране |
| **ПрофСтарт** | Индивидуальный профориентационный тест на сенсорной панели или в веб-версии |
| **Мой карьерный маршрут** | Последовательный выбор интересов и типов деятельности на LED-экране |
| **Видеорезюме** | Просмотр видеороликов «Профессии в действии» |
| **Обратная связь** | Заполнение анкеты оценки качества |

---

## Статусы активности

Для каждой активности отображается статус:

| Статус | Описание |
|--------|----------|
| **Не пройдено** | Пользователь ещё не взаимодействовал с активностью |
| **Частично** | Пользователь начал, но не завершил (например, прерванная сессия) |
| **Пройдено** | Активность завершена, результат сохранён в профиле |

---

## Детали прохождения

При нажатии на пройденную активность пользователь видит детали:

- Дата и время прохождения
- Тип активности (викторина, командная игра, тест и т.д.)
- Результат (баллы, выбранные профессии, направления)
- Связанные профессии и отрасли

---

## Источники данных

Статусы и результаты поступают из подсистем:

- **LED-медиаплатформа** — викторина, командная игра, карьерный маршрут, видеорезюме
- **ПрофСтарт** — результаты тестирования
- **Обратная связь** — факт прохождения анкеты
