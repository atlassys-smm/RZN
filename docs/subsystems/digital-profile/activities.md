# Каталог активностей

Полный список активностей, доступных в центре занятости, с отметками о прохождении. Мотивирует пользователя попробовать все доступные активности.

---

## Список активностей

| Активность | Описание | Программный комплекс |
|------------|----------|---------------------|
| **LED-викторина** | Индивидуальная викторина на большом LED-экране | `led_platform` |
| **Командная игра** | Командная профориентационная игра на LED-экране | `led_platform` |
| **ПрофСтарт** | Индивидуальный профориентационный тест на сенсорной панели или в веб-версии | `profstart` |
| **Мой карьерный маршрут** | Последовательный выбор интересов и типов деятельности на LED-экране | `led_platform` |
| **Аватар профессий** | Генерация фото в образах профессий | `profession_avatar` |
| **Видео-окна** | Просмотр видеороликов о профессиях | `video_windows` |
| **Видео-резюме** | Запись видео-резюме | `video_resume` |
| **Древо профессий** | Интерактивное дерево профессий | `tree_of_professions` |
| **Интерактивная карта региона** | Карта региона с работодателями и учебными заведениями | `regional_map` |
| **Профбаттл** | Профессиональные баттлы | `profbattle` |
| **Обратная связь** | Заполнение анкеты оценки качества | `feedback` |

→ Коды программных комплексов — в [справочнике источников событий](../../references/event-sources.md)

---

## Статусы активности

Для каждой активности отображается статус:

| Статус | Описание |
|--------|----------|
| **Не пройдено** | Пользователь ещё не взаимодействовал с активностью |
| **Частично** | Пользователь начал, но не завершил (например, прерванная сессия) |
| **Пройдено** | Активность завершена, результат сохранён в профиле |

---

## Детали прохождения

При нажатии на пройденную активность пользователь видит детали:

- Дата и время прохождения
- Тип активности (викторина, командная игра, тест и т.д.)
- Результат (баллы, выбранные профессии, направления)
- Связанные профессии и отрасли
