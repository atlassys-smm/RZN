# Дашборды административного портала

Дашборды доступны администратору в веб-интерфейсе системы администрирования (CMS).

---

## Структура дашбордов

### 1. Главный Dashboard

Общая аналитика по всему ЦЗН.

→ [Подробнее](dashboards/general.md)

**Краткое содержание:**
- Количество посетителей (сегодня, неделя, месяц)
- Вовлечённость и среднее время взаимодействия
- Востребованность профессий, направлений, работодателей, учебных заведений
- Тепловая диаграмма посещаемости

---

### 2. Сводная аналитика по ПАК

Сравнительная аналитика по всем ПАК.

→ [Подробнее](dashboards/paks-summary.md)

**Краткое содержание:**
- Количество взаимодействий по каждому ПАК
- Среднее время взаимодействия
- % достижения целей (завершённость сценариев)
- Воронка взаимодействия
- Сравнение эффективности ПАК

---

### 3. Детальная аналитика по каждому ПАК

Детальные страницы для каждого ПАК с аналитикой по контенту.

→ [Подробнее](dashboards/pak-detail.md)

**ПАК:**
- LED-медиаплатформа
- ПрофСтарт
- Аватар профессий
- Древо профессий
- Интерактивная карта региона
- Профбаттл
- Обратная связь

---

### 4. Аналитика по посетителям

Список посетителей с фильтрами и показателями, возможность открыть профиль.

→ [Подробнее](dashboards/visitors.md)

**Краткое содержание:**
- Список посетителей (авторизованные и гости)
- Фильтры по дате, ПАК, интересам
- Показатели: количество визитов, время взаимодействия, выбранные профессии
- Переход к цифровому профилю пользователя

---

## Общие требования к дашбордам

### Производительность

| Параметр | Значение |
|----------|----------|
| Отображение в дашборде | не позднее 60 секунд после события |
| Дашборд за 12 месяцев | не более 5 секунд загрузки |

### Обновление данных

- Данные отображаются в дашборде не позднее 60 секунд после события
- Агрегаты пересчитываются автоматически

### Выгрузка

- Все дашборды поддерживают выгрузку в CSV, XLSX, PDF
- PDF включает графики и текстовые выводы
