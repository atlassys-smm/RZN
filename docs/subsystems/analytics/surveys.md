# Аналитика анкет

Аналитика по заполненным анкетам обратной связи.

---

## Дашборд

Обзорная страница с ключевыми показателями:

- **Количество прохождений** — всего и по периодам
- **Средние оценки** — по вопросам типа `rating_scale` (для каждой анкеты)
- **Коэффициент завершения** — сколько начатых анкет завершено
- **Разбивка по точкам сбора** — XML_ID устройств

---

## Детализация по анкетам

Для каждой анкеты (`survey_id`):

- Количество прохождений
- Средние оценки по вопросам типа `rating_scale`
- Распределение ответов на каждый вопрос
- **Список ответов** — таблица всех `SurveyResponse` с возможностью просмотра деталей:
  - Дата и время прохождения
  - Источник (XML_ID устройства)
  - Пользователь или гость
  - Ответы на каждый вопрос
  - Контактные данные (если есть)
- Комментарии и пожелания (текстовые ответы)
- Контактные заявки (если есть)

---

## Фильтры

- **Период** — дата начала и окончания
- **Анкета** — конкретная анкета или все
- **Точка сбора** — конкретный XML_ID устройства

---

## Связь с общей аналитикой

Данные анкет передаются в общую аналитику платформы в виде событий:

- **Начало заполнения анкеты** — событие `survey_started`
- **Успешное заполнение** — событие `survey_completed`
- **Выбранные профессии** — событие `professions_selected` (список выбранных профессий)

Эти события используются в дашбордах и отчётах общей аналитики.
