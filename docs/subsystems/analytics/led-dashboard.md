# Публичный аналитический режим LED

!!! info "Статус реализации"
    Ниже описан целевой публичный LED-режим; управление слайдами и его интерфейс
    ещё не подключены. Доступные карточки исходных показателей собраны в Metabase
    в коллекции «Для заставки». Соответствие показателей и ограничения приведены ниже.

Вывод агрегированных показателей на LED-экран для посетителей.

---

## Назначение

Демонстрация ключевых показателей платформы на большом LED-экране в режиме реального времени. Используется для привлечения внимания посетителей, показа активности и популярности контента.

---

## Принципы

- **Без служебной информации** — только показатели для посетителей
- **Без персональных данных** — обезличенная статистика
- **Обновление в реальном времени** или по расписанию
- **Крупные элементы** — читаемость с расстояния
- **Привлекательный дизайн** — соответствие брендбуку

---

## Показатели

### Общая активность

- "Сегодня посетили **X** человек"
- "За месяц посетили **Y** человек"
- "Среднее время взаимодействия — **Z** минут"
- Для X человек подобраны профессии
- Топ набранных баллов

### Популярные профессии

- "Самая популярная профессия — **Название**"
- Топ-5 профессий с диаграммой
- Динамика популярности (график)

### Удовлетворённость

- "Средний рейтинг удовлетворённости — **X** из 5"
- Количество оставленных отзывов

### Рекомендации

- "Попробуйте пройти тест «ПрофСтарт»"
- "Узнайте больше о профессии **Название**"

## Показатели в Metabase

Для просмотра исходных показателей этой страницы откройте
**Аналитика / Для заставки / Показатели для заставки**.
Постоянный ключ коллекции и дашборда — `led.showcase`.

| Показатель LED | Существующая карточка | Постоянный ключ |
|---|---|---|
| Сегодня посетили X человек | Количество посетителей за период | `main.attendance.visitors` |
| За месяц посетили Y человек | Та же карточка с выбранным периодом месяца | `main.attendance.visitors` |
| Среднее время взаимодействия | Среднее время взаимодействия | `main.engagement.average_minutes` |
| Для X человек подобраны профессии | Для X человек подобраны профессии | `main.engagement.profession_people` |
| Топ набранных баллов | Топ-5 личных результатов викторины | `quiz.individual.top_scores` |
| Самая популярная профессия | Первая строка рейтинга профессий | `main.professions.professions_ranking` |
| Топ-5 профессий | Первые пять строк существующей таблицы топ-10 | `main.professions.professions_ranking` |
| Динамика популярности профессий | Динамика интереса к профессиям | `main.professions.professions_dynamics` |
| Средний рейтинг удовлетворённости | Средняя оценка, % шкалы | `main.feedback.average_score` |
| Количество оставленных отзывов | Количество заполненных анкет | `main.feedback.responses` |

Переиспользованы восемь сохранённых карточек. У посетителей одна карточка:
для показателя «сегодня» установите начало и конец периода в текущую дату,
для показателя «за месяц» — нужные даты месяца. Эти два значения не выводятся
одновременно отдельными карточками. Фильтры `date_from` и `date_to` общие,
конец периода включителен. Для остальных карточек без явных дат берутся
последние 30 календарных дней, включая текущий, в `Europe/Moscow`;
для топа личных баллов — вчерашний день.

Карточка посетителей считает уникальные user_id с цифровой активностью,
а не физические посещения. Среднее время считается по завершённым сессиям
с известной длительностью. Подобранные профессии — уникальные пользователи
с событиями PROFESSION_RECOMMENDED. Популярность профессий здесь определяется
просмотрами по пользовательскому JWT; исходная карточка рейтинга остаётся
таблицей топ-10, а динамика — линиями фиксированного топ-5 за период.
Отдельная LED-диаграмма топ-5 относится к реализации интерфейса заставки.

Текущая оценка удовлетворённости нормирована в проценты шкалы; отдельный
рейтинг «из 5» ещё не рассчитан. Количество анкет означает число завершённых
анкет обратной связи, а не число текстовых комментариев.

Топ баллов использует results[].total_score из завершений индивидуальных
викторин: лучший результат каждого пользователя за период, затем топ-5.
При равенстве баллов выше результат с более ранним завершением. Подписи участников
обезличены по позиции. Старые окончания без results исключены, явный ноль
учитывается. Период определяется датой завершения; без явных дат берётся полный вчерашний
день по Europe/Moscow. Командные игры не входят.
[Контракт результатов и топа](../../entities/analytics.md#итоговые-баллы-индивидуальной-викторины).

Призывы «Попробуйте пройти тест „ПрофСтарт“» и «Узнайте больше о профессии»
остаются текстовым контентом LED-интерфейса; отдельные графики для них не нужны.

## Получение списка заставок LED

В API-документации откройте раздел **Заставки LED - CMS**, запрос **Список заставок LED**:
`GET /api/cms/led/screensavers?limit=20&offset=0`. Ответ содержит
`items` и `total`: у каждой заставки есть `id`, `name` и объект `file` с полями
`url`, `preview_url`, `mime_type`, `title`, `description`. Для показа используется
`file.url`, для превью — `file.preview_url`. 
[Подробный контракт заставок](../../entities/led-screensaver.md).

## Дизайн

### Требования

- Контрастность текста и элементов
- Информация не передаётся исключительно цветом
- Крупные шрифты (читаемость с расстояния)
- Анимации без чрезмерного мерцания
- Соответствие единому визуальному стилю по брендбуку

---

## Управление

### Настройки

- Включение/выключение публичного режима
- Интервал обновления данных (по умолчанию 5 минут)
- Длительность показа каждого слайда (по умолчанию 10 секунд)
- Выбор набора показателей для показа
- Расписание работы (например, только в рабочие часы)

### Доступ

- Настройка через административный портал (CMS)
- Ручное управление через панель оператора

---

## Производительность

| Параметр | Значение |
|----------|----------|
| Обновление данных | не позднее 60 секунд |
| Переключение слайдов | без задержек, плавно |
| Влияние на основной сценарий | отсутствует (изолированный режим) |

---

## Взаимодействие

- **Получает данные** из подсистемы Аналитики (агрегированные показатели)
- **Управляется** через панель оператора и административный портал
- **Не влияет** на работу основных сценариев LED-платформы
