# Главный Dashboard

Общая аналитика по всему Центру занятости населения.

---

## Назначение

Дать администратору общую картину посещаемости, вовлечённости и популярности контента по всему ЦЗН.

---

## Показатели

### Посещаемость

- **Количество посетителей** за период (сегодня, неделя, месяц, произвольный диапазон)
  - Всего посетителей — карточка с числом
  - Уникальные пользователи (авторизованные) — карточка с числом
  - Уникальные гости (неавторизованные) — карточка с числом
  - Новые vs повторные визиты — карточки с числами
  - **Динамика посещаемости** — линейный график по дням/неделям (общая тенденция: сколько посетителей за период)

### Вовлечённость

- **Среднее время взаимодействия** с платформой (общее по ЦЗН) — карточка с числом в минутах + сравнение с предыдущим периодом
- **Доля завершённых сессий** vs прерванных (общая по ЦЗН) — круговая диаграмма или карточка с процентом и прогресс-баром
- **Среднее количество действий** на одного посетителя — карточка с числом

### Востребованность профессий

- **Рейтинг профессий** по выбору пользователей (топ-10) — таблица с сортировкой (название, количество выборов)
- **Рейтинг отраслей** по интересам (топ-10) — таблица с сортировкой (название, количество интересов)
- **Рейтинг направлений** по интересам (топ-10) — таблица с сортировкой (название, количество интересов)
- **Динамика интереса к профессиям** — линейный график изменения популярности топ-5 профессий по времени (сколько раз выбирали/просматривали каждую профессию за период)

### Востребованность работодателей и учебных заведений

- **Рейтинг работодателей** по просмотрам (топ-10) — таблица с сортировкой (название, количество просмотров)
- **Рейтинг учебных заведений** по интересам (топ-10) — таблица с сортировкой (название, количество интересов)
- **Динамика интереса к работодателям** — линейный график изменения популярности топ-5 работодателей по времени (количество событий `employer_viewed` за период)
- **Динамика интереса к учебным заведениям** — линейный график изменения популярности топ-5 учебных заведений по времени (количество событий `educational_institution_viewed` за период)

### Тепловая диаграмма посещаемости

- **Активность по времени суток** — тепловая карта (часы × дни недели): когда именно активны посетители (утро/день/вечер, будни/выходные)
- **Пиковые нагрузки** — часы с максимальной активностью (подсветка на тепловой карте)

---

## Фильтры

- **Период:** сегодня, неделя, месяц, произвольный диапазон
- **ПАК:** все или конкретный
