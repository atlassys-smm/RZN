# Аналитика по посетителям

Список посетителей с фильтрами и показателями, возможность открыть цифровой профиль.

---

## Назначение

Просмотр списка всех посетителей платформы (авторизованных пользователей и гостей), анализ их активности и переход к цифровому профилю для детального ознакомления.

---

## Список посетителей

### Таблица

| Колонка | Описание | Визуализация |
|---------|----------|--------------|
| **ID** | Уникальный идентификатор (user_id или guest_id) | Текст |
| **Тип** | Пользователь / Гость | Бейдж (цветной) |
| **Имя** | Имя пользователя (для гостей — "Гость") | Текст |
| **Первый визит** | Дата и время первого взаимодействия | Дата |
| **Последний визит** | Дата и время последнего взаимодействия | Дата |
| **Количество визитов** | Общее количество визитов | Число |
| **Общее время** | Суммарное время взаимодействия | Число в минутах |
| **ПАК** | Список ПАК, с которыми взаимодействовал | Теги (цветные бейджи) |
| **Интересы** | Основные профессии/направления, которые интересовали | Теги |

Таблица с сортировкой по колонкам.

### Действия

- **Открыть профиль** — переход к цифровому профилю пользователя (для авторизованных)
- **Подробнее** — детальный просмотр активности посетителя

---

## Фильтры

- **Тип:** все, авторизованные, гости
- **Период первого визита:** сегодня, неделя, месяц, произвольный диапазон
- **Период последнего визита:** сегодня, неделя, месяц, произвольный диапазон
- **Количество визитов:** минимальное/максимальное
- **ПАК:** конкретный ПАК или все
- **Интересы:** профессия, отрасль, направление

### Поиск

- Поиск по имени пользователя (для авторизованных)
- Поиск по ID (user_id или guest_id)

---

## Сортировка

- По дате первого визита (новые/старые)
- По дате последнего визита (активные/неактивные)
- По количеству визитов (больше/меньше)
- По общему времени взаимодействия (больше/меньше)

---

## Детальный просмотр посетителя

При клике на "Подробнее" открывается страница с детальной активностью посетителя:

### История взаимодействий

- **Список всех сессий** с датами и временем — список с датами
- Для каждой сессии:
  - ПАК, с которым взаимодействовал — бейдж
  - Длительность сессии — число в минутах
  - Основные действия (выбранные профессии, просмотренные видео, результаты тестов) — список

### Статистика

- **Общее количество визитов** — карточка с числом
- **Общее время взаимодействия** — карточка с числом в минутах
- **Количество взаимодействий** по каждому ПАК — мини-столбчатая диаграмма
- **Топ-5 профессий**, которые интересовали — горизонтальная столбчатая диаграмма
- **Топ-3 направления** — список с процентами
- **Рекомендуемые профессии** (по результатам тестов) — список

### Временная шкала

- **Визуальная временная шкала** всех взаимодействий — таймлайн (горизонтальная шкала с точками)
- Возможность фильтровать по ПАК и периоду

---

## Переход к цифровому профилю

Для авторизованных пользователей:
- Кнопка "Открыть профиль"
- Переход к полному цифровому профилю в личном кабинете
- Просмотр всей истории, результатов тестов, рекомендаций, карьерного маршрута

Для гостей:
- Профиль недоступен (нет учётной записи)
- Можно просмотреть только активность в рамках данной страницы

---

## Производительность

| Параметр | Значение |
|----------|----------|
| Загрузка списка (100 записей) | не более 2 секунд |
| Применение фильтра | не более 1 секунды |
| Открытие детального просмотра | не более 2 секунд |
