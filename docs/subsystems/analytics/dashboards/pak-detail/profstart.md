# Аналитика ПрофСтарт

Прохождения и результаты анализируются отдельно по типу и версии. [API](../../../../api/profstart.md).

## Данные

- /analytics/profstart/sessions — сессии, статус, число ответов, длительность завершённых.
- /analytics/profstart/results — окончательные результаты с фильтрами теста, пользователя, возраста и периода.
- /analytics/profstart/results/{result_id} — показатели групп и сохранённые профессии.
- /analytics/profstart/summary — агрегаты одного обязательного типа и версии.

Доступ требует права аналитики. Списки содержат внутренний user_id без имён/контактов; агрегаты не содержат участников и исходных ответов. Интерфейс и источник прохождения не сохраняются и не фильтруются.

## Сессии и группы

Начатые, completed, abandoned, уникальные пользователи, процент завершения, средняя длительность completed. Отдельной даты прерывания нет. Повтор — новая сессия, но не новый уникальный пользователь.

Период summary выбирает когорту по started_at; показатели результатов — только completed этой когорты. Соломин: want/can и subject/labor раздельно. Голланд: шесть RIASEC-групп. Деллингер: частоты выбора пяти фигур.

Нули входят в среднее, все равные ведущие учитываются; сумма долей ведущих может превышать 100%. Знаменатель — число результатов версии. Разные методики не складываются в общий балл.

## Профессии

Частота профессии — число результатов с ней, не количество совпавших групп. Средний score считается только по результатам, где она рекомендована. Пустой список допустим; отдельные признаки качества не сохраняются и не агрегируются.

У ответов нет правильности. Просмотр профессии требует отдельного события и не выводится из рекомендации.

Каталог типов расширяем, но окончательные результаты и групповые агрегаты пока поддерживаются только для solomin, holland, dellinger. Запрос summary нового типа без алгоритма — 422 unsupported_test_type. Сохранённая история архивных версий остаётся доступной.

Summary доступен для active/archived; draft — 409 test_not_published. Доля рекомендации профессии рассчитывается от всех результатов когорты, средний score — только от результатов с этой профессией. В агрегатах используется текущее название Profession, в деталях результата — сохранённое название.
