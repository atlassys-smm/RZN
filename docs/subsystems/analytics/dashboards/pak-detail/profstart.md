# Аналитика ПрофСтарт

Прохождения и результаты анализируются отдельно по типу и версии. [API](../../../../api/profstart.md).

## Статус

API аналитики ПрофСтарт пока отложен и не включён в текущий контракт OpenAPI. Ниже сохранены требования к будущим показателям; отдельные запросы и фильтры будут описаны при реализации аналитики.

## Сессии и группы

Начатые, completed, abandoned, уникальные пользователи, процент завершения, средняя длительность completed. Отдельной даты прерывания нет. Повтор — новая сессия, но не новый уникальный пользователь.

Период будущей аналитики выбирает когорту по started_at; показатели результатов — только completed этой когорты. Соломин: семь общих показателей want + can; категории subject/labor рассматриваются отдельно. Голланд: шесть RIASEC-групп. Деллингер: частоты выбора пяти фигур.

Нули входят в среднее, все равные ведущие учитываются; сумма долей ведущих может превышать 100%. Знаменатель — число результатов версии. Исходные показатели групп разных методик сравниваются отдельно. Общий рейтинг профессий использует нормированные баллы рекомендаций и настраиваемые веса типов 40/40/20; [правила подбора](../../../profstart/results.md#общий-подбор-по-трём-тестам).

## Профессии

Частота профессии — число результатов с ней, не количество совпавших групп. Средний score считается только по результатам, где она рекомендована. Пустой список допустим; отдельные признаки качества не сохраняются и не агрегируются.

У ответов нет правильности. Просмотр профессии требует отдельного события и не выводится из рекомендации.

Каталог типов расширяем, но окончательные результаты и групповые агрегаты пока поддерживаются только для solomin, holland, dellinger. Сохранённая история архивных версий остаётся доступной.

Будущая аналитика использует опубликованные active/archived-версии. Доля рекомендации профессии рассчитывается от всех результатов когорты, средний score — только от результатов с этой профессией. В агрегатах используется текущее название Profession, в деталях результата — сохранённое название.
