## Заставка (режим ожидания)

- **% времени в режиме заставки** — карточка с процентом (относительно общего времени работы)

### «Профессии в действии» (в режиме заставки)

- **Количество запусков профессий** — карточка с числом (сколько профессий запускалось всего)
- **Количество участников голосования** — карточка с числом + линейный график по времени (сколько человек участвовало в голосовании)
- **Популярные вакансии для голосования** — таблица с сортировкой (название профессии, количество участников голосования)

---

## Индивидуальная викторина

- **Количество запусков** — карточка с числом + столбчатая диаграмма по дням
- **Доля завершённых** — прогресс-бар
- **% правильных ответов** — карточка с процентом
- **Среднее количество участников** — карточка с числом

---

## Командная игра

- **Количество командных сессий** — карточка с числом + столбчатая диаграмма по дням (динамика)
- **Среднее количество команд** в сессии — карточка с числом + линейный график по времени (как менялось)
- **Среднее количество человек в команде** — карточка с числом + линейный график по времени
- **Среднее время игры** — карточка с числом в минутах + линейный график по времени
- **Распределение количества команд в сессии** — гистограмма (сколько сессий было с 2, 3, 4... командами)
- **Распределение количества человек в команде** — гистограмма (как распределялись размеры команд)
- **Распределение времени игры** — гистограмма (сколько сессий длилось 10-20 мин, 20-30 мин и т.д.)
