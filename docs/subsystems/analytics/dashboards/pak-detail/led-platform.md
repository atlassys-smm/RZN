## Общие показатели

Дашборд `led.common` охватывает индивидуальную и командную викторины:
`software_id=1`, `module_id IN (1, 2)`. Заставка и другие сценарии пока не подключены.
Одна реально начатая игра означает одно взаимодействие независимо от числа
участников. Одинаковые `session_id` разных режимов — разные игры.

| Показатель | Расчёт | Ключ |
|---|---|---|
| Количество сессий/взаимодействий | Реальные старты по `pak_sessions` | `led.common.sessions` |
| Сессии по дням | Те же старты, сгруппированные по московской дате | `led.common.sessions_daily` |
| Среднее время | Средний `duration_ms / 60000` завершённых игр с известным временем, включая паузы; сравнение с предыдущим периодом той же длины | `led.common.average_minutes` |
| Доля завершённых | Игры с окончанием / все стартовавшие × 100% | `led.common.completion_percent` |
| Уникальные пользователи | Различные известные `user_id` по `visitor_activity` за период, включая участников снимка старта общей игры | `led.common.users` |

Сессии, динамика, длительность, завершённость и таблица игр за выбранный период
отбираются по старту. Таблица выводит игры без SQL-лимита количества строк,
с сортировкой от новых к старым; ключ `quiz.recent_sessions` сохранён. Окончание может быть позже периода; пропущенные вопросы
не мешают игре считаться завершённой. Без старта окончание не увеличивает
счётчик; без окончания игра остаётся незавершённой. У каждой игры равный вес
в среднем времени; неизвестные длительности исключены только из среднего.
Без стартов счётчик равен 0, динамика пуста, доля завершённых — NULL.
Без текущих известных длительностей карточка времени пуста и не подставляет
прошлое значение; без предыдущего значения сравнение не вычисляется.

Уникальные пользователи отбираются по времени действия, независимо от старта
сессии. Поэтому активность продолженной игры или регистрация без старта может
дать пользователя без новой сессии в периоде. Один `user_id` учитывается один раз
между режимами; неизвестный `is_guest` не исключает его. Это цифровая активность:
разные гостевые аккаунты одного человека не объединяются, пользователи без
идентификации не учитываются. Без активности счётчик равен 0.

Фильтры — начало и конец периода включительно и ID устройства. По умолчанию
последние 30 календарных дней, `Europe/Moscow`; таблица использует те же границы.
Предыдущий период непосредственно предшествует выбранному и имеет столько же
календарных дней. Фильтр устройства исключает неизвестный `device_id`.
Пять новых SQL-вопросов поддерживают подписанное iframe-встраивание с
`locked`-параметрами; их ключи и ID доступны через справочник аналитики.
Повторы факта устраняются через `events_unique`; доставка best effort может
терять события и искажать показатели. История автоматически не восстанавливается.

Безопасная проверка: `docker compose exec api python infra/tests/led_feedback_queries.py`.
Обновление: `docker compose exec api python infra/metabase/scripts/deploy.py led.common --verify`.

## Заставка (режим ожидания)

- **% времени в режиме заставки** — карточка с процентом (относительно общего времени работы)

### «Профессии в действии» (в режиме заставки)

- **Количество запусков профессий** — карточка с числом (сколько профессий запускалось всего)
- **Количество участников голосования** — карточка с числом + линейный график по времени (сколько человек участвовало в голосовании)
- **Популярные вакансии для голосования** — таблица с сортировкой (название профессии, количество участников голосования)

---

## Индивидуальная викторина

- **Количество запусков** — карточка с числом + столбчатая диаграмма по дням
- **Доля завершённых** — прогресс-бар 0–100%: игры с окончанием / все начатые; без стартов — нет данных. Ключ `quiz.individual.completed`, формула и ID сохранены.
- **% правильных ответов** — карточка с процентом
- **Среднее количество участников** — карточка с числом

---

## Командная игра

- **Количество командных сессий** — карточка с числом + столбчатая диаграмма по дням (динамика)
- **Среднее количество команд** в сессии — карточка с числом + линейный график по времени (как менялось)
- **Среднее количество человек в команде** — карточка с числом + линейный график по времени
- **Среднее время игры** — карточка с числом в минутах + линейный график по времени
- **Распределение количества команд в сессии** — гистограмма (сколько сессий было с 2, 3, 4... командами)
- **Распределение количества человек в команде** — гистограмма (как распределялись размеры команд)
- **Распределение времени игры** — гистограмма с шагом 5 минут: 0–5, 5–10,
  10–15 минут и далее. Нижняя граница интервала включается, верхняя — нет;
  на оси X показана нижняя граница в минутах. Учитываются только завершённые
  командные игры с известной длительностью; период выбирается по старту игры.
