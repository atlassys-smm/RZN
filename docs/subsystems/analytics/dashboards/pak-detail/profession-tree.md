## Показатели

| Показатель | Расчёт |
|---|---|
| Количество сессий | Начатые сессии за период. Диаграмма группирует их по дням в часовом поясе Москвы |
| Среднее время | Средняя длительность начатых за период и завершённых сессий. Сравнение с предыдущим периодом той же длины |
| Доля завершённых | Доля начатых за период сессий с подтверждённым завершением. Сброс по тайм-ауту попадает в группу «Без подтверждения» |
| Количество уникальных пользователей | Разные известные `user_id` в событиях старта, открытия карточки или завершения за период |
| Открытые профессии | Число сессий с открытием и общее число открытий за период по `profession_id` |

## Данные

WebGL отправляет события старта (1), открытия карточки (11) и подтверждённого
завершения (4) модуля 7. UUID связывает события в `analytics.module_sessions`.
При открытии карточки API берёт название для `profession_code` из словаря
`app/services/analytics/tree_profession_names.json` и ищет по нему активную
профессию в PostgreSQL. При переименовании профессии обновите её название в
словаре. ClickHouse хранит исходный код, найденные `profession_id` и
`profession_name` в `payload`. Если для известного кода найдено ноль или
несколько активных профессий, API пишет предупреждение и сохраняет событие с
исходным кодом. В рейтинг входят события с найденным ID.
