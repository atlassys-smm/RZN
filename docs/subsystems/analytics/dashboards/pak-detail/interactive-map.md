## Показатели

| Показатель | Расчёт |
|---|---|
| Количество сессий | Сессии, начатые за период. Диаграмма показывает их по московским дням |
| Среднее время | Длительность завершённых сессий, начатых за период, в сравнении с предыдущим периодом той же длины |
| Доля завершённых | Доля сессий с подтверждённым завершением среди начатых за период |
| Уникальные пользователи | Разные известные `user_id` в событиях карты за период |
| Работодатели и учебные заведения | Открытия и число сессий с открытием по `organization_id` за период |
| Популярные города и округа | Число сессий с применением каждого фильтра территории за период |
| Распределение интереса по типам объектов | Доля открытий карточек каждой из категорий за период |

## События и сопоставления

Маршрут `POST /api/analytics/external/events` принимает модуль 8. Старт и
завершение имеют коды 1 и 4. Открытие карточки объекта имеет код 16, применение
фильтра территории — 17. Автоматический сброс сеанса считается сессией без
подтверждённого завершения. Сброс фильтра и повторный выбор уже применённой
территории не создают события выбора.

Числовые `object_category` и `territory_id` определены в
`app/services/analytics/enums.py`. Исходные коды Unity остаются в `payload`.
Поля `territory_id` относятся к справочнику территорий карты.

Для работодателей и учебных заведений API сопоставляет `object_code` с названием
в `app/services/analytics/region_map_catalog.json` и ищет активную организацию
того же типа в PostgreSQL. При одном совпадении сохраняет `organization_id`
и название. Открытия без совпадения учитываются в распределении по категориям.
Для рейтингов по организациям требуется найденный ID.
