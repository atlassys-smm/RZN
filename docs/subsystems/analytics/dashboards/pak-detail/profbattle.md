# Профбаттл

Профориентационный симулятор профессиональных решений. Пользователь проходит кейсы в роли специалиста и получает профиль из 10 компетенций.

→ [Подробное описание ПАК](../../../../external-paks/profbattle.md)

!!! danger "Требует отдельного разбора"
    Необходимо отдельно разобрать механику групповой игры и определения компетенций в групповой игре.

---

## По компетенциям

- **Профиль компетенций** — радарная диаграмма 10 компетенций (аналитическое мышление, логическое мышление, ответственность, принятие решений, коммуникация, командная работа, лидерство, внимание к деталям, системное мышление, ориентация на результат)
- **Средняя выраженность компетенций** — карточки с топ-3 компетенциями участников
- **Распределение по уровням** — гистограмма суммарной частоты компетенций

## По кейсам

- **Популярность кейсов** — таблица с сортировкой (кейс, количество прохождений)
- **Выборы в ситуациях** — для каждого кейса: какой вариант выбирали чаще (Ситуация 1 и Ситуация 2)
- **Связь кейсов и направлений** — какие кейсы чаще выбирают участники с ведущим направлением по ПрофСтарт

## По результатам

- **Среднее количество пройденных кейсов** — карточка с числом
- **Распределение по количеству кейсов** — гистограмма (сколько кейсов прошёл каждый участник)
- **Динамика интереса** — линейный график прохождений по времени

---

!!! note "Планируется при наличии технической возможности"

    ### Интеграция с платформой

    - **Код источника событий:** `profbattle`
    - **Тип устройства:** `battle_terminal`

    #### Передаваемые данные

    - Начало сессии
    - Выбор кейса
    - Вариант ответа в рамках кейса (для каждой из двух ситуаций)
    - Итоговый набор компетенций после кейса

    #### Идентификация пользователя

    Планируется идентификация через QR-код платформы.

    #### Хранение результатов

    - **Прохождения кейсов** — каждое прохождение отдельно (события: начало сессии, выбор кейса, варианты ответов)
    - **Карта компетенций** — агрегированный профиль по всем пройденным кейсам (суммарные частоты компетенций)

    #### Соответствие кейсов и направлений

    Жёсткое соответствие кейсов направлениям не требуется. Вместо этого для каждого кейса устанавливаются **веса отнесения** к профессиональным направлениям платформы.

    **Пример:** кейс «Юриспруденция» может иметь веса:
    - Социально-коммуникативное — 0.8
    - Организационно-предпринимательское — 0.2

    Это позволяет одному кейсу вносить вклад в несколько направлений с разной интенсивностью.

    !!! note "Открытый вопрос"
        Требуется определить веса отнесения для каждого из 6 кейсов к 8 направлениям платформы.
