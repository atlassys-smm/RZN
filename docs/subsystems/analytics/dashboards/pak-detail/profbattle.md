# Профбаттл

Профориентационный симулятор, в котором посетители проходят кейсы индивидуально или командой.
[Описание ПАК](../../../../external-paks/profbattle.md)

## Дашборд

Фильтры задают период по московскому времени, режим игры (`individual` или
`group`) и код кейса, например `it-school`. Все показатели периода используют
дату старта сессии.

| Показатель | Расчёт |
|---|---|
| Количество сессий | Сессии, начатые за период. Диаграмма группирует их по дням |
| Сессии по режимам | Число начатых индивидуальных и групповых сессий. Для режима без стартов отображается ноль |
| Среднее время | От старта до подтверждённого выхода из сессии. Среднее по завершённым сессиям сравнивается с предыдущим периодом той же длины |
| Доля завершённых | Доля начатых за период сессий с событием завершения |
| Количество уникальных пользователей | Разные известные `user_id` из событий этих сессий |

## События

Внешний API принимает события модуля 9. Сессия соответствует одному кейсу и
имеет общий UUID `session_id`. Записываются старт (1) и завершение сессии (4).
Старт происходит при открытии индивидуального кейса или после «Начать испытание»
в групповом режиме. `battle:finished` фиксирует подтверждённый выход из начатого
кейса, включая досрочный выход. При автоматическом сбросе событие завершения
не отправляется.

В обоих событиях передаются `case_code` из каталога Профбаттла и `mode`.
Представление `analytics.profbattle_sessions` берёт их из события старта.
Верхнее поле `user_id` заполняется, когда фронту известен пользователь.
В командном режиме счётчик показывает идентифицированных пользователей по событиям.
