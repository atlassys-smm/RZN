# Детальная аналитика по каждому ПАК

Детальные страницы для каждого ПАК с аналитикой по контенту и результатам.

---

## Общие показатели (для всех ПАК)

Эти показатели отображаются в верхней части страницы каждого ПАК:

- **Количество сессий/взаимодействий** — карточка с числом + столбчатая диаграмма по дням
- **Среднее время сессии/взаимодействия** — карточка с числом в минутах + сравнение с предыдущим периодом
- **Доля завершённых** сессий/взаимодействий — круговая диаграмма или прогресс-бар
- **Количество уникальных пользователей** — карточка с числом
