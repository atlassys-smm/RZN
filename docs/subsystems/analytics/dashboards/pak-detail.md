# Детальная аналитика по каждому ПАК

Детальные страницы для каждого ПАК с аналитикой по контенту и результатам.

---

## LED-медиаплатформа

### Общие показатели

- **Количество сессий** (запущенных сценариев) — карточка с числом + столбчатая диаграмма по дням
- **Количество уникальных участников** — карточка с числом
- **Доля завершённых vs прерванных сессий** — круговая диаграмма или прогресс-бар
- **Среднее время сессии** — карточка с числом в минутах + сравнение с предыдущим периодом

### По сценариям

- **Количество запусков** каждого сценария — горизонтальная столбчатая диаграмма
- **Доля завершённых сессий** по сценариям — таблица с прогресс-барами
- **Среднее время прохождения** сценария — таблица с числами

### По вопросам

- **Самые популярные вопросы** (по количеству ответов) — горизонтальная столбчатая диаграмма (топ-10)
- **Вопросы с высоким процентом ошибок** — таблица с сортировкой по % ошибок
- **Среднее время ответа** по вопросам — таблица с числами

### Командная игра

- **Количество командных сессий** — карточка с числом
- **Среднее количество команд** в сессии — карточка с числом
- **Среднее количество человек в команде** — карточка с числом
- **Средний счёт команд** — карточка с числом
- **Распределение баллов** по раундам — столбчатая диаграмма
- **Самые сложные раунды** (низкий процент правильных ответов) — таблица с сортировкой

### Видеосценарии (Профессии в действии)

- **Количество запусков** видеосценариев — карточка с числом
- **Среднее время просмотра** — карточка с числом в минутах
- **Доля завершённых** просмотров — прогресс-бар
- **Популярные точки выбора** — таблица (какие варианты чаще выбирали в каждой точке ветвления)

### Востребованность контента

- **Популярные карточки профессий** (просмотры, выборы) — таблица с сортировкой (название, просмотры, выборы)
- **Популярные видеоролики** (просмотры, длительность просмотра) — таблица с сортировкой (название, просмотры, среднее время просмотра)

## ПрофСтарт

### Общие показатели

- **Количество прохождений** теста — карточка с числом + столбчатая диаграмма по дням
- **Доля завершённых** тестов — круговая диаграмма или прогресс-бар
- **Среднее время прохождения** — карточка с числом в минутах
- **Среднее количество вопросов**, на которые ответили — карточка с числом

### По возрастным версиям

- **Количество прохождений** по каждой возрастной версии (12-14, 15-17) — столбчатая диаграмма
- **Сравнение результатов** по возрастным группам — таблица

### По направлениям

- **Распределение пользователей** по профессиональным направлениям (результаты теста) — горизонтальная столбчатая диаграмма
- **Самые популярные направления** — топ-3 с процентами
- **Динамика интереса** к направлениям — линейный график по времени

### По вопросам

- **Самые популярные вопросы** — горизонтальная столбчатая диаграмма
- **Вопросы с высоким процентом ошибок** или низкой завершённостью — таблица с сортировкой
- **Среднее время ответа** по вопросам — таблица

### По профессиям

- **Рекомендуемые профессии** (по результатам теста) — горизонтальная столбчатая диаграмма (топ-10)
- **Какие профессии выбирали** пользователи после просмотра рекомендаций — список

## Обратная связь

### Общие показатели

- **Количество заполненных анкет** — карточка с числом + столбчатая диаграмма по дням
- **Средний рейтинг удовлетворённости** — карточка с числом (X из 5) + звёздочки
- **Среднее время заполнения анкеты** — карточка с числом в секундах

### По вопросам

- **Распределение оценок** по каждому вопросу — столбчатая диаграмма по вариантам
- **Вопросы с низкими оценками** — таблица с сортировкой
- **Текстовые комментарии** — облако тегов или список

### По точкам сбора

- **Количество анкет** по каждой точке сбора — столбчатая диаграмма
- **Сравнение рейтингов** по точкам сбора — таблица с числами
