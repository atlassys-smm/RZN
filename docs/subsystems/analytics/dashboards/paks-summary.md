# Сводная аналитика по ПАК

!!! success "Проверенный контент"
    Эта страница проверена и актуальна.

Сравнительная аналитика по всем ПАК для оценки эффективности каждого.

---

## Назначение

Сравнить эффективность различных ПАК, понять, какие из них наиболее востребованы, где пользователи проводят больше времени, какие ПАК лучше достигают своих целей.

---

## Общие показатели (для всех ПАК)

Эти показатели отображаются в верхней части страницы:

- **Количество сессий** — карточка с числом
- **Среднее время сессии** — карточка с числом в минутах
- **Доля завершённых сессий** — карточка с процентом и прогресс-баром

---

## Показатели

### Сравнительные метрики по ПАК

- **Количество взаимодействий** по каждому ПАК — столбчатая диаграмма (сравнение)
- **Среднее время взаимодействия** по каждому ПАК — горизонтальная столбчатая диаграмма
- **% достижения целей** (доля пользователей, завершивших сценарий до конца) — прогресс-бары для каждого ПАК
- **Доля повторных визитов** к каждому ПАК — столбчатая диаграмма
