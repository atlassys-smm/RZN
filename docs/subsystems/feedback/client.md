# Клиентская часть

Описание клиентских интерфейсов для прохождения анкет обратной связи.

---

## ПАК

Полноэкранное приложение на сенсорной стойке или ПАК.

### Конфигурация

Анкета зашивается через переменную окружения при деплое терминала:

```bash
SURVEY_EXTERNAL_ID=videoresume_feedback
```

При запуске приложение:
1. Читает `SURVEY_EXTERNAL_ID` из env
2. Запрашивает у сервера активную анкету с таким `external_id`
3. Показывает форму прохождения

### UI/UX

- Один основной вопрос на экран
- Крупные сенсорные элементы
- Прогресс прохождения
- Возврат на предыдущий шаг
- Тайм-аут по умолчанию — **90 секунд**
- После завершения — подтверждение сохранения, очистка данных, возврат в режим ожидания

### Типы вопросов

- `rating_scale` — оценочная шкала (по умолчанию 1–5)
- `single_choice` — выбор одного варианта
- `multiple_choice` — выбор нескольких вариантов
- `text` — текстовое поле (для пожеланий, комментариев)
- `profession_choice` — выбор профессий из справочника

### Условные вопросы

Вопросы могут показываться при определённых условиях. Например:
- Если оценка удобства ≤ 2 → показать вопрос «Что именно неудобно?»
- Если указано затруднение → показать уточняющий вопрос

Условие хранится в поле `condition` (JSON) у `SurveyQuestion`.

## Личный кабинет / QR

Адаптивный веб-интерфейс, доступный:
- В личном кабинете авторизованного пользователя (кнопка «Оставить отзыв»)
- По QR-коду для гостей без авторизации

### QR-ссылка

QR-ссылка содержит JWT с зашитым `survey_id`:

```
https://platform.example.com/feedback?token=eyJzdXJ2ZXlfaWQiOiJ4eXoifQ...
```

**Срок жизни JWT** — защита от спама неавторизованных пользователей. Настраивается в CMS при генерации ссылки.

### Авторизация

- **Авторизованный пользователь** — видит кнопку «Оставить отзыв» в личном кабинете, ответы привязываются к профилю
- **Гость (по QR)** — проходит анкету без авторизации, может указать контактные данные с согласием на обработку ПДн

### UI/UX

Аналогично ПАК, но адаптировано для веб-интерфейса (десктоп + мобильный):
- Один вопрос на экран
- Прогресс прохождения
- Навигация «Назад» / «Далее»
- После завершения — подтверждение, очистка данных

## Маршрут прохождения

Типовой маршрут посетителя (настраивается в анкете):

1. Приглашение оценить сервис и отображение ориентировочного времени прохождения
2. Оценка удобства, понятности и полезности сервиса
3. Условные уточняющие вопросы при низкой оценке или указанном затруднении
4. Выбор интересующих профессий, отраслей или карьерных направлений (необязательно)
5. Необязательное пожелание или комментарий
6. Необязательная контактная заявка с отдельным согласием на обработку персональных данных
7. Подтверждение сохранения, очистка введённых данных и возврат в основное приложение либо режим ожидания

---

## Источник прохождения

Каждый ответ (`SurveyResponse`) хранит информацию об источнике:

| Поле | Описание |
|------|----------|
| `source_id` | XML_ID устройства (ПАК, веб) |

Это позволяет в аналитике видеть, откуда собраны данные (по конкретному устройству).

---

## Согласие на обработку ПДн

При отправке анкеты с контактными данными пользователь принимает согласие. В `SurveyResponse` сохраняется `consent_version_id` — идентификатор той версии согласия, которую показал пользователю.

→ [Сущность согласия](../../entities/consent.md)
