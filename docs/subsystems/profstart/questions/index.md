# Тесты и банк вопросов ПрофСтарт

Полный начальный состав трёх тестов для реализации и наполнения CMS: тексты инструкций, вопросы, варианты, порядок и ключ начисления баллов. Всего 58 вопросов и 263 варианта ответа. У каждого вопроса type=single_choice; пользователь выбирает ровно один вариант.

## Перенос в CMS

Для каждого существующего TestType группы создаются или используются повторно по test_code_type; все версии этого типа используют один набор group_id. Затем создаётся версия ProfStartTest. Поле name берётся из таблицы выше, instructions — из раздела «Инструкция для участника» соответствующего теста. Номер версии назначает сервер. Банк загружается в тест со status=1 (draft), возрастная доступность задаётся age_group_ids по правилам проекта. При отсутствии ограничений age_group_ids=[].

Порядок вопросов и вариантов задаётся полем order. В банке group_code обозначает группу; при наполнении используется её ID из справочника того же типа теста. CMS API принимает group_id и value.

Вопросы и варианты Соломина и Голланда не требуют файлов. У Деллингер файл прикрепляется к каждому из пяти вариантов; все PNG находятся рядом с описанием. Общего изображения вопроса нет. Загрузка выполняется через multipart/form-data, поле file.

Пользовательский интерфейс получает только вопрос, варианты и изображения. Группы, внутренние ключи и характеристики фигур до выбора не показываются. Связи с Profession задаются отдельно в CMS; этот банк не назначает фиктивные profession_id. После наполнения выполняются /validate и /publish с проверкой связей профессий и всех изображений.

## Результаты

У Соломина три ответа want и три can каждой группы суммируются: семь общих показателей 0–18. У Голланда каждый выбор даёт +1 своей RIASEC-группе; сумма шести показателей равна 15. У Деллингер выбранная фигура получает 1, остальные — 0. Влияние 40/40/20 задано в `app/models/user_recommendations/weights.py` независимо от балла отдельного ответа.
