# Анкета «Ориентация» И. Л. Соломина

Начальный банк сокращённой анкеты: 42 утверждения, по три на каждую из семи групп в каждом блоке. Объединение «Хочу» и «Могу» в итогах — согласованное правило ПрофСтарт.

## Инструкция для участника

Перед вами два блока утверждений. В блоке «Хочу» оцените, насколько вам интересна описанная деятельность. В блоке «Могу» оцените, насколько утверждение соответствует вашим нынешним умениям по опыту учёбы, повседневных дел или работы. Это самооценка: не нужно пытаться угадать желательный результат.

Для каждого утверждения выберите один ответ от 0 до 3. Ориентируйтесь на то, как вы чувствуете себя сейчас. Если не согласны, выбирайте 0 — это полноценный ответ. Ответьте на все 42 утверждения.

## Варианты каждого вопроса

| order варианта | text | value | weight |
|---|---|---|---|
| 1 | 0 — Не согласен | 0 | 0 |
| 2 | 1 — Скорее не согласен | 1 | 1 |
| 3 | 2 — Скорее согласен | 2 | 2 |
| 4 | 3 — Полностью согласен | 3 | 3 |

Каждый вопрос имеет четыре собственных варианта из этой таблицы. У всех четырёх group_id соответствует группе вопроса в ключе ниже; значение value равно weight. Варианты не ссылаются на другую группу. Файлов нет.

## Вопросы по группам

В каждой группе ниже три утверждения «Хочу» и три «Могу». Все вопросы имеют type=single_choice. В «Хочу» оценивается желание заниматься указанной деятельностью, в «Могу» — умение её выполнять.
