# Процесс прохождения теста

Описание сценариев прохождения профориентационного теста ПрофСтарт.

---

## Общие правила

- **Нельзя прервать:** тест проходится целиком за один раз
- **Длительность:** 7–12 минут (по ТЗ §2.2)
- **Прогресс:** отображается прогресс-бар на экране вопроса

---

## Сценарий 1: Терминал с авторизацией

1. Пользователь подходит к терминалу
2. На стартовом экране выбирает возрастную группу (инфографика)
3. Сканирует QR-код для авторизации
4. Проходит тест целиком
5. Видит результат на экране
6. Результат скрывается через заданное время или по кнопке
7. Результат сохраняется в профиле пользователя

---

## Сценарий 2: Терминал без авторизации (гость)

1. Пользователь подходит к терминалу
2. Выбирает возрастную группу
3. Нажимает "Пройти как гость"
4. Проходит тест целиком
5. Видит результат на экране
6. Результат скрывается через заданное время
7. Результат сохраняется обезличенно для аналитики

---

## Сценарий 3: Мобильное устройство (веб-версия)

1. Пользователь заходит в личный кабинет с телефона
2. Переходит в раздел "ПрофСтарт"
3. Выбирает возрастную группу
4. Проходит тест целиком
5. Результат сохраняется в личном кабинете
6. Можно посмотреть результат позже
