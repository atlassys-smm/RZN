# ПрофСтарт

Индивидуальный профориентационный тест школьника на сенсорной интерактивной панели и в веб-версии (личный кабинет). Собственный банк вопросов, генерация результатов тестирования.

!!! danger "Цифровой профориентационный портрет"
    Механика формирования цифрового профориентационного портрета **требует доработки**. Необходимо определить:

    - На основе каких данных формируется портрет
    - Какие данные хранятся в справочнике направлений
    - Как визуализировать результаты
    - Какие текстовые описания генерировать

    Текущее описание в ТЗ (§3.2.4) содержит общие требования, но конкретная методика расчёта и структура данных не определены.

---

## Назначение

ПрофСтарт предназначен для:

- Выявления профессиональных интересов школьников
- Формирования результатов тестирования
- Предоставления рекомендаций по профессиональным направлениям
- Интеграции результатов в цифровой профиль пользователя

## Интерфейсы

ПрофСтарт доступен в двух интерфейсах с единым визуальным стилем:

### 1. Киоск на сенсорной панели

Полноэкранное приложение на интерактивной панели в зоне ЦЗН.

**Особенности:**

- Крупные сенсорные элементы
- Авторизация по QR-коду или гостевой режим
- Результат показывается на экране и скрывается автоматически

→ [Экраны интерфейса](../../interfaces/profstart/index.md)

### 2. Веб-версия в личном кабинете

Адаптивный веб-интерфейс для прохождения теста с любого устройства.

**Особенности:**

- Авторизация через профиль пользователя
- Результат сохраняется в личном кабинете
- Можно пройти повторно

## Взаимодействие с другими подсистемами

### Получает данные

- **Система администрирования (CMS):**
  - Банк вопросов и вариантов ответов
  - Справочник профессиональных направлений
  - Настройки возрастных групп

- **Идентификация и регистрация:**
  - Авторизация пользователей (QR-код на терминале)
  - Профиль пользователя (в веб-версии)

### Отправляет данные

- **Цифровой профиль и личный кабинет:**
  - Результаты теста (для авторизованных пользователей)
  - История прохождений

- **Аналитика:**
  - События прохождения теста (начало, завершение, ответы)
  - Обезличенные результаты (для гостей)

---

## Ограничения и безопасность

- Не является медицинской или клинической диагностикой
- Базовый сценарий не требует ввода персональных данных
- Данные несовершеннолетних хранятся с минимизацией
- Результаты носят информационно-рекомендательный характер
