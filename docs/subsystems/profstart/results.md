# Результаты тестирования

Описание формирования и отображения результатов профориентационного теста ПрофСтарт.

!!! danger "Требуется доработка"
    Механика расчёта результатов и формирования портрета не определена. Необходимо разработать методику.

---

## Отображение результатов

### На терминале

- Результат показывается на экране после завершения теста
- Скрывается через заданное время или по кнопке завершения

### В личном кабинете

- Результат сохраняется в профиле авторизованного пользователя
- Доступен для повторного просмотра
- История прохождений

### Для гостей (обезличенно)

- Результат показывается на экране
- Сохраняется обезличенно для аналитики

!!! danger "Механика не определена"
    Необходимо определить:

    - Какие данные хранятся в справочнике направлений
    - Как визуализировать результаты
    - Какие текстовые описания генерировать

---

## Интеграция с цифровым профилем

- Результаты теста сохраняются в цифровом профиле пользователя
- Используются для формирования рекомендаций по профессиям, учебным заведениям и работодателям
- История прохождений доступна в личном кабинете
