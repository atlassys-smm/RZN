# Методики и группы результата

Состав заданий выбран по предоставленному документу «Тесты.docx»: шкала согласия для Соломина, выбор предпочтительного действия для Голланда, выбор изображения или карточки для геометрического теста. Документ содержит пять вопросов Голланда; банк дополнен до 15 вопросов занятиями из опубликованных инструментов RIASEC. Банк также содержит 42 утверждения Соломина и вопрос Деллингер с пятью подготовленными изображениями. Здесь описываются характеристики ответов и правила ключа.

## Анкета «Ориентация» И. Л. Соломина

В проекте используется сокращённая адаптация: два блока по 21 утверждению — «Хочу» (`want`) и «Могу» (`can`). В каждом блоке семь групп по три вопроса, всего 42 вопроса. Ответ 0, 1, 2 или 3 прибавляется к своей группе. В итоговом результате значения из «Хочу» и «Могу» суммируются: шесть ответов на группу дают один общий балл 0–18. В [исходной анкете](https://testoteka.narod.ru/prof/1/06.html) по пять утверждений на группу/блок; для сокращённого банка выбраны первые три пункта каждой группы в обоих блоках, переданные своими словами. Исходные границы интерпретации нельзя переносить на сокращённую шкалу без отдельного обоснования.

| Код группы | Название | Категория |
|---|---|---|
| `human_human` | Человек — человек | `subject` |
| `human_technology` | Человек — техника | `subject` |
| `human_sign` | Человек — знаковая система | `subject` |
| `human_art` | Человек — художественный образ | `subject` |
| `human_nature` | Человек — природа | `subject` |
| `executive` | Исполнительские | `labor` |
| `creative` | Творческие | `labor` |

Первые пять групп описывают предмет труда, две последние — характер труда. Общие показатели сравниваются отдельно внутри категорий subject и labor. Объединение «Хочу» и «Могу» — правило проекта; отдельные профили блоков и их расхождения в итогах не выводятся. [Исходная интерпретация анкеты](https://testoteka.narod.ru/prof/1/06.html).

В модели нужны семь TestGroup и семь показателей в JSON источника результата: один общий показатель на группу без axis. У вопроса фиксирован блок want/can; четыре варианта имеют value=0–3 и ссылку на одну группу. Нулевой вариант является ответом, а не пропуском.

## Тест на основе теории Дж. Голланда

RIASEC включает шесть типов профессиональных интересов. [Руководство O*NET](https://www.onetcenter.org/reports/IP_Manual.html) описывает эти шкалы; ситуационный формат проекта взят из «Тесты.docx» и не является стандартным O*NET Interest Profiler или SDS.

Дополнительные занятия взяты из [O*NET® Mini Interest Profiler, приложение A](https://www.onetcenter.org/dl_files/Mini-IP.pdf) и [O*NET® Interest Profiler Short Form](https://www.onetcenter.org/dl_tools/ipsf/Interest_Profiler.pdf), разработанных National Center for O*NET Development при поддержке USDOL/ETA. Материал адаптирован для выбора одного действия из шести по [O*NET Tools Developer License](https://www.onetcenter.org/license_tools.html); исходные инструменты оценивают интерес к каждому занятию отдельно. USDOL/ETA не проверяло эту адаптацию; её валидность до применения должна оцениваться отдельно.

| Код | Название | Буква в документе | Предпочтения |
|---|---|---|---|
| `R` | Реалистический | А | Практические действия, предметы, инструменты, техника |
| `I` | Исследовательский / интеллектуальный | Б | Анализ, исследование, поиск объяснений |
| `S` | Социальный | В | Помощь, обучение, взаимодействие с людьми |
| `E` | Предприимчивый | Г | Организация, влияние, переговоры, управление |
| `C` | Конвенциональный | Д | Данные, порядок, точность, правила |
| `A` | Артистический | Е | Создание образов, творчество, самовыражение |

Каждый вопрос имеет шесть действий, по одному на тип. Один выбранный вариант даёт +1 своей группе, `axis=general`. В тесте ровно 15 вопросов, диапазон каждой группы 0–15; сумма шести показателей полного прохождения равна 15. Ведущими считаются все максимумы.

Русская буква «А» в примере соответствует коду R, а не коду A. Ключ хранится через `group_id`, не вычисляется по букве или позиции. Сходство описаний с группами Соломина не делает шкалы взаимозаменяемыми: привязки профессий задаются отдельно.

Публикация требует ровно 15 вопросов. Тексты ситуаций, возрастная доступность и интерпретации относятся к версии адаптации проекта; нормативы других инструментов RIASEC на неё не переносятся автоматически.

## Геометрический тест Сьюзен Деллингер

Пять фигур описывают предпочтения в деятельности и общении. [Официальный PsychoGeometrics](https://psychogeometrics.com/about/overview/) использует отдельный современный опросник. Распространённая [инструкция профильного центра](https://pms-centr.spb.ru/materialy-spetsialistov/785-psikhogeometricheskij-test-s-dellinger) предлагает упорядочить пять фигур.

| Код | Фигура | Краткое описание |
|---|---|---|
| `square` | Квадрат | Последовательность, порядок, внимание к деталям |
| `triangle` | Треугольник | Цель, организация, руководство |
| `circle` | Круг | Общение, сотрудничество, поддержка |
| `zigzag` | Зигзаг | Идеи, творчество, новые решения |
| `rectangle` | Прямоугольник | Поиск, изменения, переходное состояние |

Описания — краткий пересказ характеристик фигур, не диагностика способностей. Прямоугольник в [описании методики профильного центра](https://pms-centr.spb.ru/materialy-spetsialistov/785-psikhogeometricheskij-test-s-dellinger) обозначает временное переходное состояние, а не устойчивую основную фигуру.

По «Тесты.docx» в проекте выбран сокращённый сценарий: один вопрос `single_choice`, пять карточек с изображениями, один выбор. Выбранная фигура получает +1, остальные 0; блок вопроса `general`. Показатель 100 означает факт выбора, не вероятность или силу свойства. +1 — кодирование проекта, не ключ официального опросника и не балльное ранжирование.

Для всех пяти групп профессии задаются экспертными связями CMS одинаковым способом. Прямоугольник описывается как переходное состояние; его подпись не утверждает устойчивую профессиональную пригодность. Если для выбранной группы профессии не связаны, список пуст. Обязательного соответствия фигур группам Соломина нет.

## Проверка публикации

| Тест | Группы и оси | Полный ключ |
|---|---|---|
| Соломин | 7 кодов выше, `want` и `can` | 42 вопроса; по 3 на группу/ось; 4 варианта с value=0, 1, 2, 3 |
| Голланд | 6 кодов RIASEC, `general` | 15 вопросов; 6 вариантов, по одному с value=null и баллом 1 на каждый тип |
| Деллингер | 5 фигур, `general` | 1 вопрос; 5 карточек с изображением и подписью, 1 балл своей фигуре |

Во всех тестах type=single_choice. Каждый вариант непосредственно содержит group_id и value. Балл выбранного ответа равен value, если значение задано, иначе 1; нулевое значение даёт 0 баллов; блок задаётся в вопросе. Ответы обоих блоков Соломина входят в один показатель группы, общий максимум — 18. Публикация запрещает неполный банк, чужую группу, неверную ось/тип или неполный ключ. Свободный текст, множественный выбор и ранжирование не нужны выбранным сценариям. У групп и вопросов нет собственных черновиков. Вопросы и варианты принадлежат версии и редактируются только при status=1 (draft). Группы и связи профессий принадлежат типу по test_code_type и общие для всех его версий; их подписи и связи профессий редактируются независимо от статуса версии. Поля order у групп нет. Основные группы поддерживаемых методик нельзя удалять или менять их code/category: 409; дополнительные коды или неверные категории отклоняются с 422. Дубликат кода внутри типа — 409. Для дополнительных типов категория по умолчанию general; её можно менять для новых результатов. Код группы, используемой вариантами или результатами, защищён от изменения: 409. Снимки категорий и рангов исторических результатов сохраняются.

Новые типы можно добавлять через CMS. Для них проверяются общие правила целостности (порядок, обязательные вопросы single_choice, варианты и принадлежность групп типу теста). Число групп и вопросов 7/6/5 и 42/15/1 применяется только к трём предзаданным кодам. Опубликованный новый тип можно пройти; для него суммируются баллы выбранных вариантов по заданным группам и рассчитываются нормированные показатели. Показатели групп и связанных профессий сохраняются в источнике. Для дополнительного типа профессия получает лучший нормированный балл своих групп; итоговый рейтинг учитывает источник только при положительном весе в SOURCE_WEIGHTS.

Полные тексты и ключи представлены в [банке вопросов](questions/index.md). Для Деллингер подготовлены пять PNG, которые при наполнении CMS загружаются как File и прикрепляются к вариантам. Результаты блоков Соломина суммируются по правилам проекта.
