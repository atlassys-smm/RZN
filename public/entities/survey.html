    Обратная связь¶

    Описание сущностей для модуля обратной связи и оценки качества.

    Survey (Шаблон анкеты)¶

    Шаблон анкеты для сбора обратной связи. Настраивается в CMS и используется в различных точках сбора.

    Атрибуты¶

    Поле Тип Описание
    id UUID Уникальный идентификатор шаблона
    name string Название анкеты (например, "Оценка видеорезюме", "Оценка мероприятия")
    description text, nullable Описание анкеты
    type enum Тип анкеты: basic (60-90 сек), full (до 2 мин)
    is_active boolean Активен ли шаблон
    created_at timestamp Дата создания
    updated_at timestamp Дата обновления

    Связи¶

    • Survey → SurveyQuestion: шаблон имеет множество вопросов
    • Survey → SurveyResponse: шаблон имеет множество ответов пользователей

    Где используется¶

    • CMS — создание и управление шаблонами анкет
    • Обратная связь — использование шаблонов в точках сбора
    • Личный кабинет — прохождение анкет пользователями

    SurveyQuestion (Вопрос анкеты)¶

    Вопрос в шаблоне анкеты обратной связи.

    Атрибуты¶

    Поле Тип Описание
    id UUID Уникальный идентификатор вопроса
    survey_id UUID ID шаблона анкеты
    type enum Тип вопроса: rating_scale, single_choice, multiple_choice, text, profession_choice
    text text Текст вопроса
    media_id UUID, nullable ID файла (изображение)
    required boolean Обязательный ли вопрос
    order integer Порядок отображения
    condition json, nullable Условие показа (например, "показать если ответ на вопрос 2 = 1-2")
    scale_min integer, nullable Минимальное значение шкалы (по умолчанию 1)
    scale_max integer, nullable Максимальное значение шкалы (по умолчанию 5)

    Связи¶

    • SurveyQuestion → Survey: вопрос принадлежит одному шаблону (survey_id)
    • SurveyQuestion → File: вопрос может иметь медиа-файл (media_id)
    • SurveyQuestion → SurveyAnswer: вопрос имеет множество ответов пользователей

    Где используется¶

    • CMS — создание вопросов для анкет
    • Обратная связь — показ вопросов в точках сбора

    SurveyResponse (Ответ на анкету)¶

    Факт прохождения анкеты пользователем или гостем. Содержит ответы на все вопросы анкеты.

    Атрибуты¶

    Поле Тип Описание
    id UUID Уникальный идентификатор ответа
    survey_id UUID ID шаблона анкеты
    user_id UUID, nullable ID пользователя (если авторизован)
    guest_id UUID, nullable ID гостевой сессии (если не авторизован)
    collection_point_id UUID, nullable ID точки сбора (если применимо)
    completed_at timestamp Дата и время завершения анкеты
    duration integer Время прохождения в секундах

    Связи¶

    • SurveyResponse → Survey: ответ относится к одному шаблону (survey_id)
    • SurveyResponse → User: ответ может быть привязан к пользователю (user_id)
    • SurveyResponse → GuestSession: ответ может быть привязан к гостевой сессии (guest_id)
    • SurveyResponse → SurveyAnswer: ответ имеет множество ответов на конкретные вопросы

    Где используется¶

    • Обратная связь — сохранение результатов анкет
    • Аналитика — анализ обратной связи
    • Цифровой профиль — привязка ответов к профилю пользователя

    SurveyAnswer (Ответ на вопрос анкеты)¶

    Ответ пользователя на конкретный вопрос анкеты.

    Атрибуты¶

    Поле Тип Описание
    id UUID Уникальный идентификатор ответа
    response_id UUID ID ответа на анкету
    question_id UUID ID вопроса
    value text Значение ответа (число, текст, JSON для множественного выбора)

    Связи¶

    • SurveyAnswer → SurveyResponse: ответ принадлежит одному ответу на анкету (response_id)
    • SurveyAnswer → SurveyQuestion: ответ относится к одному вопросу (question_id)

    Где используется¶

    • Обратная связь — сохранение ответов на конкретные вопросы
    • Аналитика — анализ ответов по вопросам
