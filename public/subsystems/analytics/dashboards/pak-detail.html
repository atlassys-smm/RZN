    Детальная аналитика по каждому ПАК¶

    Детальные страницы для каждого ПАК с аналитикой по контенту и результатам.

    Общие показатели (для всех ПАК)¶

    Эти показатели отображаются в верхней части страницы каждого ПАК:

    • Количество сессий/взаимодействий — карточка с числом + столбчатая диаграмма по дням
    • Среднее время сессии/взаимодействия — карточка с числом в минутах + сравнение с предыдущим периодом
    • Доля завершённых сессий/взаимодействий — круговая диаграмма или прогресс-бар
    • Количество уникальных пользователей — карточка с числом

    ПрофСтарт¶

    По возрастным версиям¶

    • Количество прохождений по каждой возрастной версии (12-14, 15-17) — столбчатая диаграмма
    • Сравнение результатов по возрастным группам — таблица

    По направлениям¶

    • Распределение пользователей по профессиональным направлениям (результаты теста) — горизонтальная столбчатая диаграмма
    • Самые популярные направления — топ-3 с процентами
    • Динамика интереса к направлениям — линейный график по времени

    По вопросам¶

    • Самые популярные вопросы — горизонтальная столбчатая диаграмма
    • Вопросы с высоким процентом ошибок или низкой завершённостью — таблица с сортировкой
    • Среднее время ответа по вопросам — таблица

    По профессиям¶

    • Рекомендуемые профессии (по результатам теста) — горизонтальная столбчатая диаграмма (топ-10)
    • Какие профессии выбирали пользователи после просмотра рекомендаций — список

    Аватар профессий¶

    По профессиям¶

    • Рейтинг профессий (в каких образах чаще генерируют) — таблица с сортировкой (название, количество)

    По типу пользователей¶

    • Авторизованные vs гости — круговая диаграмма или два числа

    Древо профессий¶

    По профессиям¶

    • Какие профессии выбирали пользователи — таблица с сортировкой (название, количество)
    • Какие профессии рекомендовала система — таблица с сортировкой (название, количество)

    По ответам¶

    • Среднее количество ответов на сессию — карточка с числом
    • Распределение ответов по категориям — столбчатая диаграмма

    Интерактивная карта региона¶

    По объектам¶

    • Рейтинг работодателей (по просмотрам) — таблица с сортировкой (название, количество просмотров)
    • Рейтинг учебных заведений (по интересам) — таблица с сортировкой (название, количество интересов)
    • Рейтинг профессий (по выборам на карте) — таблица с сортировкой (название, количество выборов)
    • Популярные регионы/районы — список или тепловая карта

    По типам объектов¶

    • Распределение интереса: работодатели vs учебные заведения vs профессии — круговая диаграмма

    Профбаттл¶

    По результатам¶

    • Средний счёт участников — карточка с числом
    • Распределение результатов — гистограмма
    • Самые сложные задания — таблица с сортировкой по % ошибок

    Обратная связь¶

    По вопросам¶

    • Распределение оценок по каждому вопросу — столбчатая диаграмма по вариантам
    • Вопросы с низкими оценками — таблица с сортировкой
    • Текстовые комментарии — облако тегов или список

    По точкам сбора¶

    • Количество анкет по каждой точке сбора — столбчатая диаграмма
    • Сравнение рейтингов по точкам сбора — таблица с числами
