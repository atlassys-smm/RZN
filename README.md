# ПрофНавигатор 62 — Репозиторий документации и API

Единая цифровая профориентационная платформа для Центра занятости населения Рязанской области.

Этот репозиторий содержит три части:

| Раздел | Описание | Директория |
|--------|----------|------------|
| [Документация](#документация) | MkDocs-сайт с описанием архитектуры, подсистем, интерфейсов | `docs/` |
| [API](#api) | OpenAPI 3.1 спецификация REST API платформы | `docs/api/` |
| [Prism](#prism-mock-сервер) | Mock-сервер для параллельной разработки фронтенда | — |

---

## Документация

Документация собрана на MkDocs и описывает архитектуру платформы, подсистемы, интерфейсы, сущности и контракты.

### Структура

```
docs/
├── index.md              — Обзор платформы
├── subsystems.md         — Архитектура подсистем
├── api/                  — API спецификация
├── concept/              — Концептуальные решения
├── contracts/            — Контракты и договоры
├── entities/             — Сущности предметной области
├── external-paks/        — Внешние ПАК (Древо профессий, Карта, Профбаттл)
├── interfaces/           — Клиентские интерфейсы
│   ├── admin-portal/     — Административный портал (CMS + Аналитика)
│   ├── led-screen/       — Основное приложение LED-экрана
│   ├── mobile-client/    — Мобильный клиент участника
│   ├── operator-tablet/  — Панель оператора
│   └── profstart/        — Киоск ПрофСтарт
└── changelog/            — История изменений
```

### Сборка

```bash
# Установка зависимостей
pip install mkdocs mkdocs-material

# Сборка в public/
bash build.sh

# Локальный сервер для разработки
mkdocs serve
```

## API

REST API платформы описан в формате OpenAPI 3.1.

### Файлы

| Файл | Описание |
|------|----------|
| `docs/api/openapi.yaml` | Основная спека (с `$ref` на отдельные файлы) |
| `docs/api/bundled/openapi.yaml` | Собранная спека (один файл, все `$ref` разрешены) |
| `docs/api/paths/*.yaml` | Отдельные группы эндпоинтов |
| `docs/api/scalar.html` | Интерактивная документация Scalar |

### Группы эндпоинтов

| Группа | Описание |
|--------|----------|
| `auth` | Авторизация (login, logout, refresh) |
| `users` | Пользователи и профили |
| `professions` | Справочник профессий, отраслей, направлений |
| `competences` | Справочник компетенций |
| `organizations` | Учебные заведения и работодатели |
| `quiz` | Викторина (сессии, вопросы, результаты) |
| `interactive-video` | Профессии в действии (видеосценарии, голосования) |
| `profstart` | ПрофСтарт (тестирование) |
| `cms` | CMS (справочники, анкеты) |
| `feedback` | Обратная связь |
| `analytics` | Аналитика и события |
| `files` | Загрузка файлов |

### Пересборка bundled-спеки

Если менялись файлы в `docs/api/paths/`, нужно пересобрать bundled-версию:

```bash
python3 scripts/bundle_openapi.py
```

## Prism Mock-сервер

Mock-сервер для разработки фронтенда до готовности бэкенда. Генерирует реалистичные ответы на все эндпоинты API на основе OpenAPI-спеки.

### Установка

```bash
npm install
```

### Запуск

```bash
npm run mock
```

Сервер запускается на `http://127.0.0.1:4010`.

### Использование

Базовый URL для фронтенда:

```
http://127.0.0.1:4010/api/v1
```

Примеры запросов:

```bash
# Список профессий
curl http://127.0.0.1:4010/api/v1/professions

# Вопросы викторины
curl http://127.0.0.1:4010/api/v1/cms/quiz/questions

# Запустить показ «Профессии в действии»
curl -X POST http://127.0.0.1:4010/api/v1/interactive-video/sessions \
  -H "Content-Type: application/json" \
  -d '{"device_id": "led-001"}'
```

### Ограничения

Prism — **stateless** mock:

- Данные генерируются случайно при каждом запросе
- POST-запросы не влияют на последующие GET
- WebSocket не поддерживается

Для вёрстки CMS, справочников, анкет, ПрофСтарт — достаточно.

Для интерактивных сценариев с логикой состояний (викторина, «Профессии в действии») позже будет добавлен stateful mock.

### Смена порта

Порт указан в `package.json` в скрипте `mock`. Чтобы запустить на другом порту:

```bash
npx prism mock docs/api/bundled/openapi.yaml --host 127.0.0.1 --port 3000 --dynamic
```

## Быстрый старт фронтенд-разработчика

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd rzn_cms

# 2. Установить зависимости
npm install

# 3. Запустить mock-сервер
npm run mock

# 4. Настроить фронтенд-проект на baseUrl: http://127.0.0.1:4010/api/v1

# 5. (Опционально) Собрать документацию для просмотра
pip install mkdocs mkdocs-material
mkdocs serve
# Документация на http://127.0.0.1:8000
```

### Генерация TypeScript-типов из OpenAPI

```bash
npx openapi-typescript docs/api/bundled/openapi.yaml -o ./src/api/schema.ts
```

### Генерация API-клиента

```bash
npx orval --input docs/api/bundled/openapi.yaml --output ./src/api/client.ts
```
